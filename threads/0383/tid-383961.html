Hello, because I had to set some attached objects, but i couldn't find a good editor for this, I fastly made one , and because I think I won't use it ever again, I will release it.
It's very simple, it doesn't has alot of features, but it's enough to set some attachedobjects to your player.

I will post some screens in a view minutes.

I don't need any credits or things, you can download it and do whatever you wan't with it.

Things you should know
- /object to create a attachedobject.
- /saveobjects to save all attachedobjects into the attachedobjects.txt in your scriptfiles.
- Only one player can use this at the same time, else it will be messed up.
- Login into rcon to use it.

If there are any simple bugs let me know, I will fix it. Maybe if alot people like it, I will create an advanced editor.
