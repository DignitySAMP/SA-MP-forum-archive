Does it happen in Single Player, or just SAMP? Does it happen on other servers? Have you run SAMP as Admin?

Have you reinstalled using the recommended process...

Uninstall GTA, and SAMP, Delete the game folder, Delete the game settings (GTA User Folder in My Documents) re-install GTA and SAMP.

The reason for deleting the game folder is to remove all the "Compatibility Settings" that have been used in the past.

In a fully working scenario, you won't need to use Compatibility Settings at all. If you are relying on them, then you have a problem in your PC, that is related to the issue.

https://forum.sa-mp.com/showthread.php?tid=339691 (Doesn't list yours but it's a good resource to show around)
