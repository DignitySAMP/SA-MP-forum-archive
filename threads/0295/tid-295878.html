Introduction
This is a original GM made from 0 by me so it's totally unique

PROJECT DISCONTINUED

Type of Gamemode
This is a Zombies VS Humans TDM Gamemode , it has the following groups:
Code:
-Humans
-Zombies
-Army Soldiers
The objective for ARMY SOLDIERS is the following:
Code:
As an army solider you must help and protect any survivors from getting infected or hurt in any way , if you fail doing this an admin will remove your Army soldier status
It is very fun as I tested it with a lot of players , but I don't have money for hosting and my IP is dynamic so I can't host it.


Commands
Code:
/radio - You can only execute this command as an army soldier
This will send a public radio message to all alive survivors
/usemedkit - With this command you can use a medkit to heal yourself
/givemedkit - You can only execute this command as an army soldier
With this command you can give medkits to survivors
/inventory - With this command you can view how many medkits you have
/armyradio - You can only execute this command as an army soldier
With this command you can talk with other army soldier on radio (Private radio so only army soldiers can see what you typed)
/getpistol - You can only execute this command as an army soldier
With this command you can take a pistol from the army depot to give it to a survivor
/getrifle - You can only execute this command as an army soldier
With this command you can take a M4 rifle from the army depot to give it to a survivor
/givepistol - You can only execute this command as an army soldier
With this command you give a pistol to a survivor. NOTE:YOU CAN ONLY GIVE AWAY AS MANY PISTOLS AS YOU TOOK FROM THE DEPOT
/giverifle - You can only execute this command as an army soldier
With this command you give a M4 rifle to a survivor. NOTE:YOU CAN ONLY GIVE AWAY AS MANY RIFLES AS YOU TOOK FROM THE DEPOT
/spawn - You will see what is it in the gamemode
/setamy - You can only execute this command as an admin
With this command you set a player to army soldier
/sethuman - You can only execute this command as an admin
With this command you set a player to human
/setzombie - You can only execute this command as an admin
With this command you set a player to zombie
_---THIS GAMEMODE HAS BUILT-IN ADMIN SYSTEM AND THAT SYSTEM IS THIS ONE : https://forum.sa-mp.com/showthread.ph...274906---_
WARNING:
There are some commands like /dmak47 /arme and others but it is because I tested it with Romanians and those commands were made to have some fun after testing , you can remove them.
