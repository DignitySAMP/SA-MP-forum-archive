IsPlayerInAnyVehicle has playerid as parameters. Not vehicle id.
Use this function:
pawn Code:
stock IsVehicleOccupied(vehid)
{
    for( new all = 0; all < MAX_PLAYERS; all++)
    {
        if (IsPlayerInVehicle(all, vehid))
        {
            return 1;
        }
    }
    return 0;
}
