Es mejor aprender el lenguage de programacion con la que quieres trabajar.

Por ejemplo, no te servira sabe hacer esto en PHP para luego implementarlo en PAWN:
PHP Code:
<?php
    $query = $connection -> prepare("SELECT `id`, `name` FROM `table` WHERE time = NOW()");
    $query -> bindParam(":id", $id);
    $query -> bindParam(":name", $name);
    if($query -> execute())
    {    
        if($result = $query -> fetch())
        {
            echo "no error";
        }
        else echo "error";
    }
?>
Y si vas a hacer un proyecto en php que oviamente utiliza una base de datos, te recomiendo que utilizas el metodo PDO de MySQL.

Realmente nose porque quieres aprender un lenguage de programacion mas deficil por decirlo asi para luego aprender un lenguage de programacion mas sencillo.
