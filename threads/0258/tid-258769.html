WELCOME!
With this script you can do boxing/wrestling. To box/wrestle with your friend, you just type this command "/wwe". Now tell your friend to type "/wwe2" so he can join the other side of the ring. Now fight all you want!
No screenshot.
By the way i'm new to scripting and this is my first thread ever in SA-MP forum, so dont be so negative

NEWBIE FRIENDLY:

Put this code in your filterscript:
Quote:

public OnPlayerCommandText(playerid, cmdtext[])
{
if (strcmp("/wwe", cmdtext, true, 10) == 0)
{
SetPlayerPos(playerid,20.909503936768,-140.90580749512,0.27134799957275);
SetPlayerSkin(playerid,81);
return 1;
}

if (strcmp("/wwe2", cmdtext, true, 10) == 0)
{
SetPlayerPos(playerid,27.470899581909,-188.86544799805,0.61486005783081);
SetPlayerSkin(playerid,80);
return 1;
}
return 0;
