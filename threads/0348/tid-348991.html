Intro
SA-MP App is a free Android 2.1+ application to query San Andreas Multiplayer Servers and send RCON commands to them.

Version: v 2.0.5
Website: http://rafael.keramid.as/sampapp/

Features
  • Get server infos, rules and players.
  • Send RCON commands.
  • Manage multiple servers.

FAQ
Q: Is this app free ?
A: Yes, it's totally free and it will always be.

Q: Does it work on iOS/Blackberry/Windows Phone ?
A: No. Read the thread title.

Q: Does it work on tablets ?
A: Yes, on Android tablets only.

Q: Will you release a iOS version of the app ?
A: Once I will have enough money from the donations to buy an Apple computer.

Q: Can you include the server chat ?
A: NO NO NO AND NO !! This app is only using the query mechanism and it's not possible to get the chat with it. Stop asking for it.
