You can do this easily, with random. For example, think random is a dice with x sides.

pawn Code:
new result = random(6);

// Think this is a rolling dice. Random single param is max size , wich means you will 6 'sides' and get numbers
// between 0 and 5 (0,1,2,3,4,5)

// Now that you have a 'result' you can set the player pos, according to this result

// For example, if the player throws the dice, and gets 4.

switch(result)
{
    case 4:
    {
        // Here will be the handle for the side number 4 of the 'dice'.
    }
    case 5:
   {
        // Here will be the handle for the side number 5 of the 'dice'.
   }
   // And you can add more sides if you want...
}
Read this: https://wiki.sa-mp.com/wiki/Control_Structures
And this: https://wiki.sa-mp.com/wiki/Random

Try to do, and let me know if you have some questions. (TRY TO DO!)

You need to use random...

An example is shown below using your coordinates:

new Float:RandomSpawn[][5] =
{
{-2228.3186,2326.7283,7.5469},
{-2234.4175,2402.6956,2.4907},
{-2267.2178,2313.0020,4.8202},
{-2189.5212,2407.6396,4.9730}
};

In your command....
new rand = random(sizeof(RandomSpawn));

SetPlayerPos(playerid, RandomSpawn[rand][0], RandomSpawn[rand][1],RandomSpawn[rand][2]);
return 1;
}
