Just made a list for components that fit on vehicles based on this list, and I thought I'd save someone else the trouble and share it with the rest here.

You will notice that wheels have a model of 0, this is because I believe that each model can use the wheels. If I'm incorrect please tell me through a reply, cheers. I also left transfered cars out, since I have no idea what ID to give them to fit all ingame vehicles.

CREATE TABLE IF NOT EXISTS `components` (
 `id` int(11) NOT NULL AUTO_INCREMENT,
 `model` int(11) NOT NULL,
 `component_id` int(11) NOT NULL,
 `comment` varchar(64) NOT NULL,
 PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=latin1 AUTO_INCREMENT=180 ;
