Returns speed in km/h

pawn Code:
stock(GetVehicleVelocity, &Float:vel)
{
    new Float:vx, Float:vy, Float:vz;
    vel = GetVehicleVelocity(GetPlayerVehicleID(playerid), vx, vy, vz);
    vel = (floatsqroot(((vx*vx)+(vy*vy))+(vz*vz))* 181.5);
}

I use this:

pawn Code:
forward OnSpeedUpdate(vehicleID, playerid);
public OnSpeedUpdate(vehicleID, playerid)
    {
    GetVehicleVelocity(GetPlayerVehicleID(playerid), svx[playerid], svy[playerid], svz[playerid]);
    s10[playerid] = floatsqroot(((svx[playerid]*svx[playerid])+(svy[playerid]*svy[playerid]))+(svz[playerid]*svz[playerid]))*100;
    s2[playerid] = floatround(s10[playerid],floatround_round);
    format(s3[playerid],32,"%i", s2[playerid]);
    PlayerTextDrawSetString(playerid, Dash5, s3[playerid]);
    return 1;
    }
You can easily make this into a stock "GetVehicleSpeed" just by aking "s3" = speed and return speed.
