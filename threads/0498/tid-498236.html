Gonna be quite blunt with your map.

The concept is nice but the actuall mapping isnt.

Reasons:

-The Electric fence kills the beauty of the island. If its a bridge why does it need so high fences?
-It seems to be floating quite alot, use some rocks/beaches/cliff objects.
-The fence inside the "castle" makes it look like a concentration camp. Use some of the "wall" objects or Bridge supports and retexture them with "SetObjectMaterial".
-Also the Verdant Meadows Runway is not level. So it will stick up a bit makingg the map uneven and damage any vehicle especially planes when going across the edge. Use a beach object if you want sand or possibly one of the "wall" objects mentioned above.
-Add some variety to your map. Making it all sand is not a good idea, add a driveway with grass (wall object again) to add some greenery (trees,shrubs,flowers,ect)

Unless the issues mentioned above aint fixed I wouldn't use this map. Sorry if this sounds cruel but if people dont say their honest opinions about your map, you couldn't get better.
