PawnPlus - 0.5.2 Beta
Information

PawnPlus is a Pawn IDE, with more features than PAWNO.

Features

Some features for PawnPlus is:
  • Update Checker
  • Good interface
  • Multiple documents.
  • Docking Tabs

Update 0.4.7:

Impelmented:
  • The program will save all files opened in a session when the project is closed and load them when it then project is re-opened.
  • SA-MP functions from A to D. (Use CTRL + SPACE to see a list with all available functions)
Fixed bugs:
  • Unreleased memory caused by dockpanelsuite (thanks roken).
  • Fixed issue when the program doesn't exit caused by XML reader.
Unfixed bugs:
  • Bug with characters saved before with PAWNO reported by Malganys. I can't find encode used by PAWNO, I tried a lot of encodings but nothing.
Download:
Github - https://github.com/WopsS/PawnPlus/re...ag/v0.4.7-beta

If you find a bug please report it here.
If you have an idea for the program please tell it here.
