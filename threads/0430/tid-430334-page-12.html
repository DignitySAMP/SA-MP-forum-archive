How to create a dynamic house ingame:

1) Find the house you want to use.
2) Stand in front of the door
3) First write : /createhouse Exterior
4) Second write : /houseint
5) Choose Burglary houses for default house interiors
6) Choose a interior from 1-16, double click the it.
7) When youve successfully entered the interior write: /createhouse Interior and right after /createhouse Complete
8 ) You have now successfully created your desired house.
9) /sethouselevel houseid Level --> This is to set the level of the house. For example: /sethouselevel 8 15 (You must be level 15 in order to buy this house.)
10) /sethouseprice houseid Price --> This is to set the price of the house. For example: /sethouseprice 8 100000 (You need $100,000 in order to buy this house.)

How to create a dynamic biz ingame:

Follow the same step above but instead of /houseint use /bizint
Instead of /createhouse use /createbiz

How to fix CJ run style ingame:

Search for UsePlayerPedAnims(); and remove that line. Compile and restart your server.

Easier than this is not possible !
