24.09.2009, 00:05
One string is 128, one string is 256, you try to place 256 cells into 128 cells worth of space and it will give you that error as they don't match 128 < 256.

Wrong:

pawn Code:
new
  string1[ 256 ],
  string2[ 128 ];

string2 = string1; //this would be strtok
Right:

pawn Code:
new
  string1[ 128 ],
  string2[ 128 ];

string2 = string1; //this would be strtok
