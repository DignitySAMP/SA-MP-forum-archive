This script allows you listen GTA III Radio like in GTA IV.
That means:
  • If you are near vehicle, you hear radio with effects. If you are in vehicle, you hear radio without effects.
  • 3D handle positions update for every vehicle in radius of 20 with player updates (OnPlayerUpdate).
  • Only driver can change radio.
  • Time of every radiostation is stored and restored when you switch on it.
  • Audiofiles are compressed for good quality.
  • Keys: R and Del.
Some things:
  • If you are in vehicle and drive near another vehicle with same radio, handle of it will fall behind (****** Translator, sorry, can't find right word ) because time can be got in integer, not float.
  • There can be some lags on clients' computers if near more than 100 vehicles because handle updates processed on client side.
  • Sometimes standart radio can't be turned off. All questions to Audio Plugin.
Requirements: Audio Plugin, Incognito's Streamer, YSI Library.
Notes: If you want to start this FS, change values of MAX_PLAYERS and MAX_VEHICLES needed for your server. Maybe, I'll add video.
Download: mediafire.com
Author: SDraw
Also, thanks for testing to user FrostJkeee.
