Quote:
Originally Posted by Manyula

So, we could create skin-like objects, animate them and use them sort of like NPCs?
You can only do static and simple animations, like the chicken with the moving head (seperate object that rotates back and forth). You cannot "bend" objects like legs or arms would do on a skin model. You can also not attach an animated object in a way that it sticks to the animated part of another animated object, so doing seperate arms/legs wouldn't be possible either (since the forearm wouldn't stick to the rest of the arm).

Something like the chicken, rotating UFO etc yes, but a Skin would look really weird, if even possible.
