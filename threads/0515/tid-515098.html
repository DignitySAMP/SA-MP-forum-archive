This one is addressed for the 2 guys arguing above. I get that new mappers should be encouraged to do more, but comments like "nice job, keep it up" ain't gonna help much. Comments like "The map is bad and I don't like it", ain't gonna do much help, either. You guys need to learn how to post useful comments. It's something that will help you and other people grow in the eyes of others. This is a community, after all.

As for the map, here is my opinion:
1. For a TDM map, it's nice work, but I think you should close the space somehow, because if you hold a TDM there, players might run off.
2. If you release a map, you can try to make it have multiple purposes. The Verdant Meadows Airstrip will need a re-work on almost every server. A map that can be used on different kinds servers is always appreciated. You don't need to do that right now, but you can take it into account next time.
3. This advice is meant for aesthetics. The map itself looks kind of unrealistic. It's a desert, trees like those aren't quite supposed to be there. Besides that, there are like 6 trees into one object, you should try to rotate them a bit, so they don't look like they are artificially placed there.

Your mapping skills will improve rapidly if you continue to do maps. If you need something more challenging at some point, you can try to look into sa-mp's retexturing functions. They helped me a lot with my island.
