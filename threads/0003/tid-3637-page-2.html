So I've added a variable to your script, because in its current form its easy to use your FS to crash servers (I think)

There is no check to make sure people don't place any more than 1 /cb at a time. As such, someone can set as many bombs as they want which has caused my server to tank.

As such, I've added a very simple check. When /cb is used, my new variable (cbplaced) is set to 1. Once its detonated or canceled, its set to 0. This way, when people use the /cb command it checks to make sure the cbplace variable isnt set to 1. If it is, it doesn't allow you to place a bomb, and tells you to detonate your original one. If its set to 0, then you can place a bomb.

GENERAL INFORMATION
Title: LuxurY Bomb Explosion (Bomb shop + Lots of bomb commands)
Version: 0.1.3
For: SA-MP 0.2
Date: 9 July 2007
Creator: LuxurY

Fixed:
- Teleport 1 time in 2 minutes fixed!
_________________________________________________

FILTERSCRIPT COMMANDS
Commands for players:

/killb - kill youself with bomb
/bt - to create timer on vehicle
/bd - to create detomator on vehicle
/cb - to create bomb on place
/dv - to activate detomator on vehicle
/db - to explose bomb
To deactivate: /ccb - bomb /cct - timer /ccd - detonator
/bs - teleport to the Bomb Shop

Commands for admins:

/setbt [playerid] [time] [0(no) or 1(yes)] - to create timer on player's vehicle
/setbd [playerid] [0(no) or 1(yes)] - to create detonator on player's vehicle
/explose [playerid] - explose player
/abomb - allow/disallow automatically creating bombs on vehicles
/setbombv [playerid] - to create bomb on player's vehicle
