v1.2
Preview

The old verstion can be found here, The new version, Contains 4 new Functions, And Supports the Dini, As it uses Files and Admins Accounts, Without any Registeration System. You can now Add Admins Through the Menu, And Only RCON Admins can Access to it. If you noticed, in v1.1 the functions are coloured with Red and Green, Now more functions added with Cyan Colour, This is what it means:
Red - 'Negative' Functions, That will effect with a Bad Result (kick, kill etc)
Green - 'Positive' Functions, That will effect with Good Result (Create a Car, Say / Announce (NEW)

Functions
Im going to show you the Functions that ADDED!
Code:
Make Admin - Make a Admin, Using Input Dialog (RCONS ONLY)
Remove Admin - Remove a Admin, Using Input Dialog (RCONS ONLY)
Admin List - Will show the Online Admins, Using Msgbox Dialog
Say / Announce - Send a Message to All the Players as Admin
