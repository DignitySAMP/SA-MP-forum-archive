11.05.2014, 05:47
Did you tried installing the Native Checker plugin?
Make sure you got Native Checker at the last line of your plugins, e.g:
Quote:

plugins streamer.so sscanf.so irc.so nativechecker.so
Once, you've done that [Added nativechecker.so into your plugins folder, and into server.cfg's plugins last line], when you will start the script and get the error "File or Function Not Found", there would be the error above it stating what is causing that File Or "Function Not Found" Error.
Like this:
Code:
<ERROR WOULD BE HERE>
[06:11:20] Script[gamemodes/SFCRRPG.amx]: Run time error 19: "File or function is not found"
After that, post the error here.
