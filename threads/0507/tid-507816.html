Before i begin, i want to say that this is NOT a script that is 'fully' done by me, it's based on [HiC]TheKiller's Group Script.
Credits are kept there, don't remove them.

FEATURES
- Squad editing -

1) Edit the Squad-Name
2) Edit the Squad-Member Limit - ( 3 - 5 members )
3) Edit the Squad-Join 'system' - ( Private or Public )
4) Disband the Squad


- Missions/Team-Work -
1) /squadannounce -FOR SQUAD LEADER- Announce a message to your Squad-Members!
2) /squadreward -FOR SQUAD MEMBERS AND LEADER- Select a Reward(Health/Money/Ammo/Score) when somebody from your squad kills an enemy
3) /squadspawn -FOR SQUAD MEMBERS(RANDOM) AND LEADER- Spawn on your Squad Members, or your Leader!


- Viewing your and other squads -
1) /squads - Show all of the current squads in a dialog
2) /squadinfo - Show more detailed information about a specific squad


FULL COMMAND LIST
1 ) /squadhelp - Shows all the commands about Squads
2 ) /squadedit - Edit your squad
3 ) /squadcreate (NAME) - Create a squad with the selected name
4 ) /squadleave - Leave the squad you're in
5 ) /squaddisband - Disband your own Squad
6 ) /squadkick (ID) - Kick a target from your squad
7 ) /squadjoin (squadID) - Join a squad
8 ) /squadinvite (ID) - Invite someone to a squad
9 ) /squadspawn (leader/member/default) - Spawn on your Squad Leader, Members(random) or the default spawn
10 ) /squadreward (armour/health/score/ammo) - Choose a reward you will get when someone from your squad kills an enemy
11 ) /squadleader (ID) - Set a new Squad-Leader
12 ) /squadinfo (squadID) - Show a detailed information about a specific Squad
13 ) /squads - Shows all active squads(Squad name, Squad ID, Squad Members)
