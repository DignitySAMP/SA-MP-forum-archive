_____________________________________________________

CHANGES
_____________________________________________________
  • Features added from version 7 to 9
    • Squad-Member and Squad-Name textdraws
    • Added 'OnFilterScriptExit', due to textdraws and some other 'data' getting bugged
    • Added /updatesquad ( Use it when your squad-member / squad-name gets bugged )
    • Added a '2nd' way of squads being Auto-Disbanded ( when in negative )
    • If the folder 'squadlogs' does not exist at 'scriptfiles', this message gets printed into the console/serverlog.txt "[HH:MM:SS] WARNING: folder 'squadlogs' at 'scriptfiles' does NOT exist"
  • Features fixed/improved/removed from version 7 to 9
    • Fixed -some- 'OnRconCommand' stuff
    • Fixed many bugs with the Supply-Drop ( leader not being able to use, message spam etc.. )
    • Fixed -hopefully- a bug with Random Team-Member Spawns
    • Fixed /squads ( strcat conflicting with the text )
    • Fixed a small bug with /squadinvite

OTHER FEATURES
_____________________________________________________
  1. squad-logging ( scriptfiles/squadlogs/squadlogs.txt )
  2. Supply-Drops, Squad-Spawns and Squad-Kill rewards
  3. Squad-Member and Squad-Name textdraws
  4. Squad-Chat
  5. Squad editing ( Name, Member Count ( 3 to 5 ), Join Mode ( Public( No invite ) or Private ( Needs invite ) )
