Quote:
Originally Posted by Wicko

The answer is simple, Kye should earn more money from SA-MP. I believe it would keep him pretty well motivated. The website could offer paid services for server owners. It could also contain advertisments. The server browser is a possible huge money source too.
I don't care, it may contain more advertisments than content if it kept SA-MP going.
That's not an issue. This mod was developed for 5 years without seeing a single cent. The SA-MP services (server list/official tab etc.) operated for free for 4 years. No money will ever be accepted for the SA-MP client software - since it would require an agreement with Rockstar Games. Donations won't be accepted. The services (server list/web site/forum) will only take in money if it makes sense to do so. And right now, people paying to be on the hosted list is a better system than giving servers official rank for free.

There have always been costs associated with maintaining SA-MP services and those costs never take in to account the time spent maintaining and protecting these services from attack.

Originally the SA-MP server lists were going to be provided by GameSpy - but it literally took months to get in contact with a manager there and, by that time, we'd already developed our own server list system.

Quote:
Originally Posted by TheInnocentOne

144 * 10 = 1440 Euros.
Quite a lot of money from the hosted tab list alone.
Not all servers on the hosted list pay. We consider that some server owners are contributing to SA-MP by beta testing. It's also not possible to do transactions on the internet without some costs associated with it. SA-MP has an agreement with serverFFS to provide listings for the hosted list. Details of that agreement have never been given out and won't be unless someone provides a good reason to.

I don't know this for a fact, I don't consider it any of my business, but I'm pretty sure there are single SA-MP servers that take in more money (mostly through donations) than the SA-MP services do. They also started doing it long before the SA-MP hosted list existed.
