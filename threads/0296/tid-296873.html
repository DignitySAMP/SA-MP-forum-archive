use this:
pawn Code:
new ReactionTest[2];
on your reaction test start
pawn Code:
ReactionTest[0] = GetTickCount();
and on your msg:
pawn Code:
ReactionTest[1] = GetTickCount();
new timeresult = ReactionTest[1] - ReactionTest[0];
(Something_Here needs to be replaces with "timeresult" ofc^^)

edit: alternatively you can just start a timer on the reaction test start and increase a global variable by 1 each round in the timer (1 second timer) then just kill the timer on the reply and show the variable in the text.
