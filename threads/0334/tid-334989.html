Code:
error 075: input line too long (after substitutions)
That means you are putting to much stuff on one line. You need to separate it into several lines.

strcat takes 3 args (one optional) not as many as you are using.
https://wiki.sa-mp.com/wiki/Strcat

Which is causing this error:
Code:
warning 202: number of arguments does not match definition.
