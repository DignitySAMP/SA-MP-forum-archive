Some routers have their own firewall like in Windows. You can disable this in the router's configuration page. To get on that page, do this:

- Open CMD
- Type 'ipconfig'
- Write down the protocol near 'Standard Gateway'
- Type this code in your browser's navigation bar & press enter.
- You may need to login, try 'admin' & 'admin'. If that doesn't work, search at ****** for 'standard router passwords'
- When you are logged in you must search everywhere for 'firewall'.
- Disable it.
