I would guess your graphics card's memory bandwidth is too low.

GDDR2 at 800mhz on a 128bit bus is pretty poor for todays standards, it only makes up for about 12.8GB/sec.
I'll give you something to compare it against; I used to have an NVidia 7800GS AGP, that thing is like 4 years old if not more but it had somewhere around 34GB/sec of memory bandwidth.
To give some more examples, 1 year old high performance graphics cards like ATI's HD4870 or NVidia's GT280 have well over 100GB/sec of memory bandwidth.

Many people think the amount of memory on a graphics card makes up for how much performance it has, this is however complete bullshit.
