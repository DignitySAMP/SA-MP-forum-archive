You configure your station connections under OnDialogRespons like this
Code:
  if(dialogid == DIALOG_WEAPONS)
    {
        if(response) // If they clicked 'Select' or double-clicked a weapon
        {
            // Give them the weapon
            switch(listitem)
            {
                case 0: GivePlayerWeapon(playerid, WEAPON_DEAGLE, 14); // Give them a desert eagle
                case 1: GivePlayerWeapon(playerid, WEAPON_AK47, 120); // Give them an AK-47
                case 2: GivePlayerWeapon(playerid, WEAPON_SHOTGSPA, 28); // Give them a Combat Shotgun
            }
        }
        return 1; // We handled a dialog, so return 1. Just like OnPlayerCommandText.
    }
Under case 0 u put the start audio stream command and under case 1 u put the second start audio stream for your second station and so on or u put another dialog for genders and so case 0 wont be your stream audio it will be show player dialog and u modifie that dialog wit the same code I gave u up here but dont forget to change the dialogid == SETSTATION.
