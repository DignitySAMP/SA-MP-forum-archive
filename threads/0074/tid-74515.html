----------------------------------GangDM v.3.07[FINAL]------------------------------------------------

Commands

/tut -> shows useful commands, which you need to know
/help
/telehelp = many teleports... ( also to liberty = /liberty )
/dmhelp = deathmatches
/dhelp = Commands for Drugdealers
/boxhelp = Commands for the BoxRing
/carhelp = Car Tunings like /nitro /hyd and so on
/ganghelp
/thugcmds = command which are only available if you are a "AdminThug"

/athug 28091991 = To become an adminthug ... you can change that password to whatever you want


Some other Commands
/cs = Cars Spawner
/alarm = To alarm other specific players to help you =)
/pInfo = To get another Player Infos
/explode = Creates a big explosion
/aexplode = Creates a big explosion to another player ^^
/jetpack
/ip = shows you the ip of the choosen player
/gw = Get Weapons by self created Menu with lots of ammu an a big choice of weapons
/gw2 = Switch between One handed Pistol's, Shotgun's and Uzi's and Second handed Pistol's, Shotgun's and Uzi's
/get[playerid] //new added in V.3.03
/goto[playerid]

-->and more commands


Integrated
Account System
Speedo with Vehicle Health!
DrugDealer System
Boxing System
Gang System
Gun Game
Car Spawner
Virtual Ammunation(Get weapons by /gw)

TEAMS
Grove Street -> CJ, Ryder,Sweet,Big Smoke
Ballas -> 3 Ballas
LS Vagos -> 3 Vagos
Varios Los Aztecas -> Cesar Vialpando and 3 more Aztecas
Cops -> Tenpenny, Pulaski, LS Cop
Anarchist
-> Each Player starts with 50000 Money

Gangzones
Gangzones are created for all Teams,exept the cops.


TeamKills added. After 10 Team Kills you got kicked!
Colors are disabled when you are in an deathmatch

->Commands to change the Weather

->3 WeaponSettings
->One Individual WeaponSetting which saves your currently WeaponSetting to a File
