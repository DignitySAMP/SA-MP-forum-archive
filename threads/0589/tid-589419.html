Formatting is where you've put up...

PHP Code:
functionname
{
code
{
morecode
}
} 
where it should be
PHP Code:
functionname
{
    code
    {
        morecode
    }
} 
Structure comes in the form of

PHP Code:
functionname
{
    if structure
    {
        if time is XXX
        {
            if listitem is CC
            {
                code
            }
        }
        code that should be in another if statement here
        else return code that won't be encountered under most circumstances
    }
} 
PHP Code:
functionname
{
    if structure
    {
        if listitem is CC
        {
            code
        }
        if time > 275
        {
            SendMessage Skin changed
            SkinChange
            Putting a return here will end the checks.
        }
        if time < 275
        {
            SendMessage Skin will change next round
            return
        }
    }
}
