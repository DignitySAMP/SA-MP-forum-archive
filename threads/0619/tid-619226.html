As I told you, loading nativechecker plugin and then any other plugin will give these messages even if there is no problem. Since you got crashdetect, you don't need nativechecker by the way - they do the same thing (plus crashdetect does more).

So change in server.cfg:
pawn Code:
plugins crashdetect sscanf streamer
and by the way, update crashdetect plugin to avoid that bug with run time error 20: https://github.com/Zeex/samp-plugin-...etect/releases
