Your code is flawed. You should check if the player is connected before using the id in an array.
Because sscanf can return INVALID_PLAYER_ID (Explanation why is down below).
And INVALID_PLAYER_ID is equal to 65535, which is always higher than MAX_PLAYERS. (And using something bigger than the array size causes problems, which can be detected with crashdetect)

Also, use if (cible == INVALID_PLAYER_ID) instead of IsPlayerConnected because sscanf already does that.
How "u" works:
Code:
If it's an id (and not a name), it checks if the id is connected.
If it is, it returns the id. If it's not, it returns INVALID_PLAYER_ID.

If it's a name, it loops through the players and tries to find the player with that name.
If it does find the player, it returns their id, if it doesn't, it returns INVALID_PLAYER_ID.
