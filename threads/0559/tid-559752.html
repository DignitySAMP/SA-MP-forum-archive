From my point of view it would be better if SA-MP didn't need font size changing and it automatically selected a font size which was 'about right' for most for most different screen resolutions. That's what it has done for the previous versions.

What has changed is that I normally had access to the latest screens and could test most of the different resolutions players would use and make sure it looked okay. Now some players are upgrading to 2K/4K monitors at a time when I'm sticking with 1080p. And the font size selected for 1080p is too small for 2K/4K.

As for why the font size is selected in multiples of 2, that seems fairly standard in Windows programs where the points system is used. It's not completely arbitrary. It also allows me to test all the font sizes quickly at different resolutions and make sure things are scaling properly.

All the elements of SA-MP's UI could all have independent font sizes but I think most users just want something simple to scale everything up or down because the fonts are either too big or too small at their screen resolution.

Even if you were able to hack font sizes in previous versions there is no way everything would scale correctly. It actually required a lot of code changes to make that work and it's still not completely done yet for 0.3.7.
