During the making of HidMin, the crappy admin system I'm developing, I got rather bored, so I put the project on halt. A few days after that, I got the bestest idea ever: Cows which keep following you without having any purpose!

What is it?
Stalkercows is a script that creates a Cowly Cow which stalks a random player by continuously moving towards (Or around) that player. The stalked player (a.k.a. the 'loser') will hopefully feel annoyed and ragequit your server.
PS: Every minute a new random player is selected to be stalked. If there's only one player online.. well.. haters gonna hate.
