Fairly straight forward and something like this should do:
Code:
/^(.+)\((\d+)\) : (warning|error|fatal error) (\d+): (.+)$/ig
Code:
$1: path
$2: line number
$3: class (warning, error or fatal error)
$4: error/warning number
$5: message
