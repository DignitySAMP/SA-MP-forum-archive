Hello All, Today I am releasing my 5th or 6th Filterscript that is based on Rcon Security.

About Script

This script allows Server Owners to set the Secondary Password for Rcon Login.
Which means that when some one log in to rcon successfully. A dialog pops up asking for Secondary Password.
The default password is " changeme2 "
You can change the password in the script to whatever you like.
