Quote:
Originally Posted by Ayhamm

Nice map but how to make the gate is opened by pressing H ?
You need "public OnPlayerKeyStateChange" and then define it by the key you press
Keys you can get from here https://wiki.sa-mp.com/wiki/Keys

You should make it something like this under OnPlayerKeyStateChange

pawn Code:
else if(PRESSED(KEY_CROUCH))
    {
        if(IsPlayerInAnyVehicle(playerid) && IsPlayerInRangeOfPoint(playerid, 10, -2039.9000200,-102.8000000,35.8000000))
        {
            if(licg == 0)
            {
                MoveDynamicObject(licgate,-2032.9000200,-102.9000000,35.8000000, 1.0);
                SendClientMessage(playerid, COLOR_LIGHT_BLUE,"You opened the Licence Center gate.");
                SetTimer("LicGateClose", 6000, false);
                licg = 1;
            }
        }
    }
Also you will need

pawn Code:
public LicGateClose()
{
    MoveDynamicObject(licgate,-2039.9000200,-102.8000000,35.8000000, 1.0);
    licg = 0;
    return 1;
}
