[GM]WorldsFreeMode v2.0(=WFM)

DOWNLOAD 0.3b:
DOWNLOAD 0.3c:

<<< GAMEMODE WFM: >>>

*** Introduction:
This is a complete Free Mode Gamemode with 4 different worlds there you can play in.
These 4 worlds are like 4 different servers!
I've spent a lot of time to make all maps and all commands (but the most of the time
has been to make MAPS).

*** Installation:
You don't need an installation. You only have to extraxt folder WFM from the rar archive
and open the server.

*** Set Main Server Info:
If you want to set a new name for the server, ot new RCON password, you have to open file "server.cfg"
and change names.
P.S: You can't modify MAXPLAYERS! even you change it, server will have always 50 MAXPLAYERS. (you
can modify it in PWN file).

*** Opening Server:
To open the server there is a particular application called "SAMP-SERVER.exe".
Open that (that app will open server). it's an anti server crash:
if server crashes, it restarts automatically (only if you open server with SAMP-SERVER.exe).

================================================== ================================================== =======
<<< GAMEMODE INFORMATIONS: >>>

*** The 4 Worlds:
WFM has 4 different worlds. Each world has a different mode. Modes are:
- DRIFT;
- STUNT;
- DM;
- WAR.
It's like having 4 different server. the only thing you can't do with 4 different server is...
public chat with each world!!! EXAMPLE: f a player (A) is in world DRIFT and a player (B) is
in world DM, the can chat!!! but they can't see in map and in radar (because they are in different worlds).

*** WORLDS INFO:
All worlds are simple. I don't need to explane you how to play in them. excent ONE!!!
World WAR is particular:
It is a World for TOTAL WAR (also with MILITARY VEHICLES) and there are 3 gangzones.
2 are in colour RED (enter in them and you'll have a minigun);
1 is in colour YELLOW (enter on the top of the towers and you'll have SNIPER RIFLE).

*** Commands:
There are some commands you can use in all 4 worlds. For example Registration commands (from Zadmin2.0)
or command /cmd and /info (first 2 commands to use when you join in server he first time).
also the command /votekick (to kick a cheater with a voting, and command to change world!! (==> /changeworld).
Command /info will tell you all important things about the world which you're playing in.
There is also a command to take weapons! type /weapons and you will have to choose 4 weapons kits.

WORLD STUNT TELEPORTS:
- /stunt [1-3]
- /jump [1-2]

DRIFT WORLD TELEPORTS:
- /drift [1-6]
- /tuning [1-3]

DM WORLD TELEPORTS:
NO teleports in DM world.

WAR WORLD TELEPORTS:
- /area51
- /area69
- /lvairport
- /sniper

HOWEVER: when you are in server, type commands /cmd to see all aviable commands (in your world).

*** How to make you admin:
WFM uses an admin system called "Zadmin2.0", which has 93 commands. It's already setted correctly
in GM to work! Take attention when you modify the 3 configuration files!!!
To make you admin in server:
- you have to register an account typing: /register [password] and System will create you an account.
- you have to login as RCON admin ( /rcon login [password] )
- use command /makemegodadmin when you're loggedin as RCON admin and also in your account (login [password])
that command will set you admin level 10 (maximum admin level).

*** How to use admin commands:
You have to type a command to see all admin commands. it's /amincmd1. It will show you the list of
all admin commands you can use.
command /admincmd2 has a little list of commands which have action on ALL players online!!!
(example: /aexplode ==> it will explode all players online).
however you can see Zadmin2.0 readme.txt (in ZIP file called "Zadmin2.0.zip").

*** OTHER:
There are also 3 good things:
- Vehicle health TEXTDRAW! (it will show you Vehicle Health of rhe vehicle woere you're IN);
- Stats TEXTDRAW (it woll show you: health, kills, deaths, score);
- pressing KEY MOUSE LEFT you'll use NITRO on ALL vehicles.


P.S: For all informations about the Admin System (Zadmin2.0), read "Zadmin2.0 readme.txt" in
"Zadmin2.0.ZIP".
