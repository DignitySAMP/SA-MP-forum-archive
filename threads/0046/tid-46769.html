Hi, this is a silly program that I made yesterday. It is for managing .cfg files and a Dinamic IP launcher, so you don't have to input the IP everytime you want to play. You can save the configuration (.jb), load the configuration(.jb), or save a .cfg file. If you want to save a Dynamic IP adress go to Dinamic IP launcher and click in the plus button to add a server. Give it a name and a IP like example.no-ip.org. The names are stored in names.txt and the ip's are stored in ip.txt. The main configuration is stored in launcher.jb. You must place names.txt, ip.txt, launcher.jb and launcher.exe in GTA SA folder.


I'm a little noobish with VB, so it's not a great program
