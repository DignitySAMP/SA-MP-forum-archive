01.03.2010, 13:00
1) Delete d3d9.dll
If you have this file, delete it in the directory of your GTA:SA folder, this is the standard directory: (C:\Program Files\Rockstar Games\GTA San Andreas)

[- Now try and run your SA:MP]

2) Deleting the gta_sa.set
This would be where you'll find the directory if not changed: (C:\Documents and Settings\YourNameHere\My Documents\GTA San Andreas User Files)

[- Now try and run your SA:MP]

3) Re-install
This is probably the first thing you already have tried, but just do it again since it's always a start.

[- Now try and run your SA:MP]

4) Delete all mods... ANY!
If you didn't backup your mods BEFORE you replaced 'em with your mods. Then you would have to re-install the game.

[- Now try and run your SA:MP]

5) Change the compatibility
Here you would have to go to your GTA:SA folder, this would be the normal directory: (C:\Program Files\Rockstar Games\GTA San Andreas)
Then you go to gta_sa(.exe) and right-click on it. Click Properties, and change to the compatibility-tab.
['Windows 98 / Windows Me' worked for me - but it could be any of the other helping you]
Once you have changed the compatibility, click Apply.

[- Now try and run your SA:MP]

6) Make a new user/account on the computer.
This can be done by going to Start -> Settings -> Control Panel -> User Account, and then there you should go 'Create a new account'
Make sure it's an administrator account + That you have uninstalled GTA:SA on your current account.

[- Now try and run your SA:MP]

Source: http://forum.sa-mp.com/index.php?topic=155877.0 (My thread )
