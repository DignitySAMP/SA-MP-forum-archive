Set up your own SA:MP server at 0.3x


Hello, today im will show you how to create your own server at SA:MP
1. First go here http://www.sa-mp.com/download.php and press the "SA-MP 0.3x Windows Server" or "SA-MP 0.3x Linux Server (x86)" and download it.
2. Create one folder at your Dektop with name "Samp".
3. If you download the SA:MP server you need to put ALL the files from the .zip to your "Samp" folder at your dektop.
DO THIS:

4. Close the .zip and open the "Samp" folder.
5. Now, open the CFG file called "Server" change something if you like but its important to change the rcon password beacuse if you dont change it your server cant open, so dont be crazy! CHANGE IT!.
~Take one example~

6. Okay close this. Now its time to create your own Gamemode or if you dont like to create your own gamemode you can download it, from the http://forum.sa-mp.com/forumdisplay.php?f=71. If you dont like to download it or create it, the SA:MP has create some good gamemodes for newbies, can be found at "gamemodes" folder.
HERE:

(To create your own gamemode go to pawno>pawno open it and press File>New)
7. Done! you are ready to open your server! Press at "samp-server" and open it!
