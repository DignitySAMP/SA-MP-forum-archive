Hello guys, I don't know if "remastered" is the correct term for it but I'd like to show you a polished version of the Vice City map which I've been helping two guys with. In the next video you're going to see a comparison with Kalcor's original conversion. You'll notice some vegetation disappears but it has a lower streaming/draw distance actually, but I might say many unnecessary objects have been removed to reduce overloading. As a reference, Kalcor's conversion creates 9454 objects and this one 6788.

Click here to watch the video!

AdrianGraber converted it completly from GTA United 1.2 using Papawy's converter and some other tools. I've helped a little bit adri1 to set better streaming distances and correct IDE flags.

In my opinion it looks pretty decent now. I was interested in this project because I've always liked Vice City. If the next SA-MP version is going to support downloadable content I'd be really interested and pleased to adapt a version of my MCSA gamemode there.

Best regards.

EDIT: after some tests we've increased a little bit the streaming distance for the vegetation and we've set a higher stream priority for land masses.
