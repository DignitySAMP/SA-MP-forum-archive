Hy every body is me again WazzUp

Today i'm gonna release my new filterscript

Updated new version...

Features

Like music from your scriptfiles... Save and load
Can add or delete music in game or out

What's news

Quote:

When player connect. The filterscript will make a folder for player in ../scriptfiles/Songs/PlayerName(folder)
And the /addmusic command it doesn't for admin anymore. It for every one
/delmusic command for every one to.
/mp3 to hear it

This version is like a mp3 for every one can edit the mp3 of that person.
Commands:

Old version:

/addmusic [For Rcon] [Add music]
/delmusic [For Rcon] [Delete music]
/mp3 [For All] [Hear music]
/musicroom [For All] [Join music room]
/m [For All] [Chat in music room]

New version

/addmusic [For All] [Add music]
/delmusic [For All] [Delete music]
/mp3 [For All] [Hear music]

Installation

Quote:

Extract all the file in the .zip files to your server
Open server.cfg

Write:

Code:
echo Executing Server Config...
lanmode 0
rcon_password ...
maxplayers 50
port 7777
hostname SA-MP 0.3 Server
gamemode0 ... 1
filterscripts ... MFA
plugins sscanf
announce 0
query 1
chatlogging 0
weburl www.sa-mp.com
onfoot_rate 40
incar_rate 40
weapon_rate 40
stream_distance 300.0
stream_rate 1000
maxnpc 0
logtimeformat [%H:%M:%S]
Open server and play

Warnings: Must have a sscanf plugin (and Filemanage if use new version) for this filterscript!
How to add music:

Out Game:

Create a new .txt and writer in there

Code:
Name=SongNameHere
Link=URLHere
Then save in folder Songs in the scriptfiles name 0.music,1.music,2.music,3.music... The number is a list item in dialog

In Game:






new version:

Out Game: // Hmm. No

In Game:

/addmusic //for every one and just this /addmusic [song link] [song name] (song name can use space)
/mp3 //To hear you own list
/delmusic //To delete music you don't want in your list any more
