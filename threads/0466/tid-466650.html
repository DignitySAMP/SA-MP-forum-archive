go into the the control panel, and look for programs you dont remember installing/dont know.

uninstall them if there are any.

also, look in the c drive and windows folders for folders that arent part of the main windows installation, ones like "boot" should stand out. remember to show hidden folders in your options first. if there are some, you have a virus and i would recommend reinstalling windows.

try a free antivirus software and scan for viruss.

also, install the latest drivers for your keyboard (if applicable) and install the latest, java and flash. these programs, especially java or known to have many security holes and should be updated whenever possible.
