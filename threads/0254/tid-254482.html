Here are a few thoughts that just came in mind:

1) Map a unique prison using a map editor. Make it realistic! Cells that can be opened by guards only (either a command or a button). Make sure you get the co-ordinates of the entrance!

2) Prisoners can escape by typing a command /escape, either using a screwdriver or a pocket knife to pick the lock outside on their cell for a few minutes. Then, make a few checkpoints to escort the prisoner outside. Then, make a door that only guards can enter, but it can be picked by prisoners. You're going to have to pick that door's lock (once again, place a checkpoint at the door, and once you've entered it, a few /me's show up saying you're picking the lock with something, and set a timer to maybe 30 seconds. Then, (only) the player can finally type /exit and grab a boat on the dock and escape to Los Santos (maybe it would be nice if it was a prison and roleplay server, based in 2 different places).

3) A guard team. Make an office that only guards can access and there, they can access their locker and type /duty. They are now on duty.

4) A cafeteria would be nice. Map a nice cafeteria with a fence and a few things in the back (such as food trays, etc) and there, you can type /eat, and a big menu full of food comes up (cold pizza, cold burger, moldy bread, and other spoiled / cold foods).

5) Oh, and don't forget animations! Especially in a prison roleplay server, this would be strongly recommended.

I'd be online every day and night if you can make this happen. Sorry if I'm bothering you with big suggestions, but if you can't script then I'm willing to help (for free).
