Greetings dear players!


After a long time of waiting, it is finally here!

We've come to inform that ESL Wire Anti-Cheat now supports GTA San Andreas Multiplayer.
http://www.esl.eu/eu/wire/anti-cheat/


The version of the anticheat was released today (1.10.X), so make sure your ESL Wire client updates.
In case you don't have the ESL Wire client installed yet, download it from the link stated above.
This is a big step for SA-MP to be initiated on ESL for once and for all. The section was closed due to the lack of support from the anticheat client, but a topic was created to get the section back open, since the anticheat is now ready.

This anticheat only works for Matches inside ESL and arranged in ESL. Public servers like GTA:T, Partyserver, etc, won't be covered by this anticheat because it only communicates with ESL datacenter. Therefore, if a match is valid on ESL datacenter the anticheat will run, else it won't.
You can still use the ESL Wire client when playing on public servers, since it has an overlay and lots of features, similar to Xfire.

If you want to test ESL Wire on SA-MP, be sure you have a completely default GTA San Andreas and SA-MP client installed.
This means no mods or hacks or trainers or plugins or any kind of stuff, that can interfer with the normal function of GTA San Andreas and SA-MP besides their original files, will be tolerated.
It is recommended that you UNINSTALL and INSTALL the game and SA-MP client if you have any mods installed. (Replacing with the original models might not be enough since the files were already touched).
SO DO NOT TEST ANY CHEATS OR HACKS OR MODS WHILE RUNNING ESL WIRE ANTICHEAT TO SEE IF IT REALLY WORKS, BECAUSE YOU WILL GET BANNED IF YOU DO. (That includes sound mods, skin mods, etc..)

You may find the GTA SA-MP ESL section here: http://www.esl.eu/eu/gtasa/
Since the section is still closed, a topic was created to open the section -> http://www.esl.eu/eu/forum/139/166/944303/
Once the section is open, Admin Applications may also open to control and monitor the ESL SA-MP section.

All the topics regarding ESL+SA-MP will be created on its respective section from now on (http://www.esl.eu/eu/gtasa/), including a tutorial topic where we explain the basic ways around ESL navigation. A test-cup will also be made soon, so clans will be able to sign up.
The bigger amount of clans interested, bigger the cup will be, and obviously the anticheat will be mandatory.

I advise you to take a look on this page for information on how to establish a team, a profile, etc: http://www.esl.eu/eu/faq/

A tutorial topic will be made on ESL SA-MP section soon, explaining how the ESL WAC works with SA-MP, how to get matches organized and how to start them with the anticheat.

Also a little side note... this is all about ESL Europe. The american and south american players should show their interest to get SA-MP added to ESL America
on this topic: http://www.nationalesl.com/us/forum/...911836/?page=1


Stay tuned!
