Bomb system by B-Matt
Introduction

This is mine first release and first FS. I'm still newbie in Pawn and Pawno and I made this for practise. You may edit this, leave or delete credits, etc. Now this is v2.0 version and I won't update it anymore.

Requirements

ZCMD - Zeex

Features
  • Timer bomb - timer of 5 seconds
  • Remote bomb - detonates when you press FIRE KEY (left mouse click)
  • Car bomb - detonates when driver press W
  • Remote car bomb - detonates when attacker press FIRE KEY (left mouse click) (new)
  • Defusing - you have 50:50 chances to defuse bomb. If you'r lucky you will defuse it, if you'r not BOOM. (new)
  • Now when you plant bomb you need input timer in seconds! (new)
  • Give - you can give all bombs with that command (new)
  • Easy to use and edit this FS
