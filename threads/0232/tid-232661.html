You should make sure your server hardware will be able to support several players. Some scripts vary, so test this on all scripts you plan to use while your server is online. Grab some friends, tell them to grab their friends and make sure the server can function properly in the necessary environment before purchasing a load of bandwidth.

As far as the bandwidth goes, you would be much better off going with an un-metered host as they must provide you with as much bandwidth as you need at no extra charge to you (read their terms of service though).

It would also be a good idea to make sure that you are running the SA-MP server on a separate server than anything else, such as your website/forums or a voice server such as TeamSpeak.
