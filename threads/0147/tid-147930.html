GTA IV AMMUNATION
Notes:

It started when I read a topic asking GTA IV type of ammunation and a video of Fallout's. But there was no script yet in that kind (if I am not mistaken). So I thought, why don't I make one. Then it was done.

Screenshots:







Downloads:

Important:

At line 20 in the script
Code:
#define TAB
Comment this line if you want to use Caps Lock instead of Tab key to buy the weapons since Tab key brings the scorecard which would be annoying.

Bugs:

I have tested the script and found no bugs. But if you find one please post them so that i could correct them in the next release.
