Hey guys, today I'm presenting to you my new Rick Roll command. What it does, is when you type '/rickroll playerid reason' It will play an audio stream to the target player of the song 'Never Gonna Give You Up' by Rick Astley. It also sets their health to 30%, just for added effect I made this command originally for a SA-MP server I play on, but I thought I would prune it and upload it here for you guys to use I added in many comments explaining everything just for the new scripters. I made this for kicks and because I'm pretty sure there isn't many, if at all a Rick Roll script on the SA-MP Forums. Enjoy, and don't be afraid to post constructive criticism! Please don't remove the credits! P.S. I made a LuxAdmin Rick Roll script because I personally like LuxAdmin and I know many others like it too, so I thought for those that DO like it, they could easily get the same script without having to edit a lot of things. IF YOU USE THIS WITH LUXADMIN, PLEASE READ THE SCRIPT SO YOU CAN EDIT THE ADMIN FUNCTIONS TO YOUR NEEDS. Please don't remove the credits, but feel free to edit these to your needs!

NOTE:
This FilterScript HAS been tested by me and works perfectly.

NOTE: This is an RCON ONLY command, so make sure you are logged into RCON before using it.
