Thats not the goal of this FS. The point of this is to automate some of the "checking" routines done by admins. Manually I used to teleport myself somewhere, teleport the player to me, freeze them, slap them, then watch their health level.

This script automates that basic check so all an admin has to do is type "/test <id>" and wait for the results.

You could however use the timer routine to set up something yourself in regards to the functionality you seek.
