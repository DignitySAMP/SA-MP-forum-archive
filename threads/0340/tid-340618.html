SA-MP 0.3e es lanzada! Como siempre, la nueva version esta disponible en la web de descargas..

SA-MP 0.3e caracteristicas:

- Se resolvieron algunos bugs menores y se realizaron cambios en la seguridad.
- Se agregaron muchos nuevos objetos para mapeos, incluyendo casas y paredes.
- Los servidores ahora pueden cambiar la textura y los colores de los objetos.
- Nuevas caracteristicas al scripting para mayor control de la camara.
- Nuevas herramientas para facilitar la edicion de objetos.
- Nueva animacion y modelo para arrestar/esposar.
- Funciones de texto para crear carteles.
- Los servidores tienen la habilidad de permitir el uso del cursor para clickear en imagenes/texto (textdraws).

Gracias a todos aquellos que testearon la version 0.3e y dieron su opinion! Por favor sigan asi para la proxima version de SA-MP.

Para los servidores que requieran mas de 500 jugadores: Por favor, enviar un mail a team@sa-mp.com y brinden la IP:Puerto de su servidor. Necesitaran probar que requieren mas de 500 slots para que se les envie un servidor mas grande.
