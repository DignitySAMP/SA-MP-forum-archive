Version 0.2a

What does it protect against?
Well, the new version (0.2a) protects aginst Interior Hacks, Money Hacks, Jet Pack hacks, Weapon Hacks, and Speed Hacks.

Here's version 0.2a. I'm gonna explain about each one..

Interior: The interior hack isn't that important but I thought I'd add it. Basically, if someone goes to a different interior with out being set there, it bans them. Warning: If you have any command that sets a player to an interior, be sure to put 'Interior[playerid] = 1'

Money: The money cheat works like this. If a player receives any money, they should have the variable set at the same time. If at anytime the 'Cash' variable doesn't equal the player's money, they will be banned.

Jet Pack: They have a jetpack = Ban.

Weapon Hacks: A certain assortment of weapons, will ban them. You can keep them from getting banned by placing the variable 'AGWeap[playerid] = 1;'.

Speed Hacks: Set '#define MAX_SPEED' to your desired amount. It is currently at 230. It gives them 3 chances while warning the admins at the same time.

That's my system, if there are any bugs. Please report them to HellBeast.Net or reply here. I DO NOT reply to Pm's concerning my releases.
