If you are using a Linux OS this normally happens when you replace the samp03svr via FTP normally in ASCII mode.

Try to switch your FTP to Binary Mode or if you don't know how to do that reinstall the SAMP server via host CP and do not replace the samp03svr or announce / samp-npc files.
