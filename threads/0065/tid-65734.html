This filterscript:
  • Stops the RCON password from being hacked, by rapidly changing the password to random strings such as "3e9h0b612e8j41f8q0o".
  • Allows you to still use RCON commands in-game.
You use RCON commands the same way you normally would. You "/scon login [RCON PASSWORD]", then you can use RCON commands such as "/scon gmx", or "/scon ban 0". All RCON commands work. Of course, the Remote Console Client is unusable.

Please report bugs.
