In blender, you should do Object > Apply > Rotation & Scale once you are finished making changes.

It might be a problem with the export script which could be fixed. The first mesh is exported as displayed, but the binary version of the mesh (the one the game actually uses) doesn't seem to account for scale and rotation changes in blender, so you have to apply them.
