Yours Gaming Roleplay v1.0.0



Summary
Yours Gaming Roleplay is my first gamemode release as of now. This gamemode is a basic outline for anyone who is an intermediate scripter, looking to skip that first initial process of creating a saving outline for their script. Which if you're anything like me, agree that's pretty annoying! This gamemode is in its early stages, and will be developed as time goes on, with suggestions from the community. Currently, it only contains few player commands, but includes a huge administration system. By version two, the administration system will be complete, along with a fully functioning report system, and commands for admins to preform on players. By version three, this script will have a completed user command system, and by version four it should be in beta mode. Feel free to leave suggestions in the comments below, as this script is developed by you guys as well!


Features
Code:
Functioning Saving System using dini.
Dynamic Server Properties
Dynamic Server Spawn
Dynamic Toggleable Admin Whitelist System.
Unlimited Administration Ranks
Very basic administration commands.
Dynamic admin-only vehicles. (No saving as of v1.0.0)
Dynamic Saving & Creation of Houses (Jason's Dynamic House System) Integrated into the script
Dynamic Saving & Creating Dynamic Doors
Dynamic Groups
Dynamic Families
Invitation system for groups
Logging system
