If your server normally saves to a particular folder, make sure that the folder exists on the host (Check '/scriptfiles' of both your local computer and the host, make sure they match). Also make sure the folders you create are available to the server for use. The easiest way to do this (With debatable security issues) is to do 'chmod' to 777. This is very easy if you are using filezilla, you can simply right-click on the folder and click 'file permissions'. Here you can set the numeric value to 777, or if you want to be safer (Better on shared hosts) you can just set the first number to 7 and leave the others. If you click "recurse into subdirectories", it'll change the other folders in there too.
