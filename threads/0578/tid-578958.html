Quote:
Originally Posted by Vaishnav

I am getting some problem I've done everything but when I go in game and type /tbr it says server: unknown command. pls help D:
Well, you obviously have NOT done everything. The simplest way to set it up would be:

1. Download the default server package.
2. Copy and REPLACE the server files from the TBR folder to the default server folder (after extracting both obviously).
3. Delete the server.cfg that came with the default server, and rename the TBR one to 'server.cfg'.

4. Run the server!

If the server fails to run, and shows a dll error, install VS Redis. 2012. If that doesn't work, place these in your server directory.

If all of this fails, report here again.
