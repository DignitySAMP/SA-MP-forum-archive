After making the previous Filter Script that was messy, I decided to Rewrite it and add something new.
Made it more organized, and more easy to understand for you guys.
(Old Filter Script: http://forum.sa-mp.com/index.php?topic=71962.0)

♠ Commands:
  • Works only if you are in Soldier Skin!
  • /gate - Opens the main Entrance gate & the garage shutter.
  • /lift - activates the Elevator.
  • Also there is a new feature I have added you can Now open the gates by pressing the CTRL or RMB.
  • Also Added a timer of 5 seconds for each object to close instead doing the cmd twice.
