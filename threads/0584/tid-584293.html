04.08.2015, 12:07
The error itself doesn't seem to be directly in OnGameModeInit, but on a function used by OnGameModeInit. You should compile your GameMode in debug mode so CrashDetect can output more useful information. To do so you need to pass the flag "-d3" to the Pawn compiler, you can easily do this by creating a "pawn.cfg" file inside the Pawno folder with the following contents:
Code:
-r -O0 -d3
After doing that, compile the GameMode, run the server and post the server log here again
