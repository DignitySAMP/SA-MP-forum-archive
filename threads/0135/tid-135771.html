Hey stoners i bring you a very good gangwars script it has fixes in it and i was using it but now that i went back to rolelplay i just put it away so ill release it now:


Features

* Zone/Turf system - take other turfs from teams/ start gang wars
* Turf Names Textdraw
* Safe Zone
* Player Bank
* Stunt Teleport
* Auto jail system with a command which enables other players to bail the jailed player
* Givemoney, hitman, bounty commands as well as team gate cmds
* Dialog Different fight styles
* Pay Day



The Teams:

Grove, ballas, aztec, nang, army, cops,
vagos, mafia, biker, triad, low rider,
skaters, undertakers, demolition workers
and admin.


Turf System:

If a player is kill X times on his own turf by the same team, then a gang war is started between the two gangs. To take the turf the attacking team will need Y kill on this turf. Alternatively, the other gang can defend their turf by, killing Y attackers or by defending the turf for Z minutes. If the turf is taken then the zone changes colour for all players.
