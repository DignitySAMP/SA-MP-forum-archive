This amazing script was made by Calgon. Click here to check out the original thread.


Added Features:
  • Whirlpool Password Encryption
  • LSPD Parking Lot Gates
  • Tons of vehicles added to the dealership
  • About 300 houses added around Los Santos
  • Dynamic Gas Stations
  • Fuel System
  • - Player vehicles' fuel save, however group vehicles spawn with 100 fuel
  • - Random 'drop car' vehicles without groups spawn anywhere inbetween 10-30 fuel.
  • /map updated & improved
  • Businesses added around.
  • Driving test added.
  • /phone improved
  • - Removed Phone Credits
  • Dynamic VIP System
  • - Five VIP levles (Bronze, Silver, Gold, Platinum, VIP Moderator)
  • - Bronze, Silver, Gold all last one month
  • Dynamic VIP interior, locker & exterior.
  • Dynamic Impound Position
  • Arrest points added
  • /tow added
  • /tazer added
  • Group badges added
  • Dynamic group colours using HTLM colour code format
  • Added 3 more group ranks
  • Added 6 group divisions (dynamic)
  • Added a group paycheque system. Group leaders can set the pay.
  • /setstation added.
  • /vstore and /vtake added for storing weapons in your vehicles
  • /sellcar added
  • /unimpound in the DMV
  • /unimpoundplayerscar (for LSPD)
  • Dynamic DMV exterior
  • /dropweapon added for individual weapons
  • Car Engine system
  • /refill added for mechanic
  • /fix now requires the hood to be open, and the player outside the vehicle
  • /deployflares /deploycades /deploycones (/destroyflares, etc etc) added
  • Car slots now show up in dialogs for players, there are still some admin commands with physical slot ids needing to be entered in commands.
  • NOP hack warnings were added, does not automatically ban the player as sometimes desync and even /uninvite can cause them to be nop hacking if they're in the vehicle when /uninvited. Only displays THREE for the admins before stopping.
  • /stats reformed, removed inventory items from /stats and the college degrees
  • /inv added for inventory
  • All script animations removed, vactions.amx replaces it.
  • Much more, please explore the script!
Added Features (2.0):
  • Added a streaming objects function.
  • Added a 'custominterior' 'customexterior' variable to most enter/exits
  • - This makes, when made 1, the player stream objects upon enter/exiting
  • Added a dynamic gate system
  • - /creategate, /editgate, etc
  • Added in a dynamic toy system
  • (Not to sure if this is working or not, I know I added them to clothing stores but the saving I think is a little iffy.)
  • Added a pizza boy job.
  • Added a taxi job.
  • (Again, still think a few things are iffy with this system)
  • Probably a lot more. It's been awhile since I've messed around with vortex.
Again, thanks Calgon for this amazing script and this edit is server-ready for light-medium roleplay.


Note: There may be some wierdly named zips in the file, but these are just backups of some files and I forgot to delete them.

Note (2.0 Only) With OnPlayerEditDynamicObject I had a weird error involving streamer which is why there are multiple callbacks with that function. Read this thread to get more acquainted with the issue in case it happens to you.
