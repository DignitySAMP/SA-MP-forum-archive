I'd pay about $10-15 for a SA-MP host with around ~100 slots, because that's all I would need for a server. But nowadays, I'd just use a VPS since I've had experience with them for years and they're fairly easy to me.

I just don't like the fact that VPS servers are very overrated @ SA-MP. I mean, this "VPS craze" has suddenly started up and now everybody is racing to get one. These things are not the solution to everything; you can only run a server with so many slots and then your server will drastically slow down. Think of it as your own computer, the more things you keep running, the slower the performance.

A 512 MB VPS isn't going to run a full blown 200 slot SA-MP server and a Teamspeak server with 100 slots. There are hosts made specifically for these services; use them. You would probably need to spend $30-40 on a VPS that has the capability of running 400+ slots and multiple services, or a dedicated server (which is basically like renting out a whole physical computer - totally different from a VPS, which is a virtual server).
