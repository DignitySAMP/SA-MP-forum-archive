[CENTER]JailBreak by RipLagger

How To Play
Round Start when in the server there are 1 player in Guard team and 1 player in Prisoner team
Guard (simon): Give instruction to prisoner
Guard : watching the prisoner and make sure the prisoner no escape
Prisoner : follow the simon instruction if there is a chance go escape and kill all guard you can find weapon scattered in this map

Command
/register <password>
/login <password>

Admin: /coor : Give you're coordinate
/gotoc : Goto the specified coordinate
For command kick or ban you can use rcon command

Guard: /openjail : Open the jail gate
/openbox : Open the box gate
/closejail : Close the jail gate
/closebox : Close the box gate
/simon

How To Install
1. copy the .amx file to gamemodes folder
2. create folder at scriptfiles and rename it to "JBRPlayer" (without ")
3. edit your server.cfg
4. run your server
