I actually forgot I even released this, it wasn't until someone asked me about something in it privately this morning
This is the first gamemode i've created. Please note that I stopped using this gamemode a while back, and it is ABANDONED. Certain features will be missing. This script is mostly what you need for a base - clean looking script. It may have some bugs, though I cannot remember. The players are saved with mysql, while everything else is done in sqlite, which allows integration with a web based control panel if needed. Like I said, I cannot remember EVERYTHING that is in this script, or what it is missing, but it is better in someone's hands that are going to use it than sitting in my PC doing nothing. I can provide support to an extent if required. The script is made from scratch, credits are added where needed, for functions etc.

Quote:
Originally Posted by Features
Factions
- Create a faction with /createfaction
- Static factions are in an order, shown below.
- View factions with /factions
- 3 faction levels, permissions vary depending on your level
- Unlimited faction ranks, done with /setrank [playername] [rankname]
- Faction Vehicles (NOT FINISHED, however, dynamic)

Houses
- Create a house anywhere with one command.
- Houses are green if for sale, blue if purchased.
- Each house has a unique address, can be used for custom maps.
- Each house is in it's own virtual world, with a specific ID set.

Businesses
- Businesses work similar to houses
- Currently only the banks [biz id 5] have commands. Others need to be scripted.
- Again, you can check the business address that the player is in with virtual worlds.

Vehicles
- Player has unlimited vehicle slots
- Vehicle has a clean looking GUI.
- Radio streams are working.

Other Features
- Server takes place in San Fierro, may have changed spawn to LS, can't remember.
- Everything is dynamic except Dealership locations and spawn, can be changed if needed.
- Custom Administrator commands
- No annoying textdraws
- You will not find a single icon in this script (I consider that a bonus)
- Uses a custom script for gates and objects.
Keep in mind, I used this as a tool to learn Pawn scripting. Some items inside may not make sense, but it works.
