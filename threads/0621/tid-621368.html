Update: 12/28/2016

Latest Changelog:
  • Revamps the 'Add Server' button
  • Changes the name of the respective fields that were called 'Language' to 'Lang / Map' as this apparently turned in to a browser for all versions of SA-MP
  • User input in the "[Applied Filters]" bar is now italic
  • Wait for it... Wait for it... And more filters! Hostname, Mode, Lang / Map (language and mapname combined in one filter option)
Please note that input from the form isn't being encoded (we're talking about the filters here), so characters such as --> ' <-- won't give you any positive results. A patch for it will come in the next update.

Update: 12/23/2016

I didn't really want to turn this thread in to a thread where I just use it to post updates and all that, but since this is an apparent issue that bothers more than a few, here I go!

Latest Changelog:
  • Changes the site's title to 'SA-MP Servers'
  • Adds the official contact email on the top right corner of the page
  • When fields that can be highlighted overflow, the remaining text is now hidden
  • Implements proper encoding
  • Adds a space for future filter options
  • Servers now load instantly
  • Servers now show in a completely random order
  • Adds the ability to submit servers to the masterlist (just click on the new 'Add Server' button)
  • Improvements for speed & bug fixes
Known Bugs:
  • After submitting a server, the proper encoding isn't applied. Just go to the server list after submitting a server, and click on the server you added for a temporary alternative fix (this will apply the proper encoding | this is a one time action | use CTRL + F to find the server easily)
Partnerships:
  • Samp4You has agreed to the partnership request I sent out, and they will be proving an API for the servers they host by the beginning of 2017 (respective implementations will be held until then)
Future Plans:
  • Users online counter
  • Double clicking on a server will redirect you to the SA-MP client and ask you if you would like to add the server you clicked on to your favorites list
  • Filter options (hostname, mapname, weburl, version, etc.)
  • Dark scheme with a material design
  • More tabs
  • Establish partnerships with more hosts
  • And possibly more to come!
Since we can now submit servers to the masterlist, we'll soon have a list with all the servers we ever imagined of. So there's no need to rant about the internet tab being broke anymore (I used to rant about it too)

Update: 12/16/2016

http://www.sa-mpservers.com - Basically just the site functioning, a lot will change if we agree on continuing it.

As many of you guys know, the best option here is to have access to the announce mechanism provided within the server package, but we know that's just not going to happen.

It is quite difficult to listen to all servers as there are a lot of IPs, and not to mention the ports each IP could have a server on. But as a side note, the server does do its job and searches for servers then adds them automatically. The process isn't instant though (obviously). So I was just wondering if you guys would be okay with a side feature, which would allow you to submit servers so they are listed on the server browser (mostly for server owners and promoters). So what is your answer to this?

Also note that the 'server checker' isn't set up yet, meaning that the server is also trying to query servers it previously found which are currently offline; slowing down the process of servers appearing.

---------------------------------------------------

I'm looking forward in partnering up with hosting companies to improve this service. They could receive promotion in return for an API which reports the servers it hosts. Let me know if you're interested via PM.

---------------------------------------------------

Anyhow, I'd appreciate any of your inputs. If you would like to see the internet tab back (well not exactly, but something really similar!), then please reply. Thanks.

If this goes anywhere, I may look forward in building up a team, and if there's any way available for the support of this project, they'll receive a percentage in return for responding to inquiries, maintaining the tabs up to date, reviewing servers to see if they qualify for the certain tabs it will have, etc.

Initial Post

Only a few know about this already, but a lot of you don't. Well. I'm working on a server browser for SA-MP servers (like the actual client, but in a form of a website - just if you're wondering, no, it's not the same as SACNR Monitor), which will possess tabs such as internet (an alternative comeback!), official and verified.

The internet tab will show servers that are online in general, the official tab will show officially hosted servers, and the verified tab will show servers that have scripts which were created from the ground up (from scratch).

It will show real time info (players online, players' score, ping, etc.), and it will use its own custom master list.

The server browser may launch in a couple of days. I just wanted to know if you guys are interested in seeing this project go live? Also, will this be permitted to be known throughout the community?
