Imperial Gaming
(Roleplay / Fun) -By Excel








DESCRIPTION
Welcome to the Imperial Gaming main page. Here you can download / suggest & Even REP+ me if i helped you. This is not a bsic gamemode for newbies. You need to be a Scripter, if you want to edit or make this gamemode complete as this is not a full version. Its a BETA version of this Game. Edit but keep the credits. Basically this gamemode is based on Roleplay or Freeroam i.e. Fun. There is included a register and login + Some games selection in game which is awesome. You must see all the textdraw work by me. Hope You Like it. Ya And dont forget to REP+ me.








FEATURES
- Login And Register System
- Y.INI saving account system
- Usage of sscanf2
- Whirpool safe password security system
- 2 Mods added i.e. Stunt and Counter Strike
- Saving player stats for all registered members
- Stunt commands
- Counter strike 5+ maps added
- Switch games by F4 + /Kill or /Games
- Car tuning menu by Kaxi
- Textdraws configuration ( Awesome )
- Random Spawn on Request spawn or Roleplay spawns
- Most of things in dialog
- Spawn selection menu on entering games
- Cookies system
- Player helping bot with textdraw box. (Left Side)
- Teleports added
- Vehicle control menu / Dialog by /Vcontrol
- Teleports added in stunt by /teles
- You can use /info in stunt to get help
- Only stunt commands are been allowed in stunt game selection, not in C.S.
- Stunt maps and C.S. maps added
