[FS]Money Bag


About this script
This script was a old script that I made a year back, totally forgot about it until I searched my computer yesterday and found it. It's a fun little minigame for servers, you can set it to any time duration you want. I only edited the colours in the text since last year, not the actual script so, it should be fine. It has over 500 money bag spawns, you can easily add more to it.

Commands:
/gotomb - Teleports to the money bag (RCON admins only).
/startmb - Starts the money bag if not started already (RCON admins only).
/togglemb - Turns the money bag off or on (RCON admins only).
/moneybag - Tells you the area of the moneybag.
