BASIC ROLEPLAY SCRIPT

Introduction: This script is coded from scratch by me. It was a big learning curve for me so don't be surprised by bad scripting methods or ugly alignment or w/e. I'm releasing it because I'm not working on it anymore. This script is a basic roleplay script and gives you an opportunity to code a big fresh roleplay script with cool features. There's already some mappings in the script, delete it if you wish to.

There might be stuff that's not finished... I just kind of abandoned this script when I lost motivation.

LINES: 11408


Credits: Kush (Y_INI tutorial), MadeMan (vehicle system), Swindle (boombox fs).


Functions:

Login/Register system,
small introduction,
administration system,
basic dynamic housing system,
basic dynamic business system,
vehicle system created by MadeMan,
basic dynamic properties system,
basic bank system,
very basic cellphone system,
very basic DMV and licenses system.
