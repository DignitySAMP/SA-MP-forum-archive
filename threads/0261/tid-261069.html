Bartje01's Admin System


I'm working on a admin script. I'm still working on it.
Please standby for updates.

__________________________________________________ __________________________________
Don't remove any credits
__________________________________________________ __________________________________


Features

- Account system included (Dialog)
- 5 admin levels excluding RCON
- Admin online notice when admin logs in
- Working reports
- Warning system with a maximum warns of 3. (Autoban)
- Ban system
- Account saving system (Money,Score,Admin Level)


Commands:
Level 1: /mute /unmute /goto /gethere /warn /ban /kick /ann
Level 2: /setstat /flip
Level 3: /car /vr /nos /ccolor
Level 4: /giveweapon
Level 5: /restart
RCON: /makeadmin /rcon unban

The rcon unban is an official command. Credits goes to SA-MP.

Installation

1. Download the filterscript (Link at the bottom)
2. Extract the files in the filterscripts folder to your filterscripts folder
3. Put the files from the includes folder to your pawn->includes folder
4. Put the accounts folder into your scriptfiles folder.
5. Open your server.cfg and put bAdmin at Filterscripts
