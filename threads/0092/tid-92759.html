HOW TO INSTALL MODERNTOPIA + MYSQL
1) Wamp
You need wamp, you can download Wamp:
Download Wamp
And install it.

2) Moderntopia
You need Moderntopia GameMode Files, you can download Moderntopia files:
Download Moderntopia
If Downloaded, then extract into Desktop.

3) mySQL Plugins (DLL)
You need mySQL plugins, you can download mySQL Plugins:
Download mySQL Plugins

4) Include
You need include(with compile), you can download Include:
Download a_sampmysql.inc

--------------------------------------------------------------------------------------------------------------------------------------------------------------------
Download it, what is in 2) guide, then extract into Desktop.



If You Extracted, Then u see theres.



Open database.sql with notepad, and select "Select all", Then Copy.



Open Wamp, then go PhpMyAdmin.



You Are In PhpMyAdmin, Type samp and press Create.



Then press tab "SQL"



And copy - paste then select Go





You are finished!



--------------------------------------------------------------------------------------------------------------------------------------------------------------------
Move sampmysql.dll to "plugins" folder.
Move libmysqlclient.dll to "root".(See where is server.cfg, samp server.exe....)
Move mtrp-final.pwn/mtrp-final.amx to "gamemodes" folder.

Open server.cfg then edit:

Code:
gamemode0 mtrp-final 1
plugins sampmysql
and Save!

CONGURATION, YOU DONE IT!
