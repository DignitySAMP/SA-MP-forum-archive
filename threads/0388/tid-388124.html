Advance Rules System v1.0

Last Update: 10/27/2012


hello there,
this is a rules Script i made for newbies because they keep looking for a great rules system. I made it in little time so enjoy it.

Command:

There is only one command which is
/rules

Features:

Features of this script are following
1). This Fs is easy to Handle
2). All rules are in dialogs
3). By Clicking on one single term you can get detail about it in main chat
4). By Clicking on one single term Rules dialog pop up again it means you would not need to type command again
5). And An title message " Server Rules" you can change it.

Installation:

You Can Install this Filter Script by following these steps:
1). Extract .rar File
2). Put rules.pwn and rules.amx in Filterscript folder ( ....../your server/Filterscript/).
3). Open Server.CFG and write rules in front for filterscripts.
4). Run your server.
