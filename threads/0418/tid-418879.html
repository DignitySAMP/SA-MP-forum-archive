I searched by ass off and couldn't find a suggestion topic, so sorry for that. However, I think this is pretty much needed in generally a lot of SA:MP servers.

A lot of the game modes of pretty much any server is purely based on commands and the like. You can hardly do anything without typing. This causes problems though, because it happends too many times that someone does something to you while typing (wheter it is talking in the middle of your sentence on a role play server, or getting shot down while spawning a vehicle on a DM server). A simple function to fix this would be implementing a function which allows others to see wheter you are typing or not. Like a small icon next to your name when you press "T" or anything the like. Something which indicates you are typing, so others can see it.

I myself am not a scripter or any sort, so I asked around some capable scripters if it was possible with the script itself already, but apparently it wasn't. So I thought I'd lay it next to the SA:MP developers to see if they can do something with it.

Cheers o/
