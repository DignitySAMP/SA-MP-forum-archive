PWN Mail Exploder
v0.3
Данный плагин предназначен для рассылки сообщений прямиком с сервера SA:MP

Плагин использует SMTP протокол так же поддерживает HTML сообщения

Функции:

SendMail(to[],subject[],messsage[],type=PME_MESSAGE_NORMAL); - Собственно создает и отправляет email сообщение
IsValidEmail(email[]); - проверяет верен ли email адресс
PrintPMEInfo(); - печатает в консоли информацию о плагине

Настройки:

Данные настройки нужно вставить в server.cfg

pme_smtpserver=smtp.servername.com - Ваш SMTP сервер
pme_username=UserName - Имя пользователя (может быть пустым)
pme_userpass=Password - Пароль (может быть пустым)
pme_from=someone@somedomain.com - Адресс отпрвавителя
pme_sname=PWN Mail Exploder - Имя отправителя

пример

===========================

echo Executing Server Config...
lanmode 1
rcon_password changeme
maxplayers 50
port 7777
hostname SA:MP 0.3 Server
gamemode0 minigunmadness 1
filterscripts r_dialoglogin
plugins pwn_mail_exploder
announce 0
query 1
weburl www.sa-mp.com
maxnpc 20
onfoot_rate 40
incar_rate 40
weapon_rate 40
stream_distance 300.0
stream_rate 1000

pme_smtpserver=localhost
pme_username=UserName
pme_userpass=Password
pme_from=kornev_r@list.ru
pme_sname=PWN Mail Exploder

===========================
