SA-MP 0.3z RC5-2 Client update

- Rйglй : Le joueur avec l'ID le plus йlevй n'envoyait aucune information а propos des vйhicules inutilisйs (unoccupied vehicle updates).

SA-MP 0.3z RC5 Client/Server update

- Erreur de vйrification de champs (range check error) rйglй dans l'outil de recherche des serveur si vous ajoutiez un port erronй (comme 777777)
- Quelques optimisations internes au client devraient amйliorer les performances.

- Pawn native GetServerTickRate() ajoutй pour donner le tickrate (comme FPS) du serveur.
- Problиme rйglй avec les tests de 3DText/NameTag LoS sur les objets du serveur

- Changement de comportements et de paramиtres pour OnUnoccupiedVehicleUpdate.

Dans les versions prйcйdentes du serveur, les clients pouvaient envoyer des mises а jour а propos des vйhicules qui n'йtaient pas contrфlйs/conduits par d'autres joueurs, quoique le serveur n'avait pas la possibilitй de supprimer ces mises а jour. Les paramиtres rйcemment ajoutйs dйcrivent la position mise а jour demandйe par le joueur. Le script peut dйsormais donner un 0 pour supprimer la mise а jour ou un 1 pour autoriser cette muse а jouer.

Tous les scripts utilisant OnUnoccupiedVehicleUpdate devront кtre mis а jour et recompilйs pour la 0.3z.

pawn Code:
