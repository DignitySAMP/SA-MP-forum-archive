Introduction


So finally after acouple of hours of work and two days I finally can create this thread letting you guys know that I'm creating a war that is based on continents.

This project is still work in progress and I work on it continously every day for about two hours or less.
I am attempting to finish this FULLY by the end of November 2014.

I've been thinking of doing something like this for quite a while, something that I have never seen before.
Even though it's not as hard to create I still think the idea is amazing.
Therefore I am working on this project.

This version of Continents Warfare aka OxiTDM is currently in BETA stage version 0.7 -
Meaning it isn't complete and probably won't reach an official stage anytime close, why?
Because I have alot of stuff to work on and continue to update, work, fix, check, add cosmetic updates, etc.


Development/Updates



25/09/2014 - Note: I have not yet updated the system, if you download it now you won't see the new updates, I'll be uploading the updated version tomorrow.
25/09/2014 - Added a skin selection system, every team has their own skin. Only one to keep it tidy.

23/09/2014 - Added skins for each class on spawn.
23/09/2014 - Added a AutoMessage system + gifts system once the auto message occurs.
23/09/2014 - Added a unique Leveling system. After a certain amount of kills you level up. Max level = 10 with 3000 kills to reach it.
23/09/2014 - Changed the whole class system required kills for each class, raised them up by alot.
23/09/2014 - Added a PM system, /pm <ID> <Message> and /togpm to toggle it.

Features


* Registration and log-in system.
* Unique admin system - Over 50 commands
* Unique RCON system - Built in RCON - No server.cfg rcon.
* Ban system that logs everything in mysql
* Kick system that logs everything in mysql
* Six Teams with different colors.
* Unique chat for each team.
* Seven different classes that check if you have correct amount of kills to use them
* Stats system - check your password, ip, kills, deaths, etc.
* K/D ratio system.
* Unique objects created - ALOT MORE will be added to create several bases (6 total bases would be created).
* Change your class/team ingame without the need to exit the game.

* More features will be added soon as me and my mapper continue to work on it.
