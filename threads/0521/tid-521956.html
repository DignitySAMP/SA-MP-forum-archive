Do you have any regards of what you're talking about? Clearly you've never actually experimented with this subject before, so please refrain from giving false advice/information.

@OP:

Yes, it's possible. You can avoid players falling through the map by mapping on SP land. For instance; build the island over existing mapping (the airports, perhaps?). Use an interior other than 0 to hide the SP mapping, which will still keep the solid areas. Use RemoveBuildingForPlayer appropiately incase you're worried about bugged objects (a invisible object in the middle of a road for example).

Regarding mapping in general, use a streamer but don't overdo it. You don't need to stream /every/ object, because that will create issues on it's own. Also, as far as I'm aware; mapping ontop of the SP islands (in a different interior) will also solve the noclip camera bug, seeing the mapping isn't out of range of the SP mapping.

-There is a stream limit in objects
-Checkpoints won't work (Not sure about pickups)

Although I'm sure all those things can be worked around with a plugin or something.
