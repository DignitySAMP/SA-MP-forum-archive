Introduction
Hello people of SA-MP forums! My name is Mads, i'm a Objective C and iOS developer.
If you are unfamiliar with Objective C, it's the programming language used in iOS and Mac applications.

Quite some time ago i posted a thread about a connection checker, but then a user made a great point. What is the purpose of that application? Why not have a RCON application instead, it will have much bigger success. So along time after i've decided to start on the application.

What can it do?
Your users are bugging you about the server isen't up, you are visiting your grandmother and you dinten't bring your laptop with you. Well here is the answer, take your iOS device open the application. Start and manage your server, all that is required is a internet connection!
  • Multiple Servers
This means you can have multiple server's to manage at the same time, and the application will save your server data on the device.

How does it work?
I've gotten a PHP script setup at my website, the PHP script uses Westie's API(might change) and will echo out the response data needed, acording to the GET parameters needed. Same goes with POST.

In the application it uses NSURLConnection, it will visit the link for the API and get the response data, store it in a array where i can use it.


That's pretty much it, feel free to ask questions and give your ideas below.
