Introduction
Cop Dashboard is a filterscript which allows real life cop vehicle dashboard. It's based on mysql and dialog and can be used in Roleplay or Cops&Robbers server. It use mysql plugin which is provided on archive.





Features
  • Mysql Kills Saving
  • Mysql Deaths Saving
  • Hotkey for Cop Dashboard
  • Dialog Based
  • Trace Dialog
  • Most Wanted List
  • Request Backup System
  • Player Information Dialog
  • Target State Detector
  • Target Interior Detector
  • Target Marker
  • Backup Marker
  • Dynamic Dashboard Access Permission[NEW]
  • Report System[NEW]
  • Anti Mysql Injection[NEW]
Mysql Kills Saving: Every player kills is saved to mysql database provided on copdash.dat .

Mysql Deaths Saving: Every player deaths is saved to mysql database.

Hotkey for Cop Dashboard: No need to type any command. Just press your SUBMISSION key.

Dialog Based: Everything is dialog based for fast checking.

Trace Dialog: Cop can trace a player on Trace Dialog which will add that player on the radar and cop can follow that player afterwards.

Most Wanted List: It will list all the players who's wanted level is above 2.

Request Backup System: Cop can request backup on Request Backup Dialog which will add the Cop on the radar so that other cop can back him up.

Player Information Dialog: It will list the player information which you have given.

Target State Detector: It will get the target(traced player) state. If he is on foot, the detector will send that message.

Target Interior Detector: It will get the target(traced player) interior. If he is inside on a building, the detector will send that message.

Target Marker: Every target has it's marker.

Backup Marker: Every backup has it's marker.

Dynamic Dashboard Access Permission: Now Police Dashboard can be access from the vehicles which is specified on access_vehicles from copdash.conf.

Report System: Now Police can report case against a player and another Police can read the report.

Anti Mysql Injection: It's impossible to inject SQL commands now.







Installation
  • Download the provided zip archive from the attachment
  • Unzip it with your favorite zipper
  • Backup your server.cfg file on your server directory
  • Extract the files to your server directory and allow overwrite
  • Change the server.cfg to your liking but don't change the cop dashboard filterscript location
  • Now go to your filterscripts\copdash and open copdash.dat with pawno.
  • It's recommended to change the Mysql Config. Everything is explain in comments.
  • Compile the script








How to use
When in game, get inside the access vehicles and press your SUBMISSION key. Then you will get the dashboard and everything is self explanatory afterwards.
