    • Features
      • Detects money, health, armour, weapon, ammo cheats.
      • Logs everything into scriptfiles/cmn/log.txt.
      • Blocks a player from entering into server only
        if he is suspected twice.
      • When a player is blocked he is asked to leave
        a feedback before he is 'Kicked'.
      • All player's case files can be found in
        scriptfiles/cmn/blocked/ folder.
      • Every player who is blocked enroll's his name
        into scriptfiles/cmn/blacklist.txt.
      • You can activate and deactivate any cheat detection
        be toggling them in scriptfiles/cmn/configuration.txt.
      • You can activate/deativate any cheat detection
        using rcon commands too( just type '(' for in the
        console for a list of rcon commands ).
    • More
      • It has a high accuracy rate of 8/10.
      • The source has been divided to multiple individual files, so that its easy to:
        • Update
        • Bug Fix
        • Develop
    • Updates
      • False detection of Health / Armour were found, so it is recommended for you to disable Health and Armour.
    • Installation
      • Unzip them into your 'Samp Server Folder'.
      • Add #include <cmn\core.inc> in your gamemode and filterscripts.
    • Examples
      • Configuration File

        scriptfiles/cmn/configuartion.txt

        money=1
        health=1
        armour=0
        weapon=0
        ammo=1

      • Log File


        scriptfiles/cmn/log.txt

        ca mo dt hr mn qn name
        1 8 1 21 30 1000 Kapil
        2 5 4 22 55 0 Leet
        5 8 8 6 9 5 Mr.Bla

      • Player Block File

        scriptfiles/cmn/blocked/Kapil.txt

        Name: Kapil
        Ip: 127.0.0.1
        Date: 1:8
        Time: 21:30
        Case I: Weapon( Minigun )
        Case II: Money( 1000 )
        Feedback: I just went up the hill and suddenly someone came to me and give me money and weapons.
