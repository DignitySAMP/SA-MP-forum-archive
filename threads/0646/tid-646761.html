He has loaded nativechecker as the last plugin and he did not received a warning about version mismatch so the problem is clear here. The versions he had loaded are not correct.

Streamer version 2.5.2 is very old and the latest version is 2.9.2: https://github.com/samp-incognito/sa...lugin/releases
If you have problems with the latest version, downgrade to version 2.8.2 which is stable.

About mysql, you've loaded R41-4 but the script still uses cache_get_field_content which was renamed in R40+
Last version using this function was R39-6
