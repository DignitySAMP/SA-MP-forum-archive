I'll give you an example:
pawn Code:
// Good indentation
else if(HallRecentlyRobbed > 0)
{
    SendClientMessage(playerid, ERROR, "The City Hall has been robbed recently!");
    TogglePlayerControllable(playerid, true);
}
and

pawn Code:
// Bad indentation
else if(HallRecentlyRobbed > 0)
{
   SendClientMessage(playerid, ERROR, "The City Hall has been robbed recently!");
  TogglePlayerControllable(playerid, true);
}
You need to make them at the same column the above and below line. If there's opened bracket then it goes inside 4 spaces (1 time TAB).
