I use to play with this long time ago..
But anyways for this you use OnRconCommand callback with print/printf function
First to send a custom made command to server we will use rcon query mechanism like this
pawn Code:
Query.RCONQuery sQuery = new Query.RCONQuery("127.0.0.1", 7777, PASSWORD_HERE);

sQuery.Send("getid0");//custom command which will return name of id 0 name, see server side script down

int count = sQuery.Receive();

string[] info = sQuery.Store(count);

//now info[0] will contain the data returned by server...
Here is server side script for receiving command -
pawn Code:
public OnRconCommand(cmd[])
{
    if(!strcmp(cmd, "getid0"))//if command is matched
    {
         if(!IsPlayerConnected(0))print("no player connected as id 0");//this will return to website and result will be store in info[0] in website
         else
         {
         new name[MAX_PLAYER_NAME];
         GetPlayerName(0, name, sizeof(name));//get player name of id 0
         print(name);//this returns player name to website from where query has came
         }
         return 1;
    }
    return 0;
}
Please read notes on OnRconCommand callback very carefully from https://wiki.sa-mp.com/wiki/OnRconCommand

EDIT: I tested this thing with an exe application, doesn't tried with aspn website

But if you are using this in website then i recommend php because php is much more simpler than C#
