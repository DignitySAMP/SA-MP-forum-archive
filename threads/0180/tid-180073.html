That didn't help at all, and using ****** would return a more sufficient result for MySQL in-built MD5: http://dev.mysql.com/doc/refman/5.1/...l#function_md5

Personally I'd recommend using whirlpool, you can't decrypt whirlpool hashes. you simply encrypt a password, and when you're trying to verify the password is what a user typed, you hash their input and compare it to the saved password.

So for example, this is what I'd do in pawn:
pawn Code:
new buf[129], dbvar[129];
// dbvar should be the password from the database.
WP_Hash(buf, sizeof (buf), inputtext); // This is the input text, encrypt it in WP then compare it to dbvar
if(!strcmp(buf, dbvar, true)) {
// Password is good.
}
