Warning loose indentation means that you forgot tabulator [Tab button]
Example:
pawn Code:
if(strcmp("/kill",cmdtext,true 10) == 0)
{
SetPlayerHealth(playerid,0);
return 1;
}
Here you'll get warning and next one is right one:
pawn Code:
if(strcmp("/kill",cmdtext,true,10) == 0)
{
    SetPlayerHealth(playerid,0);
    return 1;
}
