Example
pawn Code:
new temp[ 15 ];
cache_get_row(0, 1, temp); Variable[playerid] = strval(temp); //convert integer into string
pawn Code:
new temp[ 20 ];
cache_get_row(0, 1, temp); Variable[playerid] = valstr(temp, Variable[playerid]); //convert integer into string
