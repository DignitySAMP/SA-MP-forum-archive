rAdmin system + Advanced bank system + Shop system + Food / drinks system


└ Over 50 usefull admin cmds.
└ Integrated bank system (card-password, deposit, withdraw, transfer).
└ Saving system (dini/mysql).
└ ZCMD used.
└ There is a shopping system, you can buy weapons, vehicles, or cookies, sprunks and beers, too.
└ Also, there is a V.I.P system, as a V.I.P you have just some facilites as different shop vehicles, 3dtextlabel and enter/leave message.
└ Jail+mute system in minutes - you can jail and mute players (only admins).
└ There is a card-password system at the bank system, use /setcp in the game and you can see.
└ Advanced food and drink system - you can use the food/drink system, you can drink and eat using /my and click.
└ Kill ratio: there is a ratio between kills and deaths shown in the /stats cmd.
└ Bought vehicles count: you can see how many vehicles you have bought in the /stats cmd.
└ Simple kill system: when you kill someone you get $5000 and +1 score, otherwise you will lose $1000 and 1 score.
└ Anti server-advertising - you will be kicked if you write any IP into the chat.
└ The script has ~3000 lines, it isn't so advanced.
└ The script is based on MySQL too, the bans and the accounts are saved into a database.
└ foreach used, the simplest way to create a loop.
└ Simple admin-chat system - you can use the '@' character in the front of your text to write as an admin(if you are), if you are a simple player it will appear to the admins as a report.
└ Other things, you can see them in the game.

MySQL tutorial:

└ Download the archive and there you'll find a file, named WampServer2.0i. Double click on it and install it.
└ If you have Skype on, turn off wampmanager, otherwise it won't work properly.
└ If you installed wamp-manager, it'll be shown to you a tray-icon in the side-bar, click on it and go to phpmyadmin.
└ When you entered in phpMyadmin you will see an image like this. Into the first window type "samp-as" (without quotes) and press Create. After that, it will be created a database named "samp-as". Up, click on SQL and insert the whole things from db.sql from the archive and click Go, then it will be created 2 tables 'players' and 'banlog'.
└ Get back at the archive and you will see there a .dll file, named libmySQL. Copy it into the root folder, where samp-server.exe is. Then, in the archive you will se a mysql.dll file, copy it into the plugins folder from your server (if you don't have the folder, create it).


ADVISE: Use it on non-GF gamemodes, without register system / saving system, otherwise the errors will appear.
