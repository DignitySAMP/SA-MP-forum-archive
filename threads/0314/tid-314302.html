(f) ******** System v1.0
(f) Informations:
This is an old project started 4-5 months ago. It is a ******** system based on three functions: ZCMD, SScanf and SQLite. This system have 5 commands, and else is in dialogs. You can gave likes on a profile at interval 1 hours. I make this system because if SOPA and PIPA close the real ********, to still exists in SA-MP world ).

(f) Commands:
/******** [PlayerID] - Look your ******** profile or if you type with [PlayerID] param, you can watch another player profile.
/c******** - With this command you can create your ******** profile in game.
/d******** - This command are used for delet your ******** profile, if you have one ...
/flogin - Login your ******** account.
/fhelp - Watch the commands and credits for this filterscript.
