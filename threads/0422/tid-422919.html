Creating Teleports


Description:

It is simple and short script, with this you can simple creating teleports by means of one command.

Bugs:

If you don't returned 1 in callback OnPlayerCommandText you have error in game.

Credits:

Ranchend1998 - For created this script.

Using:

First you must logged in as rcon administrator. Next type /Createteleport [Command]. The teleports is save in file Teleports.ini. Now copy lines from Teleports.ini and paste it to callback OnPlayerCommandText.
