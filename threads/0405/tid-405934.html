SA-MP 0.3x RC

Una nueva version de SA-MP (0.3x) esta en camino. Estamos haciendo una version beta para los scripters para que puedan ver las nuevas caracteristicas antes de su lanzamiento. Si han seguido los lanzamientos de SA-MP por un tiempo, sabran lo que la version x significa (posiblemente la version final de 0.3).

Actualizaciones:


Actualizacion del cliente SA-MP 0.3x R1

Esta es la version lanzada del cliente de SA-MP 0.3x client. Sera lanzada mas tarde en la pagina oficial de SA-MP.

- Basados en el feedback, los cambios realizados al mapeo de memoria del GTA:SA para el dinero durante la version 0.3x R2 fueron removidos. El cliente de SA-MP continuara utilizando 128Mb para el mapeo de memoria como venia sucediendo desde la version SA-MP 0.2.

Actualizacion Cliente/Serveidor SA-MP 0.3x RC3

A menos que se encuentren algun otro problema esta sera la version final RC para SA-MP 0.3x.

- Ajustes finales al netcode antes del lanzamiento.
- Arregla la funcion Kick(), la cual no siempre notificaba al jugador que habia sido expulsado.

Actualizacion opcional del cliente SA-MP 0.3x RC2-4

- Arregla el problema con los offsers de los objetos al atraerlos a un jugador, los cuales a veces quedaban "flotando".
- El tag (nombre) de SA-MP puede mostrar los jugadores que pausearon. Para activar/desactivar esta caracteristica utilizenel comando '/nametagstatus'.
- Se agregaron nuevos objetos como versiones de pelo (pelucas) y gorros.

Actualizacion opcional del cliente SA-MP 0.3x RC2-3

- Mas arreglos para el cambio de material en los objetos. Todavia habia problemas con la iluminacion y demas.

Actualizacion opcional del cliente SA-MP 0.3x RC2-2-2

- Arregla varios problemas al cambiar los colores del material de los objetos, incluyendo problemas con la iluminacion y los crashes.

Actualizacion opcional del cliente SA-MP 0.3x RC2-2

- Algunos objetos causaban crashes cuando eran utilizados con distancias de dibujado muy grandes.

Actualizacion Cliente/Serveidor SA-MP 0.3x RC2

- La funcion EnableVehicleFriendlyFire() habilitara el fuego amigo para vehiculos dentro de un equipo. Algunos servidores requieren fuego amigo para los jugadores pero no para los vehiculos.
- Se agrego una nueva accion especial SPECIAL_ACTION_CARRY.
- Dentro de 0.3x, el parametro final de OnVehicleDeath (killerid) sera el jugador que reporto el vehiculo como destruido. Esto deberia ser renombrado en algun punto, sin embargo, con el interes de mantener los callbacks compatibles con los viejos scripts, esto no sera cambiado en la 0.3x.
- Se agregaron nuevos chequeos para el reporte de la muerte de un vehiculo.
- Deberia arreglar los bugs restantes que causaban la desaparicion de los objetos en algunos angulos de camara (cuando los objetos utilizan distancias de dibujado largas).

Actualizacion opcional del cliente SA-MP 0.3x RC1-3-1

- Arregla el crash causado por la explosion de vehiculos.

Actualizacion opcional del cliente SA-MP 0.3x RC1-3

- Habia un error con algunos objetos los cuales desaparecian delante de la camara. Esto deberia haberse arreglado con la nueva version.
- Si un servidor usa fuego amigo mediante los equipos de SA-MP, ya no se daсaran los vehiculos entre miembros del equipo.
- Los colores de los autos 128 al 255 fueron remplazados con nuevos colores mas exoticos, ya que antes muchos de ellos se repetian. Basicamente se renovaron los colores de los vehiculos.
- Cuando se utilizaba EditObject(), la escala podia ser accidentalmente activada y de este modo no se podia guardar.

Actualizacion opcional del cliente SA-MP 0.3x RC1-2

- En algunas tarjetas de video, el dibujado de las previsualizaciones de vehiculos se realizaba con niebla.
- La memoria del stream no siempre se liberaba cuando se utilizaba para ver skins.

Previsualizacion de modelos:
Se agrego una nueva fuente de TextDraws, la cual permite crear previsualizaciones 2D de los modelos (Se puede especificar la rotacion y zoom).

pawn Code:
TextDrawFont(playerid, txtSprite, TEXT_DRAW_FONT_MODEL_PREVIEW);
native TextDrawSetPreviewModel(Text:text, modelindex);
native TextDrawSetPreviewRot(Text:text, Float:fRotX, Float:fRotY, Float:fRotZ, Float:fZoom = 1.0);

Arreglos:

0.3x contiene importantes cambios en lo referido a la red, incluyendo actualizaciones de seguridad ante potenciales ataques DOS (Denial of Service).

- Se resolvio un problema a bajo nivel el cual reducira la cantidad de paquetes enviada desde el cliente y servidor.
- El problema con el usuario que enviava un comando con largo 0 fue resuelto.
- Se limito la habilidad de los jugadores para obtener informacion del servidor como la tabla de scores.
- %x dentro de format() ya no interpretara largos enteros como signados (que contienen signo).
