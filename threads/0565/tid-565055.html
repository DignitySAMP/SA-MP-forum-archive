Fort Carson's
SuperMarket

By Justice
Howdy! Today, I want to present, my new map called "Fort Carson's Supermarket''. It took me only two days, to finish this map, because I'm very advanced with SA:MP Map Construction/Editor and also because, I've had three holidays, which means, I could spend my whole day at PC in working with the map. So I was inspired to create a new map SuperMarket, which I've never created before. I was taking the example from Suppasave, in San Fierro and it has almost the same size, as this SuperMarket. There includes from the outside the parking place and also from the behind, the warehouse. Inside in the Supermarket, there you will see a cafe/restaurant, night bar and the grocery, with lots of stuff. Like always, it's has custom interior and exterior, with re-textured objects. Sadly, I couldn't add more objects, because of the SA:MP LIMIT. I could add more stuff like, lamps, trees, bushes and more decoration.. but yeah. You will see more in the video below.


Map overall contains 989 objects. And 43 original objects were removed.

VIDEO:

[ame]youtube.com/watch?v=SYpaNikWyCE[/ame]
Click on the image below, to download this map for free via Mediafire.

For map creation was used JernejL's Map Editor - SA-MP: Map Construction

For object re-texturing, like walls, floors was used Texture Studio by Pottus.

Map Location (Coordinates):
-383.1094, 1185.4453, 17.5000
Cheers all! Thank you for paying attention to my post and enjoy the map! Ofcourse feedback's are always welcome! So please comment & rate. Because I worked really hard on this. If you ever think of using this map, please kindly leave a credit.


Comments & rates are always welcome.
