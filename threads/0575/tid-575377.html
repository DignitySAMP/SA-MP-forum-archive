Code:
SELECT FROM_UNIXTIME(UNIX_TIMESTAMP())

Result: "2015-05-26 12:52:42"
You can specify format which you want.

Code:
SELECT FROM_UNIXTIME(UNIX_TIMESTAMP(), "%Y/%m/%d")

Result: "2015/05/26"
Where is UNIX_TIMESTAMP() put column name.
