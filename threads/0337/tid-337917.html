Infinity90 Admin System / Register System / Saving System
Introduction
I've been board lately so I decided to create a register / admin system that saves everything so, for most beginners here is the system and all it's features and information and installation!

Features!
* Admin Commands
* Saves Stats / Money, Score, Deaths, Kills, Account
* Passwords on register are hashed
* v2.0 Added More Commands
* Report And Mute System!
* Added /general So Players Know The Future Commands

Commands Below!
pawn Code:
Admin Level 1 - /kick /ban /a /freeze /unfreeze /cnn /report
Admin Level 2 - /clearchat /teleports /pos /car /hit
Admin Level 3 - /banip /unbanip /givemoney /jetpack /health /armour
Admin Level 4 - /makeadmin /giftall
More Commands Comming In V2.0

Credits
YSI!
Me Of Course!


1) Download The File
2) Compile It / Run it
3) Create A Folder Called "Users" In Your Scriptfiles Folder
4) Run The Game / Register In Game
5) Check Your Stats In The Users Folder, Your Account Should Be There
6) Want To Be Admin? In The Users Folder Open The Players Account, Where It Says Admin=0 Set It To What Ever Rank You Want The To Be Highest Admin Rank Is 4 And Lowest Being 1, If You Want To Remove Them From Admin Put A 0 There.
7) How To Make Others Admins? Use /makeadmin [id] [Admin Level]


Requirements
ZCMD
SSCANF
FOREACH
YSI/INI
