some newbies asked for the coordinates so i decided to make a tutorial to find coordinets. there are to
Coordinates:They are just like location points in sa-mp coordinates are used for the location of a player forexample: Getting their location and then sending someone to their location e.t.c

Coordinates are X, Y and Z. In a 2d image there are only 2 coordinates, x and y. The Y shows the height of an object and the X shows the width of an object. In a 3d world like Sanandreas there are 3 coordinates, X, Y and Z. Here the Z is used for upward direction.

Here is how to save coordinates:
way 1
in this way you go in the game and do /save
Then go in your samp directory which will be in your documents the txt file will written as savedposition
way 2
in this way you go in the game and do /rs This will only save raw data
Then go in your samp directory and find rawposition.txt in this file cordinates will written
