Suicide Bomb System

Hello Everyone,

I created this filterscript two or three weeks ago so today I decided to update it with more features. In Latest Version 1.2 having four commands. You can see all commands by using /bombhelp. There are three types of bomb i added in latest version you can set all bomb range from 1 to 30. Those players who are inside that range will get random anim also random drunkLevel and more blood &amp; body parts effects that show they are injured and after 8 seconds they will die. Now in briefcase bomb there is chance of bomber to survive if he run outside the range of bomb in 10 seconds and In suicide Jacket &amp; In vehicle bomb there is no chance for bomber to survive he will die after 8 seconds. Thank you Devon &amp; Culln for testing and suggestions.

Features
  • You can set the range of your Bomb from 1 to 30.
  • Added random anim effects.
  • Added random drunk level effect.
  • Added auto attachable injured body object.
  • Added briefcase bomb system.
  • Added warning countdown before exploding briefcase.
  • Added text countdown on briefcase object.
  • Added blood object viewable if player is in range of any bomb.
  • Added suicide bomb Jacket.
  • Updated vehicle bomb system.
  • You can use 1 bomb at a time.
Videos
  • ******* Version 1.2

How it work?
  • Download filterscript from any given link below.
  • Put BombSystem.amx and BombSystem.amx in your filterscript folder.
  • Open your server.cfg file write BombSystem in front of filterscript then save it.
  • For Version 1.0 use /sbomb /cbomb /bombhelp.
  • For Version 1.1 use /sbomb [range 1 to 15] /cbomb [range 1 to 15].
  • For Version 1.2 use /sbbomb [range 1 to 30] and /sjbomb [range 1 to 30] /cbomb [range 1 to 30].
