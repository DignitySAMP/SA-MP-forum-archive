Hello, I have a problem with my friends seeing my server. Please don't take me for granted though, because this is a very odd problem.

In my screenshots I have replaced my actual external IP adress with "external ip" to avoid any server advertising.

Previously I had an ISP without any problems, I didn't even have to port forward my ports for my friends to see the server, it was just like everything was going per automatum, however with that ISP I had a dynamic IP adress, and it was very annoying to check my IP every day and then update the forums with the new one.

Now I have changed my ISP and by doing so I have acquired a static IP adress. I also have a new router along with it, the D-Link DSL-2750B. However now my server is acting very oddly. As you can see I have forwarded the port that my server uses, which is 7777. http://i.imgur.com/bC0tTxF.jpg
However, even though the port being forwarded for both TCP and UDP, I still can't see the server in the SA-MP browser, neither can I connect to it.

While having my external IP adress (which the public can use to connect to the server) in the SA-MP browser, it only updates sometimes. This is what it looks like before updating: http://i.imgur.com/t2K6gGn.jpg
And then after I click on it, however after that it freezes and wont update more: http://i.imgur.com/NpICPmV.png

The server monitor finds it, however when pinging from Texas or the UK it can't connect. http://i.imgur.com/TWiceMj.jpg

When I use PF Port Checker by Portforward.com, it says that the port is found by TCP, and that it is open (both with server opened/closed) like this: http://i.imgur.com/NTykJqD.jpg
However when I try to check if it's found by UDP, I get the following error: http://i.imgur.com/Iuhm4jf.jpg and http://i.imgur.com/YeTJmbT.jpg
When I close the server and check by UDP, I get this: http://i.imgur.com/HOcbBdl.jpg

I have called my ISP two times, but both times I assume that I ended up with people who does not know anything about it, so they could not do anything about it, and I get tired of waiting in the phone queue.

I can only connect through by using the IP adress 127.0.0.1, by using hamachi or by my internal IP adress 192.168.1.2.

Any help is greatly appreciated!

I solved it!

Alright this is the story, first I went into my router setup after some googling about my router, and it said Dynamic IP (automatic settings) so I changed it to Static IP (manual settings) and messed around some with the network card settings. The internet went down for my brother so I changed everything back to normal and it worked again. After all of that I browsed through the settings on the router, first I checked Port Forward which was at the top, however I had already portforwarded port 7777 so it was pretty useless, then under Port Forward there was something called Application Rules, not knowing what this was I went in to check, and it said "This option is used to pre-configure single or multiple trigger ports on your router that will automatically activate when the router senses data sent to the Internet from one of these applications.", which sounded a lot like the stuff I had before I changed ISP and router, so I filled in 7777 as trigger port and 7777 as firewall port, then I saved it and restarted my router, then I opened my server and it worked! So right now I'm overwhelmed with happiness since I've been searching for several days for a solution!
