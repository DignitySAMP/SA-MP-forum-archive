Drug System + Anti-Drug Squad
v1.0
Hello... i made this filterscript for my dear samp community ... like it share it
Features:
Features for this system are following:
*With using command: "/drugs" you can buy drugs and a health booster.
*There are 5 different Grams. of drugs which have different effect they are following:
---------------------------------------------
1). 20g drugs for $10000 - Effect: (health + 20)
2). 40g drugs for $20000 - Effect: (health + 40)
3). 60g drugs for $30000 - Effect: (health + 60)
4). 80g drugs for $40000 - Effect: (health + 80)
5). 100G drugs for $50000 - Effect: (health + 100)
---------------------------------------------
*With using command: "/takedrugs" You can use that particular drug pack
*You can carry only one drug pack if you want to other you must throw away previous pack.
*With using command: "/throwaway" you can throw away your particular drug pack.
*There is an health booster to boost up your health.
*You can buy booster using "/drugs".
*With using command: "/boost" you can use health booster.
*Booster is dangerous for health. It has multiple results.
*If booster result is positive then your health will become 100%.
*If booster result is negative then you will die.
*you can use a drug pack multiple times (per life (if bought)) - Due to timers.
*You can use booster only one time (if bought).
----------------------------------------------
*There is an Anti-Drug Squad which search players for drugs.
*There are 2 checkpoint one on LV-SF Highway. other is on LV airport.
*There are automatic gates on checkpoints.
*You must stop on checkpoint before proceeding.
*To open gate on checkpoint use "/opengate".
*if you are carrying drugs then soldiers will catch you.
*If you are luck then you can escape from there (difficult xD 20% Success)
*If you caught then there will be some options before you.
*Options are following:
1). Death - You can choose death.
2). Fine - you can pay fine $150000 (in v1.0).
3). Arrest - You can hand over to the soldiers.
4). Bribe $15000 - You can bribe solders (if he accepts then you will go..)
(if bribe is refused then you will die!)
*On Player death drug items will be removed!
(You can request more customs checkpoint if you want.)
**v2.0 in progress more features!
