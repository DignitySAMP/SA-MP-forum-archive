zDivine's Admin System [zAdmin]

Script Release: 20130516 (YYYYMMDD)
Latest Script Version: 1.0.1.0


Features:
  • ~ VERSION 1.0.0.0 ~
  • Automatic file creation for missing scriptfiles.
  • Dynamic server settings for anti-cheat, spawning, and skins.
  • Dynamic command levels, allowing you to set the level for each command in game via dialogs.
  • Register and login with player file saving.
  • Unique banning system.
  • Four Admin levels.
    ~ VERSION 1.0.1.0 ~
  • New VIP system with 5 default commands.
  • Dynamic VIP command levels.
  • Tog-gable zAdmin health system.
  • Tog-gable VIP alerting.
  • More Admin commands.
Commands:
  • ~ VERSION 1.0.0.0 ~
  • /editcmds - Allows you to edit the commands levels.
  • /setadmin [playerid] [level] - Allows you to set a players Admin level.
  • /kick [playerid] [reason] - Kicks the specified player.
  • /ban [playerid] [reason] - Bans the specified player.
  • /unban [account name] - Unbans the specified account.
  • /banip [IP] - Bans the specified IP.
  • /unbanip [IP] - Unbans the specified IP.
  • /freeze [playerid] - Freezes the specified player.
  • /unfreeze [playerid] - Unfreezes the specified player.
  • * zDivine slaps [playerid] [height] around a bit with a large trout. - Slaps the player, setting their Z coordinate to the specified height.
  • /isolate [playerid] [time(minutes)] [reason] - Sets the player 2000 feet in the air for the specified time.
  • /unisolate [playerid] - Unisolates the specified player, putting them back on the ground.
  • /sethealth [playerid] [health] - Sets the health of the specified player.
  • /setarmour [playerid] [armour] - Sets the armour of the specified player.
  • /givegun [playerid] [weaponid] - Gives the specified player the specified weapon.
  • /givecar [playerid] [vehicleid] - Gives the specified player the specified vehicle.
  • /takeguns [playerid] - Resets the specified players weapons.
  • /goto [playerid] - Sets your position to the specified player's.
  • /gethere [playerid] - Sets the specified player to your position.
  • /explode [playerid] [type(0-13)] [radius] - Creates an explosion at the specified players position with the specified type and radius.
  • /setskin [playerid] [skin] - Sets the specified players skin to the specified skin.
    ~ VERSION 1.0.1.0 ~
  • /freezeall - Freezes all players.
  • /unfeezeall - Unfreezes all players.
  • /getallhere - Teleports all players to your position.
  • /kickall - Kicks all players
  • /ann [message] [time] [style] - Sends game text for all players with specified time and style.
  • /setcolor [playerid] [color] - Sets the specified players color to the specified color.
  • /makevip [playerid] [level(1-4)] - Sets the specified players VIP level to the specified level.
  • /gotoloc [X] [Y] [Z] [INT] [VW] - Sets your position to the specified coordinated and Interior ID / VW ID.
  • /savecfgs - Manually updated all configuration files.
  • /vipalert - Enables/disables VIP alerting.
    ~ VIP COMMANDS ~
  • /vcar [modelid] [color1] [color2] - Creates a vehicle with specified model and colors.
  • /vgun [weaponid] - Creates a weapon with specified weapon.
  • /vheal - Sets health and armour of player to 100.0.
  • /vfix - Repairs the players car.
  • /vc [message] - General VIP chat.

Installation:
  1. Move "zAdmin.amx" to your filterscripts folder.
  2. Create a directory called "zAdmin" in your scriptfiles folder.
  3. Create a director called "Users" in the "zAdmin" folder.
  4. Add "zAdmin" to your filterscripts line in your "server.cfg".
  5. Ensure "sscanf" is added to your plugins line.
  6. Restart your server, and ENJOY!
