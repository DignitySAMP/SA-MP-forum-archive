Without a doubt the best Map i've created

Info
¤ A Big City with ALOT of atmosphere.
¤ 165 objects this time :S, Yet i think its worth it,
¤ Another City based on New York.
¤ Just near the Big bridge off san fierro, which connects it to the boat village... (based on the Golden Gate Bridge, You can use /rnctele to get there though, )
¤ You may edit this in MTA Map Editor under the purpose you are removing objects Only. Because i don't want anyone taking credit for my work...
¤ I Wouldn't want you to remove the OnPlayerConnect Text, cause... Same as before: No one's gonna' know its there + I Like to be credited
¤ Has been FULLY tested.

Features
¤ Trash, (Atmospheric Purposes )
¤ A Basketball court w/ Trash, BMX's...
¤ Alot of buildings, w/ Signs/Billboards/Adverts
¤ A Liquor store w/ Interior, (Teleport point)
¤ Working Roads
¤ Still some recolored police vehicles,
¤ A Small Dock
¤ Bars
¤ Shops
¤ Police building
¤ Stunt ramps
¤ Statues
¤ Lots of deco, Hardly any non-used spaces

Commands
¤ /rnchelp - brings up a command menu
¤ /rnctele - teleport to the Liquor store in the town
¤ /rncteleroof - teleport to a roof w/ Maverick.

Bugs And Errors
¤ None, so far so good, :P
¤ Please report any bugs/errors to me, Or if you can, + willing to, DIY, (Do it yourself)
