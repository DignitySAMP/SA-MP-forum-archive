EliteDrift

This is a new drift gamemode fully scripted by me. It is very tidy and has no warnings, dialog based, there are some great commands and other different things like auto nos, 2 key repair etc.

Version2.5:

Whats new in version2.5?:
removed vehicle fixed writing when fixing a vehicle
added fallout's speedo
added name color changer dialog
New count system
Removed /cc
added reaction test
added time and date textdraw
Added fps counter
"apsf" writing fixed



Server Commands:

/cmds: /teles /flip /health /getcash /parachute /afk /back /credits /rules /kill /day /night /rainbow /rainbowoff /count /pimp /veh /world0-10

/teles: /drift1-20 /airports /tune1-3 /bombshop /ls/lv/sf /paynspray /beach /stunt1-3

/airports: /apsf /apls /aplv
--------------------------
Other Features:

"2" button vehicle repair
Random messages
Server rules dialog when player joins
Everything dialog based
Added saved vehicles
Custom character request position
Drift style nitro
TextDraws
Tips along the way
AFK system with textdraws, god and freeze modes.
All characters
Player Join/Leave messages
"Unknown command" message changed
Player has to accept rules
Vehicle menu

----------------------------------------------------------------------
It has all that a good drift gamemode would need.
But, we are missing few things that we will add in V2 like car spawner, neon, wheel dialog and more comming soon!
