Coloque isso no final do gamemode/filterscript:
Code:
forward DelayedKick(playerid);
forward DelayedBan(playerid);
forward DelayedBanEx(playerid, reason[]);
forward Ban2(playerid);
forward BanEx2(playerid, reason[]);
forward Kick2(playerid);
public DelayedKick(playerid) return Kick(playerid);
public DelayedBan(playerid) return Ban(playerid);
public DelayedBanEx(playerid, reason[]) return BanEx(playerid, reason);
public Kick2(playerid) return SetTimerEx("DelayedKick", 400, false, "i", playerid);
public Ban2(playerid) return SetTimerEx("DelayedBan", 400, false, "i", playerid);
public BanEx2(playerid, reason[]) return SetTimerEx("DelayedBanEx", 400, false, "is", playerid, reason);
Depois substitua "BanEx" por "BanEx2" nesse seu comando.
