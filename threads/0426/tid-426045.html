Hello,
So yesterday i decided to make the gamemode better, it
didn't take long, but it gave me something to do. Hope
you like it.

VVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVV VVV
--------------------------------------------------------------------
I Have updated again, A few minor changes. The anti team kill works fully,
across classes. The script is cleaner and it has come as far as a base script
can... Not very far. Hopefully i shall add some means of achievement into the script,
but i will not add a login or any data saving. Enjoy.
--------------------------------------------------------------------

So i have updated the gamemode to v2.0 and it now has the following
features.

2 Teams (Police | Terrorist).
4 Classes (Police, ARMY | Terrorist, Terror superior).
Anti spawnkill.
Different weapons for each class.
You no longer keep the /rduty weapons.
Dialogs (/commands, /info, /rules).
When selecting a team, you can now see your avatar on the screen.
2 teams require 2000 score to be able to use.

Possible that police cant kill army and army cant kill police,
terrorist cant kill terror superior and terror superior cant kill terrorist, but
i have not tested the anti team kill!
VVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVVV VVVVVVVVVV
------------------------------------------------------------------------------


TEAMS

Terrorist - Deagle, Combat shotgun, AK-47, Knife, Molotov's. "Team color = red"

Police - Deagle, Combat shotgun, M4, Knife, Grenades. "Team color = blue"

Terror-superior - Deagle, Sawnoff shotgun, AK-47, chainsaw, sachel charges. "Team color = red"


ARMY - Deagle, Sawnoff shotgun, M4, chainsaw, sachel charges. "Team color = blue"

--------------------------------------------------------------------------------------------------------

Anti spawnkill

The anti spawnkill lasts for 5 seconds and
will only come on when spawning, it provides
2 messages, one to tell you that spawnkill is active
and one to tell you it is not-active.


this shows anti spawn kill, plus some of the random client messages.

-------------------------------------------------------------------------------------------

Dialogs

Before there was unclean text in the chat when you uses
the commands, but now the gamemode uses dialogs to
keep it clean and smooth.

Commands
The is only 4 commands in the gamemode and
only one has stayed the same, which is /kill.
The commands are /commands, /rules, /info and
/rduty. Now /rduty is not show under the /commands
unless you are logged into the RCON and you can turn
/rduty off by using the same command again.
When /rduty is on, your ingame color is changed to
the admin color "smooth green" and you have godmode on
with some special weapons.

When you are RCON admin

Jarvis
Jarvis is something i added to spice the server up

the admin color "smooth green".

Bases
Police base - the police base is the abandoned airfield and
it has some vehicles that i added to the map.

Terrorist base - the terrorist base is area51 and it has some
vehicles that i have added to the map and i have also blocked off

Each base has the same amount of everything.

Originally Posted by jmh

you just forgot the admin commands like kick, ban, mute, jail
Ahh, well this is a gamemode for people to edit and mess around with,
that is why i didn't add /kick and other admin commands, because it defeats
the point. I have made this so a less experienced players can grab this and
make a unique server in a limited amount of time, because an inexperienced
player doesn't want a login system, admin commands, or an anti cheat
scripted into the gamemode, unless it is a very good anticheat, admin system
this is because they would much rather use a pre-made admin system like
0admin, which comes with a login and anticheat.


Adding admin commands would just make players have to remove them, but
i have added /rduty because some admin systems don't have a on duty command
and so instead of the players having to go and make a on duty command, all they
have to do is use there admin system include to set the required admin level for
the onduty command.

This script is made for people to edit and use as a base, not for players to run as
there server gamemode how it is, you can if you want, but it wouldn't be a very
exiting server. This just helps players in creating a server.

Wait for 3.0, i should be adding more stuff, but still keeping it a base script!

Thanks for the feedback.
