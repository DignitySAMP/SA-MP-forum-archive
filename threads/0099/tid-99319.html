Modified SAMP Cursors / Arrows



Well, basically its a modification from SAMP 0.3 cursor, i was bored, soo ive worked on these new arrows / cursors.
Its very very easy to install, just go to your GTA SA directory ( the place u have installed SAMP 0.3) usually located at:
C:\Program Files\Rockstar Games\GTA San Andreas
and replace the "mouse.png" file by the one you would like to be your new cursor.
(Note: The mod files are inside separate ZIP files to avoid any mistakes)


PS: I want to thank "Vortex" for creating a server on 0.3 so i could test these.
