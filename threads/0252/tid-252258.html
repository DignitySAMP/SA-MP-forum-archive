Introduction
Sorry for the bad english, I'm italian! raiden96ita it's my very old nickname on sa-mp. Now I'm Francesco_Ronaldo or The_Blade.
Today I show you the gm that I scripted in recent times, with which I have decided to add some roleplay to the deathmatch.
It is a beta version, which has 5035 rows. According to my point of view, is better than the previous versions of scripts, fun, and manageability. It was scripted by 0, without copying other gamemode scripts.
Inside you can choose to join a gang, a public service (police, medical) or a normal citizen in search of work.
There are the following factions: Groove, Ballas, Vagos, Atzecas, Triad, Bikers, Police, Doctors, Citizens.

Description
Here's the script that it contains:
- Register system with dialog, using the Dini.inc;
- Small anticheats: AntiBanWeapons, AntiSwear, AntiHighPing, Anti-Spam, AntiJetpack;
- Votekick, if the Admins are absent;
- Bank system with dialogs (bank accounts, deposits, withdrawals);
- Numerous interior to interact (Well Stacked Pizza, Disco, clothes shops, Burger Shot, etc.);
- (for now) three jobs, who can play only citizens, Pizzaboy, Seller HotDog, a truck driver. First we must go to city hall to apply for work permit;
- Admin System, with a home and some private vehicles;
- Interiors for all thegang;
- GPS system;
- Rob the bank system;
- Real Time;
- Ability to select / reset your respawn area;
- Userpanel (Stats, Change Password, Reset Stats, Delete Account);
- TeamChat by Peppinux aka Peppe_stasu with the # sign (example: #Hello to all);
- Turning the engine and headlights off button;
- Drug system with effects;
- Actions (except entering the server guy, guy kills) are displayed using the function SendNearMessage (created by me and Peppinux) that lets you hear only if you are near the action;
- Clothing system(glasses, helmets);
- PayDay for doctors and policemen;
and much more!
