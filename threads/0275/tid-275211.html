The game mode is based on the show LOST.

Offical server
HostName: Aerolite Gaming - LOST Roleplay
Address: server.aerolitegaming.co.uk:7778
Mode: Lost Roleplay
Map: The Island
Forum: http://aerolitegaming.co.uk/
Features
• - Working.
• - Bugged / Half working
• - Not done / Not working

• Hunger System - Have to eat to survive

• Thirst System - Have to drink to survive

• Fish System - You have to fish for food, I was going to add animals to hunt, But it never happend.

• Admin System - Not all the commands show in /ah

• Registration & Login System - You can register & login to recover your stats, Not worth to mention, i know.

• Level System - You can use /levelup to level, When you reach level 7, You can choose to stay as surivor, Or join The Others

• Faction System - 2 factions, Survivors & The others

• AntiCheat System - I scripted a simple anti cheat, But its currently commented. But if you un-comment, Admins are immune to the admin cheat

• Newbie channel - Added a newbie channel, (/n)ewbie

• Mute System - When you mute someone, They will still be muted if they relog.

• Wood System - You have to cook your food before you can eat it, I added /chopwood or a command like that, You
need to have a knife to chop it down, Was supposed to add an axe or something like that, But that never happend.
Cook System - You can start a fire with /lightfire to start cooking, and then eat
Waterbottle System - You need to find a waterbottle to drink, And you need to find a river to get water. And do /fillbottle

• Talent System - When you register, You can choose a talent. They are based from the characters in lost.

• V.I.P System - This is not 100% done, But it got some features. /makevip

• Saving POS when logging out - When you log out, Your position will save, And when you login again, You will spawn there.

• Backpack System - You can only carry some stuff, But if you find a backpack, You can carry more stuff. This is currently a little bugged, You will find more information if you scroll down.

• Accent System - You can choose a accent

• Drug System - You can find some herioin around the island, But if you choose your talent as Drug Addict, You will spawn with unlimited heroin.

• Walkie Talkie System - You can also find a walkie talkie, But when you find it, Its broken. You need to find a tech to fix it for you. The others spawn with walkie talkies.

• Inventory System - Almost the same as backpack system, do /inventory to check your inv!
Known Bugs
• Yellow screen - Some SA-MP Clients will get the yellow screen, I'm hoping to fix it.

Please report any more bugs if you find any
