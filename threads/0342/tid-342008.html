Hi, you know that feel when you immediately need ID of vehicle or other model but you don't want to quit game or press alt+tab so created new FS.

What is Showroom ?

ID Showroom showing vehicle IDs, weather ids, explosion ids, skin ids, sound ids, interior ids, pickup ids. All with prewiev.

What FS include ?

You can show ID and model in game.

Commands :

/start showroom - Start showroom
/showme - Create 1st dialog with other sub-menus

FS include these:

FS have these commands :

/showvehicles - Show main menu of vehicles (they are in many sub-category)
/showinteriors - Show 1st page of interiors (have several pages)
/showsounds - Show 1st page of sounds (have several pages)
/showpickups - Show main menu of pickups
/showskins - Show main menu of skins (have some sub-category)
/showweathers - Show 1st page of weathers (have several pages)
/showexplosions - Show main menu with explosions

FS have very much dialogs and after click on some listitem dialog gone hide. So you can press L. ALT and it shows last opened dialog, and if you want more back you can clicking on 'Back' button.

Next function is command /testit

It is able only when you showing vehicle models. After type this command you can drive/fly with selected vehicle and save it anywhere you want (/save).

You can type command /savetp or /settp

/savetp - Save your position
/settp - Set your position with selected vehicle

How it all works ?

Interiors

After select interior FS warp you into interior and enable walking. Shows interior ID and coords on monitor. So you can /save your positions there.

Weather

FS set camera on sfing in Las Venturas (near pyramid) and after select chynging weather and showing ID.

Skins

FS warp player on the roof in Los Santos and after selecting changing players skin and showing ID and name (for example Sweet)

Sounds

FS get player position and playing selected sound and showing ID of it. Some sounds are very long so you can stop them by select '<name of sound> STOP' from dialog or type /stopall.

Pickups


FS set camera on some place near skin camera place and after selecting changing pickup and showing ID and name of it (for example Armour).

Vehicles (planes, helicopters, cars, boats, trains...)


FS set camera on pos near skin camera place again and after select changing vehicle model and showing ID and name of it. You can type /testit and drive with selected vehicle. (except trailers).

Explosions


FS set players camera again near skin camera place and after select create explosions and showing ID of it.

Technical infos:

FS is only for one person.
FS have five textdraws.
FS have 4 thousand lines.
FS NEVER create more than one vehicle or one pickup at once.
Is recommended that don't run more FS or GM with dialogs (dialog conflicts).
