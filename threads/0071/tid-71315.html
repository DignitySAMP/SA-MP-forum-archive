I doubt this is a host problem, any standard host I am sure would have updated files and proper permissions.


If your host isn't in the Internet list then your announce isn't getting through. Make sure that you update your announce executable (linux) or announce.exe (windows) with the newest version from the 0.2X server package that suits your server environment. Also be sure to allow in your firewall the announce file and especially 'server.sa-mp.com'.
