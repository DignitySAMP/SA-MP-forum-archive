[Map]Los Santos Army Base

The gates

I added some gates aswell, but you DON'T have to use it, it is optional. There are some pictures of the gates in the screenshots above. There are two gates, you can open/close both of them. You can convert the commands to what ever command processor you're using. Here is the code:

pawn Code:
/* At the top of your script */
    
new
    ArmyGate1,
    ArmyGate1x1,
    ArmyGate2,
    ArmyGate2x1;
    
/* Under OnGameModeInit */

ArmyGate1 = CreateObject(988, 2720.09863, -2409.03052, 13.49358,   0.00000, 0.00000, 269.67648);
ArmyGate1x1 = CreateObject(988, 2720.17090, -2403.59082, 13.49358,   0.00000, 0.00000, 269.67648);
ArmyGate2 = CreateObject(988, 2720.13940, -2506.47241, 13.49358,   0.00000, 0.00000, 269.67648);
ArmyGate2x1 = CreateObject(988, 2720.19287, -2500.99463, 13.49358,   0.00000, 0.00000, 269.67648); 

/* Your commands - NOTE: You need ZCMD to use the following commands */

CMD:army1open(playerid, params[])
{
    MoveObject(ArmyGate1, 2720.06641, -2411.34473, 13.49358, 2);
    MoveObject(ArmyGate1x1, 2720.20386, -2399.67432, 13.49358, 2);

    SendClientMessage(playerid, -1, "[GATE INFO] You have sucesfully opened the Army gate!");
    return 1;
}


CMD:army1close(playerid, params[])
{
    MoveObject(ArmyGate1, 2720.09863, -2409.03052, 13.49358, 2);
    MoveObject(ArmyGate1x1, 2720.17090, -2403.59082, 13.49358, 2);

    SendClientMessage(playerid, -1, "[GATE INFO] You have sucesfully closed the Army gate!");
    return 1;
}

CMD:army2open(playerid, params[])
{
    MoveObject(ArmyGate2, 2720.18555, -2510.18896, 13.49358, 2);
    MoveObject(ArmyGate2x1, 2720.14160, -2497.48047, 13.49358, 2);
    
    SendClientMessage(playerid, -1, "[GATE INFO] You have sucesfully opened the Army gate!");
    return 1;
}
