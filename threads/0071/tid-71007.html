Hi all

There is a new Administrator Filterscript Ready
I created a big script that you always can use for your server

  • Administrator Level System, 10 Admin levels, A Level system that accept you to have Admins on your server with different levels.
  • Player Variables, These Variables will save The player stats like IP, Adminlevel, Name, Money, Kills, Deaths, etc...
  • A Special Bank system with 3 difference commands to control your bank money: deposit, Withdraw, balance, transfer.
  • A register/Login/Logout System to control your stats
  • Configuration System to configurate all includes of this Filterscript
  • Ping/Kick System, if there is a player in your server wit ha High ping it will automatically Kick that player
  • Advanced votekick system with multipe Textdraws and Commands like: votekick, vote, stopvote.
  • Advanced Player Spectate system that spectate the Vehicle + player so not only in the car
  • A Admin chat system, if you type #hello in the chat then the other online admins will see Hello only the admins
  • And much much much more, I checked the Filterscript on my server and it's Great!
The configuration Files:

the configuration files are placed in the scriptfiles folder and contains the collowing files:
  • Badwords.ini, In this file will be saved the badwords example if i have in that file fuck and i type that ingame then i see ****
  • ForBiddenNames.ini, In this file will be saved the Badnames example if i have in that file fucker and i join with that name i will be kicked/banned
  • Online.log, In this file will be saved the Joined players that day then you can see ingame to! to player join time and IP
  • Commands.ini, in this file will be saved the Commands if i have in that file kick=8 then i need Administrator Level 8 to use the command kick
  • Configuration.ini, here will be saved all configurations example if i change in that file pingkick=1 to pingkick=0 then the pingkick is disabled
The user Files:
  • In this folder will be saved all PlayerNames + variables:
    • IP, if the player Register then the IP will be saved here example: 127.0.0.1
    • Registered, if the player is registered then here will be stay 1
    • AdminLevel, if the player is a Admin then his Administrator level will be saved here (0 = No Admin)
    • Password, if the player register then here will be saved his password IN HASH !
    • logged, if the player is registered then here will be saved if he is logged in if he is then he will login automatically
    • score, if the player left the server then here will be saved his score and if he start the Game again then he get his score back
    • ShowName, if the Player is admin and he ban someone and he don't want everybody see his name then The server hide the name to: **secret**
    • Muted, if a Admin has muted this player and he Join again then he is still muted
    • money, if the player left the server then here will be saved his money and if he start the Game again then he get his money back
    • kills, if a player kill any player then here will be +1
    • deaths, if the player dies then he get +1
    • Jailed, if a Admin has jailed this player and he Join again then he is still Jailed
    • servertimes, if the player join the server then here will be +1
    • Cmds, if the player type any command then here will be +1
    • Kicks, if a Admin/Pingkick kick this user then he will be get +1
    • Trust, if the player is trusted by a admin then it is: 2 if normal 1 if not 0
    • Bank, here will be saved the bank cash
    • Banned, if this player is banned then he will get Banned=1 and then if anybody spawn with the same name and he login correctly then he will be banned for ban evade
