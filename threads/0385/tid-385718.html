DiGiTaL DeathMatch™ v2.0

by DiGiTaL AnGeL™



Introduction
Hi! I present you the 2nd version of DiGiTaL DM. It represents a dm system + a map, which has 190 objects. It's perfect for dm/stunt servers, and you can use it, but keep the credits.

What's new?
~**~ Added 2 teams: CTs & Terrorists
~**~ Added new tp commands
~**~ Added different weapons on each team
~**~ Added different skins o each team
~**~ Added /leavedm command(idea of jens26)
~**~ Added cmd for informations about the script

Weapons
CounterTerrorists Weapons
Knife : 1 ammo
Grenade : 1 ammo
Silenced Pistol : 999 ammo
MP5 : 999 ammo
M4 : 999 ammo
Sniper : 100 ammo

Terrorists Weapons
Knife : 1 ammo
Grenade : 1 ammo
Desert Eagle : 999 ammo
Micro Uzi : 999 ammo
AK 47 : 999 ammo
Sniper : 100 ammo


Commands
/joinct -> Teleports you to DDM as an CT
/jointerro -> Teleports you to DDM as a terrorist
/leavedm -> Respawns you
/ddmhelp -> Shows you some infos about the script
/ddmcredits -> Shows you the credits of the script

Credits

Scripting -> DiGiTaL AnGeL
/leavedm idea -> jens26
