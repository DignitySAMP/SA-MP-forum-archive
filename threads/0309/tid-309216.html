Riverwood Roleplay


Note: Original script has been created by ImprezBart

Script introduction

I've decided to edit a script a friend of mine made, i'm not that good at scripting so please do not expect great things from me. I think i will be releasing updates for this script, it pretty much depends on what you guys think about the script.


__________________________________________

Script Information

Current Features: Login & Register system, Basic roleplay commands, 15 Administrator commands, 4 Basic jobs, Unfinished vehicle System, Cocaine drug, Basic Level & Payday system, Statistics


__________________________________________

Commands

Administrator Commands:

Code:
Usage: /kick (playerid) (reason)
Function: Kicks the target from the server.

Usage: /ban (playerid) (reason)
Function: Bans the target from the server.

Usage: /unban (account)
Function: Unbans the target from the server.

Usage: /veh (vehicle) (color 1) (color 2)
Function: Creates a vehicle infront of the player who used the command.

Usage: /vehplayer (playerid) (vehicle) (color 1) (color 2)
Function: Spawns a vehicle at the targets location and put the target in the vehicle.

Usage: /addnos (playerid)
Function: Adds NOS to the targets vehicle.

Usage: /makeadmin (playerid) (level)
Function: Will make the target the selected admin level.

Usage: /rconadmin (playerid) (level)
Function: Will make the target the selected admin level.

Usage: /makebeta (playerid) (level)
Function: Will make the target the selected beta level.

Usage: /sethp (playerid) (health)
Function: Will set the targets health to the amount you entered.

Usage: /setstat (playerid) (number) (amount)
Function: Will set the targets selected stat to the selected amount.

Usage: /goto (location)
Function: Teleports to the selected location.

Usage: /setskin (playerid) (skin)
Function: Will set the skin of the target to the selected skin.

Usage: /gotoid (playerid)
Function: Teleports to the target.

- Added in v0.3

Usage: /makeleader (playerid) (faction)
Function: Makes the chosen target leader over a faction.

Usage: /givegun (playerid) (gun)
Function: Gives the target a gun.
Player Commands:

Code:
[General Help]: /usecocaine /join /kill /quitjob /drop
[Chat Help]: /b /o /me /shout /do
[Weapons Constructer]: /getmats /sellgun
[Mechanic]: /fix /addrims /addnos
[Drug Dealer]: /getcocaine
