Quote:
Originally Posted by -Luis

How'd you make this? I'd love to do something like this for my server, like auto refreshing server stats etc.
Making "auto refreshing stats" is easy, if you look at the source it just gets updates from one PHP file and all that does is read the database and return the values. As long as you're storing the number of players on your server in a database somewhere (or whatever other information you want to have) it's really quite easy.

Also I've been informed that the reason for the difference between this counter and the SA-MP site (i.e. this counter was always much higher than the SA-MP count) is because theirs filters out "fake servers". I have no idea how to detect these - whether they have a list of them or can detect them some other way I don't know, but until I can do this then my count isn't entirely "accurate".
