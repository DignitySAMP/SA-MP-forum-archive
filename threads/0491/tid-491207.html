FractalBB is now available on our own website: http://www.fractal-hub.com! We hope that everybody enjoys the software and I aim in the next few days to add some more knowledge base articles as well as make additions to the module system, since Codeigniter is not a HMVC framework it is quite difficult to create a module system however so far it seems to be going well.

What is it?

FractalBB is a complete bulletin board (forum) and content management system with SA:MP in mind, developed upon the Codeigniter framework which allows for complete control template and theme wise. By default it comes with a fairly basic template which should be used for all templates created after the initial release.
