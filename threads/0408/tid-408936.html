All of you are wrong. Download this plugin from here which fixes the "File or function is not found" error. It is called nativechecker

Windows - http://www.solidfiles.com/d/5c0a/

Linux - http://www.solidfiles.com/d/0c45/

Now do this. Once you have the plugin, go to the Plugins folder, place the plugin which you just download in there. Now open server.cfg, go to your plugins line and add this to the very end of the line. In your case it is,

Code:
plugins audio mysql sscanf streamer nativechecker
Then save it and it should work. If you have it and it doesn't work, I suggest you delete the current nativechecker, then update it here,

Windows - http://www.solidfiles.com/d/5c0a/

Linux - http://www.solidfiles.com/d/0c45/

And it back to the END of the plugins line. For example,

Code:
plugins test1 test2 test3 nativechecker
So remember to add the nativechecker to the end of the line. And make sure you have it in your plugins folder.

I hope I have helped you


IMPORTANT (READ THIS)

Also re-download your streamer plugin from here because you current streamer plugin is not working,

http://www.solidfiles.com/d/34cfba15ff/
http://www.solidfiles.com/d/552c69964c/

Download both of them, then replace it with the old ones in the plugins folder. When you download it, you should get this file,

Code:
streamer.dll
streamer.so
Hope I helped you
