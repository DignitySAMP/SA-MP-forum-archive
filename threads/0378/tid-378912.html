Dynamic Dialog Maker By AF


Introduction
This Is my first published filterscript.
What it does is making dialogs In Game and allowing the user to preview the dialog and save it

Features
It's fully dynamic!
It supports all dialog types!
It is easy to use!
It is useful for newbies!


Download Link and Installation

PasteBin
MediaFire
SolidFiles
Change the format of the file to .pwn and put it in the filterscripts folder(you need y_Commands in order to run this filter script.it's easily findable at YSI package)
Add the filterscript's name at the server.cfg in front of the filterscripts
YSI Include

Credits
Me-Scripting the filter script
Ricardo Manuel Viegas Rodrigues-Helping me to solve my problems
******-Making Y_Commands

How to use
When you are in game enter /dia in the chatbox,Dynamic Dialog maker will appear(It contains some dialogs that are easy to understand,just read them!)

Bugs
Nothing Found Yet!
if you find any, post a reply
Important Notice
This version doesn't support the editing feature for dialogs,it will be added in the next update
