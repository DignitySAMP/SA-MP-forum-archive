Quiz System by RenovanZ
Create your own Quiz
Now on v3.0
Hey!
Hey all, I want to release one of my script. This is my first release on this forum

What is this filterscript?
This filterscript can make custom quiz with easily IG! (with rewards).
For more detail, check the SS/Pictures below.

Why its different?
This FS is different than other Quiz System, because:
  • Can create Quiz IG, with 1 easy command.
  • Answer with Parameters, not Dialog List, it'll be more hard than just trying all of the option on Dialog List.
How its work?
Simply.
1.Download the filterscript.
2.Dont forget to download ZCMD (Credits to Zeex), sscanf2 (Credits to ******), and put it in pawno => include.
3.Open the script and compile it.
4.Open server.cfg and write "quiz" besides on the "filterscript"
5.Run the server!

Commands?
/quiz [create/answer/delete/end/help]
  • /quiz create : to create the quiz. (RCON Admin Only)
  • /quiz answer : to answer the quiz.
  • /quiz delete : to delete available quiz. (RCON Admin Only)
  • /quiz end : to end available quiz. (RCON Admin Only)
  • /quiz help : to see all the script commands and the function.
