Car Sumo
Working time : 30 min

Add at the begining of your [GM] this :
Code:
forward SetPlayerRandomSpawnCarSumo(playerid);
and don't forget to add these teleports :
Code:
new Float:gRandomPlayerSpawnsCarSumo[4][0] = {
{-3740.9761,-2203.2773,56.3900},
{-3631.9656,-2203.1504,56.3900},
{-3631.6462,-2314.3279,56.3900},
{-3741.8821,-2311.2261,56.3900}
};
In your teleport add this :
Code:
SetPlayerRandomSpawnCarSumo(playerid);
And put this somewhere in your script :
Code:
public SetPlayerRandomSpawnCarSumo(playerid)
{
    if (iSpawnSet[playerid] == 0)
    {
		new rand = random(sizeof(gRandomPlayerSpawnsCarSumo));
		SetPlayerPos(playerid, gRandomPlayerSpawnsCarSumo[rand][0], gRandomPlayerSpawnsCarSumo[rand][1], gRandomPlayerSpawnsCarSumo[rand][2]); // Car Sumo Others
	}
	return 1;
}
