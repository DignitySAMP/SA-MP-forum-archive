Introduction

•Well after months of releasing Adrenaline StuntWorld Gamemode i am here to release a very simple gamemode named "The Renaissance 2".
•It is a very simple and based gamemode which it has around 5-6 simple features.
•Well i was going to make it very nice but i have stopped developing it from the time i realised i didn't get any help and didn't have time too.


Features

•Using Dini #yes i know i was going to use y_ini but i was bored to change the whole system :P
•Map Changing System every 3 minutes
•Team Balancer
•Team Chat
•Admin System
•Anti-Spawn Kill
•Rank System
•Report Simple System
•Using Nice colorful random messages
•18 Maps + 2 default to change
•Top 5 Kill List

System


•Map Changing System:

--->It uses map changing system which will change maps every 3 minutes.It has a textdraw to show time left for the end of the round.
--->It will show a simple textdraw which will announce that the server is loading new map.

•Report Simple System

--->When the player reports another player it will send admin report.
--->The report will be saved in a .log file named Reports.log

•18 Maps + 2 default to change.

--->It has around 4-6 counter strike maps

--->Other 4 Maps based by other gamemode

--->It has Caspian Border Map

--->Other Call of duty/battlefield ? maps

•Rank System

--->It has textdraws under money which will show how many Kills and deaths you have more kills you get higher rank you gain.

•Anti-Spawn Kill System

--->Holds you with infinity health for 9 seconds+loading map

•Team Chat

--->To use team chat press on chatbox "!" and then text.
--->Example: !chat -->output:[TEAM-CHAT]:chat

•Admin System

--->Will explain it soon

•Anti-Spam

--->Self-explained?

•Will Explain Other Systems soon.
