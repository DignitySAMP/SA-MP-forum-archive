Hey there SA:MP community!

It's been a while since I posted a video here, here's something I made this morning:




http://www.youtube.com/watch?v=ScmfPqW94kE
http://www.youtube.com/watch?v=ScmfPqW94kE




The functions/features are something like this: (subject to change)
Create Line with start pos and destination pos, tell it what model you want to use and how long that model is.

Set a line's destination or starting points.

Set a line's model ID (and new length for that model)

Set rotation offsets because sometimes objects can have different default rotations, a good example would be the Rope and Neon, the rope points upwards by default and the neon is horizontal by default.

Set a line's maximum length, this length is how far the objects can go before they stop being created (Useful for scripts similar to the one I used in the video, that have dynamically changing positions)

Get all the data (point/dest pos, length, maxlength, total objects used, rotation/elevation angles etc)

If you like it, I'll release it when it's all done and tested
