Features

Here's a simple filterscript which allows you to explode occupied and non-occupied vehicles by shoothing at its petrolcaps. Each vehicle has its own unique offset. It's designed for all weapons (except the very heavy ones (rockets, bombs, firethrower) and non-bullet guns (fist, braces, baseball bat, spray, ...). It's quite accurate so it mostly won't explode when you don't shoot outside of the little petrolcap square. The thing that I didn't add but maybe will in future versions is detecting bullets flying out of your gun when you keep holding the fire key - You have to release the fire key to use it again.

Installation

- Download the filterscript. Put everything in the right directory and write the name of the filterscript in "server.cfg".
- Start your server and start shooting the vehicles.

Bugs

There are some bugs in the current version when you shoot from a distance. This is caused due the not-perfect weapon offsets (only sniper works without problems). I will try to fix ASAP. Please be patient.

Notes

- Only report important bugs please.
- Please DO NOT use codes from my filterscript to create new ones related to this. I have plans in future.
