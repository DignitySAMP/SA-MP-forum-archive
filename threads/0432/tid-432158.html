San Andreas Marathon
By Avi Raj

Introduction:
Hello, I Was kinda free for some days so it thought to make a server in which people run with their Legs :P.
So i created one with some admin cmds + Player cmds + Some Races.
It have 5 races at the moment and its too easy to Add races.
Hope you will like it!

What it have:
*Login/Register INI Saving System.
*5 Races.
*10+ Player Commands.
*10+ Admin Commands.
*Easy to create races with /addcheckpoint
*Script, without any Error and Created from scratch.
*Much More!

How to Add Races:
*Start the Server.
*Go In-Game and then go to place where you want to add races.
*Do it until you go to your finish checkpoint.
*Open Scriptfiles folder and open races.txt
*Copy whole codes and put them Under OnGameModeInIt like added before.
*Compile Script.
*Too easy
