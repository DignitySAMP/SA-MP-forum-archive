Se for pra apenas um player, faz como o ReDKiiL disse, cria uma variбvel global e bloqueia o chat.
PHP Code:
// topo
new bool: bloquear_chat;
// comando
bloquear_chat = true; // bloqueado
// verificando
public OnPlayerText(playerid, text[])
{
    if(bloquear_chat) {
        SendClientMessage(playerid, -1, "chat bloqueado");
        return 0;
    }
    return 1;
}
