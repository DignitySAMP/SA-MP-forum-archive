Adding More Colors
You can add more colors by editing this part of the script
Code:

{
        {"Green",  "00FF00"},
        {"Red",    "FF0000"},
        {"White",  "FFFFFF"},
        {"Blue",   "0000FF"},
        {"Yellow", "FFFB00"},
        {"Orange", "FFA600"},
        {"Grey",   "B8B8B8"},
        {"Purple", "7340DB"},
        {"Pink",   "FF00EE"},
