Features
Quote:

- Login / Register system that use MySQL-R39-2.
- Classe Selection system that use textdraws (check the screens).
- Weapon shop system with textdraws.
- Anti-Hack money.
- Anti-Airbreak.

- i have begging a clan system but i dont finish it.

Fonctions
Quote:

Lobby(playerid); to get back to the class selection
ShowPlayerComptePanel(playerid); show you the PCP ( Account part )
ShowPlayerStatsPanel(playerid); show you the PCP ( stats part )
HidePlayerPanel(playerid); show you the panel
ShowPlayerPanel(playerid); hide the panel
GiveArgent(playerid, valeur); Give money the somebudy ( recomended )
ResetVars(playerid); reset the stats
SaveStats(playerid); save the stats
pName(playerid); get the player name
KickEx(playerid); Kick someone ( recomended )
IsPlayerInArea(playerid, Float:MinX, Float:MinY, Float:MaxX, Float:MaxY); if the player is in area.
GetVehicleSpeed(vehicleid); Get the player vehicle speed.
