-| Commands |-

-| Download |-

Niixie's Small Admin System v 1.0 - Pastebin Niixie's Small Admin System v 2.0 - Pastebin

-| How to install |-
-> If you downloaded both files (.AMX & .PWN) then extract the .rar file into the filterscript folder in your server folder.
-> If you downloaded the .AMX ONLY, then put it in the filterscript folder in your server folder.
-> In the server.cfg file, put in SmallAdminScript on the filterscript line.
