You also seem to have lots of warnings about variables shadowing variables at a preceding level.
Do you have the variables "tmp", "X", "Y", "Z", "Angle", "pName", "string" declared in the main code (not inside a function)?

Those warnings mean that you have them declared outside the functions (global variables) and you're creating extra variables inside functions with the same name.
Those 'could' overwrite the values stored in those global variables, bugging your entire code.
