Bueno acб les dejo otra forma para crear autos tuneados ya que como vi no entendieron la que estaba en otro lugar o era mбs complicada.. Pues primero definimos nuestro auto

pawn Code:
new Elegy4;
Luego para recomendaciуn de bugs o algъn pequeсo error al cerrar el gamemode .. osea OnGameModeExit... Destruiremos el Auto tuneado con esto basta..

pawn Code:
public OnGameModeExit()
{
    DestroyVehicle(Elegy4);
    return 1;
}
Luego creamos el auto.. debajo de OnGameModeInit

pawn Code:
Elegy4 = CreateVehicle(562,1881.71,1070.41,10.47,269.3925,1,1,5000000);
Diran pero que son cada uno de esos nъmeros?.. 562 = Id Auto 1881.71 = 'X' 1070.41 = 'Y' 10.47 = 'Z' 269.3925 = Angulo 1,1 = Color por default antes de tunear 5000000 = Tiempo de respawneo de auto

Luego agregamos los componente ;B

pawn Code:
forward TunearAuto();
public TunearAuto()
{
AddVehicleComponent(Elegy4,1034);
AddVehicleComponent(Elegy4,1036);
AddVehicleComponent(Elegy4,1038);
AddVehicleComponent(Elegy4,1040);
AddVehicleComponent(Elegy4,1146);
AddVehicleComponent(Elegy4,1149);
AddVehicleComponent(Elegy4,1171);
AddVehicleComponent(Elegy4,1087);
AddVehicleComponent(Elegy4,1081);
AddVehicleComponent(Elegy4,1010);
ChangeVehiclePaintjob(Elegy4,2); // Cambiamos pintura
return 1;
}
Ponemos nuestro timer para tunear los autos debajo de OnVehicleSpawn

pawn Code:
public OnVehicleSpawn(vehicleid)
{
    SetTimer("TunearAuto",1000,0);
}
