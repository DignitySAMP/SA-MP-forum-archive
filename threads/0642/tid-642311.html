Introduction
The ranking's goal is to feature the biggest scripting contributors.

Motivation
I believe myself that this ranking will bring more visibility to the members who put such effort to share knowledge through public contributions here, a lot of these contributions are very useful but ends being forgotten because of forums pagination.

Methodology
Actually, the ranking does a simple calculation, counting the sum of all contributor's topics answers, but it can be changed if agreed with the majority of the community through a poll. I believe we can get into some kind of formula that can track the best and most fair solution to rank contributors.

The crawler search contributions into the following forums:
- Tutorials
- Gamemode Scripts
- Filterscripts
- Includes
- Tools and Files
- Maps
- Plugin Development

Transparency
The ranking is created from a client-side Javascript code execution and it's open-source, so anybody can simulate the ranking and compare it with the shared list on this topic.
