Penumbra: Black Plague


Gamemode Version: 1.0
Gamemode Type: RP/TDM

Introduction

This Gamemode was Made Because Nobody Have Released One Like That. I've worked in this gamemode cause I've Played This Game a Long Time Ago , i've Liked it Alot , Some Days Ago I've Remembered About That Game and i Saw That Nobody Released Or Made A Gamemode Like That , So I've Decided to Make This One And Release it Here for The Fun Of The Users. You're Allowed To Edit It As You Want. You Can Add More Classes And Everything You Want.

Features

-Player Names And Markers Are Disabled (Advantage to Hide Behind Objects And More Realism)
-Class System (5 Classes For Each Team)
-The Shelter Map (Not Perfect , But i Did The Best I Could and i've Added Some Custom Stuff)
-2 Teams (Tuurngait Infected , Human)
-Animation System (You Can Impersonate a Death using /die)
-Some Toys/Attachments (Command: /Toys)
-Admin System (Same Used In My Old LSGW Gamemode)
-Registration/Login System (Same Used in My Old LSGW Gamemode)
-4 Admin Ranks & Some Commands (Moderator , Administrator , Manager , Owner)
-Local Chat (Just Like in RP , You Can Chat With Nearest Players Only)
-Team Chat Only For Tuurngait Infected Team (in The Game it Says That They'Re All Mentally Connected)
-Every Skin Will Use Their OWN Animation (CJ Anim Was Removed)
-Anti Bunny-Hop System
-Some Textdraws
-When A Human Die He Will Spawn As Tuurngait
-When You Kill Somebody You Will get +100 Score
-Stats Command to Check Stats , etc
-If A Tuurngait use F4 + Kill To Change Again to human he will be respawned and will get this MSG: you Must Wait 20 Min To Play As Human Again

Class System

Human Classes:

Survivor - 9mm Pistol (0 Score Required)
Police Officer - Shotgun , 9mm Pistol (1000 Score Required)
Soldier - AK 47 , Desert Eagle (3000 Score Required)
FBI - Desert Eagle , MP5 , M4 (5000 Score Required)

Tuurngait Classes:

Tuurngait - Extra Punch Damage (Default Class , 0 Score Required)
Tuurngait With Bat - 40+ Damage (1000 Score Required)
Tuurngait With Knife - 60+ Damage (3000 Score Required)
Mutated Tuurngait - 1 Shovel Hit Kill (5000 Score Required)

Admin Ranks And Commands

Moderator: /slap /get /goto /warn /kick
Administrator: /giveallmoney /giveallscore /car /spec /specoff /ban
Manager: /setscore /setlevel /banip /unbanip
Server Owner: /sethealth /setarmour /cuff /uncuff
