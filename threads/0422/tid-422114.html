WARNING! If you are going to write here, that this idea is useless and it is better to play real minecraft, just keep silent, please.

You know that many copies Mineсraft are often subjects of criticism, but they still are very popular.

I created this thread to inform people who are interested in this project about how development is going. Also, I would be very grateful if you helped me to solve some problems which are written below.

This GM won't be an ideal copy of the popular game. It will be much more simple, but it will give players unlimited possibilities to build and show their creativity. When the development riches the "Beta" stage, it will be released with it's source code.

Development Day 11

What has been done today:

-Improved objects loading on server start. Thanks to "Virtuality"
-You can write text on signs.


Current main problems:
Theese are the problems which need to be solved. If you have any idea about how to slove it, please, post it here.

-Water block is solid
-Bad glass texture(if you find good one tell me)
-Bad decoration object of stairs
-Due to max visible items limit (999), when there are too many blocks on a map, you can see them only on a very short distance
