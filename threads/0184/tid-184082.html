» Description

We all know the trailer that is CJ's home in Angel Pine for some time in Single Player.

Some of you may have noticed that object is in MTA. But oh noes! "It's not solid! I can't use it!"

Now you can, I made it solid for all of you. Added small objects and stuff to fill out all the insolid areas.

So go on, use this for any caravan/trailer/mobile home interiors. You won't be able to notice that it is in fact not solid - I promise.

59 objects in total.

NOTE: This is mapped in Interior 1!
