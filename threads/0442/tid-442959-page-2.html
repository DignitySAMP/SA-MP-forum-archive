Quote:
Originally Posted by Malganys

which one is the difference between L_Skills and L_Skills2?
L_Skills2 provides Anti-Skill cheat protection and has a great bug fix which is, L_Skills won't perform any damages to any player if they're in AFK. Normally in SA-MP, OnPlayerGiveDamage and OnPlayerTakeDamage calls still even if a player is paused, but in the v2, L_Skills performs only if player isn't paused. Although, it might not work very well in case if a player pauses and unpause quickly.
