Foreword

You probably remember this topic where I presented this system and said I would release it soon, but it got delayed because I was too lazy to open a topic.
Anyway, it's here now. And no, I didn't continue working on it like adding a rope or something. You can basically do it yourself. The only thing I did change is a bit more accuracy and realism and bug fixes.

More information

The system is actually simpler than it looks. The "collision" between the bullet and object gets detect by using MapAndreas plugin with Z height checks. Please note that this can't detect "collisions" of anything that's not from the San Andreas world which simply means that you can't Grapple to a map created by you and/or inside a interior (I guess).

Installation

- Download MapAndreas, extract and put everything in the correct place (don't forget to add MapAndreas in your plugins list in server.cfg).
- Download the script from the pastebin link and name it as "GrappleHook.pwn", compile it, place it in the correct directory and write "GrappleHook" in server.cfg as FIRST filterscript.
- Start your server, write /grapple and enjoy!
