Por DraKiNs
Introduзгo:
It is a radio system using Icognitos plugin of audio external


How to add?

In Filterscript add:

pawn Code:
AddRadio("NAME OF RADIO","URL OF RADIO"); // in onfilterscriptinit
How to load the system?

Transfer the files to the server folder

in Server.cfg:
Code:
filterscripts Radio
plugins Radio
The rest of it is automatic on the server

Obs:
The player needs this file to run the radio:
www.solidfiles.com/d/5fb39/download/
