Well for some reason, it seems like Windows 8 defaults to storing things in the AppData folder. It took me awhile, but I found where the GTA User Files directory is saving information. So, if anyone else is running Windows 8 and can't seem to find the "GTA User Files" directory that would normally be in your "Documents" folder, check to see if it's here:

C:\Users\YOURUSERNAME\AppData\Local\VirtualStore\P rogram Files\Rockstar Games\GTA San Andreas
