INTELEX ROLEPLAY
Introduction:
Intelex Roleplay is a SA-MP gamemode based on the roleplay concept; powered by iRage's zGaming Roleplay. Well, yeah -- its basically an edit, but it has tones of new features added to it.

Features:
- New report system with a whole wide range of commands (/ar, /tr, /sr, /reports)
- Re-written the helper system.
- Added a lot of new faction commands to the Hitman Agency and other factions.
- Added Government Pay.
- Added a semi-dynamic job system.
- And a lot of more features (sorry that I forgot to log every instance of the script)..

Conclusion:
Well, eh - nothing more to say other than leaving the credits for me and iRage for the script. You could edit it as you wish, just don't forget us!
