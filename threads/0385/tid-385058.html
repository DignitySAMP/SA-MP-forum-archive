Hello all,
I see many releases by now on SA-MP forums.
So I thought of creating a thread which shows our works with bit brief.

Q:There's a thread named Filterscripts & Includes, Useful Gamemodes and Useful Tutorials already. This is useless, you're spamming.
Isn't it?

A:I know those are useful threads but this is where you can also explain what your release is and how it performs in a bit detailed. So, shut up!

If your work gets updated, you can edit your post.

Bumping your works isn't allowed.

Also if you've got some opinions or suggestions towards a work, you must not post it here.
Post it on that release thread.

First of all, I'll start with mine.

- Easy Weapon
This is a simple weapon fs made by me.
It's my first fs and it's build with some commands which gives you a weapon.

- Player's Teleport System
This is a script which allows player's to teleport to other player if the other player has enabled tele command. It's simple and easy to use.

- L-AFK System
This is an advance AFK system made by me which has textdraws, teleports, timers, and many other features.

- L-Bug Report System
This is a bug report system made by me which reports the bug and saves it in a log.
It also stores player's coords, name, ip, skin, ping etc.

- How to create a simple Announce command.
This is my first tutorial which is simple and teaches how to create a simple announce command.
It's well explained.

- Get Started In Creating Commands
This is a tutorial which teaches you how to get started in pawn - creating commands using zcmd include..
