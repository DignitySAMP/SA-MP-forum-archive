SA-MP 0.3e RC


Samp 0.3e es principalmente una actualizaciуn de seguridad. Muchas cosas nuevas y modelos estan planeados. Se ira adhiriendo durante el periodo de desarrollo de los RC.

- Existen algunos problemas menores de seguridad en la version anterior, los cuales resultaban en ataques a los servidores con programas diseсados especificamente, para solucionar esto, se requiere actualizar cliente y servidor.


Client/server update SA-MP 0.3e RC8

- Arregla los clicks en los TextDraws en el modo ventana. Errores similares existen para los adjunciones(pegar/unir) de edicion del modo ventana.
- Se agrego mas informacion en el manejador de errores del servidor de windows.
- El estado de control sobre el jugador es reiniciado en el servidor luego de spawnear.

client update SA-MP 0.3e RC7-3 (Opcional)

- Arregla un problema con los textos de los objetos que no eran mostrados con determinados colores de fondo.

client update SA-MP 0.3e RC7-2 (Opcional)

- Habia algunos problemas con el cambio de material en los objetos (inclusive materiales de texto), donde podia llegar a pasar que el cambio en un objeto afectara todos los objetos del mismo modelo.

Client/server update SA-MP 0.3e RC7

- Se agregaron las funciones SetObjectMaterialText/SetPlayerObjectMaterialText para reemplazar las texturas de un objeto con texto.
- Se arreglo un problema que al azar esposaba a los jugadores que spawneaban presionando la tecla Alt.
- El chequeo de la id de un vehiculo es menos estricto en aviones y botes.
- SetPlayerAttachedObject tiene ahora 2 parametros adicionales por defecto para cambiar el material del color. Esto requiere la recompilacion de todos los scripts que utilizen esta funciуn.
- El formato para el color de los materiales de los objetos es ARGB.
- Se agregaron nuevos modelos de cessil: Cuadrados en blanco para crear letreros, algunos edificios y casas.

Client/server update SA-MP 0.3e RC6

- Arregla un crash ocacionado cuando el vehiculo era borrado mientras se utilizaba la camara fija para mirar detras.
- Se removieron los iconos del Pay'n'Spray.
- Se agrego la funcion GetVehicleModelInfo() para obtener informacion sobre el vehiculo, como el modelo, el tamaсo, etc.
- Localmente los movimientos de cabeza fueron deshabilitados mientras se utiliza el editor de objetos.
- Se agrego la funcion SetObjectMaterial() y SetPlayerObjectMaterial(), de este modo se puede reemplazar la textura de un objeto por otra existente en el juego.
- Se agregaron nuevos modelos de cessil: letrero de venta, mascara de gas, pasto, tabla de poker.


Client/server update SA-MP 0.3e RC5

- Se arreglo el bug introducido en la version 0.3e RC4, el cual causaba que un vehiculo hundido pudiera ser eliminado por el cliente.
- Arreglado el bug en el que el TextDraw mantenia el color (al ser seleccionado) luego de que la seleccion fuera deshabilitada.
- Se agrego seguridad extra al script dentro de OnDialogResponse.
- Se arreglo el bug con la textura del cubo.
- Se agregaro un sistema para crear TextDraws por jugador. Ahora existen dos tipos de TextDraws: por jugador y globales. Todas las funciones de TextDraws tienen su variacion para jugadores:

pawn Code:
native PlayerText:CreatePlayerTextDraw(playerid, Float:x, Float:y, text[]);
native PlayerTextDrawShow(playerid, PlayerText:text);
native PlayerTextDrawHide(playerid, PlayerText:text);
native PlayerTextDrawSetString(playerid, PlayerText:text, string[]);
// ..[] etc
Client/server update SA-MP 0.3e RC4

- Deberia arreglar el bug que surgia con los ids de los vehiculos cuando un vehiculo 'muerto' era eliminado por el servidor.
- Los slots actuales ahora son 500.
- Se arreglo el bug con las texturas de los nuevos objetos.
- Se agrego un ejemplo (filterscript) sobre el flymode sobre la camara del jugador.
- Se agregaron nuevos objetos de cessil: 40 nuevas paredes, barreras para vehiculos, un cubo, una bufanda.
- El servidor ahora permite que un jugador realice clicks sobre los TextDraws:

pawn Code:
native TextDrawSetSelectable(Text:text, set); // por defecto 0 (no seleccionable)
native SelectTextDraw(playerid, hovercolor); // habilita al jugador a seleccionar un textdraw
native CancelSelectTextDraw(playerid);// cancela la selecciуn de un TextDraw
forward OnPlayerClickTextDraw(playerid, Text:clickedid);
Notes on SelectTextDraw():
- Todos los TextDraws que puedan ser clickeables deben tener un espacio definido por TextDrawTextSize.
- Deberia habilitarse TextDrawUseBox para hacer vivible el бrea que puede seleccionarse.

Client/server update SA-MP 0.3e RC3

- Arreglado el problema en el que los objetos atraidos a un jugador, tal vez aparecian flotando.
- Los objetos atraidos al jugador seran removidos cuando el jugador aparece en el juego o entra a la selecciуn de skin (clase) y no cuando el jugador muere (durante la animacion de muerte).
- Agregados nuevos objetos de cessil: ~40 nuevas paredes, incluyendo puertas y ventanas, esposas, luces de policia, auriculares y demas.

Client/server update SA-MP 0.3e RC2

- Se arreglo un bug donde el jugador podia ser teletransportado a la coordenada (0; 0; 0) cuando estaban surfeando sobre un vehiculo que era respawneado o borrado.
- Nuevas funciones:
pawn Code:
native AttachPlayerObjectToVehicle(playerid, objectid, vehicleid, Float:fOffsetX, Float:fOffsetY, Float:fOffsetZ, Float:fRotX, Float:fRotY, Float:RotZ);
native InterpolateCameraPos(playerid, Float:FromX, Float:FromY, Float:FromZ, Float:ToX, Float:ToY, Float:ToZ, time, cut = CAMERA_CUT);
native InterpolateCameraLookAt(playerid, Float:FromX, Float:FromY, Float:FromZ, Float:ToX, Float:ToY, Float:ToZ, time, cut = CAMERA_CUT);
native AttachCameraToObject(playerid, objectid);
native AttachCameraToPlayerObject(playerid, playerobjectid);
Client/server update SA-MP 0.3e RC1

-Hay menos problemas en los ataques a servers con diferentes programas. Se resuelve actualizando el server y la version cliente de SA:MP.
- Se ha corregido un error introducido en 0.3d, donde un jugador puede ser capaz de evitar la muerte si tienen una animaciуn aplicada.
- El problema para cambiarle un color de nick a un jugador con la ID mбs grande que 500 fue arreglado.
- El problema que kikea al jugador si usa SpawnPlayer() fue arreglado.
- El problema con el buscador de servers que se crasheaba si la data era invalida fue arreglado.

Esta actualiazacion es mas de seguridad, pero aca hay mas que tiene esta version:

- Agregar mas modelos (objetos) hechos por cessil como boina, latas, varias secciones de pared diferentes.
- Dialogs scripteados que ahora tienen una barra de tнtulo.

El server puede obtener la versiуn cliente de un jugador:


pawn Code:
native GetPlayerVersion(playerid, const version[], len); //  Retorna con la versiуn cliente del jugador
Se ha agregado un parametro a SetPlayerCameraLookAt() de modo que la cбmara se moverб a la nueva posiciуn, en lugar de teleport


pawn Code:
#define CAMERA_CUT  2
#define CAMERA_MOVE 1
native SetPlayerCameraLookAt(playerid, Float:x, Float:y, Float:z, cut = CAMERA_CUT);

Se ha creado una herramienta que hace mas facil obtener las cordenadas de un objeto atado a un player.
