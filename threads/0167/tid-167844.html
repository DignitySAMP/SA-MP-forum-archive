SA-MP 0.3b RC4-1
  • Исправлена проблема с векторами прицеливания на разных разрешениях экрана
  • Отключение пароля сервера
  • Добавлено новое значение forcesync = 2 для ApplyAnimation, при этом значении все, кроме игрока, на которого поставили анимацию, будут видеть анимацию
  • Player3D-текст теперь работает после рестарта сервера
  • Теперь нету крэша после выхода, если во время выхода вы спектэйтили
  • Обновлён SQLite до 3.7.0.1

SA-MP 0.3b RC3
  • Добавлена проверка на прикрепленный объект IsPlayerHoldingObject
  • SetPlayerHoldingObject теперь можно поворачивать по x,y,z
  • Теперь вы можете заходить в машины и стрелять с прикреплённым объектом
  • Удалена возможность "красть" вещи из-за интерьеров (прим. переводчика: раньше это вызывало warning в клиенте)
  • Пофикшена проблема с поворотом игровой модели игрока, пока он прицеливается

SA-MP 0.3b RC2

  • Добавлена /headmove для отключения поворота головы
  • Улучшилось качество GetPlayerWeaponData и GetPlayerAmmo (прим. переводчика: надеюсь, теперь не будет таких багов, как раньше)
  • Пофикшены (надеюсь) любые крэши от SetPlayerHoldingObject
  • Отрицательный score игрока в клиентском браузере теперь будет равен нулю

SA-MP 0.3b RC1
Изменения для игроков:
  • Важные обновления по безопасности
  • Обновлен механизм отображения списка серверов
  • Улучшена синхронизация игроков и их анимаций
  • Добавлен отдельный лог для чата
  • Для чата добавлена команда сохранения штампа даты - /timestamp
  • Все клиентские файлы, включая скриншоты, теперь будут сохраняться в папке "GTA San Andreas User Files"
  • Исчезло ограничение на размер разрешения экрана
  • Изменения ограничителя кадров теперь сохраняются
  • Исправлены еще некоторые ошибки
  • Убраны команды асинхронизации
  • Основные клиентские команды: /dl, /headmove, /q, /quit, /save, /pagesize
Для серверов:
  • Новые функции для транспорта
  • Возможность отслеживать работающие анимации
  • К разным частям тела игрока можно прикрепить объект
  • Многопоточный механизм пересылки данных по протоколу HTTP (тестируется)
  • Увеличен лимит объектов до 400
  • Возможность менять расстояние, на котором будет виден объект (вплоть до 300 игровых метров)
  • При записи NPC скриптов анимации будут тоже сохраняться
  • Поиск по механизму PVar стал быстрее
  • Исправлено много других серверных ошибок
  • Новые функции на wiki: https://wiki.sa-mp.com/wiki/Category:Added_in_0.3b
Информация для владельцев серверов:
  • Появился стример объектов, без перекомпиляции с новыми инклудами объекты, созданные через CreateObject/CreatePlayerObject будут прозрачными.
  • Изменение дистанции видимости объектов, которые состоят из светящихся элементов, может вызывать лаги или даже падения сервера.
  • Изменился формат NPC скриптов, которые были записаны без использования транспорта. Сконвертировать такие скрипты в новый формат нельзя, придется записывать их заново.
  • ApplyAnimation/ClearAnimations теперь имеют параметр "forcesync", т.е. теперь можно применять к игроку несинхронизированные анимации.

Нашел баг, не знаю в какой версии сампа он появился, счас постараюсь объяснить его суть.
Есть дома и у каждого дома внутри свой уникальный виртуальный мир (при входе/выходе виртуальный мир игрока переключается).
Есть команда позволяющая смотреть текущий виртуальный мир игрока и менять его на другой.
В каждом доме есть пикапы, созданные соответственно в виртуальном мире этого дома(и в других мирах не видны).
Если умереть спавнишься в доме.
Если умираешь на улице - все впорядке. Если умираешь в доме, то после спавна пикапы не видны.
С помощью описанной команды можно проверить что виртуальный мир соответствует нужному. Пикапы появляются обратно только если сменить виртуальный мир игрока на какой-нибудь другой, а потом обратно на тот что нужен.
