Stop using the bracket finder and start commenting out code until it compiles. If you have missing functions just create empty functions so your code can still compile. Once it compiles start to uncomment sections of code and narrow down the problem.

Usually you can get a pretty good idea of where the problem is and start with just a bit of code commented out if it compiles you have isolated the section of code giving you problems and can then continue to narrow down where the problem is located.
