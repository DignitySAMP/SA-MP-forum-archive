Teleport Maker

Last Updated: 07/12/12
Introduction

A new way of creating teleports.
No more typing /lsa. /sfa. /lva. But instead walk to the checkpoint.
And teleport to lsa, sfa or lva in no time. We must script it with /save.

However, There is new script invented built to make the scripting time save energy.
By this Teleport Maker. You can create a teleport in no time.

Report Bug

If you've found a bug please P.M. it to me. or post it in this topic.

Suggestion

If you've suggestion. Please P.M. it to me. or post it in this topic.

How to use it?

Download Teleport Maker. Extract the filterscripts, pawno, and plugins to your server folder from the zip file.
Click Yes to All. Now go to server.cfg. in filterscripts. Add "telemaker" without quotes.

Now open the samp-server.exe. Go in-game type /rcon login <yourrconpass>. now /saveteleport.

Go to position where you want to set the checkpoint. Then /saveteleport again.
Go to position where you want to set player position when player enetr checkpoint. Then /saveteleport again.
Now you're freeze the system will tell you to give the name of the file the teleport file. Press T or F6 now for name it as "TeleportExample" without quotes. don't put .txt when typing the name. It's automatically added the checkpoint created has been destroy.. Now go back in desktop. in scriptfiles you will see TeleportExample.txt. Open it. Sorry for bad indentation. Now copy it to your script. But don't forget to indent it properly again.

Commands

/saveteleport - 3 easy process must be rcon logged in to use it.
/stopteleport - stops creating teleport. destroy the created checkpoint during the /saveteleport.
