Affliction Roleplay
Affliction Roleplay is just a version of Vortex Roleplay 2 - created by Calgon and Brian - with quite a few new features and small fixes, It is set in Bone County as this was the location of the server when it was up and running, this can easily be changed with very little effort. If you want anything adding or feel that you want something changed, contact me via forum PM or leave a comment here and we can negociate a price depending on the amount of work required.

Now here is a brief list of all the new features or even removed from the Affliction Roleplay Script, some features may not be on here, if you wish to alert me of missing features, again, PM me on the forums;
  • Fixed Phonebook Bug
  • Added /nmute for admins/helpers
  • Added more locations to /go
  • Added /siren command for cops
  • Changed colours and formatting of /ban /kick /fine /jail /release /unban It'll now look something like this AdmBan:Name has been banned by adminname reason:
  • Moved to Bone County.
  • Added a donator system, /goldon(goldname), /goldoff(goldname off), /togpms and /dc(donatorchat).
  • Removed the CJ Run.
  • Added a roadblock system.
  • Revamped the Hospital System.
  • Increase Arms Dealer timer to 5 minutes.
  • Revamped the /cell command for the PD.
  • New /mask system; Head to the 24/7 and purchase a mask, you need to be Level 5 to use the mask.
  • When the mask is on your name is replaced with a Stranger_(random number), This can help prevent Metagaming.
  • Added new items to the 24-7; Shovel, Baseball Bat.
  • Fixed a bug where you screen would turn black when jailed.
  • Added Speedometer.
  • Added Delayed Engine system.
  • Created new sidejobs: Trucker, Paperboy and Sweeper
  • New Tutorial with extended quiz.
  • Added Sheriff Hat.
  • Made /sellcar so you have to sell it to another player.
  • Removed the Fisherman Job as it was bugged.
  • Removed /findcar as it was felt unnessacary and Non-RP.
  • Added a new /assistance system.
  • Added a new DMV system with Car, Truck and Motorbike licenses.
  • Added news faction commands; /ichat, /interview, /news, /endbroadcast.
  • Added /badge for the BCSD.
  • Added /seatbelt and /checkbelt, no real use for this only RP.
  • Added /giveradio and /takeradio for Government factions.
  • Added a weapon license system; /grantweaplic.
  • Added /helmet bought at the 24/7.
  • Removed Admin Name system.
With these new features, along with the original Vortex Roleplay 2 script, you have yourself a fairly large script.
