Simple Neon System

Hey Guys, i wanted a Neon system for my RP server but they all were with Dialogs. and it was messing up with my other Dialogs. SO i decided to make My own Neon System.Its A Very Light and User Friendly Script.

It Has 6 Colors
-RED
-WHITE
-Pink
-Yellow
-Green
-Blue

Commands

/Rneon (red color)
/Bneon (Blue color)
/Pneon (Pink color)
/Yneon (Yellow color)
/Wneon (White color)
/Gneon (Green color)
/Neonx(it will set a checkpoint to the Neon garage
/Neon(Shows the list of all Available Colors

There is a Place where u can go and fit a neon . /neonx

No Bugs Found because it doesnt have Any Bugs But If u find Any I will be here

Please rep+ if u like it. and If u have any Complaint or any Problem Feel Free to Ask
