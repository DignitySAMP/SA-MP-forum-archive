Ok so here's the little update many members were waiting for. I have done a bit of updates and bug fixes.

Features[3.0]
A nice textdraws interface on spawn
Lots of commands
Powerful and userfriendly GAdmin system
Duel system
Vehicle spawn dialog
Skin spawn dialog
Weapons setting dialogs
Commands list, help list in dialogs
SQLITE saving and loading system (BUD)
Advance attachments system (/a)
Lots of minigames
Deathmatches list
Team deathmatches list
Races list (handling from server)
Derbies list
Custom spawn selections
Random city spawns avaliable
Awesome base jumps
Lots and lots of teleports
Tune any car with command (/tc<1-3>)

Custom colors setting
In game TAG system (set your own tags for chat)
Tag color, Tag srings, Tag displays
Lots more, explore in game and screenshots...
