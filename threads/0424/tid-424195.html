Party Bus[V1.0]!

Information
Well,I was bored and decided I should release something I've scripted. I didn't want to release something to big so I decided I'd release my Party Bus! I do plan on updating it and adding new features FYI.


Includes
This Filer script requires zcmd and sscanf2.

Video

http://*********/UCT0uaeKvXw
[ame]http://www.youtube.com/watch?v=UCT0uaeKvXw[/ame]
Download

Download From Mediafire Here
Installation

Extract the partybus.amx into your "filterscripts" folder. Then edit your "server.cfg" file and add "partybus" on the "filerscripts" line.
Notes

1.This is my first Filterscript so please try to keep the hating to a minimum, thanks.
2.This filterscript is for 0.3x
3.You must be logged into RCON to use /partybus
