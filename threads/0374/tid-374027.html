Do you have the latest streamer.inc from Incognito? If not download it from here. STREAMER 2.6.1

Also, if you decide to use streamer, convert all createobject to createdynamicobject. And not only this. MoveObject to MoveDynamic Object. More precisely, every function with object, change it with the corresponding function from streamer.

This is important!

You must not have any CreateObject in your gamemode, use only CreateDynamicObject.

#edit don't forget to use #include<streamer> in your gamemode .

Also, on your server.cfg file you must have " plugins streamer.dll" - if your server runs on Windows

or "plugins streamer.so " if your server runs on linux. ( without the quotes of course) .
