MADDOG DEATHMATCH
Maddog deathmatch is a script that I created from stratch two years ago for the server I was running, unfortunately I quit hosting and went into roleplay.
Therefore didn't need this anymore, it has alot of greatly designed features
and its smartly engineered for maximum experience for any deathmatch related server you should wish to host.

For this gamemode to function correctly, you'll need these files:
ZCMD - https://forum.sa-mp.com/showthread.php?tid=91354
YSI/y_ini - https://forum.sa-mp.com/showthread.php?tid=175565
Incognito's streamer - https://forum.sa-mp.com/showthread.php?tid=102865
foreach - https://forum.sa-mp.com/showthread.php?tid=92679
sscanf - https://forum.sa-mp.com/showthread.php?tid=120356
Whirlpool - https://forum.sa-mp.com/showthread.php?tid=65290
svAddons -https://forum.sa-mp.com/showthread.php?tid=348044

Features.

• Neatly designed login & registration system.
• Ammunation system with pickups and text labels.
• Complete weapon purchasing system with prices.
• Limited map size, for quick paced combat firefights.
• Various random spawn locations to limit spawn-killing.
• User friendly, easy-to-use and easy-to-edit script.
• Dynamically create, delete, reset clan/factions in-game. (Dynamic clan/faction system)
• Individual personal skin system.
• Donation & VIP system.
• Advanced administration system. (Over 60+ commands to use in-game)
• Helping system with helper users as basic moderation through the server.
• Advanced dynamic fightstyle system.
• Intergrated event system.
• Weaponry system. (Includes weapon kill saving. eg. Desert Eagle kills.)
• Player statistic system.
• Player payment system.
• Online audio streamed radio system.
• Script written completely from scratch.
