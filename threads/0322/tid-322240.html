Hello DarkCrow,

There is also a tutorial to do this sort of thing

First add this as a global new

pawn Code:
new RandomMSG[][] =
{
    "Random Message 1",
    "Random Message 2",
    "Random Message 3"
};
Then OnGameModeInit add SetTimer("SendMSG", 60, true); This is done in milliseconds.

Then add this as a public

pawn Code:
public SendMSG()
{
    new randMSG = random(sizeof(RandomMSG));
    SendClientMessageToAll(COLOR, RandomMSG[randMSG]); // Replace the "COLOR" with your defined color.
}
