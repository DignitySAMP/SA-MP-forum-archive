A few bits of advice regarding the use of a repository. First off, don't upload binaries or compiled source code. It only slows down the commits and increases the size of the repository. Furthermore, for some of the files you've uploaded, such as the SA-MP repository, you have no rights to redistribute.

What also massively slows down your repository is the fact that you've uploaded the server log. All this is useless for repositories. Repositories are for source code and other text files required for these source codes. (Readme's and such.) here's a link on how to exclude these from commits (because I guess you've just used "git add *"): https://help.github.com/articles/ignoring-files/
