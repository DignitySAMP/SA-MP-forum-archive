Object ID limit 20000 has been breached more than one year ago in fastman92 limit adjuster. Now it's possible to add IDs over 20k, you can go up to 65535.

http://gtaforums.com/topic/733982-fa...imit-adjuster/

There are lot of mods available, which adds VC, LC to SA, without touching original map files, and lot of other mods. But the problem is that SA-MP doesn't support fastman92 ID patach, so impossible to use these mods in samp. Since 0.3c, we can add custom models but not much cause 20k limit is present in samp and can't be breached, even with limit adjuster - it will crash.

Solution is here, samp team should make samp compatible with this part of fastman92 limit adjuster.

http://gtaforums.com/topic/733982-wh.../?p=1066099922

Example mod which use ids over 20k:
http://gtaforums.com/topic/813938-sa...andreas/page-1
http://gtaforums.com/topic/776561-wi...lc-other-maps/

SA-MP with these total conversion mods would have totally new feel. Me and lot of players already don't play samp because thinks that it's boring, but support for these mods would bring back these old players.
