Los Santos Thug Life


Original Thread for UG:RP - https://forum.sa-mp.com/showthread.php?tid=430334

Introduction

The Original UG:RP by -Carrot (Tommy Martins) set a benchmark among other RP Gamemodes. But Unfortunately, that script was quite bugged. Recently, Antoniohl also released CG:RP, I used some chunks of code from his gamemode. (With his permission of course.) UG:RP was supposed to be a heavy RP server, but this update changes it to light to medium roleplay, More like RPG. (A fast paced roleplay, some might say.)

What's New?
Like I said, this gamemode was quite bugged, and was massive. I tried to find and fix bugs with the best of my abilities.

1. The /Accept Vehicle Bugged - Fixed.
2. Mapping Not Loading Up At Pershing Square - Fixed
3. Paintball Bug (Player used to spawn in Blueberry once it was over.) - Fixed
4. Trucks And Fedex Job (Checkpoint wasn't responding on entering.) - Fixed
5. House Bug (Now you can use /houseint to manage interior.) - Fixed
6. Binco Bug (Now you can buy Toys / Accessories / Clothes) - Fixed
7. In-game Mapping Bug (Now the Mapping saves and load itself.) -Fixed.

New Updates from Me.
1. VIP Lounge Scrapped and Remapped. (A LOT Better.)
2. Script now Uses Y_ini not Sqlite.
3. Added more clothes and accessories in Binco.
4. New Mapping at Pershing Square. (This was also a bug.)
5. Lots of updated new Textdraws.
6. Better Speed-o-meter
7. Removed loads of unwanted mapping.
