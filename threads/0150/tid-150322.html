NPC Creator



Author's Comments


After some hours of work, i've finally finished this NPC Generator ( You can only create NPCs OnFoot, Next Version will include all the 2 mods ).Note:Use the NPC.pwn file after creating the first NPC. If the file stays in the scriptfiles folder, and you are creating the second NPC, the NPC.pwn file for the first NPC will be deleted!

FilterScript Features

- NPC Generator
- Create NPCs in game
- Dialogs Used
- Commands
- .rec file & a NPC.pwn file are saved in your scriptfiles directory ( NPC.pwn file loads the NPC )

You can also chose your NPC Weapon & Skin.

FilterScript Instalation

Download the NPCGenerator.rar, put the 2 files in your filterscript folder, add NPCGenerator in server.cfg at filterscripts.You will also have a Readme.txt file. Read it for more informations.

FilterScript Download

1). Attachment
2). Rar File: http://www.mediafire.com/?kyduhyr68q1yuz9

Hope you like it!
Please report any bug(s) by comment or PM-ing me.
