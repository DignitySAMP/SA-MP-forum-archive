About the map

Information:
My 3rd map. Its based on Deathmatch. It has a huge amount of fun things to do. There are many sub-places inside the map. Players can hide there. It can hold a vast amount of players but what I prefer is 20 to make the game balanced and not messy. This map has health pickups which actually do refill your health. They are not objects. Thanks to MTA's features. This map can also be a team deathmatch map. As the places and buildings have been set in such a way, that both are fine and stable with it.
Objects converted: 234
Vehicles: 8
Vehicle models: 2
Map Type: Minigame/Deathmatch/Team Deathmatch

Features

1 ) Fully fenced map
2 ) Set in air, so if players jump from fence, they'll simply die
3 ) Tested map, no bugs should be there
4 ) Can hold up to as many players. Preferred amount is 20
5 ) Many barrels in buildings as traps
6 ) Up to 7 health pickups (not objects)
7 ) Many types of buildings and several sub-places in the map to give a nice deathmatch environment
8 ) 4 Hidden karts
9 ) 4 Tractors (trapped within barrels and petrol station pumps) someone can hardly escape with it
10 ) Map can be used as Deathmatch or as Team Deathmatch.
