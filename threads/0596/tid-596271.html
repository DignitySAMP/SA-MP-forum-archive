How to fix this bug (actor is moving, but don't go):

[ame="http://www.youtube.com/watch?v=LfOOmd-rJ6g"]video[/ame]

PHP Code:
new animAndSpeed[2][animData] = {
        {"WALK_civi",1.5357},
        {"RUN_civi",3.7}
};
public CreateActor(playerid, animation)
{
  new actorid;
  new Float:x, Float:y, Float:z;
  GetPlayerPos(playerid, x, y, z);
  actorid = CreateActor(189, x+1, y+1, z, 0);
  ApplyActorAnimation(actorid, "ped", animAndSpeed[0][animation], 4.1, 1, 1, 1, 0, 0);
}
