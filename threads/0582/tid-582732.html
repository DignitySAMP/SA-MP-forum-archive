Hi there,
This gamemode is a re-write of the old gamemode named GTA:Adrenaline, i've fixed all the bugs the last version has and i've made a new design and stuff, hope you will like the gamemode, here is few features:

- Admin system
- Killingspree system
- Race system
- Duels system
- Weaponset system
- Random maps system
- Ranking system on site (top kills/level etc..)
- Server config (minium fps, and much more)
- And much more!
