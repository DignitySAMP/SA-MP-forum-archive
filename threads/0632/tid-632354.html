When you are applying new textures to a mod, make sure to DFF check them with the .dff file in TXDWORKSHOP and also to compress them.

Also make sure that your picture size is correct.

123x64 won't work
128x64 will.

If any of the the numbers of your picture size are uneven, it won't work. I personally increment it times four. Also try to keep the height/width values the same unless you are dealing with a lot of empty space.

If you don't do the above, the texture will fail to load. In most cases, this results in the "Model x didn't load in time" error or it will just not show and make you lag.

If you are replacing a weapon icon, you are applying a new texture. And just because you never had to resize a picture doesn't mean that you shouldn't check this one.

The resolution should be even numbers, both height & width. You also should compress the texture by going into properties and making sure "compressed" is checked.

If you do DFF checker, it shows which textures are connected to the .dff file and which ones are missing. There should not be any red icons under the .dff file's table. It should all be green.

If it's red, see what the name is of the file and if you think it's the icon, rename your implemented icon to that by going into properties and renaming it.


This is basic modding, by the way, you should probably learn the essentials first instead of doing this kinda stuff and getting lost after every step
