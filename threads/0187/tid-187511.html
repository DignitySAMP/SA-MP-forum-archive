Boat Fly Stunt [BFT]
7265hjf72hf0q72jda8 (Lopez Trucking Scripting App)
Firstly you'll need the truckingsmissions.inc file from
HTML Code:
https://forum.sa-mp.com/showthread.php?tid=182789&highlight=Trucking+Missions+Include
I have made a vehicle/simulator gamemode where you can obvously boat, fly or do trucking.

Pro's / Cons

Pro's
+ Custom Mapped
+ No bugs that i have found
+ User Friendly
+ You can go to the other places where there are boats, planes or the truck depot and be one of those (you don't have to be what you chose on class selection)

Cons
+ When your choosing your class it dosen't make a textdraw telling you if that skin is a pilot trucker etc. But its easy to figure out the difference between pilot and trucker
+ No class for boater (you can just choose pilot and go to the boat harbour)

That pretty much sums it all up.

Download link is http://pastebin.com/qJiKXG4T Version 0.1b
Or http://www.megaupload.com/?d=V9NALW15 If you can't use pastebin.

Whats to come in future versions
+ More Commands For Pilots
+ Train Driver Spawn & Mapping
+ More Maps For Boaters
+ More Commands In General
