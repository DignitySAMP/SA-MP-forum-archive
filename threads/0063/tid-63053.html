..::[FS]Channels::..
Info:
Channels for players. When players speak, only people in the same channel will get the message. useful for RP/Teams.

Features:

• SetPlayerChannel(playerid,channel) - Set a players channel
• SetAllChannel(channel) - Set all players channel
• SetAdminsChannel(channel) - Set all the admins channels
• SetPlayersChannel(channel) - Set non admins channels
• GetPlayerChannel(playerid) - Get a players current channel
• SetChannelsByID() - Set everyones channel to their ID
• SendClientMessageToChannel(channel,color,text) - Send a message to everyone in a channel

Download:

Version 1 Mirror 1 (deLUX click n host)
Version 1 Mirror 2 (Rapidshare)
Version 1 Mirror 3 (Pastebin)
Version 1 Mirror 4 (Canadian Pastebin)
Version 1 Mirror 5 (Sendspace)
Version 1 Mirror 6 (Mediafire)

Installation:

Compile Channels.pwn and place the .amx file into your filterscripts folder.
Add "Channels" to your filterscripts line. Example: "filterscripts adminspec vactions Channels"

Information:

Any ideas or bug reports welcome!
