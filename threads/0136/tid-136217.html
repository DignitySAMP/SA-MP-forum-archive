Script Information:
Small script created out of boredom that allows users to create vehicles dynamically, this script uses djson file caching system which can be downloaded here, apart from that the script is pretty self explanatory.

Features:
* Dynamic Vehicles, which allows beginners or people that want there script more dynamic to do so with simplicity.

Commands:
* /vehicle <create | delete | park | count>.
