All the scripters would have to communicate with each other directly. You can't really have them all on the one teamviewer because then they would only be able to work on one bit at a time.

I suggest that they all have a copy of the script with all the things that will be saved already implemented so that they can all work on different parts of the script and forge it together.

Note: Your developers must have good communication. And make sure that all your developers get along and can work together otherwise it will just fail.
