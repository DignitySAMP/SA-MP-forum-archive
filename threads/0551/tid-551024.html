Well, I'm guessing that you the variable 'VehicleOwned' has an array size of 2000 or MAX_VEHICLES.
MAX_VEHICLES = 2000
Eg.
pawn Code:
new VehicleOwned[MAX_VEHICLES];
This means that you can have 2000 elements, starting at '0'. So the elements go from VehicleOwned[0] up to VehicleOwned[1999], which is 1 less than 2000/MAX_VEHICLES.

Code:
Accessing element at index 2001 past array upper bound 1999
This means you are trying to get an element at the index 2001. As our maximum is 1999, if you exceed that, you're going to get an array index out of bounds error.

The number in the brackets "[" and "]" must not be equal to or larger than what is in the introduction line.
If we have:
pawn Code:
new VehicleOwned[5000];
and I try and do:
pawn Code:
VehicleOwned[5000]
//or
VehicleOwned[5001]
Then I am going to get an error, because the maximum element index we can access is 4999. (5000 - 1 = 4999)

I'm trying to find a tutorial for this kind of error to explain it easier, but I cannot seem to find one. Basically, when you do VehicleOwned[newcar] or VGas[newcar], 'newcar' is equal to 2001, which is giving you an out of bounds error.
