This time something really big and awesome. J_Admin system with over 50 commands and all are awesome commands.

Releasing BETA version, will be updated each day or week!

Features
  • Over 50 commands!
  • Y_INI based saving system!
  • Great register system!
  • Advanced admin commands!
  • Player commands available too!
  • Anti-High ping!
  • Anti-AFK system!
  • Config saving!
  • User Friendly!
Commands:

Admin commands:



Player Commands:

/pm [playerid] [text] ---> To PM other player
/nopm ---> disable PM mode (You will not recieve PM's anymore)
/changename ---> to change your in-game name!
/changepass ---> to change your password
/report ---> To report a player!
..... more to be discovered!

Installation

Setting up FS:


-Copy the filterscript files and paste it in your folder.
-If you didn't got Y_INI copy the YSI library from pawno/includes folder and put it in your includes folder
-Copy and replace your sscanf with my in plugins folder
-Copy the folder from scriptfiles and paste it in yours.
-Enjoy the admin system!


Edit above line in the FS to do it!

Editting Command's level

Find for following line in commands.
pawn Code:
if(PlayerInfo[playerid][pAdmin] >= 1)
Change it to yours one.

pawn Code:
if(PlayerInfo[playerid][pAdmin] >= 2)
