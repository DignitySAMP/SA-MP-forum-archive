Before I decided to make this tutorial, I did search the forum to see if it already existed. It turns out, it doesn't. I took this time out of my hands to make this tutorial for those who are new and may not know. Enjoy!

Grand Theft Auto: San Andreas
Modifications Tutorial

Requirements:
  • Alci's IMG Editor. http://www.gta-downloads.com/en/gta-...mg-editor.html
  • GTA Garage Mod Manager (Optional). http://www.gtagaming.com/downloads/g...eas/tools/1218
  • Modification File.
Procedures: (Alci's IMG Editor)
  1. Download and Extract Alci's IMG Editor (Recommended to Extract to Desktop).
  2. Open Alci's IMG Editor.
  3. Click File then Open.
  4. Navigate to your "GTA San Andreas" directory.
  5. Click the "Models" folder then "gta3.img".
  6. Go to "Actions" then click on "Import (remove if exist)".
  7. Navigate to the modification files and import it.
  8. Finally, click "Rebuild"!
The following is a procedure only meant to use for vehicle modifications. Although Alci's IMG Editor allows you to import any type of modification, the Garage Mod offers a great user interface.

Procedures: (GTA Garage Mod Manager)
  1. Download and Extract GTA Garage Mod Manager to "GTA San Andreas" Directory.
  2. Navigate to the "GTA San Andreas" Directory and select the "GGM" application.
  3. Use the left column to choose a vehicle you will like to modify.
  4. Once the vehicle has been selected, go to Installer on the upper left and click "Create Backup" (Create Backup allows you to restore the vehicle to it's original state).
  5. After, select "Installer" again then "Manual mod installer".
  6. Insert the DFF model and the TXD textures.
  7. When completed, click "Install".
Troubleshooting:

- If you cannot rebuild the image file using Alci's IMG Editor, right click on the program and run it as a administrator.
- If Garage Mod Manager fails to open, make sure you have included all files inside the "GTA San Andreas" directory.

If you need help, feel free to ask!
