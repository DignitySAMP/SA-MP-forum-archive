Introduction

Hi all
I remember script which changes your vehicle when you enter it like in MTA but download link doesn't work and I wanted to make it myself but a bit different, mine is dynamic!

But why I called it MyPickup? Because someone might thought it's pickup streamer!


Features
  • In-game dynamic pickup creator
  • Script use MySQL for loading and saving
  • You can add static pickups or pickups which will spawn you in car when you enter the pickup
  • Easy editing pickup (Model, type, position - you can change with your arrow keys and Z coordinate with Y/N, vehicle model (Use 0 for static pickup), vehicle color 1 or 2 & remove pickup)
