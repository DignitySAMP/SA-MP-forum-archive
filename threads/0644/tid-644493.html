Hey guys this is another project I've been working on for a server and which got cancelled.

The gamemode is basically somekind of deathmatch all vs all but set in a new fully mapped city with objects. I've been using some sa-mp objects and alot of buildings from the 3 cities of San Andreas. This was a project that got cancelled so the gamemode is unfinished, the map however is more or less complete. I'm publishing this before I forget it existed and also to prove everyone that making a completely new city in SA-MP is 100% possible if you know how to deal with the video memory limit of the game.

This uses incognito's streamer and YSI Y_INI for accounts.

Even though I had to mess with the draw and stream distance alot for the game not to crash, the draw distance still looks alot better than you'd expect. The buildings are streamed at 750 meters, the roads are streamed at 250 meters, skyscrapers are streamed at 1000 meters. The gamemode is fully play-able the map does not make the players crash.

Use whatever you need from this gamemode.

Gamemode Features:

- Custom ammunation with spawn weapons shop.
- Property system with actors and with the ability to rob.
- Automatic weather cycle.
- Hunter/Hydra/Tank spawning every friday at "Area 52".
- Bank deposit/withdraw system.
- Wanted level for robbing/killing
- Level and exp system.

Map Features:

- Bridges connecting the map to San Andreas.
- Downtown area.
- Residential areas.
- Industrial area/dock area.
- Sewers with different exists around the city (unfinished).
- Natural areas with mountains and trees.
- A custom military base I named Area 52 with a custom interior with scientist actors.
- Some custom interiors like the bait shop and city hall.
- Entrances/exists checkpoints for all interiors.
- Custom airport.
