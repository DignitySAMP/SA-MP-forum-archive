San Andreas Maps 2.0

Everyone have used ****** Maps or ****** Earth thing, well this is something similar. This filter script will give you access to San Andreas Maps. You can watch live things happening as well. Script uses a lot of text draws which is pretty interesting as well. It has the altimeter on the left side of the screen and coordinates and location on the bottom right side. I have to give some credits to Sandra18[NL] as that person has few similar filter scripts around. Although, I didn't steal any of Sandra18[NL]'s work. Script was fully written by me and only me, but yes, I've read Sandra18[NL] scripts, so I get the logic. There might be few bugs in the script, and it's not -that- optimized. Quiet a few timers, etc. Let's call this verson as 1.0. I might add some more stuff in the script later.

I hope you will enjoy this.

Commands:
/map on; /map off

Keys to move:
Use your movement keys to go straight, backward, left and right. If you press ALT (KEY_WALK) and key for moving straight, it will zoom in, if you press the key to go backward, it will zoom out. KEY_WALK plus KEY_RIGHT and KEY_LEFT will move the camera over it's axis. No more keys.

Download:
Pastebin - Version 1.0
Megaupload - Version 1.0

Pastebin - Version 2.0
Megaupload - Version 2.0
Just download those files and extract them anywhere you want. Then copy/paste them in "filterscripts" folder in your servers root folder. Afterwards add "SAMap" in filterscripts line in server.cfg

With this new version, 2.0, you won't be able to go "through" the ground and "into" the buildings and houses. This release is using MapAndreas plugin and you will need to get it before using this release. You will also have the ability to /trackveh and it will focus the camera on the nearest vehicle, distance is measured in 2D. Vehicle focus can be lost if he goes underneath the bridge or below the building or tunnel.

Now, how to install MapAndreas plugin.
1. Download this link;
2. Extract everything in your server's root folder;
3. Open server.cfg and add "MapAndreas" in the plugin line;
4. Save and quit.
Credits to Kalcor for MapAndreas plugin.
