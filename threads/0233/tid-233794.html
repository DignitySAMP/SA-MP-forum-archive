Deal arrangement:
Like the title says, I’m looking for a good professional scripter. By professional I mean someone that is capable to make a full GM from scratch. To be able to make or add any ideas/suggestions to the script, given by me at any time of the project. (I’m a good listener and open minded too don’t be afraid ^^).

Professional to the point to see this is a Real Deal Arrangement! And by that I mean: you work (code) and you get paid for it.

Professional to the point that at start he knows that this project is for “make and sell”, deleting it after the final payment! If I keep my word you must keep yours!

Our partnership in this project will end at this moment. But if all the things run smoothly (as I hope they will) you will gain our respect and will be added to our “Pro Scripter’s List”, meaning that we can propose future jobs for you, if that is your desire.

Basic GM Stuff: (For you guys start building the general idea. More stuff will be asked later)

- No vehicles;
- No house/biz system;
- Limited Skins selection; // maybe set 2 or 3 special skins groups

- Inventory System; // like “pockets” to save some stuff – Not to many. Maybe 4 or 5..
- All standard San Andreas buyable/boosts stuff will be locked; // Like soda machines, and etc..
- Random fight Areas // different random areas all around San Andreas for gameplay that will change time to time) with different spawn points each area;
- Some dialog menus; (for some features I want to add)
- Registration, stats, inventory items and some other data saved and stored;
- Maybe 3 admin levels; // little cmds to each
- Some Admin and Players cmds. // again not many. I will provide the complete list to the chosen scripter.
- It will be linked to a mysql database.
Further ideas will be displayed later (to the chosen scripter or anything specific if someone asks by PM).

You are free to make/ask for your own price along with the “Application form”.
