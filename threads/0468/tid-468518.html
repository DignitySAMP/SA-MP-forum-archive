Hello everyone.

Today i was free and i tried to update the my oldest Filterscript
which i released on 09/10/2013, 03:29 AM that's long time so i tried to update that filterscript by adding some new Features.

Well i fixed some bugs in that filterscript and adding new Features.

Features
  • Added Many Weathers
  • Added All Weapons
  • Added More Time Zones
  • Added FunForAll
  • Added Expolode
  • Added UnBuggall
  • Added Killall
  • Added Getall
How to use this?
  • Download Pawn
  • Compile and put it in Filterscript Folder.
  • Open server.cfg and write Filterscript panel
  • Go in game and use /dmenu
