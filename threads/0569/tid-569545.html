This is the confirmed working fix

Open command prompt as admin type
ipconfig /flushdns

then close command prompt and SAMP if it is open.

Next go to your SanAndreas User files folder in documents
then open SAMP folder, rename or delete
USERDATA.DAT

Now open SAMP and add your URL/DNS server and watch it work.


The issue is with DNS resolution along side the SAMP USERDATA.DAT cache. So by "fixing" both of these it shall work again.
