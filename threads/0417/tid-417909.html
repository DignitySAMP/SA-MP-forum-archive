Well, if your going to run a SA:MP server on a VPS or a dedicated server, here are the basic requirements.

Internet access (a full 100 player server uses roughly 4Mbps upload)
A forwarded UDP Port (7777 is default) | Guide
A static IP address is nice to have, but not necessary

Now, most regular scripts and custom scripts can go up to 200MB of RAM, more if your going to use MySQL.

If your going to use a regular SA:MP server host, you really don't have to worry much about this stuff unless the host your going for has special restrictions.

CPU: Anything from Intel Pentium 4 upward, depending on player amount and script.
RAM: Anything from 256 MB (for samp server only, more for OS), depending on player amount and script.
Internet connection: At least few KB/s per player (up and down) would be good to have, it can be a bit less, and again depends on the script too.

My server uses up 300MB of RAM, 18% CPU of 1 core on Intel Xeon E31270 @ 3.40GHz and 160/300 KB/s on 74 players.
