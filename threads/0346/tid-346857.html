FAQ

Waarom een toplijst?

De bedoeling van deze topic is NIET dat servers waarmee we bevriend zijn hogere ratings krijgen, en ook NIET om servers uit te sluiten door hen een lage rating te geven. De bedoeling is WEL om servers te bekritiseren, zodat de server eigenaars zich ervan bewust zijn waar ze aan moeten werken op hun server.

Ook is het de bedoeling om een mooi overzicht te geven van alle Nederlandse/Belgische servers, zodat mensen die een nieuwe server zoeken, of eens iets nieuws willen uitproberen, een goede keuze kunnen maken op basis van wat ze zelf willen. Iemand die graag TDM wilt spelen zal bijvoorbeeld geen voldoening halen uit de best gerate server als die een RP is.

We proberen met dit topic dus een draagvlak van meningen te creлren voor alle Nederlandstaligen. Daarom is het ook belangrijk dat JULLIE zoveel mogelijk hieraan deelnemen. Hoe meer wij kunnen verbeteren, hoe correcter de lijst, en hoe beter het dus bijgevolg ook is voor de servers йn het plezier van de spelers!

Waar staan de kolommen in de lijst voor?
  • Naam: de naam van de server
  • Eigenaar(s): de naam zegt het al zelf; de baas/eigenaar van de server
  • Type: hoe dat het gemaakt is (zelf/veranderd van een andere released gamemode)
  • Mode: de gamemode zelf (RP/RPG/TDM/DM/...)
  • 24/7: ja of nee; Als het ook gehost is zal dit erbij staan: "(H)"
  • Voor de andere kolommen: zie volgende vraag
Hoe worden servers beoordeeld?
  • Scripting: de rating van de server op gebied van scripten. Hier zullen wij vooral letten op het voorkomen van bugs (wat jouw rating kan verlagen) en zelfgemaakte, originele scripts. We zullen echter NIET letten op wat al jouw features zijn, aangezien iedereen zijn eigen smaak heeft, en dus iedereen andere commands het liefst ziet op zijn/haar favoriete server. (10 punten)
  • Mapping: de rating van de server op gebied van mappen. Waarbij we zullen kijken hoe goed de eenheid is van hetgeen jij hebt gemapt. Heb je geen custom maps, wordt deze beoordeling er dan vanzelfsprekend ook niet bij gerekend in het eindtotaal. (10 punten)
  • Admin team: de rating van de server op gebied van admins. Dit gaat over vanalles. Activiteit van het team binnen de Europese tijdszones (aangezien deze lijst focust op Nederlandstaligen), behulpzaamheid en objectiviteit van het team, ... Misbruik van de status zal dan weer йrg slechte punten opleveren. We moeten echter ook opmerken dat wij onmogelijk elke admin apart kunnen beoordelen. Zit er dus ййn rotte appel in jouw team, kan deze jouw rating serieus verlagen. Maar ook omgekeerd (10 punten)
  • Playerbase: de rating van de server op gebied van populariteit. Heeft jouw server altijd een tiental spelers online tijdens 'onze' tijdszones? Dan zal jij goed scoren op dit vlak! Een lege server op cruciale uren zal dan weer slechtere punten opleveren... (10 punten)
  • Sfeer: de rating van de server op gebied van gameplay. Hangt er een toffe, vriendelijke sfeer in jouw server of niet? Dit wordt in deze raing beoordeeld. Hebben we het gevoel dat alles afstandelijk is, zal je hier wat punten laten. Heb je echter een kleine maar gezellige server, dan is deze rating zeker iets voor jou! (10 punten)
Totaal = de berekening van alle punten op 10

Beoordeling RP server by Kathleen: (door [MM]IKKE)

Zo, onze eerste beoordeling! De server van kathleen, een roleplay.

Na even te monitoren zagen we dat er op de meeste momenten van onze tijdszone toch wel 2 spelers online waren. Wat dus toch al wat punten opleverde voor playerbase. We hebben liever een server met weinig maar een constant aantal spelers dan een server met op sommige momenten veel, en op andere momenten geen spelers. Ook de ping kan beter, hoewel de server is gehost bij Volt. Misschien toch een andere serverlocatie overwegen? Ook zagen we aan de hostname dat er “Free VIP/Refunds” werd gegeven, wat ik persoonlijk niet zo leuk vind.

Wat mij direct opviel bij het joinen van de server, is dat je tijdens de obligate vragenronde kon spawnen. Dit zorgde er echter voor dat je werd gekickt zonder enige reden of notificatie. Dit zou dus toch moeten aangepast worden. Ook werken enkele commands niet, zo bijvoorbeeld /rules. Aan de andere kant zag het er allemaal toch wel professioneel uit, zeker voor een gamemode die – volgens de pm – zelf werd gescript. De voertaal is Engels

Als je wat verder speelt in de server, merk je alvast dat het bijna uitsluiten gebruik maakt van een gemakkelijk pop-up systeem. Zo vind je snel de juiste informatie. Maar we hebben wel nog enkele suggesties. Bijvoorbeeld een hotkey om de motor te starten van je wagen (in plaats van ‘/car engine’, gewoon een speciale knop indrukken). Ook zou er boven de ingang en uitgang van gebouwen mogen staan dat je ‘/enter’ en ‘/exit’ moet gebruiken om deze binnen te gaan of te verlaten.

De mapping van de gebouwen was simpel maar degelijk, waardoor de server hier dan ook een mooi punt verdient. Voor zover we zijn geraakt zaten er geen gaten in de muren of andere bugs die je vaak vindt.

Nu, over bugs gesproken, heb ik er zelf toch enkele gemerkt. De commands die niet werken. Ook zag ik boven Michael’s naam staan dat hij “Admin on Duty” was, hoewel hij vanzelfsprekend gewoon geen admin is (de admin commands zelf werkten gelukkig wel niet). Een cruciale bug echter was dat, als je in de gewone map (dus geen interior), op escape drukt en de map opent, je game volledig crasht. Deze deed toch wel de rating op dit vlak een stuk dalen.

Samengevat:
-professionele look
-gemakkelijke pop-ups
-enkele kleine bugs die gefixt zouden moeten worden
-zou beter zijn met meer spelers online
-aub geen VIPs en refunds!

Houd er ook wel rekening mee dat wij niet alles kunnen controleren. Vooral op RolePlay servers is het moeilijk, aangezien je normaal gezien een eindje moet spelen voor je toegang krijgt tot de meeste commands. Waar wij jammer genoeg geen tijd voor hebben.

We konden ook geen rating geven voor admin team, aangezien er geen admins online waren op het moment waarop we speelden. Dit houden we dus even aan de kant en kunnen we eventueel later nog beoordelen. Ook qua sfeer zijn de punten laag, vooral door het ontbreken van spelers waarmee je situaties kunt acteren.

Conclusie: deze server heeft zeker het potentieel een goede server te worden. Mits de nodige aanpassingen binnen het script. We hopen dan dus ook dat jullie deze server zeker zullen joinen zodat het spelersaantal drastisch verhoogd en de sfeer + playerbase + admin staff rating sterk naar boven gaat.
