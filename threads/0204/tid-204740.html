Fro1sha, порты открываются только для IP адреса, если в системе нет указанного IP соответственно для него не может быть открыт порт.
Сервер при запуске открывается по "внешнему" IP если его нет то по 127.0.0.1

Так что не неси ерунды. У автора просто чем-то занять порт 7777, или исходя из того что он пишет все порты.
