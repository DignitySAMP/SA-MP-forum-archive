This is Smuggler Factory v2 by SkullMaster73, extended by varga.
It is a great map with interiors and vehicles.
What is the difference in v1( http://forum.sa-mp.com/showthread.ph...light=Smuggler) and v2?! :
1) Gates can be opened by pressing defined buttons.
2) Interiors added. You can enter by pressing enter button.
3) A door at tanks added to be able to go up to the top of the house and be able to get hydra / hunter.
4) 3D text lables added to the gates, doors to help players what to type / press.

Video:

[ame]http://www.youtube.com/watch?v=ptAHPfnTmvo&feature[/ame]

Commands / Usage:

Commands
/openmain - opens main gate
/closemain - closes main gate

/opemsmuggler - opens smuggler gate
/closesmuggler - closes smuggler gate

/opentank - open the gate, allows you to take a tank
/closetank - open gate, disallow you to take a tank

Buttons:

F / Enter button - to enter / exit any buildings.
F / Enter / LookBehind - to open any gates on foot. (All gate closes automatically after some seconds)
Handbrake - to open any gates in vehicle. (All gate closes automatically after some seconds)
