Originally Posted by ancezas

how about hosts, vps'es and stuf like that, can they detect files in your pc? like if you have that program in your host and it detects your files and somehow connected to samp server is it posible?
You can only collect what you can request. SA:MP is limited to that server owners can not snoop the players computers. SA:MP respects privacy, and security. Does not matter if your running the SA:MP server on a VPS, Dedicated machine, or a shared host. Your still limited to the software. The only way you could do this is if the SA:MP client would allow requests from the server to search the users computer, or installing directory. In which case it does not, for many reason.
