Here Info. i said READ "readme.txt" FILE!!!!


* GM informations:
This GameMode has a lot of things included only in the first file:
- Anti Minigun hack;
- Admin Commands System (17 cmds);
- Register System;
* Only FS:
- Object Streamer (created by [ZFM]Zuc).

There are 5 drifting zones:
- /drift1;
- /drift2;
- /drift3;
- /drift4;
- /drift5.

And in these 5 zones there are Tuned cars:
- Elegy;
- Sultan;
- Flash;
- Jester.

There are also 3 Tuning teleports if you want to yune your car:
- /tuning1 => Wheel Arch Angels;
- /tuning2 => Loco Low Co;
- /tuning3 => Transfender.

GM has also 3 car commands:
- /fix => Repars your vehicle;
- /flip => if your vehicle is turned down...it Turnes it Normal;
- /nitro => Adds NITRO/NOS to your vehicle.
