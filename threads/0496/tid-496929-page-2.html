New version is here

Feature Changelog

Code:
• New weapon interactions
- You can now chamber bullets inside of a non bolt weapon. It will automatically split the bullet stack into one bullet and put it inside. Works as a mag.
- You can now put bullets or mags inside of weapons by using the action menu.
- You can now check inside a weapon and it will tell you if it's chambered or with a magazine inside.
- You can now empty a weapon which will give you the bullets inside back in your inventory.
- Can no longer put bullets inside of mags that aren't the same caliber.
- Can no longer put bullets inside of weapons that don't have the same caliber.
- Can no longer put mags that don't fit the weapon's caliber.
- Can now interact with objects that are inside the one that you have on your hands. Ammo will get updated when needed.
- You cannot add ammo into a magazine if that magazine is attached on your weapon.
- Empty magazine/Add into actions are not allowed if magazine is inside a weapon.
- Split/Combine/Swap interactions between bullets are not allowed if the bullet is inside a weapon or a mag.
- Magazines now have a chamber size (SpecialFlag_2), bullets will get split automatically if they wont fit.
- Can now create and use melee weapons.

• New object interactions
- Splitting & emptying objects will now be put on any container in your inventory providing you have space for it.
- Can now do swaps in global dropped objects from the object menu
- Can now do actions with objects on the ground if you have a selected object from your inventory. (Swap, add into, etc.)
- Double clicking now brings action menu, deselecting any previous object for major consistency.
- Cannot open action menu on other object rather than the one that you have selected.
- Clicking on a container with a selected object will add the object into the first empty slot of that container.
- Double clicking on a dropped container adds it to the player inventory.
- Double clicking on a object inside a dropped container will add it to the first player container that the object fits.
- If containers have the same type, clicking them with a selected container will give the player the option to swap them.

• New function: slots
- New dynamic SQL table which keeps track of player objects in direct relation with the slots created.
- Player inventories are created when the player connects, you can integrate this into a player account system, for example.
- Slots can now be created and assigned to objects.
- Slots only affect containers.
- Slots have a maximum amount of objects, this number will determine how many objects of that slot you can have as containers.
- If a slot haves MaxObjects as 5, you will be able to have 5 containers on that slot.
- NOTE: New objects don't have a slot assigned (ID 1), and there is no limit to them to be added as containers, you want to assign objects their respective slots.

• Container position
- You can rearrange your inventory as you like, placing containers in any order you'd want.
- New action menu added for containers: give the option to Add Into or Swap for operations between containers.

• On hand inventory
- If you put an object on your hand, up to the first seven slots of the object will appear.
- You can interact with these objects the same way as if they were in a container.
- No action list for these objects is included.
- You can edit the offsets of the object that will get attached on your hand.
- You can now pick up objects on the ground to your hand, and are fully functioning.
- On Hand uses index 0.

• On character objects
- New option to edit the offsets for On character objects.
- Up to nine containers can be attached on your body (Sorted by position on inventory on spawn).
- Containers will not get attached if they use bone id 0.
- In game editor to edit the offsets easily.
- All objects being used will get updated when editing the offsets.
- Uses indexes 1-9.


Fixes/Other
- Opening of objects action menu is now consistent.
- Action menu timer will get reset if you double click two different items.
- Can no longer open action menu of objects accidentally.
- Objects get deselected after opening action menu (but not when activating special actions)
- Dropped objects now have special actions menu positioned correctly.
- Dropped weapons get retextured with DisplayColor color.
- Correct interactions when swapping/moving/dropping objects that use Special Flags
- Added OnObjectSwapAttempt: it is now called at the start of the function SwapObjectWithObject
- OnObjectSwapped is now called after the swapping is completed.
- Added OnObjectMoveAttempt: it is now called at the start of the function MoveObjectToObject
- OnServerObjectMoved is now called at the bottom of the MoveObjectToObject function (after it finished)
- Objects now have their current uses left displayed as percentages.
- Removing a base object now properly erases every object that uses that base object and removes them from inventories.
- Escape closes the inventory.
- New messages (for errors, information, etc)
- Editing objects display/displaycolor will refresh all dropped/on body objects.
- Changed some database names and joined the offsets columns into one column with a string with all the data.
- Dropped objects will now appear as near items without the need to walk far.
- Objects on Hand get updated when editing the offsets for anyone who has that object in the hand.
- Object scale offsets are shared for On hand and on slot objects.
- Can now duplicate or delete an object from the object edition dialog.
- Object names will be smaller if they are longer (containers headers, action headers).
- Adding an object as a container will now add it unselected.
- The inventory page is now saved when closing the inventory.
- HUD Modified: New page change buttons, letters have smaller size, on hand object haves different position.

Notes
- Negative TypeID (TypeIDAtt) are used for actions that requiere several steps or special scripting to work. (-1 is used for Swap/Add Into interactions between bullets and mags/weapons; -2 is used for Swap/Combine interactions between bullets; -3 is used for Add Into/Swap interactions between containers)
Visit main thread and the github wiki for full docummentation of all the functions and callbacks.
