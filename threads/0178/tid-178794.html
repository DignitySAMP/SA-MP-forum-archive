Features:
►This is a system cashpoints that can be used in several ways.
►INCLUDE CASH MANAGEMENT SYSTEM◄
►INCLUDE SAVE SYSTEM. Log◄

System Functions Administration CashPoints:
►/AddCash - Adds Cash to Player.
►/RemoveCash - Remove Cash to Player.
►/SetCash - Set Cash to Player.
►/ResetCash - Reset Cash to player.
►/MyCash - The player can check your Cashs Remaining.
►Role in Show Cash TextDraw added!(v1.1)

Functions include:
►new CashPoints[MAX_PLAYERS]; - Variable
►CriarCashInfo(); - Creates the database.
►LoadCashInfo(playerid); - Load the database.
►SalvarCash(playerid); - Save the database.
►ResetarCash(playerid); - Reset the cash.
►SetarCash(playerid,Cash); - Set the cash.
►AddCash(playerid,Cash); - Add the cash.
►TirarCash(playerid,Cash); - Remove the cash.
►CashInfo(playerid); - Checks the cash.

Version to INC:
►v1.0 - Without Bugs Detected.
Version to FS:
►v1.1 - No need to deploy the GM or FS and Cash in TextDraw Shows.

Installation:
►v1.1 - Add. Inc folder and put the include in the list of FS FS.
►[WARNING]: If we do not act as filterscript for the content of filterscript within the gamemode filterscript or another.[/COLOR]
