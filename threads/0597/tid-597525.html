Tennis in SA:MP

Info
Some of us love Tennis, don't we? This is a little gamemode I've made a long time ago, and now since I lost my main account ( and got this one ), I decided to release it, so people would have a little bit of fun, you know


Features
- Choose a Tennis Superstar at the Class Selection ( Boys'n garls )
- One player will be the ball
- Small force bar, which grows when you hold LMB ( This is the power you hit with )
- Some presentation Textdraws for every player that connects
- /t command to display the score for everyone ( Simple GameTextForAll )
- A lot of fun


Presentation

[ame]http://www.youtube.com/watch?v=eKtBjhJ23Us[/ame]

Bugs
I didn't found a single bug. The script has been made a long time ago, I've still tested it and it work pretty fine, for a little mini-game
