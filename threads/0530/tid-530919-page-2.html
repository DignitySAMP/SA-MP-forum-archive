About the GameMode
- It is a basic Call of Duty Gamemode which made of 1369 lines only and include all COD Server main features(teams,classes, ranks, capture zones ...), it can be edited easily by newbie-scripters & can help those who wanna learn. It don't have any admin system, u can easily add any via FS or integrate your own admin system to it.
- I used it temporarily on my server for 2 weeks to replace the outdated/overused WaW gamemode, it successfully reached 81 players at peak and 50+ players on daily bases(and got ddos'ed by some jelly kids), we replaced it with new created custom gamemode when we moved to ddos-protected host.


FEATURES
It includes all "basic" COD features such:

- 6 teams and fully mapped bases(USA, RUSSIA, EUROPE, ASIA, ARAB, and REBELS)
- 3 classes (Assault, Sniper, and Medic)
- 6 ranks
- 9 capture zones
- Heavy Vehicles Limiter based on score(300 score for seasparrow, 750 for tanks, 1500 for hunters and hydras)
- Anti-SK and Anti-Baserape system
- Briefcases to buy health,armour and weapons at each base.
- Teamchat
