Hello!

This is a filterscript pack that will contain different minigames, being updated every so often! Version 0.1 is a Minigame called "Hitman"

Hitman is a minigame I used to play at lot with some old freinds at a server. Basically, a random id is selected to be a terrorist, and everybody else must kill him. The first person to kill the terrorist, wins!

Hitman


Features

- Similar to the SA:MP Gamemode, Manhunt.
- Rcon Admin's can only activate it.
- Sets Every players color to white, and a random id to red!
- The basic objective, is to kill the red person!
- Configurable cash prize, and weapons!
- Automatic "Burn Baby Burn" Features that force the targets car to go in flames every so often!
- Easy to use and configure!
- Commands: /hitman /endhitman
Bugs

If you do not change a players colour from the default SA:MP Colour in your Gamemode, then when the minigame ends, everybodys colour will be black!
Found another bug? Report it!
