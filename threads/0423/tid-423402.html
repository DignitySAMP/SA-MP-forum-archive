Ultra Cubic World BETA

Introduction

Some days ago a weired idea came to my head - "What if I create a GM, where players can build what they want from blocks, like in Minecraft?"
And today I am glad to introduce you the implementation of this idea - that stunning project, called World Of Cubes!
It was created from a scratch and it proves people, that nothing is impossible in Sa-Mp!

Some information about the GM

In UCW you can build really everything you want! You have a full freedom!
Create magnificent masterworks from cubes, or just build something more simple - it's up to you!
You have 42 diffrent types of blocks, 15 decoration objects and 12 plants available!
This project is unique! Learn more - just start playing!

Users/Admin system

At the moment it includes the simpliest user system, which saves player registration date, IP address and a password(hashed) and also some game information(e.g Safe zone, label, etc).
No admin system is included yet

Extra possibilities

Besides the main ability - building, the server has a few commands, which are quite useful:
-/spawn - go to spawn place
-/fly - get jetpack to fly
-/safe [distance] - to set a safe zone at your place
-/delsafe - to delete your safe zone
-/label [text] - to set a 3D text label at your place
-/dellabel - to delete your label

Problems

-Water block is solid
-Bad glass texture(if you find good one tell me)
-improper decoration object of stairs
-Due to objects limit in Sa-Mp(1000), when there are too many blocks on a map, you can see them only on a very short distance
