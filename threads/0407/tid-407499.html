Introduction

This is an RCON panel that you can use to control ANY server as long as you know the RCON password. Due to security issues with most hosts, the allowed ports have been restricted to 7770 - 7780. If you do not know how to host a website, it is recommended that you just use the live demo. This is also a handy tool for your phone. This is blocked on Internet Explorer.


Live Demonstration

You can view a live demonstration of this panel here: http://rcon.rickyphelps.com


Bugs and Suggestions

Please reply to this thread with your bug report or suggestion for the website. All of these posts will be reviewed carefully and dealt with accordingly.[/B]

Downloads

Version 1.000 BETA - Mediafire
XAMPP Download (required) - Official Website



Installation

1) Assuming that you have XAMPP, turn on Apache.
2) Drag all of the files into C:\xampp\htdocs.
3) Go into bugs.php and change the emails accordingly (donotreply@rickyphelps.com and bugs@rickyphelps.com).
4) Go to 127.0.0.1 or localhost in your web browser.
