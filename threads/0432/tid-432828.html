DogFight World - Fly Like a Fighter
Introduction:
After This :- This i thought that i should prove myself that i don't just copy and paste.So i thought to prove that, i need to make something really unique.
So i Thought of This : DogFight World.
Its a Place where we all can fly fighter planes/heli's and Get score/Money by killing them.

Features:-
*Login/Register System.
*Skin Class Selection.
*Plane Selection Dialog Menu.
*Some Basic Server Commands.
*Scores + Money on Killing someone.
*You can not exit vehicle.
*/changeplane to Select another Lobby.
*Admin System with Some commands and 4 Levels.
*Basic Player Commands.

Images:




*I Didn't Added all Images - Due to less speed of my net :P

*sscanf
