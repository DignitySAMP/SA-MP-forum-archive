++i - Pre-increment
i++ - Post increment

there is minimal differences between the two for the most part except when you do something like this...

pawn Code:
if(a)
{
   b[++nextval] = c;
}
pawn Code:
if(a)
{
   b[nextval++] = c;
}
If the variable "nextval" starts as 0 the first if() would reference the array b[1]; the second if b[0]; so it has it's uses potentially.
