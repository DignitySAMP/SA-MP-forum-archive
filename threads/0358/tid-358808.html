ADVANCED WEAPON MENU MADE BY PREDA

Hello everyone, I am new in PAWN world.This is my first SCRIPT. I hope you like it and probably will use it with pleasure.
IT INCLUDES:
Multiple weapon PACKAGES such as "KILLER", for instance. Each weapon package provides specific weapons.
This script has some nice features LIKE :
-3D TEXT attached to player that purchases a package EX: BUY ASSASIN PACKAGE = it adds a 3D text label to player with text "ASSASIN" and lets everyone see what "class" is he.
-MULTIPLE TEXTDRAWS This script is based much on textdraws. You can see SCREENSHOTS with textdraws that I am talking you about.
-Random SKINS: Each weapon package includes some skins wich will be provided in random to its owner.
-JUGGERNAUT package. This feature is a very nice and improved one: at purchasing one package of this type, player gets all possible weapons, one from each slot, picked by my preferances.
-Objects attached to player are avaliable to JUGGERNAUT package only, at the moment.
-OnPlayerKeyStateChenge feature: If player presses key "N" it automacally opens dialog with weapon packages.This function is a very important one, because players don't have to waste time writing commands.Also, I made one TextDraw that "tells" the player what key should press to open WEAPON menu.
-GetPlayerMoney feature : Checks player money and lets him know if he doesn't have enough to buy specific package.
I hope you all like this FILTERSCRIPT and sorry for my english.
I am waiting suggestions in order to improve script's abilities. Thank You !
