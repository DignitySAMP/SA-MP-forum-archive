Vehicle speeding radar

What is this?
This is filterscript whose job is to tell the owner of the vehicle what's the speed of the vehicle infront. This can be used by cops for example, to catch those who driver over the speed limitation. In my opinion this is really good for roleplay servers.

How do I use this?
Really simple, below you will find download link from MegaUpload. You'll get .rar file. Just extract this one and put what you got in filterscripts folder. Then add "VehicleRadar" to filterscripts line in your server.cfg
There are few commands. Firstly when you enter your vehicle write /placeradar. That will create object id 367, which is a camera usually, it will be located in the middle of vehicle's dashboard on some models. At this point your radar is inactive. Then you type /checkspeed. Timer which is repeated every 100 milliseconds starts. Function checks if there is a vehicles infront of yours and if there is it will return that vehicles ID. Nextly model and it's speed will appear in the textdraw on the right side of your screen. You can stop the checking by typing /stopchecking and you can disable everything with /removeradar (it will destroy object as well). Afterwards, you can /issueticket which will deduct the speeders money by $1.500.
