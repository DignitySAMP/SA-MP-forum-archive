SAMP uses roughly 4mbps / 100 players
4mbps/8 = 0.5MB(500kb)

500kb*60*60*24*30 = 1,296,000,000 kb * 2 = 2,592,000,000 kb / mo
~2.4tb / mo

Thats how much you'd need for 200 players IF the server has 200 players online 24/7
