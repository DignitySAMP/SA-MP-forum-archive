Alle regels uit dit topic gelden ook hier!

Regels behorende bij dit board:

Algemeen
  • Het is verboden om over illegale praktijken te praten. Hieronder vallen onder andere:
    • Warez (Illegale software zoals keys, cracks en dergelijke).
    • Cheats
    • Erotiek
  • Gebruik een goede titel. “Help” of “Probleem” zijn geen goede titels.
  • Aangeboden/gevraagde diensten komen in het Sticky Topic “Aangeboden en gevraagde diensten”.
  • Een moderator heeft het recht om een post te verwijderen naar eigen inzicht.
Reclame/adverteren
  • Het adverteren van je server of homepage is NIET toegestaan in een topic buiten een van de volgende topics: (dit geldt niet voor je signature).
    • Server advertenties
    • Nederlandse server toplist
  • Het aangeven van een server-ip met daartoe uitdrukkelijk het informeren van een andere speler (bijvoorbeeld omdat deze er om heeft gevraagd) valt niet onder deze regels.
Scripten
  • Dit board is ook bedoeld voor hulp met programmeren cq scripten (in welke programmeertaal dan ook).
  • Zorg dat er altijd broncode bij je script staat anders wordt het topic verwijderd!
  • Het verkopen van scripts is verboden. Ook een link geven naar een website waar dit wel gedaan wordt is verboden.
  • Kleine stukjes code moeten tussen de PAWN of CODE tags staan, grotere stukken code moeten op pastebin.com komen!
  • Het releasen van scripts moet in de Script Showroom (subboard van dit board).
  • Als men hulp vraagt bij het scripten, zorg dan dat je een goede omschrijving geeft van het probleem en niet alleen het script zelf geeft!
Spam
Gezien er in het verleden veel onenigheid is wat nu gezien wordt als spam en wat niet, stellen we hier ook maar even wat regels op:
  • Gebruik de zoekfunctie voordat je een vraag plaatst! Het kan zijn dat je vraag al eerder is gesteld.
  • Niet dubbelposten. Wacht minimaal 24 uur voordat je opnieuw een reactie plaatst (bumpen van je eigen topic).
  • Ga niet offtopic, ook niet in een offtopic topic.
  • Geen berichten met alleen maar een plaatje.
  • Ofwel: Alle berichten die niet met het originele topic te maken hebben is spam!
Breken van regels.
  • Als je de regels overtreedt, wordt eerst gekeken naar de grootte van de overtreding.
    • Bij een lichte overtreding (zoals dubbelposts of grote scripts niet op pastebin) krijg je een waarschuwing en/of wordt je topic gesloten. Als je topic gesloten wordt, moet je 24 uur wachten voordat je een nieuw topic aanmaakt met hetzelfde onderwerp (als je topic niet heropend word. Mocht je toch een nieuw topic aanmaken dan riskeer je een ban.
    • Bij een grove overtreding (het uitschelden van andere spelers of het uitlokken van een flamewar) wordt je naam doorgegeven aan de global mods en heb je minimaal een week een ban te pakken.

Wijzigingen voorbehouden

Veranderingen in Algemeen:
Het praten over warez is nu ook verboden aangezien er onenigheid ontstaan was over of er nu wel of niet over gepraat mag worden. Er is besloten om dit niet te laten doorgaan om conflicten in de toekomst te vermijden.
Een moderator mag iedere post verwijderen als hier aanleiding toe is. Dit was al zo, maar nu is dit ook in de regels toegevoegd voor de duidelijkheid.

Veranderingen in Reclame/Adverteren:
Het adverteren van een clan is toegestaan, mits de advertentie in het Nederlands blijft en binnen de overige regels blijft! Geen server adverteren buiten het daarvoor bestemde onderwerp dus.
