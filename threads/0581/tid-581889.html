Treasure Hunt System v2.1
New Release



Hello! It's TRL. I'm Here with Treasure Hunt v2.1. I would like to thank Gammix for advising me. This Script uses Zcmd, Streamer, Sscanf2.

Features:
  • Dynamic System for Adding,Editing and Removing Treasure Box.
    Treasure Box Distance Textdraws. (It will appear if Player is in 20m Range of Treasure)
    Random Gifts (can be added via script)
    Players can Open Treasure Box By Pressing 'Y'
Commands:
  • /ctreasure - For Adding Treasure In Game
    /tedit [Treasure ID] - For Editing Positon Of treasure Box, However, 3D Text Label won't move.
    /destroyt [Treasure ID] - Destroying/Deleting Treasure Boxes
    /destroyallt -For Deleting All Treasures Placed in Server.
