If you use double quotes then you can insert variables into your string like this:
PHP Code:
"Hello $username!" 
If you use single quotes you can do it like this:
PHP Code:
'Hello' . $username . '!' 
And if you do this, it will insert $username literally.
PHP Code:
'Hello $username!'
