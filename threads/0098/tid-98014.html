[center]Weather Menu for RC5+
First ever 0.3 Dialog Menu release


• What is it?
Sick and tired of boring old 0.2x Menu's? Want to use that little mouse of yours? Well heres your chance!
This Weather Menu uses the new Dialog Box features for RC5 and up to select Lots of different weather settings.
DialogID: 6969

• How to use
make sure to Extract what you download, Go into the new folder and there is a .amx and a .pwn named "WeatherMenu" Open up your server.cfg and place WeatherMenu on the filterscripts line.
This Menu is avalible to everyone so make sure you add a check for admin if you dont want it like this.
