Monolith Roleplay
•About•

I will be further maintaining this project, adding bits and pieces here and there.

Original topic: https://forum.sa-mp.com/showthread.php?tid=505752

Quote:
Originally Posted by Scaleta

Starting this project on the dawn of this year, I have not actually progressed that far. However, I am always working on this in my spare time and just love doing it. Originally going to be a CnR-styled server called The Heist, I diverted from the original idea. Many beginning features were very roleplay in nature, and I realized that I really wasn't into continuing it as a CnR whilst developing RP features. All the code is mine, except otherwise stated within the script and a portion of The Heist was taken out/re-written.

Although containing no original code, this comes from my first project (GF2) and a project called Project-Alpha (something I contributed to with a friend from NGG).
The Script Is Modular! It is not hard to revert, but it is also easier to add/remove scripts to the GM in the current format.

•Features•
  • Simple Login and Registration
  • Achievements [Image: http://imgur.com/sb0Bko4]
  • Money drop system (handling over 20k on person)
  • Experience System (formula from Shane) [Image: http://puu.sh/82RIT/5bffdebd8f.jpg]
  • Unique Dynamic ATM System
  • Dynamic Doors (lightly tested)
  • Dynamic Houses
  • Custom nametags [Image: http://puu.sh/82REW/31de6974c5.jpg]
  • Interactive trucking job with random checkpoints and NPC interaction [Image: http://imgur.com/j1nmeGl]
  • Dynamic help infos [Image: http://puu.sh/82Rya/c05963775a.jpg]
  • Accent System [Image: http://imgur.com/OA93wfg,jpBrj0i,1jZPOAQ]
  • Dynamic Faction System (complete with dialog to edit)
  • House Storage System (store up to 7 weapons)
•Requirements•
  • SA-MP's default include packages.
  • Zeex's Command Processor [Link: https://forum.sa-mp.com/showthread.php?tid=91354]
  • ******' SSCANF [Link: https://forum.sa-mp.com/showthread.php?tid=120356]
  • ******' YSI Library [Link: https://forum.sa-mp.com/showthread.php?tid=61548]
  • BlueG's MySQL [Link: https://forum.sa-mp.com/showthread.php?tid=56564]
  • Icognito's Streamer [Link: https://forum.sa-mp.com/showthread.php?tid=102865]
  • Icognito's GVars [Link: https://forum.sa-mp.com/showthread.php?tid=151076]
  • Scaleta's SPC Library [Included]
  • Slice's TimerFix [Link: https://forum.sa-mp.com/showthread.php?tid=289675]
•Downloads•
  • Repository on GitHub!
  • No longer supporting Mediafire releases.
