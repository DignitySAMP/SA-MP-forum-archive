Caspian Border V1.6.2
Hello ladies and gentlemen,

After a long wait I'm finally releasing the map based on the Caspian Border map from the first person shooter game called Battlefield 3. Caspian Border is a map which consists out of many hills, but also a large forest. The pinnacle of this map would be the famous red and white electro mast. It doesn't exactly look like the one in Caspian Border, but I think it has some similarities. The map is free to download now, and I'd appreciate any feedback!

Check the video below for a preview of the map.

[ame]http://www.youtube.com/watch?v=rjqGWypOVVo[/ame]


Release info & Download

Object count: 1353
Requirements: Incognito's streamer (Or any other streamer)
Coordinates: X: -3621 Y: -2115 Z: 27
