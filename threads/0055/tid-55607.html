some of these may help you, as they helped me

- make sure thats ur local ip address for the computer your running the server on. (you have 192.168.2.3)

- also if it is tcp and udp, do it as separate entries for example

Code:
TCP  7777  192.168.2.3  sa-mp  enable
UDP  7777  192.168.2.3  sa-mp  enable
- allow though firewall on computer

- allow through firewall on router ( called Virtual DMZ host) if you have it

- and turn off WAN Ping Blocking (if u have it)

hopefully that will help. goodluck
