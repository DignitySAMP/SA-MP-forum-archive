Hey guys,

I am currently working on a user control panel for SAMP which is available for free as soon as it is finished.
In this Post I want to give you the first screenshots and information about it.

You can only download the basic version. (which you see on the screenshots)
All other functions will be available as extensions.

Why? Because I want to make it work for all servers not only one gamemode or server.
So as example you download the basic ucp and need a news system, just download the news system extension and add it to the ucp.

Also there will be a installer so you can easily install the ucp on your server.
Password Hash options are also included as example: md5, sha1, whirlpool etc.

Different languages will also be available.

In the SAMP-CP Config you can change your servername, server ip etc. easily.

Enough text for now, screenshots:
Login: https://imgur.com/BWhq38B
Profile: https://imgur.com/7MNurLH

https://imgur.com/a/MNnjR (OUTDATED)

Please note: this is the first preview! Not all things are final and will be changed before release.

I would love to get your feedback on the ucp.

Thanks!
