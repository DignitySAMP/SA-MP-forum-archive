Try to load nativechecker plugin when running the server. It can be downloaded from here. I guess you're hosting it on Linux, so you will have to use the file in .so format.
Add it to your server's root, in plugins folder, then edit server.cfg and add nativechecker.so as the last plugin.
e.g. plugins streamer.so nativechecker.so

Most of the cases, this means you either:
1- Compiled the script with a version of a plugin and when you uploaded the gamemode, You added an older version of the plugin.
2- Compiled the script with a version of a plugin (very old version) and when you uploaded the gamemode, you added new version of the plugin.

How to solve it ?

Download the plugins and compile your gamemode again with those plugins and upload the same plugins to your host (with .so if it's linux host)

Finally, If the solve didn't work, Add nativechecker.


Edit:
After reading your logs.

Please, Update your streamer and sscanf.
