I started Madoshi stunt server (now Everystuff) in 2006 as pretty much a copy of Mt Chilliad Madness server. Cars atop the mountain, with a few other stunt and dm areas (no scripted objects back then). I didnt set out to compete, and just thought their set up was a good framework for what I wanted my server to be. Diff vehicles on mine, but pretty much same places.

I played a few other servers then too (TDM and other Freeroam) and when I saw features I thought would go well in my server, Id create my own using their system as the general idea. Id improve (imo) and refine them and they would end up not being copies, but my own systems using their concepts. Of course I had plenty of my own ideas too.

I dont feel it bad to use other servers stuff as inspiration, and sometimes tweaking and refining lets you discover better ways to do things, or carry over code ideas into other parts of your script. Once I set out to have NPC players like another server (back in the day), which I turned into a Pet system (using marine life objects), which irritated me and I turned it into a command where players turn thenselves into chockens or cows that can blow things up. Just how it naturally progressed, from me wanting to "copy" someones NPC bot system.

Also: Asking for unique ideas in a thread is illogical if you dont want to copy, because the ideas people post will be theirs and techinically youd be copying them if you put them in your server (lol)
