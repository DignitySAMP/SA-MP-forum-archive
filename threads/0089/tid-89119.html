It's netzeek's server full attacks, pretty easy to stop by blocking a few IP ranges.

190.0.0.0/8

200.0.0.0/8
189.0.0.0/8
To block those ranges, first try adding them to samp.ban in the following format;

Code:
189.*.*.*
190.*.*.*
200.*.*.*
201.*.*.*
If your SA-MP server is still suffering, you will need to ban them at the physical server level through the use of a firewall so that the traffic never even reaches the SA-MP server.
