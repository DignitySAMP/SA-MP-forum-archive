There are several options.

- Create some NPCs. Most things, like spectating, work for them too (you can create commands for several actions/commands they should do).
- Use a second PC/Laptop, which is the best of these 3 options (if available)
- Run SAMP in a virtual machine (Like I do sometimes, but it needs a good PC and a goodvirtualization program).

for windows :
step 1:
make a new user account
step 2:
login to your first account SAMP/connect to your server login to your server
step 3:
alt+tab, alt+esc or alt+crtl+del (remember : dont close your GTA:SA) and then switch windows user account ( the one you made before see step 1 )
step 4:
samp login to your server and then you will see the other player/your other other yourself
step 5:
experimentation for testting your commands (switch user /back to other/vice versa)
