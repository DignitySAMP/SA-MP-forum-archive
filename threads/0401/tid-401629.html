Church System v2.1
Project Started at: 1/8/2012
Last Update: 23/12/2012
Now Make You Server Free for Pray. Have More Fun With Updated Version.



Features:
This Script is totally Dialog Based. There are many feature which are following with respect to their versions:

V2.1

1). You Can Pray In Church. May In Return God heal you.
2). You Can Confess For your Sins. May God Will make you to go in peace.
3). You Can Donate GAME money to Church.
4). You Can Buy Holy wine. Health will increase.
5). You Can Buy a Bowl For soup. Health will increase.
6). You Can Rob Church
7). 10 Church Around SA.
. To Get Attraction of players ingame random messages are added - Each message after 4 min
9). Added Map Icons [Pink "C"]. Look Bug section.
10). Now Churches need $50000 if you donate them some miracles will happens like health refill, received Armour, got weapons .... etc.
11). Added Flower item in Church Menu.
12). Added command /clocations For locations and info of all churches
13). Added Animations/Special Actions.
14). Added Church vehicles.
15). Added 3d Labels.
16). Added More Random Things.
17). Added Mini - Missions Which Can Be Done Form Church vehicles.
1. Added Toxic Miracles.
19). Added More Command
20). Commands are /ccommands - /clocations - /cmission - /cancelmission.
