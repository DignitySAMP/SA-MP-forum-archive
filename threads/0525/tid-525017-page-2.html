The code can be found under OnPlayerTakeDamage.

PHP Code:
if(team[issuerid] == TEAM_ZOMBIE || TEAM_HUMAN)
{
    if(pInfo[issuerid][pHour] <= 2)
    {
        if(team[playerid] == TEAM_HUMAN)
        {
            pInfo[issuerid][pXP] += 10;
        }
    }
} 
If you want zombies to get score when they damage a human:
PHP Code:
if(team[issuerid] == TEAM_ZOMBIE)
{
    if(pInfo[issuerid][pHour] <= 2)
    {
        if(team[playerid] == TEAM_HUMAN)
        {
            pInfo[issuerid][pXP] += 10;
        }
    }
} 
If you want humans to get score when they damage a zombie:
PHP Code:
if(team[issuerid] == TEAM_HUMAN)
{
    if(pInfo[issuerid][pHour] <= 2)
    {
        if(team[playerid] == TEAM_ZOMBIE)
        {
            pInfo[issuerid][pXP] += 10;
        }
    }
}
