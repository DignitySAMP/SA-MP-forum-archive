Rainbow Neons
Version 1.0
Hey guys i was bored and playing with code and i made a Rainbow car (Color Changer) and decided it would be cool if i could have
Rainbow Neons, so this is how i started making this code, anyway this code is pretty unique and i havent seen one yet.
This filterscript will apply the neons according to the vehicle you are driving, and it will automaticly change the neon colors every
10 seconds, there are 2 commands one of them commands is /rainbowneon and the other is /rneon (remove neons), you do not need to be in
The vehicle in order to use /rneon, and you dont have to use /rneon as neons will remove upon exiting the vehicle, dying or quitting
the server.

Features:
  • Each vehicle has its own neon offset cordinates to accomadate each vehicles ride hight
  • You can only have 1 set of neons on a vehicle at a time
  • Neons are destroyed upon exiting the vehicle, Leaving the server, and dying, i have even set it upon spawn aswell to prevent any bugs
  • Neons use a timer in order to change their colors
  • Only two commands
  • Only the driver can activate the neons
  • Only 20 vehicles have neons (Sports Catagory)
  • 3527 lines on code.
  • More vehicles to come
Current Vehicles Allowed Neons:
  • Alpha - Banshee - Blista Compact - Buffalo - Bullet - Cheetah
  • Club - Euros - Flash - Hotring Racer 1 - Hotring Race 2
  • Hotring Racer 3 - Infernus - Jester - Phoenix - Sarbe
  • Super GT - Turismo - Uranus - ZR-350
Commands:
  • /rainbowneons
  • /rneon
Requirements:
  • zcmd.inc
  • foreach.inc
Installation:
  • Download the RainbowNeons.zip
  • Copy and paste the files into the correct folders.
  • place 'RainbowNeons' on the filterscript line on the server.cfg
  • Start your server and enjoy.
