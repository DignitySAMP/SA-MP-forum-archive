The best way for me is using Event Scheduler in mysql and here's a really good tutorial if you want to learn about it: https://forum.sa-mp.com/showthread.php?tid=546630

I'd also save the player's timestamp instead of day, month and year separately. It is then much easier to add the interval of 7 days to the field and if the result is greater than the current one, the house will be auto-sold itself (it is supposed to execute the appropriate queries for this though).
