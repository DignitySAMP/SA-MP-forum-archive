Sometimes happens to me. However, I can "unfreeze" it.

If you ALT+TAB without pausing the game (Pressing ESC) it will freeze. When you click back on it, the game still isn't paused (ie, on the Pause Menu), it only turns to the pause menu when you click on it (or alt-tab to it) from outside the game. The issue arises here, it tries to "Pause" itself, however can't because the game isn't "back up and running", shall we say? So it freezes. If you're in a vehicle, with a radio on, you may still be able to hear the radio and/or some sound affects, this is a good sign! If you can hear them looping or stuttering, just CTRL+ALT+DELETE and end the process, there's no point in trying, it doesn't work. But if not, Press ESC twice. This will allow the game to enter the pause menu, and exit it again, leaving the game back to it's original state (before you ALT+TABBED).

How do I know this?
Normally, it doesn't crash (ie, Not Responding) - it just freezes. Fraps says it all when this happens. If you have your FPS counter on, it shows that the Frames per Second is actually 0 (so nothing, or frozen image - effectively a static picture) - ESC takes you to the pause menu, which, without mouse movement, is FPS = 0. Pressing ESC again, takes you out of the pause menu, and the game catches up with itself to allow you to continue playing.

I'm not sure if this will work for everyone, but from my experience, that seems to work all the time.

//Edit: I have a dual screen setup, and I only seem to notice this freeze when I ALT+TAB on a single monitor, and not when using the dual screen setup. If I ALT+TAB when using my dual screen setup, it never freeze or crash (and I actually have better FPS on a dual screen setup).
