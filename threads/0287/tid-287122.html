Try removing gta_sa.set from the GTA San Andreas User Files directory in your documents. A power outage could of interrupted the write/read from the gta_sa.set file, thus corrupting it. This means SA is trying to load data that is in effect, invalid. Removing the file will cause San Andreas to recreate the file with default settings, you can modify them to your needs.

I'm not sure if that has anything to do with the crash though, I have no idea about those Crash Reports!
