No, you got it all wrong, buddy.
1000 objects its the maximum of objects the client can take before crashing.
So your map can safely have more than 1000 objects if they are streamed correctly.
There is a plugin that can help you do that. (here) It will basically set the streaming distances according to the size of the objects.
That's kind of how the game works normally. The big land masses are loaded first, and as you get closer, trees and other small objects are progressively streamed.
This include will save you from a lot of trouble when loading the map on the server.
The in-game mapping tools, however, will crash very often. I've learned to live with it so far, but if I ever have time to get on with the expansion of this map, I'll look into a workaround.
