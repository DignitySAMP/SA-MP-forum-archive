Old School A/D
About
Old School A/D was [BoD]'s official script for quite a long time, had a bunch of clanwars on it, trainings, etc. I hope now, after release, it will find it's usage or will simply help someone.

This mode is edit of old "AAD Rumble" (people who know it will remember, no chekpoints, weapons in class menu, etc) by 90NINE, the one which i guess was first A/D being made, dunno for sure, but fact is that almost every A/D script novadays is based on this.

Lately, almost everything what i was doing with this was fixing/rewriting old stuff, so script drops from about 5000 strings in 1.0h to 3800 in this with all the commented/old stuff being removed, original was about 1800, that's for stats.

Commands
Public commands (no explanation given, people who know what A/D is will get what they do immediatly):
!<text>, /me <text>, /sync, /switch, /kill, /base <base id>, /tdm <TDM id>, /spec <player id>
/specoff, /ww, /deagle, /cs, /sawnoff, /ws <weapon set id>, /rw <1-2>, /lobby, /help, /afk
/car <vehicle name>, /carlist, /dance <1-4>, /teams, /scores, /credits, /cmd, /rules, /aadrules
/sub <team id>, /viewbase <base id>, /viewtdm <TDM id>

Admin commands (still no explanation):
/acmd, /add <player id>, /remove <player id>, /startbase <base id>, /starttdm <TDM id>, /random, /arandom
/end, /swap, /mode <0-2>, /modetime <minutes>, /modehour <hour>, /weather <id>, /setteam <player id> <team id>
/teamskin <team id> <skin id>, /resetskins, /allowset <weapon set id> <0-1>, /limitset <weapon set id> <limit>
/resetscores, /config, /showsets <0-1>, /setsmenu <player id>, /cptime <seconds>, /cpsize <size>, /usecp <0-1>
/killvotes, /tagdistance <distance>, /monstealth <0-1>, /ltonkey <0-1> <0-1>, /ids <0-1>, /pause, /unpause
/readd <player id>, /balance, /pile <team id> <tag/name>, /maxtdmkills <amount>, /reload

Game config
config.ini parameters (all changeable from ingame):
attskin - int, attacker skin
defskin- int, defender skin
refskin- int, referee skin
weather - int, weather id
modehour - int, time
tagdistance - int, distance of player name/hp visible
modetime - int, base time
maxtdmkills - int, max kills in TDM (/mode 2)
usecp - bool, parameter to turn checkpoint on and off
cptime - int, checkpoint time
cpsize - int, not float(!), checkpoint size
showsets - bool, parameter to turn on and off messages to team with who choosed which weapon set
monstealth - bool, money + armour as hp
ids - bool, show ids in chat after player's name
ltonkey - 1st: bool, lobby textdraw with teams/scores appears if player press "look behind" key - 2nd: bool, show text or textdraw on spawn with hint regarding how to use feature (only if 1st is 1)
setallow - bool, 1-7, which weapon sets are allowed
setlimit - int, 1-7, weapon set limits

Creating bases/TDMs
Bases/TDM ini formats: i was tooo lazy to edit damn 180 ini files with old bases and since needed only 1 coordinate for each team spawn made script support world cup ones since they're very easy to create, so ini formats are exactly same.

Admin FS
Admin script included, before we were using LAdmin for quite a long time, all that time i was removing and removing stuff from it, it was still laggy as hell so i decided to write my one with all the stuff i wanted + some stuff straight from LAdmin, so LethaL got his credit here. To view it's commands use /cmdlist and /acmdlist

IRC Echo
IRC Echo is included (for Jacob's IRC plugin), originally by Grove, ProRail, Jacob, Alex, Towlies and Simon. I just edited few stuff there (messages from a/d, some fixes, etc), you will need to edit defines in it (bot names, chan, server, e.t.c.)

Credits
Original script: Boylett, 90NINE, Ryden, Dracoblue, kyeman, Hamm3r
All adds / edits: Murid
Admin script: Murid / LethaL
IRC Echo plugin: Jacob, filterscript by Grove, edits by Murid

If you plan on using/editing this, the only thing i ask is to keep credits.
