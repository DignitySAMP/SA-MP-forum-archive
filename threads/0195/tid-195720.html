Okay, where shall I start .

Leeroy and Me (alpha500delta) made a GM for a server, but it did not work well. After that we went to a RP server and we thought that RP wasnt a succes because its overused, so we used this. But this did not work well either (lol) so we thought we'd release it

SWX (Stunt World Xtreme) is a Freeroam/ Stunt GM scripted by Leeroy (some things by me) and Mapped by me.
Here is a list off all features .



Code:
SWX features:

- Everything written in ZCMD so it is super-fast
- Use of sscanf wich makes everything even faster

- Unique commands (/sync, /gunshop)
- Multiple commands so you dont have to search (/commands, /cmds, /help)
- Transfer system (player can transfer money)
- AFK, BRB and Back system
- Vehicle ID list, can be used for /vec [id]
- Speedboost! (press Horn-Key for boost)

- Unique Maps and Teleports (by Alpha500delta)
- Various Admin commands (not to many, not to less)
- Well organised Script
- Objects are streamed so they dont lagg
- AutoBan for Jetpack and Minigun and AutoMute for spammers!
- AntiFlame (by Alpha500delta)
- Car Auto-Repair!
- Server-Side money
- Advanced admin level system ( levels 1-1338 )
- Admin chat
- Anti fall-off bike

And Many, Many more! (See for yourself)

Raw Commands List:
PLAYER: /register, /login, /stats, /report
VEHICLE: /veh, /vec, /[un]lock, /vehs, /flip, /eject
OTHER: /sync, /pm, /credits, /time, /gunshop
OTHER2: /afk, /brb, /back, /pay
TELEPORTS: /teleports



Teleports List:

 /lsairport, /sfairport, /lvairport
/drift, /drift2-5, /arch, /trans, /locolow
 /grove, /highbuilding, /navy, /blueberry, /police
 /farm, /showroom, /aa, /quarry, /area69
 /chilliad, /skyroad, /skyroad2
 /ak47, /deathmatch, /deagle, /arena, /leave (leaves all events)
 /deadrace /deadrace2
TO MAKE THE SERVER RUN:

1) Just start "samp-server" and have fun!



Known bugs:

- Pyramid does not show correctly untill you did /sync
- /deadrace freeze timer is a bit bugged, if you fall trough do command again
