AlarmClock
Introduction:

I think this is recognizable: You're playing Sa:mp hours after hours, you totally forget the time.
From now on you don't have to worry, because new there is the Sa:mp alarmclock!


What is the AlarmClock?:
This is a filterscript that checks the server time (local time of the host), every player can set an alarm for example on 11:30
When an alarm is set, the filterscript will check if the local time match with the time the player has set on his/her alarm.
If it matches, an alarm will go off.
A flashing (red-white) message will display and you will hear a beeping sound.


A menu will apear with 2 options:
  • Snooze: This will turn the alarm off for 7 minutes. (Just like real alarmclocks )
  • Turn off: This will turn off your alarm completely

How to instal:
  • Download AlarmClock.pwn and put it in your filterscripts-folder
  • Open it in Pawno, you can ajust the snooze-time (optional)
  • Complile it, and run it as a Filterscript

How to set an alarm:

Ingame you type /alarm a menu will open looking like this:


As you can see, you have 5 options:
  • Turn On/Off = With this option you can turn the alarm on or off
  • Set Hour = With this option you can set a hour for your alarm
  • Set Minute = With this option you can set a minute for your alarm
  • Set Message = Use this option to set a message that will appear when alarm goes off.
  • Exit = To exit this menu
To set the hour en minute, a new menu will be shown, containing the opions:


And finally, to set the message, you'll be asked to type the new message in the chat and thats all
