Hello,I had done this small script for my own server using SetObjectMaterial earlier. I decided to release it since it is buggy and I didn't want it really. ( Well the objects load slow) And some CP's even appear above than usual when you use it. (Its a SA-MP bug)

Anyway,if you try to use the FS it will not work (because of this you need to include it to a gamemode) I couldn't make it work as a FS.

I am releasing this to give an idea to the ones that would like to use the SetObjectMaterial. I didn't do the whole desert,so you might see a few objects missing.

Here are some photos:











Here is the download:

Don't forget this will not work as a FS. You need to copy the code to a gamemode.


Or:

http://pastebin.com/XuW7y916

Known bugs:

Objects are removed using removebuilding and created back,so the objects are deleted they must be created again,because of this they load slow and you may see some areas empty.

Meanwhile,if you go very fast with a car the objects might look like a desert still,but it fixe's it instantly.


Note:

If you want to change more lands to green do this:

1.Select the land you want to change to green.
2.Then,delete it.
3.Copy the removebuilding object and paste is somewhere
4.Then,clear all code.
5.Copy the object you want it to get removed.
6.Copy that createobject code and paste it near the previous removebuilding
7.Clear all again
8.Now,paste them together.(Removebuilding+Createobject)
9.When you do this,you will realise that the object has lost its rotation,to fix it you must go to movements tab and do "reset angels"
10.Now,copy the code again and clear all.
11.If you know how to use setobjectmaterial,you know the rest

Your rights:

Ask me if you want to re-release it or so. The gamemode is my gamemode in the pictures,it is not a part of the FS
