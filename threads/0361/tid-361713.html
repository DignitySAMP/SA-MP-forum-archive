Smart Checker System V1.2 (UPDATED!)



What does S.C.S do?
S.C.S (Smart Checker System) is an advanced system in SA-MP that checks for certain OOC words, and smileys in IC chat, and sends a message to the player saying that he can't use such crap IC'ly, and fines him automatically.


How will S.C.S help improve Roleplay?
Basicly, the whole point of making this system, was just to stop newbies, trollers, or anyone else from using such words in IC chat. So it would improve roleplay alot, as people will be forced to roleplay rather than talk such crap IC'ly (This would work great if you make an admin command to tog /b for everyone).


Words supported by S.C.S v1.0:
- "Lol"
- "Rofl"
- "Noob"
- "fu"
- "lmao"
- "lmfao"
- Brackets to avoid OOC chats in IC chat. (( ))
V1.1 & V1.2
- "brb"
- "afk"
- ":d"
- "derp"
- "DM" & "DMer"
- "RP" & "nonRP"


If you feel like there should be more words added, feel free to post about it.

Change log:

Change log for V1.2

-Edited the script so now "lol"  and such are considered an actual word, and will be auto fined for it.

-Brackets are now more flagable (added if a player uses "( (" or "((" to OOC'ly chat in IC chat.)
-Added a few more words such as DM, DM'er, and RP etc.
