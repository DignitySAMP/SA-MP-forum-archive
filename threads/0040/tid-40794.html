Features:
There are many features.
Most of them can be also disabled if you dont want to use them.Take a look at the
generalconfig.cfg and levelconfig.cfg in gAdmin Config folder.
Basically the levelconfig.cfg just stores the level you need for a specific admin command,for
example "kick=3".You need AdminLevel 3 to use /kick.
The generalconfig.cfg stores all other configuration options like disabling functions (Whitelist=0) or other settings
like "MAX_VOTEKICK=5".

+ GENERALCONFIG.cfg
  • Whitelist=0 - Decide if the FS should start with WhiteList On *Read Whitelist under Features
  • Blacklist=1 - Decide if the FS should start with Blacklist On *Read Blacklist under Features
  • ClanBlacklist=1 - Decide if the FS should start with ClanBlacklist On *Read Clan Blacklist under Features
  • LoginTime=40 - How many seconds you have to Login after Spawning to Login if you haven't done this already.Set to -1 if you want to disable this function
  • PingKick=1 - PingKick on or off?1=On | 0=Off
  • PingKickInterval=5 - Decide in which Interval the Ping has to be checked | 5 Seconds
  • MAX_PING=400 - Max.Ping allowed on the Server
  • MAX_PING_WARNINGS=5 - How often a Players Ping can be too high before he gets kicked
  • DisplayConnectMessages=1 - The normal Enter/leave message you maybe remember from 0.1 (0=Off/1=On)
  • DisplayMode=1 - Displays GameText while you are in a Car(0=off/1=SpeedOMeter/2=AreaName/3=SpeedOMeter+Areaname)
  • ShowAdminCommand=1 - Do you want to show every Admin Command in the chat?(0=Off/1=On) If off,only Admins will see the message
  • DynmWeather=1 - Dynm. Update of the Weather (0=Off/1=On)
  • DynmTime=1 - Dynm. Update of the Time (0=Off/1=On)
  • ScoreUpdate=1 - Updates the Player Score to the Amout of Money a Player owns(0=Off/1=On)
  • GodHP=1000 - The value to set PlayerHealth or VehiclesHealth for God-Mode (/god),10000 is a good value
  • SlapHP=25 - The Health Points to take away from a Player when slapping him ('/slap')
  • Advertise=visit www.san-vice.de.vu - A message you want to send to a player when he connects (visit: www.-whatever-.com)
  • AutoLogin=1 - Enables AutoLogin via IpComparision
  • RegisterToSpawn=1 - You have to register before you can spawn (0=Off/1=On)
  • DefaultJailTime=300 - Time a player has to be in jail in seconds after he gets autom. unjailed
  • MAX_VOTEBAN=5 - How many votes you need to ban a Player via /voteban
  • MAX_HELIKILLS=3 - I hate people killing with Hydra/Seasparrow etc.Lets kick them after some kills with these vehicels... (0=off)
  • MAX_BADWORDS=5 - The name explains all.The bad words are defines in '/gAdmin/gadmin.inc'.The Count how often a Player can say Bad Words before he get's kicked
  • SPAMRATE=3000 - Interval in which not more than 'MAX_MSG_IN_SPAMRATE' should not be send
  • MAX_MSG_IN_SPAMRATE=5 - How many messages are allowed in 'SPAMRATE'
  • IRC_Channel=#gAdmin - The name of the IRC Channel you want to join if you would like to use the IRC thingy
  • IRC_Botname=My_gAdmin_Bot - Your Bot's name if you would like to use the IRC thingy
  • IRC_Botpassword=duntknow - The password for the Botnames Account
  • IRC_ServerPort=6667 - Port of the IRC Server
  • IRC_IRC_Server=irc.gtanet.com - IRC Server you want to connect to
  • V_[NAME][NUMB] - Those are Vehicle Model ID's which are used for the Vehicle Spawn Menu ('/v').

Translations:
Currently I have only english,german and polish available as a languagefile in the downloadpacket.
I would be happy, if someone could translate it into another language.I don't really bother what
language it is, but some language would be awesome.For example spanish,polish,french,russia,italy,dutch etc.
If any of you can translate it into another language (not one I mentioned above) it's great too .
- - - - - - - - - -
You can add new Languages very easily.
You need under OnFilterScriptInit():

AddLanguage("GER","Deutsch","txt");
LoadLanguageFile(l_German);

I used seperate Commands,so you can reload language entrys on the fly.

Note: Not every Message is editable via language includes.Those who can only be changes in the *.pwn are in english.
