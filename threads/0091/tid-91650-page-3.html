Protect the President v3

Introduction

PTP v3 is a gamemode for SA-MP 0.2X based on the original Protect the President gamemode by Tratulla (Popular in 0.1)
PTP v3 is a complete rewrite and contains no code from the original script.

Features

- All new GMXless system: The gamemode changes rounds seamlessly and respawns all players in the next round without interrupting gameplay.
- MySQL based account and admin system.
- MySQL based ban and logging system - All bans use mySQL as opposed to samp.ban file.
- Over 30 admin commands.

Credits

- Tratulla for the original idea.
- Ez and KmanN for coding the gamemode.
- G-stylezz for his MySQL plugin.

Downloads

Gamemode (Source + Compiled) http://files.uploadffs.com/a/a74ca421/PTPv3.rar

Other

Please read the Readme.txt file located in the rar file, this will explain how to setup the various MySQL databases, etc.

Any other questions or comments can be posted here or directed to Ez or KmanN on irc.ffsnetwork.com.

Make sure you create "scriptfiles/echo" otherwise the gamemode will not load.
