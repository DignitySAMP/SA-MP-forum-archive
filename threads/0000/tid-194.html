CONDITIONS OF USE:

The source is released for educational and server
security purposes only. DO NOT copy or use
any of the source code without conscent or rightful
credit to the authour. Feel free to manipulate it and
improve the code, as long as full credit is given to
myself and any other contributors.

**********************************

FEATURES:

Clan Battle is a contemporary script designed to make it
easy enough to hold a clan war. Great Script, Great features.

- User Defined Teams (ClanConfig.txt)
- User Defined Weapons/Ammo (ClanConfig.txt)
- Ability to set max kills
- On-Screen Clan Score Counter
- Freezes everyone once clanwar ends
- /reset feature to reset all players and clans scores
- After clanwar statistics are saved to a file
- Clan Details
- Winning Clan
- Each Players Statistics (Kills, Deaths, Ratio)
To allow easy stats to post on forums, websites etc.



**********************************

CONFIGURATION:

--------------------

Team-1 =BDC= // TEAM CLAN NAME/TAGs
Team-2 =BDC=

Max-Clan-Kills 10 // ClanKills required to win war

Weapon1 24 // WEAPON ID
Weapon2 26
Weapon3 32

Ammo1 500 // AMMO AMMOUNT
Ammo2 500
Ammo3 500

--------------------

COMMANDS:
/reset - (Admin Only) Resets the entire Clanwar
/scores - Shows Clan Scores
