Quote:
Originally Posted by roeiking12
can u explain what is it SQLite and how to use it?
ty!
SQLite is a database system that's natively implemented into the SA:MP server. It will work on any server that's compatible with the SA:MP server, and is no fuss to set up. To use SQLite you only need to put your .db file (your database, which is lva_gm.db) in your scriptfiles folder.

You can view/edit the contents of the lva_gm.db file using the SQLite command-line program found on the SQLite official website (here).
