Whitelist

What it does?
You can enter PlayerNames with a Command into the list. If the PlayerName is in the list, the Player can play on your Server. If his Name is not in List, he can not play on your server.

How to add a Player?
Type /whitelist [PlayerName]

How it works?
It reads the PlayerNames out of a File, which is named Whitelist.cfg

Install
Put wl_eng.pwn & wl_eng.amx in your Filterscripts Directory.
Create the File Whitelist.cfg in Your Scriptfiles Directory and add you name in the Whitelist.cfg

Problems with this FS?
Post the Problems With the FS here in the Theard.
