segui estos pasos:
1є Copia el archivo MidoStream.INC a la carpeta de los includes de pawno.
2є Copia el FS MidoStream a la carpeta "filterscripts" de tu server.
3є En el archivo server.cfg en la linea "filterscripts" agrega "MidoStream".
4є Crea un FS con este codigo:

pawn Code:
#include <a_samp>
#include <MidoStream>

public OnFilterScriptInit()
{

  //aca pones tus objetos. ej:
  CreateStreamObject(1668, 2005.804199, 2226.624268, 11.639277, 0.0000, 0.0000, 0.0000, 500);
  CreateStreamObject(1669, 2001.322998, 2223.902344, 12.747864, 0.0000, 5.1566, 0.0000, 500);
  CreateStreamObject(1551, 2000.830933, 2226.712158, 12.244444, 0.0000, 12.8916, 0.0000, 500);
  CreateStreamObject(1951, 2001.434692, 2223.804688, 13.912299, 0.0000, 5.1566, 0.0000, 500);
  CreateStreamObject(1520, 2003.332642, 2223.871094, 13.575435, 0.0000, 0.0000, 0.0000, 500);

  return 1;
}

public OnPlayerDisconnect(playerid, reason)
{
  MidoStreamDisconnect(playerid);
  return 1;
}
5є Compilas tu FS y lo guardas en la carpeta de tu servidor "ilterscripts" con un nombre x ej: objetos
6є En el archivo server.cfg en la linea "filterscripts" agrega "objetos".(o el nombre que le allas puesto a tu FS)
y ya deberia funcionar.
espero que te sirva
