Introduction

A very simple circuit consisting of not many objects, it was created because I thought it was about time I designed a racing circuit instead of another city/town, the track itself is roughly 2 miles in circumference and is south of the docks in Los Santos, enjoy.

Videos/Pics of the map

I don't have any pics but I do have this short video http://www.youtube.com/watch?v=pgUBWnFirFw

Commands

/circuithelp - This command makes the command menu appear.
/clearchat - This command clears the chatbox.
/circuitinfo - This command gives you the important information about this filterscript.
/opengates - This opens the circuit gates so racers can go.
/closegates - This closes the circuit gates so racers can't go.
/raceloc - This command puts a red marker on the map showing you where the circuit is.
/rcp - This command removes any checkpoint on your map.
