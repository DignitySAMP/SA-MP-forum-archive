SA-MP ScriptBuddy
v1.7
_________________________________________________
About
- Allows easy creation of commands, teleport commands, vehicles, pickups and objects! -
- Easy to use interface -
- Required fields change font -
- AddStaticVehicle and AddStaticVehicleEx supported -
- CreatePickup and AddStaticPickup supported -
- My first app -
_________________________________________________
Changelog
1.0
Initial release

1.5
Added pickup option
Both AddStaticVehicle and AddStaticVehicleEx supported
Changed the size of the app a little
Added an icon

1.7
Converted everything from VB6 to VB.NET
CreatePickup and AddStaticPickup supported
Clicking on some textbox labels will give info about it
