Features
Simple Box
Easy To Use
With Some commands
Informs When some one joins
Informs When some one leaves
can be used as 2nd chat of the server..
Can use,
~r~ for red
~g~ for green
~b~ for blue
~w~ for white
~y~ for yellow
~p~ for purple
~l~ for black
~n~ for new line
~h~ for lighter color


Commands
/Clearbox - To Clear the Box
/ABox - Send Box Message
/Box - Send Box Message but will ur name and Id.
