It's not good. You never check if the issuerid is an INVALID_PLAYER_ID, therefore if the player for example will fall from somewhere he will receive damage with the issuerid to be an INVALID_PLAYER_ID which probably causes the crash.

You should do the above check

pawn Code:
if ( issuerid != INVALID_PLAYER_ID )
before you use the issuerid parameter

as an example

pawn Code:
if( ( issuerid != INVALID_PLAYER_ID && ( weaponid==0 && PlayerInfo[issuerid][pGodziny]<2 ) ) )
always check the wiki
