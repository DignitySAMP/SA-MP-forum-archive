Falloutі
Backgroundі:
This gamemode was one of my more recent projects. I've recently lost the desire to script in SA:MP and I'm not really active anymore. Since there haven't been many roleplays based on Fallout, since it's a very different type of roleplay, I decided to release it.
Featuresі:
This script really isn't far along, I've only spent a couple of weeks developing it, although it is very playable in it's current state.
  • Desert Based (Near AA)
  • Shelter for all (Castle type map)
  • Character Selection
  • NPC Characters
  • Tutorial for new players
  • Radiation Zones (Areas still affected by the latest bomb that can deal you damage)
  • House System (Currently houses can only be added manually by editing files)
  • Hunger and Thirst System (Replenish by buying from NPC)
  • Usual RP stuff (/me, /o, etc)
  • Admin System (Although there aren't tons of commands)
  • Streamer based objects (for further development)
