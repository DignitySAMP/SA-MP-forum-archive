Skins Cutscenes


Hello

The SA-MP 0.3.8 is coming, and in this it will be possible to add skins to our server.
I walked a few days, looking for the skins that the SA-MP Team did not add and that were present in the game.

I was able to find some already in the format of the game, searching the archives of GTA SA. Others, I had to find them converted.

Demo (ingame)


Images (kdff gui): https://imgur.com/a/oabjU
Images (blender*): https://imgur.com/a/7x64u
Images (ingame): https://imgur.com/a/fwsEQ


Bugs
I made several tests and reviews. I did not encounter problems with these skins. But if you find it, just report it.


Instructions
Download and extract to the models folder. Remember that it is only compatible with SA-MP 0.3.8.
After extracting the files, edit the file artconfig.txt (there is one inside the compressed file). Copy the lines and see the skins IDs. You can change them if you wish.

As soon as you connect your server, connected players will download the templates and the skins will be available for use in the IDs reported in the file.

Note: It has been reported 8 skins of which there are problems with the tag informing name and life of the player. These skins are in the untag folder, and you can use them however aware of these problems. There is no timeframe for these changes.
