ADMIN AREA
By: Chris10




------------------About--------------------
-This is a Simple MAP & FS. It is an Admin Area with lot of stuff to to do there.
Admins can go there to rest or have fun.There are also many commands to use to open gates or to teleport somewhere and also there is a hydra for admins only.


------------------Features--------------------
-It includes:

-Main Gate [At the entrance]
-A big House that considers to be the Admin house
-Some vehicles [You can Add More]
-An Admin Park that is behind admin house.There are lot of stuff there.
-An elevator that goes up and down by entering the pickup.
-A secret area that is located in the admin park.
-Admin secret Area can be open by typing a command.
-Inside the admin secret area there is a hydra [Only admin can use it]
-Many objects using Icongnito Streamer

------------------The Commands--------------------


~You must be RCON ADMIN to use them~

/ahelp -Viewing the commands for Admin Area
/agate -Opens the main gate.When you enter.
/adminarea -Teleport you in from of the main gate.
/adminhouse -Teleport you in the Admin House
/adminpark -Teleport you in the Admin Park.
/secretarea -Opens the way to secret area.
