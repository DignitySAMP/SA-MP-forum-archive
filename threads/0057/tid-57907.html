Weapon Menu

This FilterScript adds a nice menu for several weapons. It's ideal if you don't have any ammunation shops open.

If you don't have enough money to buy a certain weapon, then you get an error message.


~Commands~

/WeaponMenu



~Prices~
M4 - $600
AK-47 - $600
MP5 - $600
Desert Eagle - $250
Grenandes - $100
Sniper - $1000




~Links~

Version 1.0
My Host (Right-Click and Save As.)

Version 1.1
UploadFFS

Version 2.0 NEW!
UploadFFS
This version includes a new feature. You must be inside an ammunation to buy a weapon.


~Credits~

Just me, Tez. :P



~Future Releases~

I'll be adding more weapons soon. This version was requested by a friend of mine.
