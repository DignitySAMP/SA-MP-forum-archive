Church System v1.2
Project Started at: 1/8/2012
Last Update: 23/11/2012
Now Make You Server Free for Pray. i just make this script in few hours hope you like it .

News:

v1.2 Released. Check it Out!


Features:
This Script is totally Dialog Based. There are many feature which are following with respect to their versions:

V1.0 & V1.1

1). You Can Pray In Church. May In Return God heal you.
2). You Can Confess For your Sins. May God Will make you to go in peace.
3). You Can Donate GAME money to Church.
4). You Can Buy Holy wine. Health will increase - Only If You Have -50 health.
5). You Can Buy a Bowl For soup. Health will increase - Only If You Have -50 Health.
6). You Can Rob Church - Gives Random Money - Increase Wanted Level **

** ROBBERY SYSTEM IS NOT BASED UPON TIMERS IT BASE UPON PLAYER(S) HEALTH

V1.2

1). Added 5 More Churches around San Andreas - Total Churches 10 use /clocations ingame to view their locations and informations
2). To Get Attraction of players ingame random messages are added - Each message after 1 min
3). Added Map Icons [Pink "C"]. Look Bug section.
4). Now Churches need $50000 if you donate them some miracles will happens like health refill, received Armour, got weapons .... etc.
5). Added Flower item in Church Menu.
6). Added command /clocations For locations and info of all churches
7). Added Animations/Special Actions.
. v1.0 & v1.1 were laggy . (fixed) V1.2 is lag free.

Installation:
You Can Install this Filter Script by following these steps:
1). Extract .rar File
2). Put Church_System.pwn and Church_System.amx (in v1.2 church_systemV1.2.pwn and church_systemV1.2.amx) in Filterscript folder ( ....../your server/Filterscript/).
3). Open Server.CFG and write church_system (for v1.2 write church_systemV1.2) infront for filterscripts.
4). Run your server.
