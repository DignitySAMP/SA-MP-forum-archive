map2pwn by CracK
Introduction:
Newest MTAM map editor is a lot better than MTA:Race one(just try it!). But there was no converter from MTAM map format to CreateObject.
After non-finding such a converter(delux's doesn't work) I decided to make my own, based on seif_converter.

Usage:
-Paste map2pwn.amx in filterscipts folder(You will need dutils from here for compiling)
-Paste your *.map file in scriptfiles folder
-Start server, type in serverwindow loadfs map2pwn
-Type convert type* mapnamehere
-*.pwn file with your mapname will appear in scriptfiles folder

*type 0 or 1, it depends on MTA map file format, if you have problems with 0 type, use type 1

Credits:
-CracK (me)
-Seif (seif_convert)
-Draco (dutils)
