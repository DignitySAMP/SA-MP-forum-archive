Information

Hi, I had this speedometer done far back in May, but I never released it, I guess I should release it now . This speedometer is not the ordinary speedometer, if features visual tire damage, which is what I haven't seen on other speedometers .

Features

- Health Bar
- Speed Bar
- Customizable URL.
- Tire Damage.
- Speed (MPH)
- Health #
- Vehicle Name

Pictures



Videos

[ame]http://www.youtube.com/watch?v=aRIYXCvrvc8[/ame]
Sorry if you can't see it, but the picture can tell you what's happening.

Tutorials

Here's how to change the URL inside of the speedometer.

pawn Code:
#define SERVER_WEBSITE "www.volt-host.com"
Obviously change the default URL to your URL, if you don't want a URL just keep it blank.
