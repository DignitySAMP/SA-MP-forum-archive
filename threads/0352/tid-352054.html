Failed to set data for
la deschidere pawno va apare acest eroare click

Rezolvare
Folderul Pawno>>>deschidem settings.ini>>>gasiti FileAssoc=1>>>inlocuim cu FileAssoc=0>>Save

File or function is not found
majoratatea are acest probleme "File or function is not found..." la deschidere serverul

Rezolvare
descarcati plugin nativecheker acest plugin puneti in folder Plugins si deschidem server.cfg gasiti linia Plugins adaugam nativecheker,.so pentru linux,dll pentru windows si salvam,pornim serverul apoi inchidem,deschidem server log aveti acest eroare Error: Function not registered gasit de nativecheker,daca e audio,streamer,sscanf exemplu Error: Function not registered 'Audio_Stop',descarcati ultima verisiunea plugin si include(tot ce este in arhiva) care va da eroare si recompileaza totul(filterscript si gamemodul) in caz la fel va da eroare,va propun sa descarcati noi fileuri pentru verisiunea serverul vostru, verificati daca sunt pluginurile in folder plugins si #include in scriptul,verificati daca functia a fost sters sau schimbat de creator
Atentie:este necesar sa aveti Microsoft Visual C++ 2010 Redistributable Package si net.framework 3.5

Invalid/unsupported P-code file format
Rezolvare
folder Pawno>>>>deschidem Settings.ini>>>Adaugam Params=-r la sfarsit>>>Save


in caz ,daca nu puteti rezolva ,puneti server log si o rezolvam
