You need to but the Map Spawns outside of the enum because an enum is just a list of constants therefore it can't handle arrays with 2d or more

pawn Code:
enum CurrentMapData
{
    Event_Name[30],

    Interior,
    World,

    Weapon_1,
    Weapon_2,
    Weapon_3
}
new cMapData[CurrentMapData];

enum SXYZR
{
    Float: SpawnX,
    Float: SpawnY,
    Float: SpawnZ,
    Float: SpawnR
}
new cMapSpawn[2][3][SXYZR];
