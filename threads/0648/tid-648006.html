Ok so after spending a long time with both minecraft and samp I have found a differnce between the owners of the 2.

Minecraft:

+ They use Xenforo as a forum software (we at least the more professional servers do. the newers server use enjin)
+ They use play.domainname.com (if you have default port 25565 you dont need to put in the port to connect)
+ They're mostly in it for profit
+ They restrict gameplay for donation perks so you're forced to donate in order to do something like setup a shop
+ They're mostly all against mojangs EULA and some have even been blacklisted for been pay 2 win
+ Most servers don't allow swearing or insults
+ Most people are equal
+ They use the donation money for personal use
+ pretty much everyone hacks or has hacked on servers
+ You can apply for staff on their website(s)
+ They have full 3d over the top rendered expensive server logo's
+ Minecraft has a plugin called buycraft which is automated donations with commands


Samp:

+ They use vbulletin forum software
+ They use samp.domainname.com:7777
+ They're mostly in it for fun like a hobby
+ They don't restrict gameplay as much for donations
+ Pretty sure there is no EULA saying they cant sell perks, items, etc
+ Their communities are a lot more immature, like they say the n word and swear all the time and its pretty much allowed
+ Only famous/known players get the attention when they speak like in /newb /g or whatever
+ They use most of the money on the server (at least i think so)
+ pretty much everyone hacks or has hacked on servers
+ Staff positions are hand picked
+ They use simple but eye catching logo's
+ most servers on samp don't have automated donations
