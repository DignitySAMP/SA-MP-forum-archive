en la carpeta scripterfiles debe haber un archivo que ponga cars.cfg

los aсades alli con este codigo:

Code:
536,2118.743408,-1140.133666,24.724407,304.783538,3,0,Dealership,Blade,70000,,0,1

563= modelo
= 2118.743408,-1140.133666,24.724407,304.783538= saveposition
3,0 || 0,1= color 1 y color 2
Dealership= propietario
Blade= nombre
70000= precio
y luego en el GM debes buscar una cosa como esta

pawn Code:
public IsAnOwnableCar(vehicleid)
{
    if(vehicleid >= 184 && vehicleid <= 268) { return 1; }
    return 0;
}
