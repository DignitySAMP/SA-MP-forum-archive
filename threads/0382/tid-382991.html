You need to create a new enum for this as far as I'm aware because you can't have two [size][size] for enum variables.

pawn Code:
enum e_Ranks
{
    pRank[32]
}

new playerRanks[MAX_PLAYERS][/* maximum amount of ranks */][e_Ranks];
