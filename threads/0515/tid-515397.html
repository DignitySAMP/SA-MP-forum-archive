It's something to do with the players animation. An animation style seems to be applied but it doesn't exist, thus causing a badly handled crash - R* returned null from "CAnimManager::GetAnimationBlock(name)" and didn't check it before reading - so if a name is passed which doesn't exist, the game crashes.

You're using mods, so obviously just try removing them all or seeing which particular one causes the problem. But if the server game mode were to attempt to apply the anim too, then it is possible that could also cause the crash, and you need the animation present. So it's either a badly coded script, or something is incorrectly installed.
