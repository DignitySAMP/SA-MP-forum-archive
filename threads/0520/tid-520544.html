Usage

1- Compile The Script
2- In scriptfiles folder, create those empty files so that the server doesn't crash:
Code:
admin-request.txt
bug-reports.txt
players-admins-reports.txt
questions.txt
suggestions.txt
tag-requests.txt
For Players : use /forum
For Admins: First you have to login as an RCON admin.
next: Use /cr1 , /cr2 , /cr3 , /cr4 , /cr5 , /cr6 to clean the chat rooms, you can also edit the news.
