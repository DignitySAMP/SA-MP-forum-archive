pawn Code:
pInfo[playerid][pSex] == 1;
pInfo[playerid][pSex] == 2;
== means "is equal to". It's used in statements like these:

pawn Code:
if(pInfo[playerid][pSex] == 2)
{
   doSomething();
}
You're supposed to use:

pawn Code:
pInfo[playerid][pSex] = 1;
pInfo[playerid][pSex] = 2;
That way pInfo[playerid][pSex] is assigned to either 1 or 2.
