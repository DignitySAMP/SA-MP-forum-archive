This is a Login/Register System .
It Saves your Score and Cash.
It also includes a Premium Players System.
If a Player Registers on your Server a file will be created in your scriptfiles folder.
Then you can easy edit the players score,cash and Premium level.
Premium Players have special commands,to see all command type /pcmds.
I added just 5 simple commands: /heal , /armour, /flip, /nos, /hyd
You can remove them or add more if you want.
