Hello everyone welcome to my new gamemode called CounterForce, Sounds like CounterStrike as it was kinda based on counterstrike but yeh just changed some names around. I made this because I wanted something good out when my forum is all done, But yeh still the coder has more things to do (It really looking epic the website) but it will be done soon.

CounterForce
1a
By mobiliz

Features:
Map changing system - 2 maps
First Person
2 Teams
Admin System
Register/Login System
5 Simple Player Commands
V.I.P System (No cmds yet)

Pictures:



Credits:
Y_Less - Sccanf, YSI, foreach
Jack_Wilson - First Person
Kitten - Map Changing System + Other Stuff
Incognito - Streamer
Zeex - zcmd

Info:
In your scriptfiles you need to make a folder called CF for your accounts to be saved in.
For some reason you need to relog when you register so your stats will save (not when you login).
