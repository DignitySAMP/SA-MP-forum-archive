You do not need to forward ports in other for other computers in the LAN to connect to each other, forwarding ports is only for the internet. Additionally that wouldn't work as he explained his nephews are on the same network, you cannot connect to services on your own network directly through the internet, they need to be accessed locally.

You don't need to set the lanmode to 1 to connect from the Local Area Network. All you should need to do is run the server, and any other devices connected to the same LAN should be able to connect to the server through the LAN IP of the computer running the server software.

For example my main house PC is 192.168.1.21, if I ran an SA-MP server on it, and wanted to connect to it from another computer located on the same network, I would just connect to 192.168.1.21. To get the IP of the PC you are hosting the server on, open a command prompt and type ipconfig, and look for the IPv4 address of the active network adapter. I'm assuming that you may be trying to connect to the router, as the IP of the router is generally 192.168.1.1 or .254. So make sure you're connecting to the LAN IP of the computing with the SA-MP server running on it.

This sounds like a problem with your network configuration, can you ping the other computers in your Local Area Network? Try pinging the computer running the server from another computer in the network that you are trying to connect to, if you cannot ping, you have an error in your network setup.

Also if you want to remove it from the internet list on SA-MP, you need to set announce to 0 in the server.cfg.

Heres what you do
First, find your IP
-VISTA-
Open the Start menu, search CMD
Then open the file called "cmd.exe"
when it is opened type "ipconfig"
Without the "s of course
Example lines:
Link-local IPv6 Addres.....: XXXXXXXX
IPv4 Address.....: 192.168.1.10X
Sometimes it could be 192.168.1.104, 1.105 ETC
Then, go into the SA-MP Menu
Go to Favorites
and click Add Server
Then type your IP then your server port (Most likely 7777)
Example:
192.168.1.101:7777
once its added
It should say"YOURSERVERNAME 0/?? Players PING MODE
(EG.Mylanserver 0/50 players 4 ping grandlarceny)
If your hosting a LAN Server
make sure Lanmode is set to 1
I suggest making your max players 50 if its a lan server
your ping should be Low,really low.
