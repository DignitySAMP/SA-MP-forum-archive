Okay, if it's a column, you mark it with `Column`, if it's a string you put '%s', notice the apostrophes.
Example
pawn Code:
SELECT * FROM `players` WHERE `Name` = '%s' AND `PlayerLevel` = %d",
So what you gotta do is add `` around tables and columns, and ' ' around strings. Integers and floats don't need any wrappers.
