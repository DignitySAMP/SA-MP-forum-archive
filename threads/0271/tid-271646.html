Fala galere, vou mostra pra vo6 como converter um carro tunado do mta pro samp, Here Fuckin' Go;


1є- Fazendo o carro

1є - Faзam o carro e salve com /save

pawn Code:
AddStaticVehicle(534,2517.1960,-1672.4552,13.7670,60.7259,1,1); // remington
2є - Abra o MTA (Qualquer Versao!!)



3є - Va a o Map Editor

4є - Bote o carro escolhido (usei um remington)



5є - Tune-o



6є - dps de pronto salve(((com nome que quiser

2є - Achando os componentes


1є - Vao a que vs instalou o MTA, depoois em server, mods, deathmatch, resource e procurem uma pasta com nome do carro
<Meu Caso:
pawn Code:
C:\Arquivos de programas\Rockstar Games\Nova Pasta\server\mods\deathmatch\resources\Carro tutorial\Carro tutorial.MAP
2є - Abra-o com notepad

pawn Code:
<map edf:definitions="editor_main">
    <vehicle id="vehicle (Remington) (2)" paintjob="2" model="534" plate="JYCU XBI" interior="0" dimension="0" color="6,1,0,0" posX="2498.5251464844" posY="-1673.3040771484" posZ="13.166930198669" rotX="0" rotY="0" rotZ="0" upgrades="1101,1010,1087,1078,1127,1185,1178,1125" />
</map>
3є - Procurem o ultimo parametro(upgrades)

pawn Code:
upgrades="1101,1010,1087,1078,1127,1185,1178,1125"
4є - Copiem-o, agora noiz vamos utilizalos

3є - Fazcendo o carro tunado no GM/FS


1є - No Comeзo do FilterScript/GameMode botem o seguinte

pawn Code:
new nomedocarro;
2є - Em GameModeInit Botem:

pawn Code:
nomedocarro = AddStaticVehicle(534,2517.1960,-1672.4552,13.7670,60.7259,1,1); // remington
3є - Agora vamos botar os componentes

pawn Code:
AddVehicleComponent(IDcarro,IDcomponente);
4є - Instalando os componentes

Se lembra do codigo q eu pedi q copiacem?Vamos usa lo agora

Vao a GameModeInit e botem AddVehicleComponent(nomedocarro, IDdocomponente)

Deve ficar assim:

pawn Code:
new nomedocarro;

public OnGameModeInit()
{
   nomedocarro = AddStaticVehicle(534,2517.1960,-1672.4552,13.7670,60.7259,1,1); // remington
   AddVehicleComponent(nomedocarro, 1101);
   AddVehicleComponent(nomedocarro, 1010);
   AddVehicleComponent(nomedocarro, 1087);
   AddVehicleComponent(nomedocarro, 1078);
   AddVehicleComponent(nomedocarro, 1127);
   AddVehicleComponent(nomedocarro, 1185);
   AddVehicleComponent(nomedocarro, 1178);
   AddVehicleComponent(nomedocarro, 1125);
}
E Pronto! Desfruteem!

5є- Adicionando Paintjob's
pawn Code:
ChangeVehiclePaintjob(IDCARRO,IDPAINTJOB)
pawn Code:
new nomedocarro;

public OnGameModeInit()
{
   nomedocarro = AddStaticVehicle(534,2517.1960,-1672.4552,13.7670,60.7259,6,1); // remington
   AddVehicleComponent(nomedocarro, 1101);
   AddVehicleComponent(nomedocarro, 1010);
   AddVehicleComponent(nomedocarro, 1087);
   AddVehicleComponent(nomedocarro, 1078);
   AddVehicleComponent(nomedocarro, 1127);
   AddVehicleComponent(nomedocarro, 1185);
   AddVehicleComponent(nomedocarro, 1178);
   AddVehicleComponent(nomedocarro, 1125);
   ChangeVehiclePaintjob(nomedocarro, 2);
}
E praque o carro respawne com os componentes:

pawn Code:
public OnVehicleSpawn(vehicleid)
{
   AddVehicleComponent(nomedocarro, 1101);
   AddVehicleComponent(nomedocarro, 1010);
   AddVehicleComponent(nomedocarro, 1087);
   AddVehicleComponent(nomedocarro, 1078);
   AddVehicleComponent(nomedocarro, 1127);
   AddVehicleComponent(nomedocarro, 1185);
   AddVehicleComponent(nomedocarro, 1178);
   AddVehicleComponent(nomedocarro, 1125);
   ChangeVehiclePaintjob(nomedocarro, 2);
    return 1;
}
