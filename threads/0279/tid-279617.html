Hello all!

I'm thinking about a new hosted list which can be contains the servers that have hosted by a public hosting on the internet.

The name can be for example 'Internet Hosted'.
The 'Internet Hosted' contains: the servers that can be do a 40% or more response in average to the master server (all the servers that hosted by a gamehost or by VPS), do not contains: temporary (home) servers.
As you know there are 3 of them in the SA-MP client: 'Favorites', 'Internet' and 'Hosted'.
The 'Internet Hosted' can be the 4th in the list.
The 'Internet Hosted' would be free to register a server and use!



Where can be the servers registered (for example):
- On a webside which in connection with the sa-mp.com
- In the client
- etc.


Why is it good? (I think)
- The servers get more players about +30%
- The players can choose: connect to a home server or an internet hosted one?
- Players can see that the server is hosted in 0-24h.
- SA-MP lifetime would be increased
- The 'Internet Hosted' would be free to register a servers and use!


Quote:
You will can add the ip of your server(s) and the master server (like game-monitor.com) every 5 or more minutes will check that your server is online or not.
If your server is not online at all-time average 40 or more % the master server will delete your server from the list.
It you server is stooped for a while your server will be there after it reached the 40%!
Your server will be deleted if it won't take a response for a week!

By the way it can be changed if you have a better idea!
Please comment!
