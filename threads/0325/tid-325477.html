RNPCC

Remote Non-playing Character Creator
Released on 13.3.2012.



INTRO:
So, since I see many problems and questions regarding creating/connecting NPCs, I decided to make a simple application in C++ which allows you to create NPCs outside of the game in few easy steps! All you need is your record file and this application!
