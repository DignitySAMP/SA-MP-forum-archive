Well, and all IsAHENRYCar are Cop Vehicles...so this get ignored...

So change your IsACopCar function:

Code:
IsACopCar(carid)
{
	for(new v = 0; v < sizeof(LSPDVehicles); v++)
	{
            if(v == 17 || v == 18 || v == 26 || v == 27) continue;
	    if(carid == LSPDVehicles[v]) return 1;
	}
	return 0;
}
