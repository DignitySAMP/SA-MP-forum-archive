Someone on MSN told me to post something like this, and i've added a poll

I will be happy to add any suggestions

Hosting Company

Pro's
  • Good Support
  • High Uptime
  • Fast Servers
  • Ok cost
  • Contol panel
Cons
  • Can't install your own libaries
  • No root/SSH access
  • Limited slots
  • Shared IP
  • Suffer from other people's problems (DDoS)
  • Expensive for 100+ slots
VPS/Dedicated Server

Pro's
  • Root access
  • Can install teamspeak/vant/webserver etc
  • Good slots/price ratio
  • Fast Network
  • Uptime garentee
  • Not effected by other people's problems as much
  • Can run multipul servers
Cons
  • No SA-MP related support
  • No SA-MP control panel installed
  • Must have good Linux knowlage
  • Have to install everything yourself
  • CPU/RAM Limited
  • Can be expensive for running a lage comunity
Home Hosting

Pros
  • No monthly cost (see cons)
  • You own the server
  • Not effected by other people's problems as much
  • High uptime (Think about it, when was the last time your ISP went down for a long time?)
  • Can run more than one server
  • No uploading files needed
  • Easy to setup
  • no special plugin requirments (if windows)
  • You can run TS/Vant/Website
Cons
  • Crap Connection
  • NO support
  • Some ISP disallow running servers
  • High electricity price!
  • May be unsafe to leave on holiday
  • Ping depends on your network activity
  • Low ammount of players from other countrys due to high ping
  • IP can change, leaving your players stranded

I can tell you that hosting companies do not share the same pros and cons. For instance, I've been with a shitty hosting company (hint hint serverffs) where support is virtually non-existent. Uptime is rather dependent on their service provider. Fast servers isn't always the case (they can oversell). Ok cost is subjective. Control panel, sure.

VPSes and Dedicated servers do give you root access and yeah you can install whatever you want to install as long as it's legal. Good slots/price ratio ??, Fast network is severely dependent if you have a VPS (you're mostly on a shared connection). Uptime is dependent on their datacenter. However VPSes can be affected by other people or by the provider. Some virtualization platforms can cause more problems if abused than other platforms. Also providers can oversell.

You also don't need good Linux knowledge, I just install VNC on the box and manage my dedicated by GUI and some providers offer managed support, meaning they do the work for you.
