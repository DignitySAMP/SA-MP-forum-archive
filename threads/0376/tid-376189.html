Romania New Generation v1.0

Romania New Generation Stunt/Drift/DM.

This GM containts

-Login & Register System
-Anti Flood
-New Maps
-Max. level 4
-Admin System(Ladmin)
-Advanced Gangs System
-V.I.P System(max. level 3)
-Speedometer
-VUP System


Admins Level
Level 1: Basic Moderator
Code:
-Player: getinfo, weaps, ping, ip
-Vehicle: fix, repair, addnos, tcar
-Tele: saveplace, gotoplace
-Adm: onduty, saveskin, useskin, dontuseskin, setmytime
-Other: lconfig, viplist, morning, reports, richlist, miniguns
Level 2: Moderator
Code:
-Player: giveweapon, setcolour, burn, spawn, disarm, highlight, jetpack, flip,warn, slap, (un)mute, laston, lspec, lspecoff
-Vehicle: acar, abike, aheli, aboat, aplane, lspecvehicle
-Tele: goto, vgoto, lgoto
-Adm: clearchat, write, announce, announce2, screen, (un)lockcar
-Other: wanted, jailed, frozen, muted, fstyles
Level 3: Master Moderator
Code:
-Set: set(health/armour/cash/score/skin/wanted/name/weather/time/world/interior)
-All: setallskin, armourall, setallskin, setallwanted, setallweather, setalltime,setallscore, setallcash, giveallcash, giveallweapon, clearallchat, healall
-Player: ubound, duel, akill, aka, caps,(un)freeze, kick, explode,(un)jail, force, eject, (s)removecash
-Vehicle: car, carhealth, carcolour, destroycar, vget, givecar
-Tele: teleplayer, gethere, get, move, moveplayer
-Other: gps, lcam, lammo, countdown, aweaps, invisible, visible
Level 4: Administrator
Code:
-All: spawnall,slapalll,disarmall
-Player: cage, ban, rban, tempban, settemplevel, crash
-Adm: ctele, spam, god, godcar, botcheck, forbidname, forbidword, fakedeath
-Other: uconfig, die, hide, unhide
