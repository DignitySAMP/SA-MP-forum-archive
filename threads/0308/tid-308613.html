Simply create a bidimensional array where you put coords of vending machines:
pawn Code:
new VMachines[43][3]=
{
    {x,y,z},
    {x2,y2,z2},
    // ... and so on (previous post has all the coordinates (should be 43))
Then create a function that look is player is in range of vending machines:
pawn Code:
stock IsPlayerInRangeOfVMachine(playerid)
{
    for(new i=0;i<sizeof(VMachine);i++) {
        if(IsPlayerInRangeOfPoint(playerid,2.5,VMachine[i][0],VMachine[i][1],VMachine[i][2]))
        return 1;
    }
    return 0;
}
Then in onplayerkeystatechange
pawn Code:
// Make sure to define PRESSED as this:
#define PRESSED(%0) \
    (((newkeys & (%0)) == (%0)) && ((oldkeys & (%0)) != (%0)))
if(PRESSED(KEY_SECONDARY_ATTACK)) {
    if(IsPlayerInRangeOfVMachine(playerid))
    ClearAnimations(playerid);
}
