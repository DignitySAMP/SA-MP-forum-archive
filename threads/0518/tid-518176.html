Unfortunately the problem is the script. I'll give a simple example to explain it. This is wrong because it doesn't check the file handle:
pawn Code:
new File: fhandle = fopen("somefile.txt", io_append);
fwrite(fhandle, "I wrote here\n");
fclose(fhandle);
and this is correct because it does:
pawn Code:
new File: fhandle = fopen("somefile.txt", io_append);
if (fhandle) // if file handle is not 0, thus it is valid.. write to the file and close it. It won't crash the server if it's invalid
{
    fwrite(fhandle, "I wrote here\n");
    fclose(fhandle);
}
If you could compile with -d3 and test the script after using -d3 would be much easier (and faster) for me to help you fix it.

---

Now about 'Error: Function not registered', it's because you loaded nativechecker before IRC. nativechecker should be last.


And like I told you you need to update your plugins. Their versions are too old.
