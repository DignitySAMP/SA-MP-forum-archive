Union Gaming Roleplay

Note, this script is not from scratch, this is a zGaming edit. Post all bugs found below, I or Daboyio will be fixing them.
Upcoming Updates

-SpeedCams [100%]
-Advanced Inventory/Loot System.
-Possible MySQL conversion.
-Unique Death System. [10%]
-Master Account System with multiple characters.
-Crafting System.
-Corpse System that is lootable.
-Money drop on death. [30%]
Scripter Daboyio will now begin scripting some new features as I don't have much free time.

Update 8/30/2014


-Added command /fps
-Added command /deletecvehs for administrators.
-Added a Dynamic Speed Camera System.
That's correct, a dynamic speedcamera system has been added. If you are an admin level 6+ or the leader of the LSPD, you may create, edit, and even destroy all speedcameras. The speedcameras fine players a certain amount of money and are saved and loaded upon gamemode exit and start up.

-Fixed a few bugs involving stat saving.

Update 8/29/2014


-Redid Login System
-Fixed bugs involving fire system.
-Fixed bugs involving the family vehicle system saving.
-Removed death system due to request, will be redone at a later point.
-Fixed a few bugs that caused crashing of the server.
-Fixed a few bugs with the garage system.
-Fixed download link.



Previous Updates

-Redid the Firework System (epic)
-Added Garage System.
-Added a new awesome barricade system.
-Added a vault for the SD and revamped /locker.
-Redid the login screen with saving stats.
-Added an "asshole" system. /setasshole, a player can't use any commands if they are an "asshole".
-Fixed many bugs with the last update.
-Added /hpm and /apm, /crash(Copfan5)
-Fixed it so you can't kick,ban,crash a higher/equal leveled admin.
-Added numerous administrator commands.
-Added/Changed a few factions (14 in total)
-Added and Smoothed out the San Andreas Airforce faction.
-Fixed the death system and the event system.
-Admins can now check a players IP address, /checkip.
-Revamped the Character Kill System.
-Added a kick/ban timer so the ban/kick reason is displayed.
-Fixed the mapper system and changed up the helper system.
-Minor Bug Fixes
-Redid the ammunition system.
-Added a CK Player system. /ckplayer
-Fixed the login screen.
-Added a weapon license system. /giveweaponlicense(/revokeweaponlicense)
-Mapper System works 100% as of today.
-Minor Bug Fixes
-Fixed the Register/Login bug where you could login with any bug.
-You can no longer crash the server based off of the login dialog.
