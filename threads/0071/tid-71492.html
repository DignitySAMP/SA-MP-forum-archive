Hi!

Introduction

I'm going to release my first gamemode and script ever released. It's called Los Santos Madness and is all about Grove fighting Ballas. I've spent over a month developing this, I have had a lot of people who helped me fixing bugs and gave me some nice ideas, I would like to thank all of them.

Anyway, over to the gamemode.

Features

This is the very first version so it doesn't have that many features:
  • A scoreboard and a timer which automatically restarts the server after one of the teams has reached 50 points.
  • A few admin commands to change the scoreboard
  • A few cool player commands
  • A "car" system. Every team has a black car with a marker. The other team can steal it.
  • A nice gang chat
Player commands:
/help /rules /commands /bomb /kill /info

Admin commands: (You have to be logged in on rcon to use these commands).
/announce /givegrove /giveballas /resetscores /resetballas /resetgrove

Download:

Pastebin: Download.
(Sorry if the intendation got fucked).

Zezombia: Download (.pwn)
Zezombia: Download (.amx)

Solidfiles: Download (.pwn)

How to install?

1) Download LSM.pwn and LSM.amx
2) Extract them both in your "gamemode" folder.
3) Open server.cfg and add LSM to the "gamemode0" line.

Code:
gamemode0 LSM
4) Save server.cfg and close it!
5) Run the server and enjoy!
