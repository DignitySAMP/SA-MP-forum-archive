Hello Guys, today im going to release my next work. That is simple Minigames system which scripted by me . Let me tell you what it does:

This Filterscript contains of:
1.Duelling system
2.Capture The Money System
3.Stole The Limmo

-----------------------------------
Duelling System

-----------------------------------
This filterscript let you duelling each other. You can setting up the weapons too. Only one weapon allowed in a duel. Location duel is helding on baseball field(LV). How to duel in this filterscript:
1.First, enable your duel mode by typing /duelmode
2./configureduel to setting up the weapons
3./duel ID to duel the targetid. Make sure, targetid that you issued have enable/active his duel mode yet!
Some screenshoots of it:


NB:The duel system is a bit worse

-----------------------------------
Capture The Money

-----------------------------------
This minigames is unique, but fun!This like kind of moneybags event. Only RCON Admin who able to start this event. Simple, RCON Admin type /startctm then, it will make briefcase pickup, near him, and players should find the hiden money!Once he found it, he should protect and capturing the money, to not let hisself down. Once he is down, pickup will be re-make on his location when he was down. And of course, he cant enter vehicle while he is holding money. Some screenshoots:




-----------------------------------
Stole The Limmo!

-----------------------------------
This one is unique too. This Minigames is simple. RCON Admin will start this event, it will created a Limmo. Then, player should found the hiden limo. Once he is found it, he should take it back to City Hall in Los santos. If he succesfully to stoled it, he will get rewards and some money too. Screenshoots:
