RAM - Remote Administration Menu

VERSION 1.0 (INITIAL RELEASE)


__________________________________________________ _______________________________________________

20 RCON Commands:

1. Load FS
2. Reload FS
3. Unload FS
4. Change Hostname
5. Change Gamemode
6. Change Map Name
7. Restart Server
8. Close Server
9. Ban IP
10. Unban IP
11. Reload Bans
12. Reload "server_log"
13. Say To All
14. Gravity
15. Weather
16. Change RCON password
17. Change Web URL
18. Echo
19. Execute File


IMPORTANT:
- All commands are performed through DIALOG_STYLE_INPUT!

__________________________________________________ ___________________________________________

Q: What is this?
A: This is RCON Admin Menu with commands!

Q: What does it contains?
A: It contains all RCON commands in dialog except ban, kick, cmdlist, varlist and players!

Q: Is this only for RCON Admins?
A: No, you can simply change:
Code:
(IsPlayerAdmin(playerid))
To:
Code:
(YourAdmScript(playerid))
Q: How to open this menu?
A: First login with RCON pass, then type /rconsole!
