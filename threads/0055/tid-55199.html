About:
  • This is a vehicle debugging filterscript for SA:MP 0.2.
  • It's easy to use, small & fast.
Features:
  • Key based control
  • Sorted list of vehicles (by category and weight)
  • Ability to change vehicle colors while selecting
  • Some usefull commands for manipulations with vehicles
Screenshot:




How to use:
  • You must compile the source (if you didn't download the compiled version), add the easyVehicleSelector.amx to your filterscripts/ folder and then add the appropriate lines to your server.cfg.
  • Start sa-mp server and client.
  • Connect to your server.
In game, like as in original debug mode, type in chat /vsel to launch vehicle selector and use next keys to select/change vehicles:
  • VEHICLE ENTER / EXIT - quit from vehicle selector
  • SPRINT - create selected vehicle
  • WS - list vehicle categories
  • AD - list vehicles of selected category
Also you can use next commands:
  • /vHelp - help info
  • /vSel - launch vehicle selector
  • /vDel - destroy current vehicle
  • /vInfo - show current vehicle's info
  • /save {comment} - export to file {GTASA dir}/savedpositions.txt current vehicle's data ( It's built-in sa-mp command )
