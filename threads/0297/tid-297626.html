Game Text Creator For Beginners 2.0


Hola a todos hoy vengo a aportarles un pequeсo programa llamado "Game Text Creator", este programa es para principiantes

Caracteristicas

* Es un programa especial para aquellos que apenas comienzan con el aprendizaje pawn
* Contiene una serie de ayudas y explicaciones sencillas

Que Hace?

* Este Programa hace un procesamiento de el comando GameTextForPlayer
* Te permite escribrir el texto que quieres que se muestre
* Te permite escoger el tipo de letra que se va a utilizar
* Te permite escoger el color para el texto
* Contiene una serie de caracteres especiales que puedes usar (Opcionalmente)

Algun Extra Que Contenga El Programa?

* Si, si lo contiene; se trata de una lista de los callbacks utilizados en samp

Porque Lo Debo Usar?

* No es obligatorio que lo uses pero lo recomiendo para personas que apenas comienzan con su aprendizaje en pawn.
* Es un sencillo que te ahorra tiempo para escribir tus textos
