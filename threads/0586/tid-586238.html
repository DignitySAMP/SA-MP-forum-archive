Hello Everyone, many you have been wondering how to get PAWN compiler and all of that in Sublime Text but never made to get it.

Well, There is many Tutorials around!

But today i'm sharing here Sublime Text 2 with the PAWN Auto Completion, File Detection, Syntax Highlighter and Compiler already because to be honest, it's an annoying work to download everything and all that shit!

After you downloaded it just place the folder where you want!

But you still have to do something now, yes lazy boy you do :33

1- Click on Preferences > Package Settings > Pawn Compiler Settings > Edit Build Settings

2- Now change the 3 paths to your pawncc.exe one, Save it and Close it's window!

3- Now Click on tools > build system > Pawn

Done you now have Sublime Text with PAWN Auto Completion, File Detection, Syntax Highlighter and Compiler

If you don't know what is Auto Completion, This is Auto Completion:

When you write something it will give you a list of functions under, when you click on it, it will give you the whole function writen already, now you just have to set the parameters to what you want!

If you don't know what Syntax Highlighter is
Syntax highlighting is a feature of text editors that are used for programming, scripting, or markup languages. The feature displays text, especially source code, in different colors and fonts according to the category of terms.

File Detection detects the .pwn & .inc files!

To compile press F5!
