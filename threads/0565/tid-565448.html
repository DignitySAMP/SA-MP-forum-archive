Turning on the frame limiter in GTA:SA is the same as enabling vsync. Then you can use the SA-MP chat command /fpslimit to change the frame limiter amount so it's higher than the vsync.

Say I want vsync enabled and my monitor refresh rate is 60hz, I enable the frame limiter in GTA:SA then use a /fpslimit 90, which is a value higher than the monitors refresh rate so it hits the vsync limit first. That will give a constant 60 fps without screen tearing.
