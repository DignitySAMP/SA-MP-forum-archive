Code:
C:\Users\Vijay_Rasigan\Desktop\RWRP.pwn(12833) : warning 202: number of arguments does not match definition
Is a warning, you probably did something like this:
pawn Code:
SendClientMessageToAll(playerid, COLOR_RED, "Lol"); //Incorrect, playerid isnt called when sending to all
SendClientMessageToAll(COLOR_RED, "Lol"); //Correct

Code:
C:\Users\Vijay_Rasigan\Desktop\RWRP.pwn(13697) : error 047: array sizes do not match, or destination array is too small
Means: Your arrays are to small

pawn Code:
Enum lolinfo [3] [4] //Now if you use 5 instead of the given four, it gives this error
0,0,0, 50, 10 //Incorrect, It has 5, not 4
0,0,0, 50 //Correct
And finally
Code:
C:\Users\Vijay_Rasigan\Desktop\RWRP.pwn(13682) : error 021: symbol already defined: "strtok"
Means strtok is already defined in your code, or in an include. Check if you have them more then 1 time, if yes, delete one of them


Hope I helped
