Quote:
Originally Posted by Lunnatiicz

Cuando un jugador muera, para cuando uno mate a otro tienes que crear una funciуn oh callback
No, el callback OnPlayerDeath tiene dos parametros, asesino y victima (la persona que muriу).

Si quieres que le apareza al asesino:
pawn Code:
public OnPlayerDeath(playerid, killerid, reason)
{
    TextDrawShowForPlayer(killerid, Textdraw0);
    return 1;
}
Si quieres que le aparezca a la victima:
pawn Code:
public OnPlayerDeath(playerid, killerid, reason)
{
    TextDrawShowForPlayer(playerid, Textdraw0);
    return 1;
}
Ambos:
pawn Code:
public OnPlayerDeath(playerid, killerid, reason)
{
    TextDrawShowForPlayer(playerid, Textdraw0);
    TextDrawShowForPlayer(killerid, Textdraw0);
    return 1;
}
