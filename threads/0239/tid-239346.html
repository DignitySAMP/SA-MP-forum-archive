How do i install?

Download those .pwn and .amx files and put it in FilterScripts, then go open server.cfg and add there ViPMenu.

What's the command for this ViP Menu?

/Vipmenu ingame cmd.

How do i set vip?

You cannot set vip, If you have Lux admin only you can use this Vip Menu, it works only with Luxadmin.

And also you will need Ladmin include made By Luxadmin author.

You will have to set yourself ViP in Luxadmin by typing /setvip (id) 3
