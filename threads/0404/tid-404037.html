Hello everyone!
I was looking around the old times I used to develop GTA servers.
I downloaded the game again and tought, "Why not create my own version of Pawno?" And here it is.
I present you, Pwn-O. A whole new evolution of pawn IDE.

I customly made up the syntax-highlighting for this program. If any are missing, please give me a message in what is missing and maybe add an example to it so it will be easier for me to understand.
There are some bugs but they are so small, you will not even notice them.

The features:
  • Everything a standard editor needs
  • Syntax highlighting
  • Auto-complete
  • Interactive compiler
  • Autocompile (Works now asynchronously, all laggs are gone)
  • Customizable interface, select what you want to see and what not
  • Read the includes folder (appears on right)
  • Like pawno doubleclicking a function in the includes list will insert, but this one is a bit smarter, refer to images
  • Tools (all included under tools tab): Colorpicker, Insert timestamp (idea from r_DjolE), Simple missing brackets finder and a string length checker
  • Colorpicker
  • Insert Timestamp (thanks for the request to: r_DjolE)
  • updater (disabled until next version)
  • Settings saved after shutdown
  • Resizable controls and select what you want to see
  • Besides syntax highlighting and fonts, fully customizable
Requirements:
Windows XP+
.NET framework 3.5 / 4.0 (please let me know if it works on 3.5)
