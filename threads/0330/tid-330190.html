Next Panel V0.1 A

I've saw alot of problems with the game server control panels on this forum for sa-mp, so im here to offer you the next-panel, basic server management without problems!
This panel can offer fast start/stop/restart functions or slow, depending your vps location and the panel location, for example, if your panel is Hosted on United States of America, and you have your vps on france, will take about 5 seconds to start, stop or restart.
Some people will say, it's badly coded!
I've coded like this, just for the end user can manage better the php files without doing mistakes.
  • Functions:
This panel offers basic support to start/stop and restart your game servers!
You can host the panel on web host servers or on your vps/dedicated server, the same will work!
You just need to have php 5.3 + ssh2 extension!
  • Compatiblity:
This panel can works alot of game servers! Such like sa-mp, mta sa, iv-mp, teamspeak, minecraft, etc
Since this panel does not work very very good with centOS, it's preferred for you to have debian Operating system.
  • Information about this panel:
I've created a small game server control panel before, to control my teamspeak server, and i did not had any problem with the same.
So when i saw this forum starting having alot of problems with the control panels(nitok, antctrl, grex....) i've created this one, the same took me about a half day to be done(just the php code, the design took a little bit more ^^)
And since alot of people want to control their server without going to putty, connecting to the server ssh bla bla bla, im here to release this panel, i hope you guys will like it. (:
This panel can be used on webhosting account(shared accounts), but the host need to have php 5.3 and ssh2, if they do not have, you're fu####
