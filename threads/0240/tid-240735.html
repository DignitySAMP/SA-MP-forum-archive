[FS]PRaceSystem by Phanto
Version: 1.1


This is an update of PRaceSystem.
I dediced to update due to the fact i received a lot of request to add a race editor.
Now you can create race whithout working manually on the file! All you have to do is log as RCON admin and type /builder to create your own race!
In my opinion this is the best race system ever published, because mainly of his unique structure and features.

Announce: I fixed some string left in italian and translated them to english, sorry my mistake. Now all the FS is in english.

Description:
Tired of your server? Don't worry! Here it is a nice filterscript that allows you to race with your friends in various tracks. You can also build your own race in few minutes with the new Race Editor implemented.
Try it out!


Features:
•Coloured strings (only Sa:mp 0.3c)
•2 types of race: Circuit & Sprint
•The system saves best times on tracks (time & player's name)
•Different Players can also race at the same time on different tracks.
•There is not limit for players joining a race (500 players in the same race D: sounds such a mess up xD)
•Once the race start, player cannot join anymore until the race finish
•Nice and functional system
•Use of nice textdraw (Example: Laps/Time/starting Traffic-lights)
•In-game Race Editor

Commands:
•/race
•/quitrace
•/ready
•/builder (Rcon Admin - Enter builder mode)
•/check (Rcon Admin - Used in builder mode)
•/endcheck (Rcon Admin - End Race Editing and saves it)


Fixed bug & upgrades:
//V 1.1
•Fixed a bug dealing with /quitrace when the race wasn't started yet
•Added a In-Game Race Editor


Known bug:
•No bugs found.

Conflicts:
•If you have another race system, I suggest to remove it before mounting this one.
•Be sure not to have used OnPlayerEnter/ExitRaceCheckpoint functions in order to make works the system without generating conflicts.

How do I build my race?:
•Simply type the command /builder when logged as Rcon Admin and follow instructions.
