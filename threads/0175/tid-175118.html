Game Object Reader 0.1b

With this Filterscript you can see Game object ID.
You can enable disable 3DLabels by type /OL
This is beta version for global test.


Version 0.1b Featurs:
+18249 Game objects support
+Info about objects as example: Pos, Rot and Flags
-Not support Interior objects
-Not support object names
+3DLabel draw distance 100.0
-Don't have any protection to prevent Client side usage


Screens:




More about this Filterscript:

This filterscript reads San Andreas IPL files.
To everyone know, I didn't copy and paste IPLs from DATA folder, because in data folder these IPLs contains only LODs, so I needed to open Binary IPLs and convert them manualy for human/pawn readable format, that was hard work so I hope people will use this.


Install:
1. Put maps folder into scriptfiles folder of your server directory
2. Put GameObjects.pwn/GameObjects.amx into filterscripts folder of your server directory
3. In server.cfg into Filterscripts line add GameObjects
4. Have easy way to build maps with help of this GOR 0.1b

Future version:
Interior objects support
Road objects support
Masive complex objects support.


This is open source so can feel free to update it to your own needs, if you find bugs post it here.
