You can only learn by doing. I found the absolute best way to learn scripting is to download other (simple at first) scripts and looking at them. See how they work. Don't understand what something does? => Look it up in the samp wiki. Still don't understand? => ask it on the forums. Eventually you'll start to get used to things, you'll start to know how they work. It's okay if you don't understand stuff in the beginning, scripting is really hard. As long as you don't give up you'll become a great scripter.
