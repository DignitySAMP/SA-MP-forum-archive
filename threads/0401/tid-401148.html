NOTICE: This server was first called SAMP Battlefield. It then changed to eB Gaming ~ Gangwars after around 2 months, to try and revive the project. (It didn't work well, wasn't active enough ).

Hello!

Today I have decided to release one of my well liked scripts. It's a TDM and based vaguely *around* battlefield.
The server contains 45 ranks - each one being all of the real Battlefield 3 ranks. These ranks are decided upon how many kills/exp your account has.

What's so special about this script?
Well, I believe it's one of the best TDM servers available. I really do. I'm not sure if anyone else thinks the same - I didn't have much time to show everyone the server, as it's popularity did not last very long, thus another reason of why I am releasing it.


Features
  • 45 Ranks
  • Fully working map changing & voting
  • Add and delete maps dynamically
  • Choose and customize your own loadouts!
  • Fully MySQL, all kills logged and many statistics for users to see! (Such as how many kills with a specific weapon).
  • Killstreaks (They aren't anything big. Just little XP + Cash bonuses.)
  • Custom gamemaster system (Basically admins, just decided to be different and give them a new name. levels 1-5 (5 being the highest).
  • Premium system (Premium users can get 5 loadouts, instead of 3, and have extra commands. Premium is given to whoever helps the server/donates or whoever I feel is worthy of being premium. They can also have DOUBLE sawnoff, DOUBLE uzi instead of the SINGLE uzi/sawnoff - Regular users only get 1 sawnoff/uzi.)

Dynamic Map System
The map system on this script is my favourite, and most unique part. Maps can be dynamically added or deleted.
All maps are stored in the /scriptfiles/Maps/ folder with the extension: .map <example.map> - These .map files can be MADE in MTA Map Editor, without the need of converting. A simple drag & drop!

Along with adding the .map file to the server, you add a line to the MySQL Database, which stores data for the map, such as the ID, how many times it's been played, team skins, team spawns and some more information which is needed for the map system!

Structure of the map system database: http://i.imgur.com/7vYb5.png [WARNING: Large width resolution]


I have no experience in running samp servers or using mysql!
Hey. Sadly I do not give support since I do not have much time. If you are not experienced in setting up/using SAMP servers or with low knowledge of MySQL - I really do NOT recommend downloading this script. You should read up on some guides or tutorials beforehand, so you know the basics before spamming this thread posting errors you shouldn't be receiving.

Setup
I do not give out support, so sadly this is as much help as I will give you:
  1. Download the package from the link above
  2. Download the database file
  3. Import the database file to a MySQL server
  4. Enter the MySQL server details in the script
  5. Compile the script
  6. Edit the server.cfg to your standards
  7. Start the server. It should now run (Windows only).
