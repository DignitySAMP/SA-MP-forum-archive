BotSpawner-FS v1.0 by Prozack: 9/23/2010

----------------------------------------------------------------
Based on TaXi's Original Vehicle Streamer.
Utilizes the "npctest.pwn" included with the server download.
----------------------------------------------------------------
These are static NPC's which can be animated.
These are not recordings. They are idle.

Bots are stored in the Jail until needed to reduce loading time and are cached using military designations, then destroyed whenever their interior becomes vacant. Each time a Bot is called into action another is spawned in the jail.

Unfortunately, a special exception is required to sustain the Bots that occupy interiorid 0, and this issue will be addressed with the next release. A solution is already in the works.

The botheap is currently set to 5 cached bots but can be easily changed to support more. There are 13 unique designations available within the current build, so I would only suggest a maximum of 7 active at anytime. A dynamic botheap that sizes according to server stats will also be addressed in the next release.

The current bot locations are stored in "globals.inc" in a very manageable array.

Comments and suggestions are welcomed.. enjoy

Instructions ()

1. Unpack BotSpawn_fs.rar
2. Put botspawn_fs.amx and botspawn_fs.pwn in your filterscripts folder.
3. Put globals.inc in your Pawno/Include folder.
4. Add botspawn to your server.cfg -- on the filterscripts line....
5. Start Server

To modify botspawn locations - edit globals.inc and recompile.
