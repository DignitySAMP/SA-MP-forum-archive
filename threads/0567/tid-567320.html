I've been doing a lot of debating about creating a light/medium RP server. I finally decided to start on it. Now, one big question for every new server is, where do you have it based from? I had picked a part of the map, then thought about maybe making a city, about 1/3 of the size of LS, that would support all different types of roleplay. Now, obviously the pros are that it would be unique, and it will be one of the only places on the map that is not Los Santos and can support all types of roleplay, in a smaller, more controlled environment. Everyone I am working with agreed with wanting to go ahead with this, but I want other's opinions too. Mapping an island like that can cause some people to lag who have a poor connection, high ping or not a very powerful computer, which is my biggest concern.

That being said, has anyone else tried this, what was its outcome, and if you have not tried it, what would your opinion on trying something like this be?

You might want to stay on the default SA map, but you can also try making your own one.

Here are some things that I suggest for a custom map. First of all, you should probably make the ground/base of the map solid (CreateObject, not streaming), which might make it a little more reliable. To make it accessible more, you can create gangzones as roads/buildings blabla. Believe me, it would make it more 'knowable' to the players and they will be able to find places more easily through their minimap. Next thing must be creativity and uniqueness. You should have a proper and realistic map which would be likely wanted from players. And yea', that's all from me.

But, as Lannister, a custom map will totally lose the game experience. Players wouldn't know it much, they wouldn't be able to use their map (unless you make a custom one, which would like player-side installation). So yea', both choices have cons, and pros too.
