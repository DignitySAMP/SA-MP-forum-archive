Is nativechecker last in the plugins line (server.cfg)? If not, then add it last and start the server again. Re-post your whole server log so we can know if a plugin failed to load because you forgot to write in it server.cfg or it doesn't exist in the plugins folder.

If you get a run time error 19, then it's sure plugin(s) missing. If not, it was just the mistake of not loading the nativechecker last.

In the messages above, it seems those function from streamer, Whirlpool and sscanf are not registered. Make sure you've also updated the plugins and their includes to their latest version (and re-compiling).

About crashes, use crashdetect plugin.
