one problem could be caused by objects being created without a reference:
Code:
CreateObject(blabla);
creates the object, but the script cant know which one to refer when deleting it. to solve this problem, create an array for holding the returned objct IDs (returned by CreateObject):
Code:
new Object[200];
new ObjectsLoaded;
...and now your objects lines - a modified version which takes care for the array (Object[]):
Code:
new o;//array Object[0] gets used as next pointer for the object id:
