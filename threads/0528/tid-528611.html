Intro
Hello! Cannary2048 here, let me introduce you the dynamic vehicle renting I've made, it's dynamic and can be easily configured, simply an admin must create the rental booth by typing /rentalmenu, set the rental booth, and where the vehicle spawn, and then select complete, now players can rent a car in the rental booth, currently the saving uses dini, it saves anything related to the rented vehicle, rental booth, and the owner.
Saving
The saving system saves:
  • Vehicle Position
  • Vehicle Body Damage + Vehicle Health
  • Player's Time-left Before Unrenting
  • Rental Booth Position
  • Where the Rented Vehicle Spawn
  • Vehicle Color
Feature
CAN Dynamic Vehicle Renting only have 1 feature:
  • A fine if a Rented Vehicle is destroyed
Command
CAN Dynamic Vehicle Renting has three commands
  • /rent
  • /rentalmenu (for admin)
  • /timeleft
Bugs
  • Currently no bug, but you can message me if you found any

Installation
  1. Compile+save the code in filterscript\dynamicrenting.pwn
  2. Open server.cfg, write "dynamicrenting" beside "filterscript"
  3. Create these folders in scriptfiles: Rentals\Users
  4. Run samp-server.exe, Done!
