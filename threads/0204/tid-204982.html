Simplemente es como windows pero cambian algunos archivos y la forma de encenderlo.

http://team.sa-mp.com/files/samp03csvr.tar.gz

Te bajas eso que es el server para la version linux , hay pones tu gamemode y lo configuras todo , si usas plugins tienen que ser .so

Luego te conectas por ftp a tu vps , puede ser con filezilla perfectamente , y creas una carpeta llamda samp
Luego pones hay todos los archivos de tu server y les das permisos 755 para que se ejecuten

Luego conectandote por consola a tu vps , con putty por ejemplo haces esto

cd .. (enter)

cd samp (enter)

y te saldra -> root@tuvps/samp:

eso es que ya estas en la carpeta de tu server , luego pones

nohup ./samp03svr &

y el server Se enciende y se mantendra encendido aunque cierres la consola

Si no me entiendes nada de nada investiga por aqui ->> https://wiki.sa-mp.com/wiki/Linux_Server

Saludos

Puedes usar protocolo SCP con el pograma WinSCP, es como un FTP pero mediante SSH.

Sube todos los archivos con el WinSCP, luego le das permisos 0777 haciendo click derecho en samp03svr y en propiedades (desde el SCP).

Para ejecutar el servidor puedes usar el programa PuTTY escribiendo simplemente "./samp03svr &".

Otra alternativa es crear un script mediante el WinSCP de la siguiente manera: click derecho >> nuevo >> archivo, con el siguiente script:

Code:
#!/bin/sh

./samp03svr &
Luego click derecho >> comados propios >> ejecutar.

Aunque si no recuerdo mal, usando este mйtodo, el servidor deja de ejecutarse al cerrar la conexiуn del SCP.
