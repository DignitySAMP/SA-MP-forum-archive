From where it all started.
Quote:

Well, I searched through the ad sections, but I didn't find any server's that might relate to a sci-fi or future themed roleplay. Does any of you know one or might be interested to bunch up, if there's enough people who would want something like that, we could organize up. Well, pretty much anyone who has ever watched Stargate or anything similar and has actually liked it, would be up for it.
Kardo.
Current idea/feature list:

Ships

Main ship Hydra/Some sort of helicopter. Haven't decided yet. Hydra would fit in, since it can hover and fly, but there's the rocket firing problem.
Features: There's one "class" of ships at first, each one can be customized to fill in for a certain role on the battlefield, sounds like deathmatch, but it isn't.
Each class would have different attributes attached to it:
Life support - Shows how many people can be in the interior of the ship. If there's more than life support can handle, people will slowly start to lose HP until a horrible death.
Shield - Damage issues. My plan, haven't gotten to scripting yet, but, for example a Hydra gets hit for 500 damage, then it calculates that off from it's full hp, lets say 1000. That makes 1000-500=500. Then the Hydra would be "repaired" to full health but the shield value would go down and show up in the ships HUD.
Structure - When shields go down the ship starts to take real damage.
Cargo - Each ship would be able to take aboard different materials, which I will get into later, each would weigh/have a different volume which would take more/less space. Certain ships ( For example the mining one ) have a bonus capacity for ores for example.

PS: If anyone knows a spaceship mod for Hydra, or any other flying thing, I'd appreciate it. ( And no, I don't want the UFO thingy I've seen around used to troll )

Engineering vessel: Possibly to repair the main ships/outposts?

Resource system

I'd like this to be rather complex, enables trading runs and such.
Main resources ( haven't figured all out yet )
Water - Obvious
Food - Obvious

Deuterium - Used as fuel for different ships. Would be produced by different outposts owned by factions. One small example, didn't turn out well but explains my thought a bit better:http://www.upload.ee/image/1420331/fuel_outpost.png

Lime/H2O - To use in life support systems.
Ores - many different ones in mind, used to produce items/ship components.
Stuff produced by ores:
Conductors, ship engines and so on.

Outposts would provide most of the resources, they would accumulate resources and you would have to transfer them to ships etc.
Possibility to create your own faction from scratch, build bases etc. Needs a lot of scripting, I have come over a few ideas, but it'll take atleast a day to get it running. Any help here would be appreciated aswell.


Galaxy map
A textdrawn System map, that's what I've come up with so far. Main ships(Bigger ones) can "warp" themselves between systems. ( Just changing the interior/ virtual world so it just disappears and can only be accessed if you actually go into that specific system)
Each system would have it's stationary bases.

Story
Well, currently I'm going for 2 factions, some sort of either democratic/good versus "No man, no problem" people.
Haven't made up much mind here.


Any contribution/idea at this point would be just awesome.
As this seems to be huge, but still, I'm very sure that after I manage to put enough effort into it, enough people will get interested with this idea. So far it's been amazing, all the feedback has just been awesome. This isn't an order, it's just a humble request at this point.
