Commands & Features

Commands======
/defuserhelp - Obvious
/c4help - Also obvious
/c4menu - Defuser/C4 purchase menu
/plantc4 <timer/1-600>- Must have a bought C4, supports up to 10 Minutes.
/defusec4 <frequency> <code>-If you are willing to take your chances on guessing a 8-digit number go ahead.
/setdefuser <frequency>- Set a defuser to a C4's Frequency
/plantdefuser -Plant a defuser. Must be near the selected C4

I can't explain everything, Go to the screenshot section if you have that need, and if not, just head to the downloads.

C4
To purchase a C4 type /c4menu and select the first option.
Next, you will type in a desired password to defuse the c4 later, with /defusec4
Now you will type /plantc4 <timer>
The timer can be anywhere from 1 second to 600 seconds (10 minutes)
After the time has been set, there is only one more thing to do.RUUUN!

DEFUSER
To purchase a DEFUSER type /c4menu and select the second option.
Next you will type /setdefuser <frequency> <startcode>
The defuser works like Brutal Force attacks. Every C4 has a unique Frequency.
After locating a C4 the top number will be the frequency.
The startcode is the code from wich to start cracking. Suggested: 0
You will be able to monitor the Defuser throughout the numbers.
The bottom one represents at what code it is, and the top one at what frequency is set.
If it goes well the Defuser will automatically remove and give you a message and the C4's Numbers will turn into "C4 DEFUSED", and if not, then time will run out
