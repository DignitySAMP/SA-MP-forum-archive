Mount Chiliad DM Area
This is a really simple DM area for Mount Chiliad, which can be used on DM/freeroam/whatever servers as an extra DM area. This is not a gamemode and it does not have any functionality, this is just a map with objects which you can edit for your needs, map- and scripting wise. I would've added a script to it myself, but I suck donkeyballs in scripting. It is also my first map, so don't expect something huge. This is just a simple addon DM area for servers who'd want it.

Screenshots
http://s5.tinypic.com/25zrvq0.jpg
http://s5.tinypic.com/rtky8w.jpg
http://s5.tinypic.com/2jfd4bs.jpg

I have a shitty computer, so the screenshots aren't really good, and the map has more than the screenshots show. It has several objects to hide behind, and it's ideal for long-range DM weapons. It also has 2 camps and outposts, so it's suitable for TDM as well.
