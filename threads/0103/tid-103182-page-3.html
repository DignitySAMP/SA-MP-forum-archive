Delete samp.exe

Redownload the SAMP Installer. (samp-0.3b-install.exe or something)

Open the installer and IMMEDIATELY CANCEL THE SETUP. Windows will detect that "This program did not install correctly" and give you the option to "Reinstall with recommended settings". Do that.

Follow normal installation steps.



I'm not entirely sure what those "recommended settings" are (probably installing it in Windows XP compatibility mode or something) but it's worked for me on Windows 7 x64.
