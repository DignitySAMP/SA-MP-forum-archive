[center]Weapon Menu for RC5+

Credits To:
All The SA-MP Team
wiki.sa-mp.com
Gappy

• What is it?
Sick and tired of boring old 0.2x Menu's? Want to use that little mouse of yours? Well heres your chance!
This Weapon Menu uses the new Dialog Box features for RC5 and up to select every Weapon type and Weapon!
DialogID 1337

• How to use
make sure to Extract what you download, Go into the new folder and there is a .amx and a .pwn named "WeaponMenu" Open up your server.cfg and place WeaponMenu on the filterscripts line.
This Menu is avalible to everyone so make sure you add a check for admin if you dont want it like this. Also make sure to take any Auto kicks/bans out of anyother scripts if you dont want people or yourself getting kicked for no reason.

[center]/wmenu
