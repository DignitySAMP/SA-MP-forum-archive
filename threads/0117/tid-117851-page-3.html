Quote:
Originally Posted by MaNiii
Hi,

Just the smaller player ID can manage projects. Ask him to open one.

whats this?
The Textdraw Editor is intended to be used by a single player, alone, in his server. However, multiplayer support is partially added.
In case more than one player is in the server, the player with the lowest playerID will be able to open, close, and export projects. The rest of the players can just edit them.

That is, for example:
id 0 - ImaPlayer
id 1 - AnotherPlayer
id 2 - OneMorePlayer

Then the player named "ImaPlayer" will be able to open, close and export projects, and the rest can just edit them. Another example:

id 1 - ImaPlayer
id 3 - AnotherPlayer
id 4 - OneMorePlayer

Again, "ImaPlayer" will be able to manage the projects, and the rest just edit them.
