These NPC's are the old versions so you will need to run samp-server.exe twice for them to work.

• What is it?
Front Yard Ballaz comes with 5 NPC's. The File includes the .rec files, the NPCModes and the .pwn and .amx of a FilterScript. All NPC's are located South-West of Jefferson near the Basketball courts. 2 NPC's walk up and down near the Basketball courts keeping an eye out for Grove's, another is having a chat with the Boss and the other 2 are smoking/drinking together.

• How to use
Each folder has a either a .pwn and .amx or a .rec file which need to be placed into the correct folders where your SA-MP 0.3 Server is located. IT WILL NOT WORK IF NOT DONE CORRECTLY!
Once completed this, "FYB" needs to be placed into your server.cfg filterscripts line.
Join your server and watch the NPC's Walk and talk Exactly how they would in SinglePlayer round Jefferson.
