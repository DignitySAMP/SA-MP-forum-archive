The error is given because you have loaded the wrong mysql plugin. The script uses StrickenKid's mysql plugin.

Consider updating to BlueG's mysql plugin and the latest version (R39-5 with threaded queries) eventually (of course will take a while but it's worth it) as Shinja suggested because for a simply fact: there is no support for outdated versions.
