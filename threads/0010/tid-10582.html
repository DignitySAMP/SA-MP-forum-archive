FUEL SYSTEM + SPEEDOMETER v1.8 MULTILANGUAGE
A total of 18 GAS STATION!:O almost all the gas-station in game!
With this FS, every car in your server will have its own Fuel indicator and SPEEDOMETER! (only Car, trucks and bikes, not BMX, mountain bikes, planes, boat or helis, BUT all vehicle will have speedometer)(BTW you can change this). If the Car run out of fuel, NO ONE will be able to drive it. You can get more fuel JUST by entering a checkpoint is a GAS STATION and using a pop up menu. When a cars spawns, it will get random fuel.
Your gas consumition depends on your speed, the faster you go, the faster your fuel goes down!

SNAPSHOT!


Limitations!:
1) This Filter Scrit use checkpoints tecnology, you need a checkpoint handler, if you don't have one, I will provide you with one (sorry in spanish, but with english README) If you have one, you will need to add the Gas Station coordenates to your checkpoint handler, you will find them inside "FuelSystem.txt" remember that first item (15.0) is the checkpoint size.
2) I have only 18 Gas station coordenates, if you find a gas station with out a chekpoint, PM ME PLEASE!

Editing:
You can edit many things:
1) Fuel price: Edit line 20
2) Max Fuel Capacity: Edit line 19
3) Minimum Gas for spawning cars: Edit line 23
4) Random extra gas for car spawning: Edit line 24 (make it 0 if you want car to spawn with only MIN_GAS
5) DON'T TOUCH LINE 21 AND 22 "#define MAX_VECTOR 700" & "#define MAX_GAS 50"
6) Wich vehicle should have Fuel indicator:Edit line 65 (see line 358 for vehicle type detail)
7) How faster your fuel goes down acording to your speed: edit line 101 (change 3000.0 value, the higher it is, the lower rate your fuel drops)

Editing SPECIAL:
In scriptfile folder you will found a file with the name FuelConf.txt. Open it and you will see 2 words, "FuelMenues" and "comands" followed by a number, "0" or "1". "1" means "enable" and "0" means "disable". If you want to disable the menues, just change the 1 to a 0
NOTICE Fuel menues need cheekcpoints to work,

HOW TO USE FUELSYSTEM [FS]
1) Copy FuelS.pwn and FuelS.amx into FilterScripts folder
2) Copy FuelSystem.txt into your scriptfiles folder
3) Add FuelS and the end of the line that start with the word "FilterScripts" in Server.cfg (open it with notepad)
4) Add FuelSystem.txt coords into your checkpoint handler (see next topic if you are going to use my checkpoint handler)

HOW TO USE CHECKPOINT HANDLER [FS]

0) You don't need to used checkpoints if you allow commands, but you will need them if you want to use MENUES.
1) Copy Check.pwn and Check.amx into FilterScripts folder
2) Copy CheckpointsFiles.txt into your scriptfiles folder
3) Add Check and the end of the line that start with the word "FilterScripts" in Server.cfg (open it with notepad)
4) Create a File inside scriptfiles folder and insde it add the checkpoints size and coordenates like this "SIZE X Y Z" (one per line) see FuelSystem.txt from FuelS[FS] for an example
5) Add the name of the file inside CheckpointsFiles.txt (if you are using FuelS[FS] just add FuelSystem.txt (only one file name per line))
