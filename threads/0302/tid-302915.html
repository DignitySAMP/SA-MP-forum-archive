PlayAudioStreamForPlayer solo lo reproduce para una persona, y si quieres que lo reprodusca para todos haz un bucle para que todos los jugadores lo oigan, ejemplo:

pawn Code:
if(!strcmp(cmd, "/talsonido", true))
    {
    for(new i = 0; i < GetMaxPlayers(); i ++)
    {
        if(IsPlayerConnected(i))
        {
                PlayAudioStreamForPlayer(i, "http://k002.kiwi6.com/hotlink/g20ed12zr5/club_can_t_handle_me_david_guetta.mp3");
        }
    }
        return 1;
}
Eso hace el bucle para todos los jugadores, es decir, chequean todos los jugadores, despues de IsPlayerConnect chequea si estб conectado y despues le envia la informaciуn.
