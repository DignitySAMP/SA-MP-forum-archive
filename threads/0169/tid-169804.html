Quote:
Originally Posted by Marshall_Banks

What do you mean by when the ip changes? My ip? And another question when 0.3b comes out can i upgrade my server to be compatible with 0.3b?
You installed that program which automatically resolves your IP to XXX.no-rp.org, yes? So when player adds XXX.no-rp.org in the client it will show up your server info. When your IP changes, that program you isntalled updates IP to XXX.no-rp.org and end user will still see your server info in the client.
In earlier versions, when you added XXX.no-rp.org, it automatically got IP from it (like 123.123.123.123) and saved it. When your IP changed, client still had 123.123.123.123 in it, but your IP was 321.321.321.321, so server info didn't show up, but you needed to re-add new IP. With 0.3b this is fixed since hostnames are saved in client.
