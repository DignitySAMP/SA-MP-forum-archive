Script Intro:

My hungarian friend made a mapicon placer but that is very lame, so i made this.

Script Info:

This is a mapicon player filterscript. If you use this to place mapicons you'll finish faster and easier.

Warning:

If you downloaded the script make a new directory in scriptfiles named EMapIcons, or the script'll crash!


Script Data:

Owner: Epsilon

Script name: EMapIcons

// Copyright © Epsilon 2009

Script Infos:

Code:
-You can place every mapicon
-You can place 31 maximum per time (this is the max in SA:MP )
-The placed mapicon(s) will be save.
-You only can use as RCON ADMIN
