Ok you do need a static ip address. To get one go here: How to make IP address static I used that video and it helped me when i never had a server.

Now after you have done that go to your server cfg and see what port you are using (Most likely 7777) So now go to this website: http://www.whatismyip.com/ That will help you see your ip address which will allow everyone to see your server. So it will look like this for example: XX.XXX.XX.XX:7777 (X meaning the numbers in your ip.) You send them that ip address then they should see your server.

Hope this helps. If not respond here and i`ll try and help you even more.


Note: your port is the number you set your router to open. Example you opened port "7778" then you put "7778" instead of "7777"
