SA-MP 0.3x RC Testing Gamemode
Note: This gamemode will only be updated when the new RC contains something worth updating for.


0.3x RC2

- Added /carry command
- Updated /changelog

_____________________________

Because of lots of positive feedback of the 0.3e test gamemode, I decided to create a new version for the next SA-MP release.
This script provides you a "ready-to-use" gamemode with which you can test all the new features that have been added withing the RC stadium of SA-MP 0.3x.
It contains many features, including
  • A /commands dialog providing you a complete list of all available commands
  • A /changelog displaying you all updates of a certain 0.3x RC
  • All new objects created at one place, with handy 3D labels giving you basic information
  • 3 Infernuses and 3 NRG bikes for mobility
  • Of course all the new features of SA-MP 0.3x








Download

Note: You need atleast SA-MP 0.3x RC2 client and server to run the newest version of this gamemode




Installation
  1. Download the gamemode
  2. Paste the .pwn file into the 'gamemodes' directory of your server (same with the .amx if you download it)
  3. Compile the .pwn file
  4. Set the gamemode to '03x_RC2' in the server.cfg

Note

You can edit it as much this gamemode as you want, and you are free to use any parts of the code.
But you may NOT re-release this gamemode without providing the original credits.
