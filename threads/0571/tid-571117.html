Hello Guys i am releasing my unfinished GameMode, unfinished because i scripted this gamemode for my own server since i am not Intrested(active) anymore so there is no point keeping the script that's why i decided to share my script with you guys
Now lets start :

Gamemode Features

1-Bank Syetem,
2-ATM System,
3-Random Hospital Spawn
4-Level System
5-Two jobs (Trucker , Farmer)
6-Admin System
7-VIP System
8-Car Engine, Fuel, GPS System
9-Car, Flying, Bike Licence System
10-CellPhone System (With Numbers)

Admin Commands

Admin Level 1 : /asay /a /clearchat /aduty /kick /go /announce
Admin Level 2 : /v /teleport /setmyweather /get /eject /disarm /mute /unmute /repair
Admin Level 3 : /vrespawn /freeze /unfreeze /slap /explode /jp
Admin Level 4 : /setscore /heal /sethealth /setarmour /settime /setweather /setint /setworld /setmoney
Admin Level 5 : /ban /unban /giveallcoins /setcoins /resetcoins /spec /specoff
Admin Level 6 : /banofflineplayer /fakechat


(VIP) Very Important Player Commands

VIPS : /announce /mycolor /vskin /myweather /mytime /jp /vcolor

Normal Players Commands

1- Chat: /me /do /t /s
2- Car Commands: /engine /refuel /canrefuel /gps /gpsoff /lock /unlock /dltest /fltest /bltest
3- Phone: /call /sms /pickup /hangup /ignorecall /mynumber
4- Other: /bank /atm /jobs /rpname /buyskin
