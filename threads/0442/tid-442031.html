About the map

Information:
Well, this is my 1st map and I'm very happy to present this. I got it's idea from another map of MTA which was very incomplete. So I thought, why not make a new one and improve it. The map is now fully fenced, many barrels are added, starting point is added, shortcuts are blocked and many more features are added in it. and I've shown you from a Helicopter so you guys can see how the map looks like. The ending pointing is also shown.
Objects converted: 625
Vehicles: 0
Vehicle models: 0
Map Type: Stunt/Minigame/Racing

Features

1) Fully fenced to avoid players from getting out
2) Preferred vehicle is NRG or any kind of bike.
3) Tested by Xessive to make sure the map can be completed without problems but at the same time, it is challenging.
4) It can hold up to 5 players easily, the more players there are, the harder it will be for the players to win.
5) Barrels are set at such a distance that if one of them blows, other will notblow so that the players nearby the blown player will not die.
