Another hello to you,

This time I used the new objects from 0.3c to make police lights on normal vehicles.

These cars can be spawned with a police light on the dashboard, or on the roof. It all works with a simple dialog which can be shown by typing /spu.

The lights can be put on and off by pressing the "2" key, (the submission-key). Note that the lights only work when it's dark, at daytime they will be turned off, unless you use some specific weatherid's, like i.e. 2.

New functions:
  • /destroyspu
    Destroys the SPU.
  • AddSPU(spuid, Float, Float:y, Float:z, Float:rotation, color1, color2, lightonoroff)
    Can be used to create a SPU without using the dialog, i.e. in OnFilterScriptInit.
  • ADMIN_USE and POLICE_USE
    ADMIN_USE --> Only admins can use /spu and /destroyspu
    POLICE_USE --> Only players with police skins can use /spu and /destroyspu
If you find any bugs, please report them to me.
-Lights will stop flashing when the vehicle drives at an angle, nothing to do about this, it's a GTA bug.

This will only work in 0.3c
