X_Cutter\'s EasyBank Filterscript(xBank)!

Author : X_Cutter
Version : 1.2
Description : A simple bank script using Dini/Dutils. Just put it into your filterscripts folder and add "xbank" to the server.cfg filterscripts line!
Commands : /banklogin /bankregister /deposit /withdraw /transfer /bankhelp

You do not need extra configuration! The script is ready as soon as you download it!

This script is fully working! If you have crashes make sure you have created the XcBankAccs in your scriptfiles folder!
Passwords are now hashed with udb_hash!
