Use this instead of Kick(playerid)

PHP Code:
forward KickFromServer(playerid);
public KickFromServer(playerid) { Kick(playerid); }
stock KickPlayer(playerid)
{
    SetTimerEx("KickFromServer", 200, 0, "d", playerid);
}
