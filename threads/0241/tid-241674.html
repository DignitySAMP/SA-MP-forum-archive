Hey All
Wazz Up?

Open mIRC
Fill All Options


Press Add Click Select Press Connect
Type /join #YourChannelNameHere
/chanserv register #channel password description
Your Done Making Channel!
Now Add Bot
Now Time to Echo it
Download From Here
https://forum.sa-mp.com/showthread.php?tid=98803
Copy And Paste All Files In Specific Folders
Then Goto Filterscripts
Open irc.pwn

Enter Bot1 Name
Add Irc.focogaming.com to Server
Code:
#define IRC_CHANNEL "#Your Channel"
Compile it
Make Sure You dont receive Any Warning Or Error
Open Server.cfg
Add
Code:
filterscripts irc
Add
Code:
Plugins irc

Open Samp-servers
Now your done!!1
