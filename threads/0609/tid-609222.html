MB
Racing System

Hello everyone,

Today i tried to make Racing System because i know many Death match and Stunt server even some Roleplay servers need
Racing Events. So i decided to create one its simple and easy to understand.

Features

Version 1.0
  • Manual Race Creation.
  • Manual Start and Stop System.
  • 14 Checkpoints.
  • Sports Car Menu.
Version 1.1
  • Added delete race option.
  • Top Racer cmd added.
  • You can now set 1 to 99 Race checkpoints.
  • Optimized code.
CommanDs
  • /createrace
  • /enableraceevent
  • /startrace
  • /endrace
  • /joinrace
  • /leaverace
  • /rcmds
  • /deleterace
  • /topracer
How it work?

/createrace
only rcon admin can use that cmd to create race checkpoints by using /createrace after that press Fire key to
set checkpoints for race.

/enableraceevent
only rcon admin can use that cmd to send message to all that race is going to start and it show /joinrace message to all.

/startrace
only rcon admin can use that cmd to start the race for the players who join that event.

/endrace
only rcon admin can use that cmd to end the race for the players who join that event.

/joinrace
player can use cmd if the race event is enabled.

/leaverace
player can use cmd if he want to leave the race.

/topracer
player can see top racer in current on going race.

/deleterace
rcon admin can delete race using that cmd.
