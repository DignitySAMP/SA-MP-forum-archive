This is a client crash, not a server crash. The thing you want to look for in crash reports is this line:
Code:
SCM Op: 0x77E, lDbg: 0 LastRendObj: 9831
You can search the opcode (077E) in the opcode database. This one's apparently related to interiors.
The last rendered object is the object model that the client last rendered. If you can find it in your script it is likely that this object or the ones following it is the culprit.
