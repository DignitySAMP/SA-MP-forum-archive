So you guys think volt-vps.com is the best website to host a SAMP server? Is it reliable and so if I want to run a 50-60 player server I would need about 1GB Ram and how much bandwidth? Also can you guys tell me what to expect what is best kind of VPS and so on, thanks.
Volt VPS is a good choice for game servers from what I've seen in the past. I happen to know some of the staff / support (I designed the site a few months ago), who work there and they're all very knowledgeable about running game servers, especially on Linux. The servers are pretty unloaded as well running on the Xeon Nehalem platform (which is good for game servers).

The 1GB plan should be good for you if you want to run a larger game server (50 slots). The Volt VPS 1GB plan should be enough to hold around 50 players at a constant rate (an active 25 players on all the time for a month uses 300GB of bandwidth). If you're planning on running forums / ucp / a web server / vent / other game servers, you may want to upgrade to 2GB just to give yourself some extra room for growth for processes such as Apache (which work better when you give them more memory).
