Welcome to Flakes admin script 1.0

This is a 100% working mysql and IRC Script, made by Flake witch includes irc integration and a lot of ingame commands to make your server great! full mysql database security with Whirpool password hashing!


Features
Some of the features include
  • MySQL Logging/MYSQL FULL
  • Whirlpool hashing for passwords
  • sscanf2 for unformatting strings
  • ZCMD as command processor for the admin script
  • IRC Script, with a lot of commands!
  • Auto log-in
UPDATED IN 1.2:
  • ANTICHEAT - Jetpack
  • Server Alapha Mode
  • Automessages
  • upgraded reports system
  • fixed some mysql bugs
  • updated the IRC
  • added a DATA Anticheat reporter so cheaters get reported to admins

    TO COME IN 2.0!
  • Anticheat - Money
  • Anticheat - Speedhacks
  • IRC Ip banner
  • Range ban system
  • ISP banner
The mysql_Dump is uncluded in the download pack!

The admin commands and stuff
The administration system features 4 levels of commands (I was planning on making a 'lite' version as well (3 levels), but that was canceled). I'm planning on creating more in the future. Here's a list of the current commands:

Level 1:
* /getinfo /ip /text /spec(off) /slap
* /(un)freeze /(un)mute (/voice) /warn /kick

Level 2:
* /get(here) /goto /explode /an(nounce) /ban

Level 3:
* /veh /giveweapon /unbanip

Level 4:
* /makeadmin /gmx

There's also a small list of public commands, like /report and /login:

Public:
* /login /register /stats /admins /report /acmds

IRC:
Voice:
* !say !pm !getname

Half OP:
* !kick !disarm !remove

OP:
* !ban !kick !announce !rcon !

NOTE: A lot more will be added next version!
