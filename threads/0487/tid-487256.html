PawnPlus - 0.1.1 Beta


Choose next version features here!
Information

PawnPlus is a Pawn++ IDE, with more features than PAWNO.

Features

Some features for PawnPlus is:
  • Auto indentation
  • Auto completion
  • Update Checker
  • Good interface
  • Tabs selection (For the moment is only console)
  • Resizable Tabs
  • Text highlight
  • Docking Tabs
*Note: More features will added in future updates.

Planned Features

I planned to add new features for PawnPlus some of them will be:
  • More theme (for code editor)
  • Limits List (Maybe)
  • Functions helper
  • Code analysis
  • Vehicles List
  • Skins List
  • Arms List
