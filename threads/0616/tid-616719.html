- Always include a_samp first and then any other include.
- Never end with semicolon (public) functions.
- The first parameter of RemoveBuildingForPlayer is playerid which you have removed.
- You need to move all the RemoveBuildingForPlayer code in OnPlayerConnect.
- Since you include streamer, replace (CTRL + H) "CreateObject" with "CreateDynamicObject".

Since you are new, try not to use bad habits of other people (referring to pragma tabsize). All you have to do is indent the code properly (1 tab = 4 spaces): https://wiki.sa-mp.com/wiki/Errors_Li...se_indentation

If you use filterscripts, always use:
Code:
#define FILTERSCRIPT

#include <a_samp>

...
because most of the includes check if it is defined to keep track whether is it included in a filterscript or gamemode (so they can hook the appropriate callback).
