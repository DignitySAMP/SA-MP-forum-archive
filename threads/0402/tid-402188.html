Informations
If you want to be an admin just connect to the server and type /rcon login [ur RCON password] The RCON password can be changed in server.cfg. On my script the RCON password is "windows7" (without ");
If you insert a wrong RCON password then you'll get IP banned (Here's a photo: http://s7.postimage.org/v75cqg657/sa_mp_000.png)
