DDOS , or DOS means D(Distribuated) Denial of Service
DDOS / DOS simply fills up the SERVER network "port", or make the server cpu freeze up on processing something.
So there isn't a way to protect it 100% from the attacks, but out there are the cisco software, which can filter these attacks on at least 50%(or something like that).
