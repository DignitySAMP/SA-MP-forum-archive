After fixing all the bugs that were found/reported i decide to release the final 2.0 version.

Bug fixes:
  • Copy, Cut, Paste now work.
  • Some code optimization on the detection of user defined fuctions/macros/vars.
  • Toolbox bugs were fixed.

  • Added support for special chars
