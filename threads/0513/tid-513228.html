Code:

Native Checker is optional.

Since, I've experience with Stevo127's CnR Script and been an owner/scripter in that script for 1.5 years, you can make yourself admin by going into Scriptfiles, SFCRRPG and you can see your own accountname over there. Open that with any text editor and at the "AdminLevel" section, make yourself 1337. Save the file and close it. Re-join the server. You can access the admin commands by /adcmds.
