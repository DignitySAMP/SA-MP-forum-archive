StrickenKid's MySQL is outdated and the speed improvement is quite slow.

Use BlueG's plugin (now developed by maddinat0r) R34 or R35b3 (pre-release), can be found at Github. The speed improvement of this plugin is good, also, use threaded queries not unthreaded queries if you want to see the result between them, check AndreT's tutorial (https://forum.sa-mp.com/showthread.php?tid=337810)
