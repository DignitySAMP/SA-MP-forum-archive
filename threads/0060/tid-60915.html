FilterScript Guide:
(A)Installing Filter Script
[|1|]Unzip/Unrar the rar file.
[|2|]Move 'AdminMode.amx' and 'AdminMode.pwn'(.pwn = the source code) from filterscripts
folder to your filterscripts folder.
[|3|]Move 'AdminMode' folder from scriptfiles folder
to your scriptfiles folder.
[|4|]add "AdminMode" at the filterscripts line in server.cfg file.
[|5|]Restart the server window/load the rcon Cmd the filterscript(/rcon loadfs AdminMode).
(B)Add Admin/s to Server
[|1|]Open Admins.txt file with pawno(scriptfiles -> AdminMode -> Admins.txt)
[|2|]Fill Username and Password to the specific admin.(In one of the 10 Places)(Format:Username|Password| -
like the Example|1234|[Remove/Edit the Example|1234| and fill it as 0|0|].)
[|3|]Save the file.
[|4|]Get Ingame
[|5|]Type the command /adminlogin or /al and then
type your Username and Password(not in the same "Step") - simple as you write in the
global chat.
Warning!
Do not remove the 0|0| codes,save them
Use their Places if you need more Admins...
So always you'll have 10 places with Code
of username&password!
