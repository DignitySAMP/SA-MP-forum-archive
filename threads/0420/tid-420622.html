Hey everyone. I began working on this script a few weeks ago and discontinued it now as the server it was far wind up removing me from their 'police department' for a stupid reason.

There's not alot, only 1007 lines. But you can actually do alot with this as it has a few features that are useful and you can actually go further with the script.

Features:
Account System
The account system is very simple, you'll have to be a level 1 administrator to be able to /createaccount for someone. If the username you try to use to create an account with is already in use, it will not let you over write the user, and it'll say 'ERROR'.

After an account is created, the account's password MUST be changed afterwards as the password is the username.
EX: Username: Apple
Password: Apple

It'll also save in scriptfiles under account.log when an admin creates an account, it'll also show their IP address, useful for server owners incase something goes wrong.

Administration:
There's only two admin commands, /makeadmin and /createaccount. To use /makeadmin, you must be logged in as a rcon admin.

/admins command aswell, every 1-5 of the admin rank is considered a moderator, 6-1337 is considered a regular admin, 1338 is hidden.

Join Messages:
Self explanatory, when someone joins, gets kicked, or leaves, it tells everyone.

Basic Stuff:
You'll have chats, when you talk like a normal chat, it'll come up as Apple says: blah blah blah. Like a roleplaying gamemode almost. You must be logged in to type any command.

/breach - Will teleport you to set of house/business interiors, there's only 9 I believe. You can add more, very easy to do.

/enter - enter an interior.

/exit - exit an interior

/duty - gives you a blue color, firearms. for cops.

/criminal - gives you a white color, firearms, for criminals.

/swat - gives you the SWAT skin, 200 armour, 100hp, firearms.

/kill - self explanatory.

BUGS/STUFF I DIDN'T FINISH OR DO:

The chat commands are bugged, easy to fix if you know what you're doing. (/o, /b, /s).
I did NOT save the kills/deaths yet, and I wont continue with the script, so figure it out yourself.
I did not save the IPs yet aswell, easy to do.
I was going to make it where you click a player's name in tab, that'll show their deaths, kills, ratio of deaths and kills, country they're from, and there rank.
I did not do a ranking system either, easy to do, figure it out.
I was going to add the taser systems with the SDPistols, ect, so if you wanna do that, do it.
I never added /siren or /siren2, there is a few filterscripts around though on the forums some where with sirens.
This script was mainly for driving, shootouts, breaching houses, ect.
