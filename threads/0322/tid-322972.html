I'm not sure what maps you are talking about. I'm going to assume that these maps are mods for GTA:San Andreas. SA-MP does not support mods. You may be able to make it work, but there will be no official support for you here.

What you need to do, is to have everyone install these maps on their copy of GTA:San Andreas. Then you have to design the server for the new map. There is no way to "install the map for everyone". They have to install the mods themselves.
