I want to let you all know that this is a re-release. I have updated the previous script I released, Underground RP, and it works with 0.3D here. I am also including all includes for 0.3D so please feel free to use them! The reason for a re-release is that the previous was very old, had no 0.3D compatibility, and this new one is now working fine. I feel the script may have some features that people may be interested in using, if not the whole thing itself.

- Dynamic housing & business system
- Dynamic vehicle system
- Fully functional LSPD
- An array of administration commands
- Unique engine system
- Helper system (style of PR-RP, believe me this isn't new)
- Radio system
- Unique driving system
- Tons more
