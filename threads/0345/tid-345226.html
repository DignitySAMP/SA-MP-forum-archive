Here i present you another Gamemode from ColdFusionZ Team

SWAT with a slight change

Where did we get the idea from?

What does this gamemode is about?

There are basically 2 Teams
SWAT
TERRORISTS

Theme/Story
So basically the theme is that
There are 2 Teams as also defined above SWAT & TERRORISTS
Both team has a objective
So the Story..
Terrorists have undertaken a Ship which is filled with NuclearBombs/Weapons/Ammo etc
They will stay in the ship and defend it
The second part of story is that
SWAT who doesnt know about this yet is somehow informed, They move to docks fully locked and loaded
to hunt terrorists ass down.
Terrorist who already have spotted them have to defend their ship from SWAT
So..
The SWAT Team has only one way to stop this masscre
Destroying the whole ship
SWAT move fully armed to poop those suka's ass down

Story in Short
Terrorists need to defend the ship whereas SWAT Need to Destroy the ship

Misc/Features

Weapon Shop
∞ A Basic feature that enables you to buy weapons

Tazer System

∞ A Tazer system that tazes/freezes player when shot (Works only with SD Pistol)

Admin system

∞ A Administration/Server mangament system that help you control player with loads of commands, Features include registration/login + autosave player stats

Rank System

∞ A Rank System Textdraw at right side bottom of your screen, it shows player ranks that depends upon his kills also cash

Score 0 - Rank 0
Score 50 - Rank 1
Score 100- Rank 2
Score 200- Rank 3
Score 500- Rank 4
Score 700- Rank 5
Score 1000- Rank 6

IRC

∞ Server also has a IRC FS/Include that help you to echo your server at any irc network in anychannel.

Player Commands:

!imsg <send message to server>
!igetid <get a players id based on nickname>

Admin Commands:

!iban <ban a player with optional reason>
!ikick <kick a player with optional reason>
!islap <slap a player with optional reason>
!ikill <kill a player with optional reason>
!isay <send message to the server as admin>
!ipause <pause the echo, !pause again to unpause>


Commands

Player Commands

/shop - Enables a player to buy guns
/tazer - Toggles Tazer system on/off
/help - Server help
/rules - Server Rules
/credits - Server credits

Administration

5 Levels of admins
Level 1: Basic Moderator
Level 2: Moderator
Level 3: Master Moderator
Level 4: Administrator
Level 5: Master Administrator
Rcon: Rcon Administrator

Commands in-game
use /level <level> to see your commands list.
