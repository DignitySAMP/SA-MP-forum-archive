Controllable Alien Ship version 0.1b

This is scripted extension of the Alien Ship Remix that allows you to move it around San Andreas.

Requirements:

-Map Andreas Plugin
-sscanf2 Plugin

Commands:

/aup - Move the ship up Parameters: 1.0 - 20.0 (speed)
/adown - Move the ship down Parameters: 1.0 - 20.0 (speed)
/aright - Rotate the ship right
/aleft - Rotate the ship left
/amove - Start moving ship along heading
/aheading - Set the heading of the ship Parameters: 0.0 - 359.9 (angle)
/aspeed - Set the speed of the ship Parameters: 1.0 - 20.0 (speed)
/areset - Resets the alien ship to spawn position


Notes

Do not exceed more than 20.0 as speed actually not more than 10.0 is recommended otherwise it's a problem for client FPS
