-> Note System <-
  • Description
  • Commands
  • Downlaod
  • Credits
Description
  • In this script you can use some functions to create your own note, this system is best for a RP server but it can be used for other server modes aswell. Well but in this script you can create notes, delete them and give them. Let's say that you has to remember a number you have got from a friend ICly, maybe a important number. Then you can type /createnote to create one. Then when it's time to call then you can type /shownotes to show the note you've created, and then you can call them.

    Commands
    • Quote:
      • /createnote[text]
      • /deletenote[1/2/3/4/5]
      • /Shownote[1/2/3/4/5]
      • /givenote[1/2/3/4/5][playerid/name]
