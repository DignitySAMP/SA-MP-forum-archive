Commands:
/fun1block - blocks first funicular
/fun1unblock - unblocks first funicular (not starting of funicular, you must wait for timer)
/fun2block - the same, for second funicular
/fun2unblock - the same, for second funicular

Intervals of timers are set to: First funicular (lower) - 5 minutes, second funicular - 7,5 minutes, speeds: 1. funicular - 2,5 (in PAWN (MoveObject)), 2. funicular - 3 (because upper funicular has bigger distance between stations, so funiculars donґt go at once for compensation )

Known Bugs:
- There could be some bugs if you commands for (un)blocking funiculars, so i recommend not to use commands
- You must walk (or run) in the direction of funicular moving; this is because of SAMP bug of MoveObject (i havenґt tried to solve this problem with freezing player at some other place and set his camera to funicular, but iґm going to try it sometime)
