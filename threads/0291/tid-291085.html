Peace,

today I've decided, to publish a new Open Source Project. I sincerely apologize for my imperfect English. This Include allows you three new Functions for "Boom-Text". I can't explain perfect in English, what a "Boom-Text" is - so watch the Video - try to explain: Its an animated Textdraw with a Text - like an explosion. Good for Deathmatch Server, but for every else Server Types too. Like "SetPlayerBoom(playerid,"Headshot"); if anyone gives another player an Headshot.

Function's:
pawn Code:
SetPlayerBoom(playerid,Text[]);
StopPlayerBoom(playerid);
IfPlayerBoom(playerid)
