Introduction


So bassicly, due to this being version 2.0 and the final one of OxiDialogs,
I have decided to create a new , better looking, more features, sexier thread.


Note, it is now the last version and won't be updated anytime soon.


Features

1. You are able to create inputtext styled dialogs.
2. You are able to create msgbox styled dialogs - as of 2.0
3. You are able to create listitem styled dialogs - as of 2.0


Note that before creating one you'll see an overview of how it looks,
you can either change it, bassicly not create it at the end or create it.

After you have created a dialog you'll find it by the name given under the scriptfiles folder.
Open it with a 'writing' software, copy everything into your gamemode and you're done.

In the listitem dialog creation it'll be represented to you when you go into a new line it'll be this /n instead of this \n.
Why? Because if it'll be used as a new line then it wouldn't show the actual \n.

Also when you are trying to make new lines, use /n instead of \n.
This is very important.


Include Creaters

1. a_samp - sa-mp team
2. zcmd - Zeex

This'd be a great start to learn how to use dialogs for beginners in pawn.
