Because far as hosting goes windows uses more resources which can be cut down completely with Linux. Linux is also far more secure as it's open source and based off security if you know what you're doing of course, because if you don't your leaving it open for everyone to attempt to get their way inside, just like a Windows Server.

all in all, windows is not a recommended hosting OS by professionals. Windows Servers require updates which require restarts quite a bit where linux can be updated and not rebooted for months. Which means less downtime for your services.

Linux support is just as good as windows support and learning the OS is not really a challenge especially CentOS where you can look up just about every problem and every solution over ****** and find a answer.

The OS can be a challenge to handle but with control panels like cPanel or webmin it can make your life a whole lot easier and actually enjoy using Linux.

Depends if you are talking about Linux 100%, or Windows running a Linux VM, or Linux running a Windows VM.

When samp03svr is running on my 100% Linux system;

Summary

The process samp03svr (with pid 30537) is using approximately 6.9 MB of memory.
It is using 6.8 MB privately, and a further 1244.0 KB that is, or could be, shared with other programs.
Dividing up the shared memory between all the processes sharing that memory we get a reduced shared memory usage of 105.0 KB. Adding that to the private usage, we get the above mentioned total memory footprint of 6.9 MB.

Library Usage

The memory usage of a process is found by adding up the memory usage of each of its libraries, plus the process's own heap, stack and any other mappings, plus the stack of its one other thread.
