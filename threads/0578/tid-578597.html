I just realised that it is in fact GameMode Exit.

Think about it logically. Typically, GMX is actually used to exit the current gamemode and run the next in the list (the list of gamemodes in your server.cfg). This is also precisely what our GameModeExit function does.

It is "gamemode exit". Once the gamemode, e.g. gamemode0 has exited it starts the next, e.g. gamemode1. If there is no next gamemode it starts gamemode0. Because we all only use 1 gamemode we use game more as a restart command, but it really isn't.
