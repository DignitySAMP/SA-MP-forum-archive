Weponz Battleship Warzone

This is my 2nd map release and my 1st map ive ever done,It was mapped for my "Counter-Strike Battleship" Server but id thought id release the map because it will be perfect for TDM/DM/WAR servers.

You can download the Counter-Strike GM here: http://forum.sa-mp.com/showthread.ph...712#post889712

What is it?

This map has 225 Objects,94 Hydras/Hunters/Rustlers/Sea Sparrows/Bikes/Patriots and Boats! 2 Aircraft Carriers/Airstrip/Tank area fully mapped with a admin base!

Where is it?

Map located at the Container ship North San Fierro near the red bridge ("Golden Gate Bridge")

Teleports?

To get into the admin base put this teleport command in you Gamemode

Code:
   		if (strcmp("/wepzbase", cmdtext, true) == 0)
	    {
	    //if(IsPlayerAdmin(playerid))//Uncomment these 2 lines if you want only RCON admins to be able to get in admin base
		SetPlayerPos(playerid,-2471.8823,1544.7992,36.8047);
	    //else SendClientMessage(playerid, 0x0, "You Are Not A Admin!");
		return 1;
	    }
To teleport to the map put this teleport command in your Gamemode

Code:
   		if (strcmp("/wepzwar", cmdtext, true) == 0)
	    {
		SetPlayerPos(playerid,-2366.3794,1602.9595,9.4613);
		return 1;
	    }
