https://wiki.sa-mp.com/wiki/Fread

Invalid file handle crashed your server, in other words the file could not be opened and you're trying to read from a closed file.

Re-compile the script with debug info as I mentioned above to get the exact line otherwise it'll be harder to fix it because the only thing we know is that it was in OnPlayerConnect.

By the way, an example of what I meant before.
pawn Code:
new File: fhandle = fopen(...);
fread(fhandle, string);
...
that is wrong. The correct way would be:
pawn Code:
new File: fhandle = fopen(...);
if (fhandle) // valid file handle (not 0)
{
    fread(fhandle, string);
    ...
}

Since it returns 0 if the player's IP is not in the file and 1 if it is. We need to return some other value if the file was not opened to prevent any action.

PHP Code:
stock CheckBan(ip[])
{
    new File: file = fopen("ban.cfg", io_read);
    if (!file) return -1;
    new string[20];
    while(fread(file, string))
    {
        if(strcmp(ip, string, true, strlen(ip)) == 0)
        {
            fclose(file);
            return 1;
        }
    }
    fclose(file);
    return 0;
} 
An example would be:
PHP Code:
switch (CheckBan(player_ip)) // supposed "player_ip" stores the player's IP on connect.
{
    case -1:
    {
        // could not read from the file, send a notice to admins
    }
    case 1:
    {
        // banned; do something
    }
} 
However, I'd recommend you since you're new to scripting to try better and more efficient ways such as SQL or y_ini instead.
