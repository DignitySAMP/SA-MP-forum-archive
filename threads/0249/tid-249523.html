3D Text System by ShOoBy

Description

V2 - Alot of people were crying that Texts must be saved.
So in the V2 the 3D Texts are saved into a file called "Texts.txt" which you put in ScriptFiles.
Now you can use it for making 3D Texts for your server and then you simply add them into your GameMode

V1 - This is a simple FilterScript.Simply is an Dinamic 3DTexts placer.
But just an Rcon can use it.The 3D Texts are placed but they are not saved in a file.

Instalation

To install make the following things:
  • Download the Script and put it in the Filterscripts folder
  • Name it and then compile it (the blue arrow)
  • Put his name(without the .amx extension) in "server.cfg" at the "FilterScripts" line
  • Put "Texts.txt" file into Scriptfiles
