Name: BondCar
Version: 1.1
Developers: Apec и AHTOXA
Description:
This FS will add to your server spy car.
What could this wonderful machine?
The main function works when you press the NUM, and more through a special menu.
NUM2 - shot from a cannon.
NUM8 - spikes
NUM4 - smokescreen
NUM6 - menu

Menu options:
disguise - When this option is not visible machine standing in one place. Your nickname is hiding. When auto motion is once again visible.
change color - Auto color change to black or white.
sensor damage - over the car, the indicator which shows the number of HP car and inflicted damage.
repairing tires - if suddenly struck your tires, you can always restore them with the help of this function.
password - that would use any opportunity car you first enter the password. This option will help you change your password and do turn it off.
self-destruction - if necessary, the machine can be quickly eliminated. You just need to set a timer from 1 to 60 seconds. and run faster.
