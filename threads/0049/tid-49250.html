Gamemode Starter Kit

One of my friends decided he was going to create a DM script and he asked me if I could make him a registration system... So I did, then I added a few other things that would be nice to start any type of game mode with... I think its nice, so I will share it with all you guys.

Code:
..::Gamemode Starter Kit Features::..

~Easy to read format
~Comments in the script that explains how things work and how to use them.
~Customizable text draw displaying name of server and website (only need to change a define value at the top of the script.)
~Files save to "accounts" folder for easy access
~Unhackable money(hacking attempts logged in server_log.txt)
~Commands that display text typed by a player (/me, /w...) get logged in server_log.txt.
~Preset stats
	~password
	~ip
	~banned
	~warns
	~skin
	~spawn(x,y,z,angle)
	~money
~No command register/login system with afterlogin password protection
(if you type your password in after login on accident, the text does not show up.)
~Alternate /register and /login commands for people used to the godfather script.
~Includes lrp.inc which contains all include files of the godfather, plus a few others added by
me.(colors.inc - my own color definitions)
(carcomponents.inc - every car component listed and made easy to use.)
