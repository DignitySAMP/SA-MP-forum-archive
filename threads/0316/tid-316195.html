Introducion

-I made an Roleplay mode in island from scratch with my own mapping
-Its My First Release


Commands

/help,/cmds/pee,/refuel/opengate,/closegate,
/travel,/jobinfo etc...

Jobs
There are 2 Simple Jobs:

Trashmaster and Medic

how to get these jobs:

just get on trashmaster or medic truck and type /trashmaster or /medic

Features

-Making the map bigger
-Adding register +admin system(Added)
-More roleplay commands
-Convert all commands to dcmd


Code:
Changelog v1.5

-Added Register system +some admin commands like 
/setlevel(for rcon),/kick(for lvl 3),/ban(for lvl 3),/freeze,/unfreeze(for lvl 1)
-Also i added a simple loto system you can buy tickets by typing /lotto <number 0-100>
Note
If the gamemode dosent load any map then delete weed.pwn,.amx from filterscripts and from server.cfg
