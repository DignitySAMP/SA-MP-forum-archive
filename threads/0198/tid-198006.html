its what the name suggests, XmasTrees using the new object "XmasTree1" which was added in the new version (R4) by the SA-MP Developers "These Guys Rock "

i think its pretty much self explanatory...

* edited -added gifts and flashing efffect *
it enables you to create upto 100 xmas trees (1000 objects) Containing the tree+8 gifts.
Note: up close if you up at the tree it flashes.

all streamed thanks to fallouts magnificent streamer which i have implemented.

Commands are:
/xmastree to place a Xmas Tree
/delcxmasree to delete the Xmas Tree closest to you
/delallxmastree to delete all Xmas Trees currently created on the server
