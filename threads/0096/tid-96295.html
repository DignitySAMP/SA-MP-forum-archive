What is this ?
These it the Better version off the Bus driver,it's still in the LV city.
In this version, you weill have lines.
You can Choose line from 1-4
[1-2 - I did, 3-4 , You can Add your own lines-If you will don't know how to do it,Ask here]
Installation
If you selected it will be as a FILTERSCRIPT,follow the next instruction:
  • Download the files
  • Put the PWN+AMX in your filterscript folder
  • open Server.cfg
  • in the line "filterscripts" add this: busv2fs
Code:
it need to be like that: filterscripts busv2fs
  • Run your server,and enjoy this FilterScript
If you selected it will be as a GAMEMODE,follow the next instruction:
  • Download the files
  • Put the PWN+AMX in your gamemodes folder
  • open Server.cfg
  • in the line "gamemode0" add this: bus_v2
Code:
it need to be like that: gamemode0 bus_v2 1
  • Run your server,and enjoy this GameMode

Commands
Code:
/Bushelp - to get more help about the mod
/Buscmds - To view all the commands that avliable
/BusCredits - To view credits
-Gates:
/OpanAll - To open the all gates
/CloseAll - To close the all gates
/OpenE - Opens the Main gate
/CloseE - Closes the Main gate
/OpenP - Opens the Parking gate
/CloseP - Closes the Parking gate
/OpenG - Opens the Garage gate
/CloseG - Closes the Garage gate
/Driver - Work As a bus driver
/DriverOff- stop working as a bus driver
/Bus - teleport to bus area.
/Line - To see the list of your destenation
/SLine - To Choose your destenation

What do you need to do as bus driver?
You need to enter to any bus,and write /Driver .
Now you will be able to use the command:"/Sline" ,and afetr you will choose a line,it will show you the checkpoint[on the map] and you will need to collect all of the checkpoint.
after you will finish,you will get money[Can be easly edited]
