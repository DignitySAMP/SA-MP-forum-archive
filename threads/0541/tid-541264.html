Hey all,

This is a little tutorial on how to create SA:MP home server (Windows).

1. Download the lastest SA:MP server from official SA:MP page or from this link: www.sa-mp.com/downloads SA-MP 0.3z Windows Server

2. Unpack!

3. Open server.cfg with notepad!
It's in server.cfg:
Code:
rcon_password changeme
maxplayers 30
port 7777
hostname SA-MP 0.3 Server
gamemode0 grandlarc 1
filterscripts gl_actions gl_property gl_realtime gl_mapicon ls_elevator test_cmds ls_mall attachments
announce 0
query 1
weburl www.sa-mp.com
onfoot_rate 40
incar_rate 40
weapon_rate 40
stream_distance 300.0
stream_rate 1000
maxnpc 10
logtimeformat [%H:%M:%S]
4. Change the RCON password:
Code:
rcon_password anything
5. Save the file

6. Run samp-server.exe

7. Go to http://www.whatismyip.com/

8. Copy your IP

9. Open SA:MP client

10. Press 'Add server' button

11. Paste your IP and write after your IP: ':7777' (Example: 2.2.2.2:7777) and press 'Ok'

12. Select you server from list, connect and enjoy!
