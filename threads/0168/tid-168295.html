-Ache nesses publics o pCarKey;
-Copie a linha referente ao pCarKey;
-Modifique a Linha, e coloque logo abaixo.


Exemplo:
pawn Code:
enum pInfo
{
    pKey[128],
    pLevel,
    pAdmin,
    pDonateRank,

}
Agora, vocк simplesmente copia o "pPcarkey3,", e coloca logo abaixo dele "pPcarkey4," (Sem as aspas).

No OnPlayerConnect, existe esta linha: " PlayerInfo[playerid][pPcarkey3] = 999; ".

Adicione abaixo dela:" PlayerInfo[playerid][pPcarkey4] = 999; ".


Em OnPlayerRegister, existe esta linha: " format(var, 64, "Car3=%d\n",PlayerInfo[playerid][pPcarkey3]);fwrite(hFile, var);".

Logo abaixo, coloque " format(var, 64, "Car4=%d\n",PlayerInfo[playerid][pPcarkey4]);fwrite(hFile, var);




Em OnPlayerUpdate, existe a linha: " format(var, 64, "Car3=%d\n",PlayerInfo[playerid][pPcarkey3]);fwrite(hFile, var);".


Logo abaixo, escreva: " format(var, 64, "Car4=%d\n",PlayerInfo[playerid][pPcarkey4]);fwrite(hFile, var);"



Por Fim, em OnPlayerLogin, existe a linha " if( strcmp( key , "Car3" , true ) == 0 ) { val = ini_GetValue( Data ); PlayerInfo[playerid][pPcarkey3] = strval( val ); }".


COloque logo abaixo: " if( strcmp( key , "Car4" , true ) == 0 ) { val = ini_GetValue( Data ); PlayerInfo[playerid][pPcarkey4] = strval( val ); }".
