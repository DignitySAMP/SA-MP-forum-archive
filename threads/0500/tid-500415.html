Hello.

I'm currently developing a Hunger Games game mode with my current team, which consists of 4 members. We've been developing it for some time now and I'm honestly just curious to see how many people would actually be interested in playing this type of game mode. That's the whole point of this topic.

If you're interested, please just make a simple vote. If you are, explain why you're interested and if you're not, do the same. I'd also like to read any suggestions you may have regarding the current progress of the server.

I'm interested in hearing the communities thoughts on this type of game mode. If you have any suggestion that you would like my team and I to hear, then please leave me a private message or message me on skype at the name 'Twackers'.

(Features which will be in the current version. Note: Some may not be listed):
* Dynamic fires
* Fishing.
* Cooking
* Hunger/Thirst systems.
* Weather changing. Different weathers can hurt you. Example: You'll need face protection in sand storms, or you'll get injured.
* A Lobby.
* Lobby activities, such as parkours, demolition derby's, death matches.
* Backpacks. Higher backpack tiers = higher carry capacity.
* Traps
* Radios
* Caves with game-changing events.

Update 12-5-14
We have began rewriting this mode from scratch about a week ago. If you would like to know more information then please refer to the post on page 6. I'll also be posting updates here every other day (If not every day.)


Thanks.
