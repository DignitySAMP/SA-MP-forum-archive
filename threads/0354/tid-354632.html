• Como instalar el GameMode •

Para instalar el GM debe hacer lo siguiente:

1)Descargar el GameMode.
2)Configurar el server.cfg (Rcon y Plugins al igual que GameMode y FilterScript) a tu gusto.
3)Abrir Server Restar o sampserver.exe.
4)Agregar en tu sa-mp la IP 127.0.0.1:7777.

Para hacerte Admin del Servidor:

1)Ir a la carpeta USUARIOS.
2)Abrir tu nombre de usuario y editar la linea que dice AdminLevel.
3)Ponerle el numero 1338 a esa linea y guardar.
4)Entrar al servidor con esa cuenta.

Posibles errores:

Si tienes el siguiente error:

Code:
Run time error 19: "File or function is not found"
Es porque debes tener el plugin xStreamer en tu server.cfg y en tu carpeta Plugins.
