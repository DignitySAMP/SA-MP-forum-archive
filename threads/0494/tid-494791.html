Do:

Code:
/mode $chan +f [5c#C120,5j#R60,10m#m60,5n#N60]:15
(replace $chan with your channel name, eg #SA-MP)

+f is flood control mode. The :15 in the end means that it counts per 15 seconds.

Code:
5c#C120
If you get 5 CTCP requests (ping/version/time/...) per 15 seconds in your channel, it will set mode +C for 120 seconds. Mode +C disables CTCP requests

Code:
5j#R60
If you get 5 joins per 15 seconds in your channel, it will set mode +R for 60 seconds. Mode +R allows only registered nicknames to join. If it's a server echo channel, you should also take notice of the bots joining on server restart, which may be more than this limit.

Code:
10m#m60
If you get 10 messages per 15 seconds in your channel, it will set mode +m for 60 seconds. Mode +m means moderated, aka people who do not have a voice set (+v) will not be able to send messages in the channel. Again you should increase this probably since it is an echo channel, which will post more than 10 messages per 15 seconds.

Code:
5n#N60
If you get 5 nickname changes per 15 seconds in your channel, it will set mode +N for 60 seconds. Mode +N will disallow nickname changes. Don't leave this on for too long, since it is extremely annoying for most people. It's also not really necessary so you can leave it out

Documentation about this feature can be found here: http://www.unrealircd.com/files/docs...ture_antiflood
