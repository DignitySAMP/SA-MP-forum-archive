Hello, yeah there's a way to do it.

1. In your server.cfg set announce to 1.
2. Visit this site - http://www.whatismyip.com/
3. Copy the IP adress and check it in the SACNR Monitor - http://monitor.sacnr.com/checker.html
(Make sure server is running)
4. In the SACNR Monitor it will show 0/- players, now join from your local IP 127.0.0.1: port
5. Check your server in the SACNR Monitor again, it will show 1/- players.

P.S: You wont be able to join your server through the IP you got from http://www.whatismyip.com/, but other players will, you can join only from your LOCAL IP.

Let's hope it will work for you, have a nice day

127.0.0.1 is a local ip, you can use this to connect with a sa-mp server thats running on your computer
you also have a lan ip, something like 192.168.1.XXX, thats the ip that friends will need to use to connect with your server after joining your hamachi room.

To find the lan ip of your computer;
- Open start menu, in run/search type "cmd" and press enter (or if windows 8, go to metro interface, open settings, enable administrator tool icons, then find "command prompt" in the list of programs and start it)
- In the window that pops up type "ipconfig" and press enter
- In the text that shows up look for "IPv4 Address", on that line should be your lan ip.
