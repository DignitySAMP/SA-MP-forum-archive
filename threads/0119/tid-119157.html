[b]IntroZones - Version 1.0

-You're not allowed to release this without my permission.
-You're allowed to change this script for own usage but NOT to remove the credits.
-You're not allowed to make unofficial updates/versions of this FS and release them.
-Any rulebreaking which gets in my knowledge will be reported.


This filterscript helps you to create gangzones on a very simple and easy way.


Installation:
-Download the filterscripts.rar file.
-Extract the files to ".../filterscripts"
-Add "IntroZone" to the line Filterscripts inside Server.cfg
-You're Done! Good luck.

-How to use
-Start your server.
-Connect and login(if needed)
-Go to a place and stand in a position where you want 1 of the zones corners to be.
-Type /zone
-Select "Createzone" and choose a color in window 2
-Move to the opposite corner of where you want the zone to end.
-Check the minimap to make sure you're zone looks like you want it.
-When you think your zone is perfect, type /zone and select "Savezone".
-Now go to your "Scriptfiles" folder and look for a file called "savedzones.txt".
-Once you've found it, Open it and copy the line(s) which is inside.
-Open your Gamemode script and place the lines under "OnGameModeInit".
-Now your gangzone will show as soon as your server (re)starts.
-To cancel the creation of the zone, type /zone and select Cancelzone.


In Progress:

Version 2.0:
-Ability to create notes when you save.
-Zones will be saved in the filterscript so you don't have to add them manually into your gamemode.
-More colors will be added.
-Change a zones color which have already been saved in the filterscript.
-Change zones sizes when they're saved.
-Ability to delete zones from the filterscript.

Bugs and common problems
- You don't get the second window after you've selected "Createzone".
Fix: Make sure your gamemode doesn't use a dialog ID which is 0 or 1. If it does, Change the Dialog IDs in the Filterscript to 2 unused IDs. This will probably solve the bug. If not, leave a comment.

Got something you want to be added? Leave a comment.
Hope you enjoy it.
