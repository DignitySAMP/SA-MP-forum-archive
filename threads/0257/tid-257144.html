Lorenc Color (Color program coded in Microsoft Visual C#)
Introduction
Suddenly I was inspired by Jack_Rocker's Color system, since there were quite a basic amount of features such as just the color and outputs just the HEX code this one allows you to name your color and convert it into a define, it also as a pawno defining syntax like:
pawn Code:
#define THIS_COLOR_BLUE
I also had added an 0.3c color embedded code, theres options how you wanted your code to output like anyway.

Credits
Lorenc - Design and mainly coding
Jack_Rocker - Just took a look to check his method on how he make it convert to HEX.

Notes
This isn't a program like Jack_Rockers, his uses Visual basic and mine uses C sharp, completely different coding syntax and isn't that alike.

Reports of bugs or anything shall go here, i haven't had that much time to check spelling or grammar mistakes. Once again quick and nice release (AT LEAST NICE TO ME) and is 100% harmless, if you do not trust the .EXE download the source and open the files till you find a debug folder then click the exe there or run the project via Microsoft Visual C#
