Dongi's Basic Trucking GM
Features:
  • 2 classes, Trucker and Police
  • Register system (saves score, v.i.p, deaths)
  • Requires 50 score to join the police class
  • Depots are marked with a on the minimap (global)
  • 3 custom depots (made by me) and a custom city (custom cities are marked with a on the minimap (local)
  • When you have successfully registered and spawned, a dialog shows up and you are able to choose where to spawn
  • Admin system (3 ranks - Moderator, Administrator and You)
  • V.I.P system
  • Truckers are Yellow and Cops are Blue (light blue to be more precise)
  • Tollbooth system (thanks to DobbysGamertag)
  • PM system
  • Random weather
Commands:

General: /admins (it shows just the admins that are on /duty), /reclass, /stats, /help (dialog with everything you need to know about the server; you can add more options)
Trucker: /work, /stopwork, /detach
Cops: /fine (useless 'cus there aren't speed traps yet - the fine is based on wanted level)
V.I.P: /vcolor, /flip

Moderator

Quote:

/kick
/freeze
/unfreeze
/mute
/unmute
/goto
/get
/duty
/warn
Administrator

Quote:

/ban
/announce
/repairall
You (your rank, you name it)
Quote:

/setvip
/setadmin

Other Info:

- In order to run it, you need the following:
  • sscanf (click)
  • zcmd (click)
  • streamer (click)
- I did not added the command /credits; if you will, you better add me there as i did all the work (i know you won't)

- I did not added any screens as i'm not on my PC. Just download it and check it out yourself

- Don't reply "GJ" "Nice" and you did not even test it. Don't reply unless you downloaded/tested it.

- Since i'm not that good at scripting, it took me 1 week to do this so don't go hard on me. I'm realising this 'cus there are like just 3 Trucking GM, although this is just a basic GM you can start of with.

- Regarding /fine, just add speed traps that sets your wanted level to 1 if you don't obey the speed limit
