Beginning
Hey Guys , this is my First Map release maybe its not good enough but everyone learns from his mistakes ;P
Requirements: Streamer plugin Here to get it(if you couldnt install it pm me to convert it for a_samp only).
Features
1- Well Mapped
2- 2 gates and a garage (moving gates)
3- Elevator.
4- 4 vehicles
5- 2 interiors ( house&club )
6- theres 2 dialogs 1 for guns and other for guns inside the house ( with pickup icons easy to find )
7- Messages displays after anything done by you.
8- easy and friendly Script Codes, you can add/remove things quite easy.
Commands
1- Gates Commands :
PHP Code:
Gate N.1:
/om1//opening door N.1
/cm1//Closing door N.1
Gate N.2:
/om2//opening door N.2
/cm2//Closing door N.2 
2-Garage Commands:
PHP Code:
/og//Opens the garage
/cg//Closes the garage 
3-Elevator Commands:
PHP Code:
/eup//elevator goes up
/edown//elevator goes down 
4-Interiors Commands:
PHP Code:
Club:
/enclub/enters club(at the arrow)
/exclub//exits club (at the arrow)
House:
/enhouse//enters house(at the icon)
/exhouse//exits house (at the icon) 
5-House Teleporation:
PHP Code:
/gomaddogs//teleports infront of the house 
6-help cmd IG
PHP Code:
/househelp//displays it
