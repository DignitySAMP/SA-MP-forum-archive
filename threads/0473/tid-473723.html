So, I just made a compare between TRIANGLE.GS, SA-MP.GS and ULTRA-H.com. I'm sorry if I'm being offensive, because I don't know which should I choose.

TRIANGLE.gs
Advantages of TRIANGLE.gs
1. 30 player slots
2. Medium ping (Tested from Malaysia-France, 350 ping)
3. The server will be yours if you use the banner that they given! (Means no more worries if you're getting a tiny community ^^)
4. Lots of port, more than you can't ever think! (1 server location, France)
5. You can even own more than 1 server (max 2), if you think your first server is going well.
6. FTP supported.

Disadvantages of TRIANGLE.gs
1. Hard to set up for newbies (Took me around half an hour because lack of experience of running a server)
2. Web is a bit slow (My area?)

Information/Rules of TRIANGLE.gs
1. Operating system: CentOS 6
2. Renewal for 1 day if you just want to test server. Renewal for permanent (use their banner) if you're interested to make a community.

SA-MP.gs
Advantages of SA-MP.gs:
1. 30 player slots
2. Have a lot of port to choose (1 server location, France)
3. High up-time (Not sure of this)
4. Easy to get (Once register, you'll receive an email from them within 5 minutes, guess so)
5. Just upload your gamemode, no restriction of the gamemode!
6. Medium ping (Tested from Malaysia-France, 350 ping)
7. pHpMyAdmin database support.
8. Able to upgrade to 100 slots, increased CPU usage and another free database by getting 16-digit code, do the survey and you'll get it.
9. FTP supported.

Disadvantages of SA-MP.gs
1. No forum support (Only via contact)

Information/Rules of SA-MP.gs
1. Operating system of the server is: Debian 6 Wheezy x86 (32 bit)
2. If you don't login for 3 days or above, your server will be removed.

Ultra-H.com
Advantages of Ultra-H.com
1. 20 player slots
2. Medium ping (Tested from Malaysia-France, 350 ping)
3. Easy to get (Once you requested, done within 10 minutes, guess so)
4. Has forum support
5. Giveaway event! (Only for Ultra-H.com users?)
6. FTP supported.
7. Can even buy server when free ports are not available? (Not sure)

Disadvantages of Ultra-H.com
1. Hard to get a server.
- Why I say this? I just checked this and the ports are for only 20-30 persons and they are always get occupied.
2. No MySQL database support
3. Medium up-time (Sometimes the server can down for several days)
4. You must use their handmade script ("SendClientMessage" about the server is hosted by Ultra-H) and you must not upload roleplay gamemode! (That's cool)

Information/Rules of Ultra-H.com
1. Operating system of the server is: Linux (Not sure what is the name and the bits)
2. If you don't login for a day (thefak), your server will be removed

Updated on 21st of May, 2014, if anything wrong please contact me via Private Message/Visitor Message!
