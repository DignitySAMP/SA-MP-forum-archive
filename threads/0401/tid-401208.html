Hello everyone, I've decided to release a very small walkie talkie system to you guys. Basically you type /wt and you can communicate in it depending on the frequency it's set on, kind of like a radio. A small warning is, you must take the pawno and put it into your script if your using a already existing gamemode, you must edit it into your script with various functions, such as add it to a 24/7 shop in your script where players will buy it.


Suggestions

If you have any suggestions, reply to the thread and I will add them to this list here and soon look at it when I have time and add it.
  • Make the walkie talkie colour in chat blue. - Done
  • Make it already made in shops around Los Santos. - Working On It
  • Make the command shorter to /wt so players can type /wt instead. - Done
  • Add a portable radio script to this. - Suggestion Denied
  • When you use the walkie talkie make a object appear with a hand anim going up to the players mouth. - Done

Download Link(s):
AMX: http://www.2shared.com/file/ThjqMbkz...kiesystem.html
