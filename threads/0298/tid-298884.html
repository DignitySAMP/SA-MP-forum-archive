blazee14 Radio System 1.2



Information:

Basically with the new 0.3d update where you don't need any plugins and the new HUD Under the map I decided to create this for the NwL Server. Yes it's a basic filterscript but I'm not in the mood to create a big one. After loading the filterscript just type /setstation and it will show you a dialog with 4 Stations I randomly added with a stop button. And to not mess it up I added to each time you change station this function will load before playing the other stations (StopAudioStreamForPlayer) if not all the stations will play at the same time.
