Safety Shop - Buy Safety Items Filterscript by BenJackster

Simple and useful.


Version 1: Created the Dialog for weapons.
Version 2: Added some new weapons, fixed some typos and bugs. Also Made key "Y" to buy weapons.
Version 3 [MAJOR UPDATE]: Added 2 more parts into this, making /buyweaps into another dialog which will show the player 3 options. You will be able to buy weapons, body defences and health care items too.

Introduction:

This is just a simple Filterscript which took me like half an hour to make. This is my second Filterscript release. So let's get started.

Download & How to install:

Downloads:

Pastebin:


Installing:

After you've downloaded from pastebin, paste the .amx file into the Filterscript's folder. After you've done that, open server.cfg and go to the Filterscripts line.
Type The Name of The .amx file you compiled of infront of it, and save the server.cfg. Restart your server and enjoy it.

Using them In-Game:

Type the command press key Y or "/buyweaps" and a dialog would display. Choose the item which you'd like to buy. Click on it, if you don't have that much money, it'll not let you buy and it will Send you a message. If you'd have the money required, it'll gladly give you the item and take the money.

Current Known Bugs:

No bugs at all.
