Name: Dialog Chat/Message System
Version: 1.0 Beta
Author: Mike Garber
Credits: Hypo(hamish) for Pre-Beta-testing

Description: Makes you able to, with dialogs, have an instant messaging session (a chat) in SA:MP.
Usage suggestions: Might be good in Roleplay Servers, you could change the name to MSN Messenger or Xfire w/e.

Bugs: No major bugs found. Please report all bugs found!

Features;
Type /dchat to bring up the menu.
- Single Message (like PM)
- Chat Session (like MSN (instant messagin)
- Block all messages (to not be disturbed while playing)
- Block a certain player (can only block one person at a time for now)
- Unblock all messages (Make players able to message you again)
- Unblock a certain player (Make the person you blocked able to message you again. Does not work if you have activated "Block all messages"!)
