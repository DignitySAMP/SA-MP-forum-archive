Peace,

I only wan't to show you my new Project. Its not an PAWN Project, this time I use Autohotkey as Scripting Language. I sincerely apologize for my imperfect English. This tool convert Pictures (32*32px) to a Ingame Label.

Download's:
Image2Label.exe
Virustotal
Source Code:
Pastebin

Video's:
[ame]http://www.youtube.com/watch?v=iRSTtIhWEN4[/ame]
pawn Code:

[ame]http://www.youtube.com/watch?v=zOY5a3VF_C4[/ame]
pawn Code:
http://www.youtube.com/watch?v=zOY5a3VF_C4
Screenshot's:
http://s14.directupload.net/images/u...3/5m3eb6ep.png

Special's:
-» Resize pictures automatically
-» 90% perfect Ingame Labels
-» Super fast (Max. 4 Seconds)
-» Does not exceed the 3D Label limit
-» Help/Colorpicker On/Off switchable
-» If desired, it removes the background color.
-» Option to make the Label 0-100% transparency

Future Update's:
-» Several Label combine, to reduce Label amount
-» Set some colorcodes, that got removed (like multicolored background etc.)
-» Change the colors with some styles like "Invert, Rainbow, Dark etc."
-» Improve the converting speed
-» Compiling .pwn automatically after converting
-» Save Server directory, for direct input in Filterscript Folder
-» Position selecting with GTA Map
-» Select Ingame Picture size
