You have too much cases. Some have their switch, but some don't. Cases can't be alone. They must have their switch.
pawn Code:
swirch(Var)
{
     case 0:printf("Hello");
}
^this is ok.
pawn Code:
case 0:printf("Hello");
^not good.
pawn Code:
swirch(Var)
{
     case 0:printf("Hello");
     if(Var==2)
     {
          printf("Hello2");
     }
}
^not good aswell. In switch clause only cases, and default can exist
