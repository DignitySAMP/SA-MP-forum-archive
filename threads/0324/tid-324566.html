Pra mudar o lugar, basta ir na public OnPlayerRequestClass(playerid, classid)

SetPlayerPos - Mude a pos para a que vocк quer.
SetPlayerCameraPos - Coloque a Pos com a camera apontada para o player.
SetPlayerCameraLookAt - Mesma posiзгo do SetPlayerCameraPos.

Por exemplo
PHP Code:
public OnPlayerRequestClass(playerid, classid)
{
    SetPlayerPos(playerid, 1958.3783, 1343.1572, 15.3746); // Aonde o player vai ficar mudando de skin.
    SetPlayerCameraPos(playerid, 1958.3783, 1343.1572, 15.3746); // Aonde a camera vai ficar apontando pra ele.
    SetPlayerCameraLookAt(playerid, 1958.3783, 1343.1572, 15.3746); // Mesma cordenadas da SetPlayerCameraPos.
    return 1;
}
