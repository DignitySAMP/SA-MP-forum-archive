Nice
But a tip: Use 'switch' instead of 'if(listitem == 0) if(listitem == 1) etc'
Then you'll have something like this:

pawn Code:
switch(listitem)
{
    case 0:
    {
        //Code
    }
    case 1:
    {
        //Code
    }
}
This is a replacement for:

pawn Code:
if(listitem == 0)
{
    //Code
}
if(listitem == 1)
{
    //Code
}
It's beautifullier and clearer (that's my opinion)
But whatever, cool script!
