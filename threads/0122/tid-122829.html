DEATHER’s PAUSE/BACK SYSTEM (updated)
ABOUT THIS FS
In most of the AFK/BRB systems I found that they only make the player freeze at a point and then he unfreezes. I thought of making the player to place at a distant point, from playing area where players cannot reach easily. [This is my first Filter Script Release]

NOTES
Commands:
/pause = Freezes the player.
/back = Unfreezes the player and sets his position where he used the /pause command.
(There are no change in commands)

Updates in the new version:
Added a new pause location. (older location is also available)
The new pause location is near the pirate ship in Las Venturas.
Added god-mode so that the player cannot be killed during pause.
Added a code to disable other commands when paused.

BUGS/SUGGESTIONS
If you have any suggestions or found something wrong in the script, please post it.

FINAL NOTE
I would appreciate it if you could add me in the credits if you use this Filter Script for your server.
