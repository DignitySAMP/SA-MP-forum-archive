Created By: Zero_Cool
Version: 3.5

Functions:
- Account System: Register, Login, Changepass
- Save Player Statistics: Deaths,Kills,Money,Time In Server, Ip,Score
- Automatically Login
- Anti Weapons Hack
- Anti Spam, Anti Pause
- Lock/Unlock Server
- Many Dialogs: Vehicles,Weapons,Server Time , Weather
- All Reports saved in Files
- Save in Log: Kicks, Bans, TempBans, SetLevel, and more...
- Temp Ban System (Ban Player for specified Days)
- Dueling System
- Warn System (Kick after the specified number of warnings)
- Spectating System (With TextDraw)
- Flying Camera System
- And many other functions!

How To Make Yourself Admin
Connect to your server
Register new Account
Log in Rcon Admin
The Two Rcon Password is "changeme"
Type /setlevel [YourID] [Level]

Spectating System (I Tested with Npc)


How To Install ZeroAdmin
Download the file!
Unzip the Files!
Put "ZeroAdmin.pwn and ZeroAdmin.amx" in your "filterscripts" folder
Put "ZeroAdmin.inc" in your "pawno/include" folder
After, put the folder "ZeroAdmin" in your "scriptfiles" folder
Open "Server.cfg"
Go to in line "filterscripts"
Add "ZeroAdmin" (filterscripts ZeroAdmin)
Save the file!
Done!
