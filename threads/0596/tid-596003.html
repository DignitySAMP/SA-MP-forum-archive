Cops and Robbers Filter Script
Features

- 6 Classes
- Cops and Swat and Army
- Robbers and Pro Robbers and Elite Robbers
- Arrest System
- Robbery System
- Stun System
- Bomb System
- Swat and Elite for Vips (If you have vip system you have to reedit Them)
- CnR Stats
- Cnr Help
- Saving and loading like Arrests and Cops killed and Take downs and Robberies and Playerrobberies
- Cmds for Rcon
- Stand Alone
- 22 Store
- Backup System
- Cops Radio System
- Different Rob cash for each class
- Player Rob System
- Cuff System
- Evading System
- Escaping System
- Jailing System
- Killer Cam System
- Gate System
- Gang Zone Sytem
- Different Bases

Images









Instructions

1. Create a " save " folder in scriptfiles
2. Add CnR in front of filterscript in your server.cfg
enjoy
Rcon Cmds

1. /setarrest to set arrest
2. /settakedown to set takedown
3. /setrobberies to set robberies
4. /setcopskilled to set cops killed
