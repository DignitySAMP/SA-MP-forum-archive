Я задался вопросом, можно ли как-то их найти в файлах GTA SA и изъят те координаты, дабы использовать их в личных целях.
Воспользовавшись поиском при помощи NotePad++, я смог найти несколько файлов которые можно использовать для РП сервера, не отталкиваясь от оригинала.
А именно:
GTA San Andreas\data\pedgrp.dat - Как я понял, в этом файле сгруппированы скины, пример:
PHP Code:
HMOGAR, WMYCON, WMYCONB, WMYMECH, WMYSGRD          # POPCYCLE_GROUP_WORKERS

WMYCON, WMYCONB, HMOGAR, WMYSGRD, VBMOCD        # POPCYCLE_GROUP_WORKERS (VEGAS)

PHP Code:
400,    landstal,     landstal,     car,         LANDSTAL,     LANDSTK,     null,    normal,     10,    0,    0,        -1, 0.768, 0.768,    0
401,     bravura,     bravura,     car,         BRAVURA,     BRAVURA,     null,    poorfamily,    10,     0,    0,        -1, 0.74, 0.74,        0
// normal
// poorfamily
// так-же есть и другие категорий

PHP Code:
Name, Type, X1, Y1, Z1, X2, Y2, Z2, Island, Text
