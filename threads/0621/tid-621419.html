Keep in mind that vehicle ID is not equal to vStats index. Vehicles that were created are stored in index 0, 1 and 2. The loop returns vehicle IDs 3, 2 and 1; therebefore index 3 for vStats array is empty.

EDIT: A custom iterator (that adds the index and not the vehicle ID to the iterator) would probably be the best choice for vehicle-loops.
