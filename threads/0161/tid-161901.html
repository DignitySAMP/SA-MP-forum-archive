Well I decided to make finished NPC Tutorial since i had too much trouble
to set it up i want to make it easier for other people to have NPC`s

Ok now we are going to start:
* First we need .rec files they are used to get NPC`s movement
Since this is Finished Tutorial i have here 4 .rec files

*1st is the Train,train will be going around all 3 cities and will be stoping at train stations

*2nd is is on foot this guy will jump over buildings like in that Movie Jamakashi,if u watched that but you can make your own

*3rd is a bus he will be driving around SF and stoping on some stations

*4th is hely(hunter) he will be flying over SF like patroling it could be useful for zombie server like some backup if you configure it a little

These .rec files to go Yourserver>NPCModes>Recordings

I picked SF because its my favourite city and i saw this 4th in server : Zombie Apocalipse.

Ok now after we are done with that we need to set up the scripts that are controling NPC`s, so called "mini" scripts
They are going in YourServer>NPCModes. And copy them to Filterscripts too YourServer>Filterscripts.And make sure you include it in Server.cfg too

Now after that is done we need to make NPC itself i have prepared filterscript and gamemode so you can chose what you want i would recomend GM because FS can conflict sometimes

DONT FORGET TO SET MAX NUMBER OF NPC`S IN SERVER.CFG.

Ok i wont bore you anymore here are the download link
All is included GM,FS,recordings and mini scripts

Train_NPC
Helicopter_NPC
Bus_NPC
On_Foot_NPC
