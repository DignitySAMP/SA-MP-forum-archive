Hello guys I started developing a gamemode before some weeks and I made a lot of features I just wanted to ask you if you have any idea or something that I could add the gamemode is Freeroam (not stunt freeroam etc. just freeroam) things that I made till now

• Dynamic Business system
• Dynamic House system
• Dynamic pickup system
• Dynamic 3D text label system
• Advanced administration system (SQLite)
• Textdraws that say server's name, website your cash and score
• Los Santos based
• PM system
• Rules command
• 5 level of admins
• Anti flood system
• Anti spam system
• Anti advertise system
• Some anti cheat detections (Rapid Fire, Airbrake, Aimbot) they only working with alerting admins
• Textdraws on spectating

Thanks for reading

New things

• New Bank system added
- You can deposit money in bank
- You withdraw money in bank
- You can check your balance
- You can transfer money to another online guy
- Bank has pickups to enter/exit
- Bank has checkpoint to open up the dialog
• Imrpoved anti-cheat detections
• Added log with player's actions with textdraws left of minimap

Latest News

  • Added Payday system (With VIP's boost)
  • Added actors on many aereas with information
  • Fixed a bug where textdraws would display wrong stats
  • Fixed some Anti-Cheat wrong detections
  • Converted all anti-cheat codes to texts
  • Now if a detection is not sure for kicking will alert admins
  • Fixed a bug with Anti-Money where that it wouldn't remove the money
  • Added Weapon saving system, weapons are saving and loading each time you spawn
  • Added /top list with top 10 players on EXP, Kills, Deaths, Bank money, Money
  • Added /hevict to remove house's owner
  • Fixed a bug with dialogresponse on House system
  • Added GPS system with SQLite database that loads the destinations and print them (With object)
  • Fixed all typos and minor bugs I found
  • Added wanted level system, if you end a player with wanted you will get a reward, or if you kill a player and increase your wanteds you will also get a reward
  • Added DM arena players can join from pickup on marketplace(mall) on LS and leave with /leavedm, players will repsawn on DM after dieing
  • Added VIP system with a lot features, Vip Chat, Double XP for vips, Special color in chat, some money and much more
  • Gang system is coming soon


There are many updates I made but I don't remember them, core of the game is almost done I just want to add the ammunation system
