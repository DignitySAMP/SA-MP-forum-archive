Version 1.1 released!
Introduction:

This is a simple toxic bomb script i made in my spare time it gets launched from an area then lands in an other, this is my first release so don't be too cruel.
Tutorial:
1-The Bomb gets launched from the police station in Los Santos, you have to have at least 50.000$ to launch, then the Bomb will land in Grove street and chock every one in the area.
PS:I picked the target zone and the area as example you can change them.
Features:
Version 1.0:
1-Dialog system,Text draws.
2-Death message sent for the each victim and the Bomb launcher gets 3 score for each kill.
3-Screen flash for the victim.
4-Fitting animation as if the victim got chocked.
5-three commands + map icon + gang zone (For testing)
Version 1.1:
1-Fixed the weather bug.
2- Added countdown system.
3-Added missile system + explosion.
Requirements:
1)-Incognito's streamer
2)-fader by Joe Staff
3)-colors.inc use which ever you like
