Gang Wars: LS
This is a gamemode that I created for fun and I decided to release it for you guys to use it.
It is a Team Death Match gamemode that players will join 1 of 4 gangs of Los Santos and they
Will fight against each other and try and capture zones for their teams.

Features:
4 Gangs from Los Santos,
Random gang skins,
Random spawn places inside base,
Capture Zones,
Gang vehicles,
Only gangs can drive their gang vehicles,
Ability to do drive by's,
Global chat,
Global death reason,
Score and pay per kill,
Gang HQ,
Gang Shops inside HQ,
Can buy guns and armor in HQ shops,
Gang HQ's shown on map,
Capture zones shown on map
Basic admin commands
Login and Register system
Report system
Saving and loading player stats
More admin commands.

New Features:
Added a stats command
Fixed the bug were players die but respawn at same position
Players respawn at base when they die

Gangs:
Grove Street Families
The Ballas
Varios Los Aztecas
Los Santos Vagos

Capture Zones:
Hospital by skatepark,
Idlewood Gas station,
Ammunation,
Stadium

Credits:
Blademaster680: Coding the entire gamemode
Blueserpunt820: Adding vehicles to the map.

License:
Do not re post without my written permission.
Do not remove the credits.

Download:

TDM.pwn
TDM.amx

Y_INI Download:

Version 1.0:
TDM_v1.0.pwn

Version 1.1:
TDM_v1.1.pwn

Install Y_INI Version:
To install the Y_ini version you need to create a folder in "scriptfiles" called "Users".
