PARTYLAND
Version: 1.0 [BETA]

CREDITS
Hello everyone. Finally i released my first filterscript/map and i hope you like it.
Alright, so this map is about having fun time with friends in the "secret" island on the water, in Los Santos. Well, you can call this island how ever you like: base, admin house and other. Of course, this is just a first and beta version, and now i'm working forward to the next one.
================================================== ============
The island includes:
  • Private mansion, you can enter.
  • Private carpark.
  • Private beach, with quad bikes and monstertrucks.
  • Private bridge to the sea, with boats.
================================================== ============
Location:
The entrance with long bridge in Los Santos, Santa Maria Beach, but it has teleport, so you no-need to walk or drive!
================================================== ============
Teleports:
/partyland - teleport near the bridge to the island.
/entermansion - teleport to the island mansion.
/exitmansion - exit teleport from the mansion in the island.
ATENTION! If you want to leave the mansion, ONLY use /exitmansion teleport, because this is an interior!
================================================== ============
Installation [IMPORTANT]:
Alright, so the filterscript is fully ready, but the objects is converted to MidoStream and now i tell you why.
Well first of all, i have been doing tests with this island, converting objects to Y_Objects or xObjects, and they're not properly work with this map.
xObjects DO NOT EVEN WORK with this map, because the map has alot of same objects, like palm trees, rocks and other, so xObjects always crashes.
Y_Objects WORKS with this map, but it loads objects very slow, so you might won't see some objects or you might fall into the water if you will use this streamer.

SO i just want to say, this map works perfectly with MidoStream and i havent seen any problems with this streamer, so MidoStream is included in the filterscript!
1. Download.
2. Extract files with winrar.
3. The MidoStream.inc file from the includes folder, put into YourServer/pawno/includes folder.
4. The MidoStream.pwn/amx and PartyLand.pwn/amx put into YourServer/filterscripts folder.
5. Now open you server.cfg and in the filterscripts line put it: MidoStream and PartyLand.
6. Thats it! Go and have fun!
