Sup, im not sure if there is a tutorial on this, but if there is im wasting my time lol.
Map Editor is a program that loads the whole gta world and you can add cars and objects then import them into pawn and have them in you server! Saves a lot of time. When i first got it i was confused, so im here to help if you are confused.

Getting Started
If you do not have it download it here: https://forum.sa-mp.com/showthread.php?tid=282801
HOW TO INSTALL: You should have a folder called: editor. Extract it and drag all the files into your GTA SA folder. (C:\Program Files\Rockstar Games\GTA san andreas).

Ok. So now open it!

Importing Objects
If you have a pawn file with the objects you have already made you can import that by clicking: http://i.imgur.com/PnUqk.jpg(top left)
This will add all the objects located in that file.
If you dont have any objects made yet, dont worry! You can make a whole stunt course in no time!

Adding Objects
Ok, so you want to build? Awesome! To start adding objects click the tab called: Objectshttp://i.imgur.com/qvXrq.jpg
Now you want to click: Add http://i.imgur.com/Q6ByV.jpg
Now you can either search part of the name of the object or the id. I searched ramps; and a bunch of objects popped up.
Example: http://i.imgur.com/lb0K9.jpg
So you want to pick the one you want. Click the name and click add.http://i.imgur.com/aFNPz.jpg (bottom right)
So what this does is, it adds it to the list of objects. kinda like a shortcut to that object.
An easy way to add an object in a specific spot is click on the object in the right list, then put the mouse cursor on the location of where you want to object to spawn then press Insert (on your keyboard)
Now a box will pop up, just click okay.
http://i.imgur.com/ueA86.jpg
Now that your object is added to the map you can; Rotate, move, lower/higher or delete it.
In this step we will make the ramp come out of the ground. Click on the tab called: Movement
Now you go to the nudge section and click the up arrow until its where you want it.
http://i.imgur.com/lMiA6.jpg
My object is now higher.
http://i.imgur.com/4aa4U.jpg
Okay, lets assume that you are finished adding on the objects you want. Click Show Codehttp://i.imgur.com/bvXBB.jpg
This will show you your code you just made! You can either have it just CreateObject, or if you use Streamer you can change it to CreateDynamicObject with a click of a button!
You can copy the code and open a pwn file and paste it in there. (i hope you know how to do that)
http://i.imgur.com/J7sfz.jpg
Congrats you just made your first stunt course! (or what ever you are building :P )
Adding Cars
Adding cars is just as simple as adding objects. Under the Objects instead of searching for an object name type a car name in.
Example: http://i.imgur.com/u7CCk.jpg
Now click add like you did for the objects.
using the same method, click on the monster truck on the right and press insert (on keyboard) of where you want to spawn the truck.
http://i.imgur.com/diENm.jpg
Higher it rotate and all that good stuff!
Okay, so assuming again, that you are finished adding all the cars where you want!
Once again clicks show code.
http://i.imgur.com/0o7j1.jpg
You can import into a pwn like the objects. You can even add the vehicles to the same script as the objects.

Testing

Testing the objects/cars before you even add them into your server!
You can see if you like or dislike them. On the top just click Test!http://i.imgur.com/uj7VD.jpg This will take you into something like Single Player.

Shortcuts
These are found when the program is launched.

Thanks for reading i hope i helped! If i did help some rep would be appreciated for the time it took to write this!
