To add some actual sense to a far-gone topic,

Consoles:
Modern consoles do not allow modifications to existing games in any way, shape, or form. You would need a hacked console which is extremely hard to make yourself and there aren't very many people that have them (or ones that still work). Also, hacking/modding a console to run unsigned code is illegal in some cases. I am speaking for current-gen consoles.

Smartphones/tablets:
It is possible to create some kind of multi-player modification for any of the GTAs released for iOS or Android. While I am entirely sure that it is possible with iOS (being a jb-dev myself), I'm not entirely sure that it is for Android. For iOS, you would most likely require a jailbroken device (to make things easier for the mod developer).
