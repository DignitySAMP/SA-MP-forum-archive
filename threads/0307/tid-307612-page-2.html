As I consider this gamemode "old and obsolete" by myself, you can do whatever you want with it.
Just don't claim that you scripted it yourself.
Still, most people would use the original version from the original topic.


As we found out, V1 still has some bugs left in it.
Like this bug: when you have a house over lvl 5 (lvl 6 or higher) and it had more than 5 vehicles, the last 5 vehicles cannot be sold (you get the message that there are no more vehicles assigned to this house) and therefore you cannot sell the house (as there are some vehicles attached to it).
A weird bug that won't get fixed anymore.
You could still ask an admin to /evict your house and giving you a refund.
It would work the same way and will remove the house-vehicles properly.

The new V2 (or V3 as I call it now) is in full development (still upgrading the speedometer script to have in-game modifyable settings) and this one will get my full attention.

The speedometer script already has these in-game settings:
- enable/disable a 3DText label on the speedcamera's (which shows the speed at which this camera catches speeders)
- enable/disable the vehicle-name textdraw
- change the maximum fuel setting for all vehicles (determines how fast a vehicle runs out of fuel)
- change the price for refuelling vehicles at a gas-station
- change the shadow-size for the text in the textdraws

All these settings can be changed in-game without editing any code or restarting the server.
Upcoming is also a toggle to switch between kph or mph, since some servers would want the speed to be displayed in mph.

All these settings are implemented because many players asked for such things:
- how can I change/remove the textdraw's shadows
- how can I convert it to use mph instead of kph

Also, the old speedometer filterscript didn't exit properly, the textdraws were still there if you would use "/rcon unloadfs PPC_Speedo".
This has also been corrected.
