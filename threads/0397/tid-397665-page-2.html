This thread was a year old and it was bumped because someone decided to point out that GTA SA for mobile devices was released.

A more recent thread exists with the same request, where I posted the following:
Quote:
Originally Posted by ev0lution$YOLO$

Quote:
Originally Posted by Mauzen

1. This has already been discussed so damn often in the past years.
2. Mobile SA versions are completely rewritten games, you wouldnt "port" samp to mobiles, you would create a whole new client, even more different than VC:MP to samp. With a lot of luck, you might be able to keep the samp server, everything else is a complete new work from scratch. If you think it is possible, try it yourself, there wont be a big difference between you and kalcor in this.
3. Multiplayer experience on phones sucks hard, because phones are too different to allow fair matches. There are tons of GTA-like singleplayer games for phones, but can you name a single third person MULTIPLAYER shooter? Probably no, because others also know that this would suck too hard on phones.
4. Phones would probably need to be rooted to allow memory hacking of the game.
5. People would need to BUY the phone SA. As about 90% of all samp players just got pirated GTA, barely anyone could play samp on his phone.
Mauzen is the best on point here, but there are a few more things to note:

- You can't have anything like a "mod" on iOS (and realistically, most other platforms too). Simply not possible. Apps are sandboxed, you'd need to use an exploit to break this sandbox and such an app would not be approved on the app store.
- In the unlikely event that it was finally cobbled together: SA-MP works based on a single GTA version, and newer versions require downgrading in order to work on PC. Pushing GTA updates on iOS + other platforms is so much simpler for Rockstar, and now most of these updates are applied automatically with no chance to downgrade, which would break the mod on every new update.
- Above all, Kye is not a mobile developer (to my knowledge). SA-MP for PC has been hard enough to hack together and I doubt he has months/years of free time to dedicate to learning how to port such a mod to mobile platforms, especially when it could not be done legally and would be incredibly difficult to actually play.

It's not a bad idea, but it's just technically impossible or infeasible in so many ways that seem to escape the minds of all the people here every time this topic is brought up.
Stop this stupid shit.
