Informaţii

Acest gamemode (GM) este făcut de mine de la 0.
Am reuşit să-l fac după ce Pain123 a lansat versiunea MySQL R33 BlueG. Am lucrat la el оncă de la versiunea MySQL R31 BlueG. Cвnd a apărut versiunea MySQL R33 BlueG am făcut mici modificări. L-am făcut deoarece am оnceput să-mi creez propriul gamemode, nu are toate comenziile pentru un server RPG, este o versiune (stabilă) pentru a оncepe un server RPG de la 0.

Dacă faceţi un server cu acest gamemode respectaţi această licenţă.

Caracteristici

- Un sistem de incarcare mai rapida a datelor. (Cache)
- Un sistem de Оnregistrare / Logare bazat pe MySQL.

Comenzi

- Comandă /makeadmin, poţi să оi dai unui jucător admin sau chiar ţie. Trebuie să ai admin level 6 sau să fi logat că RCON.
- Comandă /makehelper, poţi să оi dai unui jucător helper sau chiar ţie. Trebuie să ai admin level 6 sau să fi logat că RCON.
- Comandă /ah sau /adminhelp, оţi arată comenziile pentru admini , pe level-ul pe care оl deţine admin-ul. Dacă ai admin level 1, оţi arată comenziile pentru admin level 1, s.a.m.d.
- Comandă /hh sau /helperhelp, оţi arată comenziile pentru helper, pe level-ul pe care оl deţine helper-ul. Dacă ai helper level 1, оţi arată comenziile pentru helper level 1, s.a.m.d.
- Comandă /a sau /adminchat, poţi să scri un mesaj, vizibil tuturor adminilor online.
- Comandă /he sau /helperchat, poţi să scri un mesaj, vizibil tuturor helperilor online.
- Comandă /report, trimite un mesaj adminilor online, оn caz că ai nevoie de ajutor. O poţi folosi odată la 10 secunde.
- Comandă /helpme, trimite un mesaj helperilor online, оn caz că ai nevoie de ajutor. O poţi folosi odată la 10 secunde.
- Comandă /stats, оţi arată status-ul tău.
- Comandă /check, verifică status-ul unui jucător (ales de către admin ). Se poate folosi de admini şi helper.
- Comandă /makeleader, face un jucător lider (ales de către admin ). Se poate folosi de admini level 6.

V0.2

- Comandă /ban, poţi să-i dai ban unui jucător. Se poate folosi de admini level 1, minim.
- Comandă (/bano)ffline, poţi să-i dai ban unui jucător offline. Se poate folosi de admini level 2, minim.
- Comandă /kick, poţi să scoţi afară un jucător după server. Se poate folosi de admini level 1, minim.
- Comandă /respawn, poţi să respawnezi un jucător după server, fie că este оn facţiune sau nu. Se poate folosi de admini level 1, minim.
- Comandă (/checkw)eapons, poţi să vezi armele unui jucător după server. Se poate folosi de admini level 1, minim.
- Comandă /auninvite, poţi să scoţi un jucător din facţiune. Se poate folosi de admini level 6.
- Comandă /spec || /rcon, poţi să asişti un jucător după server. Poţi vedea orice face el. Se poate folosi de admini level 1, minim.
- Comandă /gethere, poţi să aduci la ţine o maşină sau un jucător, оn funcţie de caz. Se poate folosi de admini level 1, minim.
- Comandă /goto, poţi să te duci la un jucător, o maşină sau o locaţie, оn funcţie de caz. Se poate folosi de admini level 1, minim.
- Comandă /uninvite, poţi să scoţi / concediezi un jucător din facţiune, doar dacă eşti leaderul facţiunii respective. Se poate folosi de leaderi.
- Comandă (/f)action, poţi să scrii orice pe acest chat şi toţi ceilalţi membrii din facitune o pot vedea, oriunde se află. Se poate folosi de membrii factiuniilor.
- Comandă (/r)adio, este la fel că (/f)action, dar doar cвteva facţiuni o pot folosi. Se poate folosi de membrii factiuniilor (LSPD / LVPD / SFPD / NG / Paramedics).

Instrucţiuni / Instalare

- Dacă vreţi să rulaţi server-ul, descărcaţiSĂ-MP Server for Windows or Linux, după această descărcaţi şi MySQL BlueG R33 şi puneţi gamemodes, pawno şi server.cfg оn fişierul unde aţi descărcat SĂ-MP Server for Windows or Linux.

- Dacă vreţi să editaţi datele pentru baza de date, va duceţi оn \pawno\include\ şi dechideti cu Notepad / Visual Studio / Wordpad etc. şi dechideti connection.inc. Modificaţi următoarele linii:
pawn Code:
#define mysql_host "ip-ul host-ului"
#define mysql_user "numele de utilizator pentru baza de date (MySQL)"
#define mysql_password "parolă pentru baza de date (MySQL)"
#define mysql_database "numele bazei de date"
- Baza de date o găsiţi оn folder-ul pe care оl descărcaţi sub numele de w3op.sql

- Dacă vreţi să modificaţi level-ul, banii, banii оn banca etc. va duceţi оn gamemode (GM) şi căutaţi linia pLevel, pCash, pAccount etc., оn funcţie de caz, după această va duceţi şi оn baza de date MySQL şi modificaţi valoarea iniţială.
