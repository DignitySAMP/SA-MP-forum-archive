tAxI's Xtreme Vehicle Management System (XVM)


Version: 2.1
Author: CJay9209 / tAxI / cptnsausage / Necrioss

Required Includes:

Foreach Include
LStream Include
SScanf Plugin/Include
ZCMD

Description:

OK so this is a major rewrite of the BEST vehicle management script ever seen in the history of sa-mp. That's right everyone tAxI's XVM is back and better than ever. Way more efficient and with some snazzy new features:

- Permanent Vehicle Ownership (now own up to ten vehicles per person!!!)
- Automatic mod saving (mod in any mod garage and mods are saved permanently!!!)
- Advanced Vehicle Security systems
- In game vehicle editing (add/remove/change spawn loctions etc etc)
- Batch add vehicles from external files
- Now Fully SQLite database backed
- Fuel system with fuel stations on mini-map etc
- Admin vehicle protection
- Faction vehicle protection (still buggy but I'm almost done)
- Unoccupied vehicles have external labels displaying owner and price etc
- Call your vehicles to you!
- Buy/Sell control over your vehicles
- Fully menu driven.
- Stable and reliable.

The system has received a MAJOR rebuild and now supports any Gamemode. The FS has an independent login system which allows players to login to the vehicle system with their password and manage their owned vehicles from there. Admins can add or remove any vehicle from within the game and in addition reset vehicles and set vehicles a admin only etc. there are 3 admin levels which allow admins to do pretty much anything they want within the system.

*** A MAJOR UPDATE IS THE SETUP: The server owner must set the XVM Master password by editing the password file located in "scriptfiles/xvm_files/core_files/xvm_password.txt". The default master password is xvmpass123456. PLEASE CHANGE THIS BEFORE SETTING THE SERVER AS LIVE!!!!!!!! this password is requred for you to set yourself as the Full system administrator. ***


Commands:

- /xvm - Open vehicle control menu - can be used in or outside your owned vehicle.
- /xvmreg - Register yourself to be able to use the XVM system.
- /xvmlog - Login to the XVM system.
- /xvmsetpass - Set your XVM system password
- /xvmmakemanager [password] - Makes you a level 3 vehicle Admin (full system Administrator). This requires the XVM master password
- /xvmsetadmin [player] [level] - Gives your target (player name or id) vehicle admin powers (0= No Admin / 1= Basic / 2= Advanced / 3= Full System Administrator).
- /xvmhelp - Display's XVM system help.
- /xvmcredits - Display's a list of credits for XVM.
