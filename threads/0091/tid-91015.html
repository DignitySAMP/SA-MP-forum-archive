Hey, This is a little FilterScript that i made,after a realy loong time that i didn't used pawn/or played GTA...
So,Enjoy
First of all,Sorry for my bad English,Hope you will understand =]
What is this ?

It's a gamemode[you can use it as filterscript too] that you are a bus driver.
In the Bus driver job,you need to collect all the checkpoints[59] around lv.
after you will dont this,you will earn 120$[can be changed].
Installation

If you selected it will be as a FILTERSCRIPT,follow the next instruction:
  • Download the files
  • Put the PWN+AMX in your filterscript folder
  • open Server.cfg
  • in the line "filterscripts" add this: bus
Code:
it need to be like that: filterscripts bus
[*]Run your server,and enjoy this FilterScript [/list]If you selected it will be as a GAMEMODE,follow the next instruction:
  • Download the files
  • Put the PWN+AMX in your gamemodes folder
  • open Server.cfg
  • in the line "gamemode0" add this: bus
Code:
it need to be like that: gamemode0 bus 1
  • Run your server,and enjoy this FilterScript
What is in the mod?

Commands

Code:
/Bushelp - to get more help about the mod
/Buscmds - To view all the commands that avliable
/BusCredits - To view credits
/Gate - To open/Close the Gate [thanks to Burridge for this command.]
/Driver - Work As a bus driver
/DriverOff- stop working as a bus driver
/Bus - teleport to bus area.
What do you need to do as bus driver

You need to enter to a bus,and write /Driver .
it will show you the checkpoint[on the map] and you will need to collect all of the checkpoint[5 minutes-real time - i didn't check it..]
after you will finish,you will get 120$ and you can do it again if you wanna rean more money.
