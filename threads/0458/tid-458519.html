Death Ship TDM by qazwsx


Hello Everyone.
In This Post, Im going to release my first Game Mode, mainly, it is simple TDM GM.
Location is taken on military ship in San Fierro.
The Game mode is very simple, You just to need capture the zone(capture zone is the whole of ship). There are 3 teams, Army USA, Soviet soldier, and terrorist. Each Teams has 3 class, Attacker, Capturer, and Commander. Attacker's duty is to protect the capturer while capturing. Of course commander is able capture the zone too, but it will be better, Commander helps the attacker for protecting capturer.

These all of scripts originaly scripted by me.
Includes the Administrator system. I was going to using filterscript, but ive decided to make it by my self.
This is very simple Game mode as same Im still newbie scripter. So, dont judge about this much, because this GM is for Newbie scripter too

Features

>> Capturable Zone.
>> /Pm system.
>> Simple Team chat using !TEXT
>> 3 Teams each teams 3 class, Attacker, capturer, Commander
>> Anti Spawn Kill system
>> /shop commands. I was going use briefcase, but because it is bugged, and i dont have much time, so i decided to make it use /shop.
>> Pickupable Weapons.

Admin System
>> /warn commands
>> /freeze commands
>> /unfreeze commands
>> /ban commands
