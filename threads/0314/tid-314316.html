Incorrect. For problems like this you need to understand how sin and cos work.
Cos is a periodic function, meaning it repeats itself constantly. Unless amplified, the range of sin/cos is from 1 to -1. Furthermore, cos is 1 when the numbers between the brackets equal 0 +1/2k*pi, with k being a whole number.

Maybe this helps you to solve it yourself.

Um I don't know how you could solve that other than at sight.

But if you think logical:
-cos(number) will always be an irrational number if it doesn't equal 1, -1 or 0. If the cos is irrational and you know x is rational, it's not solvable
-cos(number) equals 0 when x is pi/2 (+k*pi): if x is pi, you've got an irrational number in the "normal" formula thus not solvable
-cos(number) equals -1 when x is pi (+2k*pi): if x is pi, you've got an irrational number in the "normal" formula thus not solvable
-cos(number) equals 1 when x is 0 (+2k*pi): you'll again have irrational numbers if you have a k different from 0. So the only solvable thing would be when it's cos(0), and therefore x = -3


EDIT: corrected some stuff
EDIT 2:
There's one option missing: if both x and the cos are irrational numbers, it might have a solution as well. In this case it doesn't, but you can't know that by sight...
