Introductions

This a simple job made by myself that can be used on any server. Its a Fishing Job. Took me around 2 hours to make the entire thing including the mapping.
I plan to add Shrimping soon which will include boats and so on.


How it works
First of all you need to buy fishing rod from the Pier Shop located at the fishing pier. Once you get the fishing rod you would go to fishing rods on the Pier and start fishing.
Once you type /fish. It will take around 5 seconds to get your fishes.
There are 5 possibly outcomes that can happend.
1. You can catch a moneybag that can give you from 10 to 200$
2. You can catch a different type of fish that can weigh from 1 to 50 kilograms
3. You can sometimes break your fishing rod while fishing so you would have to purchase a new one
4. You can sometimes catch trash while fishing which wont give you anything.


Fish species and price
All species are currently set to same price which can be changed by simply changing #define Fish_Price to any ammount you want. Currently its set to #define Fish_Price 3. I will assign prices to fish species sometimes soon in the future.

Download
Pastebin: http://pastebin.com/1K9uRrXH
How to install

You need to download ZCMD command processor. Created by Zeex. (https://forum.sa-mp.com/showthread.php?tid=91354). Once you get it just make a new pawn file and compile it using the code.
