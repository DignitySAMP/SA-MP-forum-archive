Heres a few bugs for you

* /Tde box - Icons don't move to the new position.
* Box sizes are not set when a project is loaded/textdraw is duplicated.
* The red lines (ctrl+r) sometimes snap back to your mouse for some reason. Not sure what caused this.
* Changing a textdraws model sometimes duplicates the textdraw. The old textdraw keeps the old model while the new textdraw has the new model.

I also had some weird behaviour with keys/mouse not being detected after alt+tab. This was fixed with /Tde exit then loading the project again.

I'm glad this finaly works on 0.3.7 as I use it alot and swithing versions all the time is quite a pain.
