Uhm, Ill make a tutorial on how to run with XAMPP, since i use it for localhosting my mysql script

1. Download XAMPP Link : https://www.apachefriends.org/download.html

2. Double Click on XAMPP control panel. Start 'Apache' and 'MySQL'
(Note: End Any Skype process, it wont allow Apache to run with its default settings).

3. Goto your localhost/phpmyadmin/ .And then create the database called ccnr.

4. Upload the .sql file into the database.

5 goto define.inc and then, edit your username password host and database name.
(Look at Bradley7's tutorial).

6. Recompile your gamemode. with the edited define.inc (Dont Close apache or mysql).

7. Play And Enjoy.

8. Breathe.

Cheers

This will help you.
