LOST WATERFALLS
Map details

Map name: fallen.map
Number of objects: 107
Supposed drawing distance under object streamer: 500
Size: Small-Medium
Supposed number of players: 4-20
Map Type: Nature-Epic
File Type: MAP file only, without any script

Map description

This is a medium sized beautiful nature map with 1 huge waterfall in the side of it, and 1 smaller in the centre of it. Also there are some caves and other hiding places for campers and sneakers. Map is bordered by hills so players inside the map wont be able to go out. This map is ideal for small to medium sized dm/tdm servers or for a dm tekeport in stunt or freeroam servers etc. but its not ideal for big tdm/dm servers becouse of its size. Its a map that i made about a year ago but finally did nothing with it so i posted it maybe it will usefull for you.
