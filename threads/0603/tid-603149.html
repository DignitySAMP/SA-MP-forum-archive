How to get players

I started from absolutely nothing. These are my experiences as a server owner consistently doing well. I see too many people being mislead by people who are clueless themselves.

This thread won't make your server an overnight success but should provide you some insight. I will continue this thread if it grasps attention over the week, otherwise it will just die.

I write this post also to promote RevCTRL, a site that I work for, so that it can improve into the future. That's the catch and I hope mods allow it for the sake of this thread.

Here are some IMPORTANT quick links:

Hosted tab: http://game-mp.com
Changelog creator: https://revctrl.com

Your gamemode

Generally, work on something that's worked for someone. And then do better.

Freeroam works well, make that. Deathmatch, CNR, RP, and so on. If you make a completely different gamemode you will take a risk.

I made a Call of Duty server that was strictly mirrored CoD. To be able to hit 20 players on a Saturday night was a miracle. I'm sure you some of you can relate. It was EXTREMELY unique lol.

Should my server be unique?

It does not matter. It has to be a fun server that has certain distinguishing features to others. Some features can't be helped and just need to be the same (some examples login/admin system). It's okay.

Don't waste your time following those "your server needs to be unique" opinions.

That is how you get them to come back, to enjoy the exact moment they had previously.

Do not copy servers exactly.

If I am a player, why should I join your 0 player server if I can join the original with more than yours?

Think about it. Don't go and copy another server then expect to suddenly absorb their success. It won't happen.

If you're inspired by another server, make it alike but try make it better.

Keep it simple.

Make it easy to understand for everyone. Make your commands similar to other servers.

Example, if you have an arrest command called /arrestplayer. Most servers have /arrest therefore the player will assume the command is /arrest at first. So make it the same. (Ask for elaborating)

Release as soon as possible

I didn't have a /report command when I launched my server, had no admin system too. Used strictly RCON bans.

My focus went into developing the gamemode until players just loved it and continuously stayed.

[to be elaborated...]

My gamemode is finished, what next?

You need hosted tab.

Saying this makes me shake, because this is the reality. You need it.

Continued here!

Make an account on RevCTRL and get people to follow you.

Each time you release an update, you alert all your followers (especially through emailing) with what has changed. Quite a few SA-MP servers use it at the moment to which I applaud.

This is how you can remind players that your server exists. They might even check out your server out for the updates!

SA-MP forum won't determine your success

Controversial. The comments you get "nice server bro", "wow this looks so good" mean absolutely nothing. They're motivating, but those comments won't get you players.

What you need is comments that are constructive. E.g "your server UI looks absolute jack shit". That'll help you improve. Don't go mad or anything, just see how you can make it better.

  • What host should I buy? Do I need to worry about DDoS protection?

Nice thread, I guess this will help a lot of people.

I think you forgot (or did not get to) one important thing yet - the staff.

You will definitely need a good team to run a successful server, some people that you and your guests can trust.

I've seen several servers loosing a lot of players because of one or more really bad, childish admins. If they ban people for simply being better (or similar unreasonable things, everyone experienced that at least a few times..), those players will not be likely to come back, even when unbanned later on. It's just killing the fun.

If the admin team is friendly and most importantly fair, the players will see them as a part of the community. I think that is not only important to the players, but also to you, so you have a good time on your server yourself.

You don't want to run a server where you cannot have fun playing yourself because everyone hates you (worst case).
