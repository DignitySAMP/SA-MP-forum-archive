Are you trying to use GMX to restart your server only, or are you trying to switch to another gamemode? GMX is for switching gamemodes and therefore if you're just using it to restart your server, this can cause a lot of bugs which won't make sense. Restart your server manually through the host or VIA the console to avoid this, or make your own command which exits the server, but it won't be able to start the server itself. (I don't believe).
