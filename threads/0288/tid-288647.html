Peace,

today I've decided, to publish my sixth Open Source Project. I sincerely apologize for my imperfect English.

Declaration('s):
This script removes the gates on the Area 51 terrain. I know, its a little code, but really useful for many people!

How it work's:
It remove the hole Fence from Area51 that includes the gates via RemoveBuildingForPlayer (Function added in 0.3d) and create the hole Fence new with the new Area51 Fence Obejct (1Object only, for the hole Fence!) (Object added in 0.3d RC3-3).

Requirement's:
This Filterscriptis only for Sa:Mp Version 0.3d RC3-3 or higher, because it use a 0.3d RC3-3 Object.

How to use it:
1.) Put the Files 'pNoArea51Gates.pwn' and 'pNoArea51Gates.amx' in your Server directory ..\pawno\filterscripts\..

2.) Write in the server.cfg at the Filterscripts 'pNoArea51Gates' behind Filterscripts.

3.) Restart your Server, or load the Filterscript Ingame via RCon loadfs Command.

4.) Go Ingame to the Area51 terrain!
