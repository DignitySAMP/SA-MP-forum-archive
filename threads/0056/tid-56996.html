CS Radio - this analogue voice commands in the game Counter-Strike, only the selected message written in the chat. There are 2 languages: Russian and English. Information about the language used is stored in a file CSRadio.txt, which is created automatically when you first start the server (0 - Russian, 1 - English).

To open the menu, use a combination of "Space + C" (Acceleration + Sit), press this combination to open another menu (a total of 3), through all the menu, they automatically shut down, but can they close themselves Not the leaf, a combination of "Alt + Space" (The slow step + Space). Once you've stopped at the right menu, and select a message, chat and send messages of this figure. (not '/ 1', but simply'1 ', without quotation marks).
_________________________________________________
RCON commands:
/cslanguage [LangID] - select language (0 - russian, 1 - english)
_________________________________________________
Features:
- Options for messages displayed on the screen
- 2 languages: Russian and English
- There is a configuration file to preserve the language
- Language can be changed through command
- And much more ...

- 4 additional functions
