Seeing as the old poster(WacoX) had his account deleted and there have been commands that have been left out for years, I'll go ahead and create this. This also includes some of the keys generally used by SA-MP. If a BT wants to update the original thread and delete this that'd be fine aswell.
These are the current commands built into the SA:MP client:

Current Commands
/q - Close the SA:MP client.
/quit - Close the SA:MP client (same as above).
/save [extra] - Save your current coordinates into savedpositions.txt
/interior - Shows the current interior ID.
/fpslimit [20-90] - Set the maximum FPS for your client.
/pagesize [10-20] - Change the amount of lines in the chatbox.
/timestamp - Show time stamping in the chatbox.
/headmove - Toggle player's head movements.
/dl - Handy developers command to show vehicle information.
/mem - Shows the current amount of memory usage.
/rs - Saves On-Foot coordinates in rawpositions.txt
/cmpstat - Exists but doesn't seems to do anything? more info please!
/nametagstatus - (Added in 0.3x) - When enabled, an hourglass icon shows next to the nametag of a paused player.
/audiomsg - Toggles whether the client recieves the green "Audio Stream" message when the PlayAudioStreamForPlayer function is used.
/rcon - In-game client RCON


0.3.7 Testing Commands
/fontsize - Allows you to change your fontsize(0.3.7 RC1+)
/togobjlight - Allows you to toggle whether light appears from(if applicable) an object(only for the client using the command ofcourse, not other players).(0.3.7 RC1+)

/ctd - Shows camera target information.(0.3.7 RC2+)

Removed commands:

/pm [playerid] [message] - Send a Private Message to a player.
/tpm [message] - Send a Private Message to your team (if used SetPlayerTeam).

Keys used by SA-MP

F1 - View the SA-MP help menu.
F5 - See states such as memory, streaming memory(0.3.7 RC1 and above), packetloss stats, loaded vehicles, etc.
F7 - Toggle the HUD, chatbox, etc.
F8 - Take a screenshot
F9 - Toggle deathlist
F10 - Same as F7, but only hides when the player holds the F10 button.
G - Enter a vehicle(GROUP_CONTROL_FWD).
