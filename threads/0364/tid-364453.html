If mysql doesn't insert data, it means that the query has error in it.

Try change this:
Code:
    format(query, sizeof(query), "INSERT INTO users (Name, Password, AdminLevel,Score) VALUES ('%s','%s',0, 0)", pname, passwordstring);
to this:

Code:
    format(query, sizeof(query), "INSERT INTO users (Name, Password, AdminLevel,Score) VALUES ('%s','%s','0', '0')", pname, passwordstring);
