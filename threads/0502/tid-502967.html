What we're NOT looking for:
-conversion to MySql
-hosting advertisements
-lectures on why we should convert to MySql

-people saying that the issue is in our script, and not the host, because the script works fine

Conclusion:
Everything works fine running the server locally, or on {Host A}. If you know how to fix the issues we are having without switching to a new host, speak up. Also know that everything in our server is up to date, except Streamer. Yes, we use an old version of streamer so that we don't have to add the last parameter to all 500+ objects in our server.
