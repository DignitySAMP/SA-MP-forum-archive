Beste iedereen,

Ik weet precies wat jullie denken: Ohnee, niet weer zo'n topic die gamemodes probeert te jatten, die je geld probeert te krijgen, etc.

Maar: Dit is niet zo'n topic. Dit wordt serieus, duidelijk en eerlijk.

Oke, ik zal wat vertellen: Ik heb hier in de berging, een kamer in mijn huis, een leuk server rekje staan met daarin 1 Asus rs700 server (zie YouTube). Ik doe hier niks meer mee. Ik gebruikte hem voor school, maar dat is niet meer nodig. Dus nu, wil ik hem graag voor jullie gaan gebruiken. Ik ben op dit moment bezig met alles zo op te zetten dat als jullie het nodig hebben voor bijv. de website van je sa-mp server een MySQL database kunnen hosten. Ik bied:

- 24/7 online
- Volledige controle via PHPMyAdmin
- Super snel, geen stomme trage sh*t
- Edit: Net zoveel db's als je wilt

Je krijgt een apart account op de PHPMyAdmin, natuurlijk met iets minder rechten, zoals zelfs accounts aanmaken/verwijderen, maar verder is alles voor je beschikbaar.

Op dit moment ben ik nog druk ermee bezig, met permissies e.d. Ik denk dat ik morgen ochtend (7 Dec.) Met alles klaar ben en dat jullie m dan kunnen gebruiken.

Ik denk dat een hoop mensen voor hun sa-mp server een forum of iets dergelijks gebruiken, zoals SMF ofso. Allemaal (vooral SMF) hebben een snelle database nodig, anders is t gwn hopeloos. Ik kan deze jullie biden. Nogmaals, check YouTube als je wilt zien hoe de server eruit ziet. Alleen de specs in die video zijn iets lager dan mijn specs. Mijne heeft iets meer RAM, beter processor enso.

Dusss, conclusie: Wat vinden jullie hiervan? Graag hoor ik wat jullie vinden!

Edit: Meer info over systeem specs, zoals internet snelheid e.d komen eraan!
Edit 2: Informatie, zoals tabellen e.d worden NIET voor andere toegankelijk. De enige die dit zou kunnen zien is de hamster die naast mn develop computer staat
Edit 3: Alles is klaar, contact via PM als je wilt!
