|| Advanced RCON admin system ||



Whatґs this FS about?

This filterscript is a simple, easy and clean extension of the regular RCON admin system. The commands are accessible when logged into RCON. Its useful on test servers or new servers. Itґs my first filterscript ever made and released.


Commands

This filterscript(FS) is featuring 12 basic commands needed to sucessfully administer your server.
  • /kick :: Kicks the given player from your server
  • /ban :: Bans the given player from your server
  • /freeze :: Freezes the given player
  • /unfreeze :: Unfreezes the given player
  • /say :: Announces a admin message to all players
  • * Striker_Moe slaps :: Slaps the given player around a bit with a large trout.
  • /heal :: Heals the given player
  • /akill :: Kills the given player
  • /jail :: Sends the player directly to jail
  • /jail :: Unjails a jailed player
  • /minigun :: Gives the player a minigun
  • /god :: Makes the given player godlike - max. health and weapons
New included: A auto-ping kick feature.

How to install
  • Upload the aras.amx to your ~/filterscripts directory.
  • Open the server.cfg and write "aras" next to "filterscripts"
  • Save the server.cfg, restart the server and youґre done!

How to become admin ingame
  • Connect to the server.
  • Enter /rcon login [RCONPASSWORD]
  • Youґre done!

Spotted a bug?

This is my first filterscript ever, and although Iґve tested everything, bugs can emerge. If you spot one, please report it in this thread!
