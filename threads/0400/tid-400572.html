Hello Guys. I made this Filterscript in past few days.
This FS contains 8 features related to upcoming Holidays:
1) Christmas Tree
2) Santa's Hats
3) Countdown till New Year
4) Snow
5) Snowman Text draw
6) Christmas and New Year Messages
7) Christmas songs that are played via Audio Client and 0.3d function.
Party Location located in SF, west of Jumping Tower

There are 4 song that players can listen to:
1) We Wish You A Merry Christmas
2) Holidays Are Coming
3) Jingle Bells
4) Let It Snow

Every feature can be enabled/disabled from in-game or via configuration file (Christmas.txt) located in scriptfiles folder
NOTE: Songs are hosted on my web site so don't worry about streaming




There are public and RCON Admin Commands.
Player:
/xsnow - Toggles Snow On/Off for player (NOTE: Snow can cause FPS Lag!)
/xmessage - Toggles Christmas and New Year Messages On/Off for player
/xplaysong - Plays song for player
/xstopsong - Stops song for player
/xsnowman - Toggles Snowman TD On/Off for player
/xhelp - Displays all available commands for player
/xcredits - Displays Credits for FS

RCON:
/xsnowforall - Toggles Snow for all players
/xnosnow - Disabled Snow for all players
/xsettree - Places Christmas tree on player's current position
/xdestroytree - Deletes Christmas tree
/xplayforall - Plays Song for all players
/xstopforall - Stops Song for all players
/night - Sets World Time to 23h
Following commands are changing status of features in Configuration file (Determines can player use feature)
/xen_snow - Enables/Disables Snow (Player won't be able to use it)
/xen_snowman - Enables/Disables Snowman TD
/xen_count - Enables/Disables New York Countdown
/xen_hats - Enables/Disables Santa's Hats
/xen_message - Enables/Disables Christmas and New Year Messages
/xen_songs - Enables/Disables Christmas songs

NOTE: If you aren't RCON it will return Unknown Command




To use this script you'll need ZCMD include, Streamer include, Dini include, foreach include and Streamer plugin. All files are located inside Filterscript file.
To install FS copy/paste all files from Download into your server directory.
To manually enable/disable features go to your server directory\scriptfiles. Open Christmas.txt. Set value to 0 to disable or 1 to enable (NOTE: Use PosX,PosY and PosZ ONLY if you know what you are doing. If you set manually co-ordinates you must set Placed to 1 in order for tree to be placed!)
