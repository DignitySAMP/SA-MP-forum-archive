Check this one: https://forum.sa-mp.com/showthread.php?pid=1892937#pid1892937
I once wrote a small tool that scans includes and creates the auto-completion and highlighting info, as I had exactly the same problem.
Its Java though, but it works well. With a lil bit of knowhow you can change the main method if you like, to add only natives like in Pawno. Right now, the .jar parses all functions by default, so also your stocks, publics, and unscopeds, as well as defines and tags. If you dont like that and dont know how to change it, send me a PM and ill upload a small update for disabling it.
