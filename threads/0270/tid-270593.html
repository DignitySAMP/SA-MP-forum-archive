||- Informacion -||

Bueno este include tiene 35 funciones utiles que podras usar en tus scripts.
Es una recopilacion de varios autores y de varios lugares.


||- Funciones -||

pawn Code:
NombreEx(playerid) // Devuelve el Nombre del jugador. Si el nombre contiene _ lo elimina.
Limpiar(playerid,lineas) // Limpia el chat con la cantidad de lineas indicadas.
JugadoresCerca(jugador,jugadorcerca,Rango = 5) // Comprueba si X jugador esta cerca de otros jugador.
Crash(playerid) // Crashea un Jugador.
MandarMe(playerid,Mensaje[128],Color = 0xC2A2DAAA, Rango = 20) // Manda el clasico mensaje /me
EstaNadando(playerid) // Detecta si el jugador esta nadando.
EsNumero(snumeral[]) // Detecta si un texto contiene numeros.
TieneTag(playerid,TagStr[]) // Comprueba si un jugador tiene X palabra
IsPlayerInRangeOfObject(playerid, objeto, rango) // Comprueba si el jugador esta cerca de un objeto.
ObtenerMasVida(playa1,playa2) // Compara dos jugador y devuelve la id con mas vida.
DetectarSpam(SPAM[]) // Detecta si un texto es candidato al SPAM
SetPlayerMoney(playerid, CDinero) // Establece el dinero indicado al jugador.
HasName(playerid,name[]) // Detecta si el jugador tiene el nombre indicado.
EsUnAvion(modelo) // Detecta si el modelo de coche es un avion.
EsUnHelicoptero(modelo) // Detecta si el modelo de coche es un helicoptero.
EsUnBarco(modelo) // Detecta si el modelo de coche es un barco.
OnlinePlayers() // Cuenta los jugadores conectado.
GetVehicleSpeed(vehicleid, speed) // Devuelve la velocidad de un vehiculo.
SetVehicleSpeed(vehicleid, speed) // Setea la velocidad de un vehiculo.
ConvertirVelocidad(Float:X, Float:Y, Float:Z) // Convierte las coordenadas indicadas en velocidad para vehiculos.
SEGUNDOS(numero) (numero * 1000) // Convierte los segundos en milisegundos.
MINUTOS(numero) (numero * 60000) // Convierte los minutos en milisegundos.
HORAS(numero) (numero * 3600000) // Convierte las horas en milisegundos.
GetClosestVehicle(playerid, Float: distancia) // Detecta el vehiculo mas cercano el jugador.
RGBA(Rojo, Verde, Azul, Trans) // Transforma numeros en colores hexadecimales
GetClosestPlayer(except,Float: radius = 99999.9999) // Detecta el jugador mas cercano.
GetAllHere(playerid) // Teletransporta a todos los jugadores a un jugador en una ronda.
getdist(Float:x1,Float:y1,Float:x2,Float:y2) // Devuelve la distancia entre 4 puntos.
GetPosFaInFrontOfPlayer(playerid, Float:OffDist, &Float:Pxx, &Float:Pyy, &Float:Pzz, &Float:Fa) // Comprueba si el jugador esta de frente a X punto.
GetHighestNumber(...) // Detecta el mayor numero.
hexstr(string[]) // Transforma un string en hexadecimal.
IsPointInPolygon(Float: point_X, Float: point_Y, { Float, _ }: ...) // Detecta si el jugador esta dentro de un poligono.
GetVehicleSize(modelID, Float: size_X, Float: size_Y, Float: size_Z) // Devuelve el tamaсo de un vehiculo.
GetXYInFrontOfPlayer(playerid, Float:x, Float:y, Float:distance) // Devuelve las coordenadas de enfrente del jugador.
RandomEx(min, max) // Devuelve un numero al azar entre dos numeros.
Encrypt(string[]) // Encripta un texto.
