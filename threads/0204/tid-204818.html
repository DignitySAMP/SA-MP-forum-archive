Animations
With this fs you can view all animations, that I found on wiki.

>> Features?

☺ Menu controlling with arrows
☺ Comfortable animations preview
☺ Chat shows, which animation is playing ( and library too )
☺ You can change animations params ( loop ... )

>> How to use?

☺ Add"animacijos.pwn" to filterscripts folder, and compile it.
☺ Add folder "Anims" to "scriptfiles" folder.
☺ I recomend not to use this fs in public server, for big arrays. But if you want, change MAX_PLAYERS value in this fs.
☺ Open "server.cfg" and write "animacijos" to line "filterscripts.
☺ Start the server, go into it and type "/animmenu".
☺ Choose your animation, then press "KEY_SPRINT". If you want to freeze player, find "Control" in settings menu and press "KEY_SPRINT".
☺ To finish type "/animmenu" again.
