Sistema de Corrida v1.0
Sistema de corrida por checkpoint de veiculos Terrestre / Nautico / Aereo
Traduzido por Murilo

• Comandos Administrador logado na RCON

/ConstruirCorrida
Entra em modo de construзгo, totalmente em Dialog com um mini tutorial no inicio

/IniciarCorrida
Apуs terminado e salvado a corrida construida, o administrador podera iniciar a corrida, assim tendo 30 segundos para os jogadores entrarem na corrida.

/PararCorrida
Para cancelar a corrida atual.

/EntrarCorrida
Apуs o Administrador ter terminado de construir / carregar alguma corrida, o jogador terб 30 Segundos para entrar na corrida, ao entrar serб colocado automaticamente no veiculo.

/AutoCorrida
O FilterScript ira iniciar corridas automaticamentes logo apуs a anterior ter acabado

/PararAutocorrida
O FilterScript ira parar de iniciar as corridas automaticamentes

/Desistir
Caso o jogador nao ter mais changes de ganhar ou nao querer mais correr, ela poderб desistir.

• Salvamento

Include para Salvamento: DOF2
Criar a pasta "Corridas" dentro de sua pasta "scriptfiles" exatamente como postado para salvar todas as corridas construidas

• Configuraзгo

Sistema totalmente configuravel

Define o tamanho dos Checkpoints
pawn Code:
#define TAMANHO_CHECKPOINTS         8
Define o tempo para a contagem regressiva
pawn Code:
#define CONTAGEM_START              30
Define o maximo de Checkpoints que poderб ser colocado em cada corrida
pawn Code:
#define MAX_CHECKPOINTS             800
Define o maximo de Corridas que poderб ser construida
pawn Code:
#define MAX_CORRIDAS                500
Define o tempo permitido para a corrida
pawn Code:
#define MAX_CORRIDA_TEMPO           6000
