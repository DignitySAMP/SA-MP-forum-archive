Your previous SAMP chatlog gets overwritten when you join a new server - thats shit. So, I have made something that automatically copies them to a folder so they don't get overwritten.

That creates a new problem for any enthusiastic SAMP aficionado. Too many god damn chatlogs. How are you supposed to find the one you're looking for?
Wouldn't it be awesome If a bunch of info about that game session was stored with that chatlog. Stuff like how long you were online, what server you were on, what nickname you were using, what time you joined, what time you left.
Well, that is what this wonderful thing does. It also lets you view all your chatlogs in a nice organized window.
The program also leaves the chatlog contents completely untouched. It merely changes the name.

The chatlog viewer
Can be accessed by either choosing View logs in the right click menu of the tray icon or by double clicking on the tray icon.
Lets you sort your chatlogs by:
  • Time of backup
  • Server join time
  • Server leave time
  • Nickname
  • Playtime
  • Server IP
  • Server name
Installation/Setup
Download the executable.
Create a folder where you want the program to keep all its assets and store the chatlogs.
Place the executable in the aforementioned folder.
Run the executable.
Choose whether you want it to run on startup or not.
Choose the location of your chatlog.txt file - It dosen't matter if there is one there currently.
Woilah, Now your chatlogs should be backed up using wizardry.

Version 2 - Slight reliability improvements
It now automatically falls back to using command line commands "copy" and "del" incase it detects that AutoHotkeys FileCopy and FileDelete haven't worked.
