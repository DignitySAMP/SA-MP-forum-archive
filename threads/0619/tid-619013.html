Introduction:
This is simple c# program which converts textdraws to be used in tde / iPELOMAX textdraw editors.


How to use it?
click on choose file, choose kind to convert, TDE Editor / iPELOMAX Editor, then click on convert, you will be able to save the file to custom directory by clicking on save button...
