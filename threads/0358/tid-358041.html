Register/Login System [SIMPLE] (y_ini + whirlpool + zcmd) - with Antijetpack Hack Support!

Built and Script by Romel
NOTE: PLEASE USE THE LATEST VERSION OF SA-MP TO MAKE THIS SCRIPT WORK!

Introduction:

This script uses the fastest INI Writer which is y_ini.
It load/save the file fast, unlike dini, it save/load slow.
This script uses the string password hashing which is Whirlpool
It hashes password (string).

y_ini and whirlpool are made by ******.
so credits to him.

This script uses zcmd, which is the fastest (i think?) command processor.

zcmd is made by Zeex
so credits to him.

This script included Antijetpack Hack support!

The Antijetpack Hack is made by Romel (me)
so credits to me.

Credits to newbienoob for his Y_Ini + Whirlpool Tutorial!

Commands:

There is 4 commands which is:

/stats for Player (Showing their account status)
/ahelp for Admins Lvl 1 (Showing all available admin commands)
/jetpack for Admins Lvl 1 (Ability to have jetpack - 100% will not detect as Hack!)
/makemeadmin for Rcon Admins (Ability to make yourself admin lvl 5)

Its up to you to add many more commands like /kick /ban /admins etc...

How to Make yourself admin?

1.) Go to your server (the server must be open)
2.) type in game /rcon login [YourRCONPASS]
3.) type in game /makemeadmin
4.) Done!
