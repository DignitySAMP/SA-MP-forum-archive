The management system is the method RCON ....
To make actions on a player , press TAB and select the player you want ( logged RCON ) , there would
A dialog with several options appears .

To change server settings IG (name, restart etc. ) added a key ( which is in the file ) ...
With that key you can change the server name , map name , time, restart or shut down the server In Game ( / server )
( The key can be changed [ #define master_key 1234 ] )
