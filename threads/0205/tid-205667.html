This script is a heavy modification of Yagu's yrace. I take no credit for its full creation, but if you compare the two pieces of code, you'll see the work involved. It has been created over the last two years by myself. AFAIK, it is the most comprehensive race mod on SA-MP behind AdrenalineX, which is not public.

Credits go to:
Yagu - Base script
Betamaster - Vehicle names
Slick - SII
Draco - dini
Dabombber - Alar
And likely others!

A wiki of the fs can be found here: http://circlejerkserver.com/wiki/index.php?title=RacerX
This was created for my server, which ran the mod up until a month ago, hence release. The script is in an as-is form, and some features may not be fully completed (i.e. MTA style pickups which are coded and tested, but not polished).


The script allows for the change of many variables, from weather and virtual world to auto-repair and NOS.
Please note that gravity is all scripted in, but will not work unless you implement YSI to allow for player gravity.

It also has race building in game, with admins being able to create races, or admins able to temporarily give race making abilities to players.

You are able to search all races made by a player to find races. Races will auto-complete when you type part of their name.

A Config.iRf file exists in scriptfiles, and variables such as money won, join fee etc can be modified here.
iList.iRf is also here, which holds a list of race names that have been created, and these are the races that will be loaded. If you don't want a race to be loaded, just take it off the list.

Race objects can be added to a file, and that race should be named "RaceName.iRo", the 'o' being for object. RacerX will then load this file with the .iR race file.



Installation instructions:
Place 'iRaces' in your scriptfiles folder.
Place the .amx and .pwn in 'filterscripts'.
SII needs to be in 'pawno/includes' for compiling.

Alar (Admin script) is required to compile the stock code without warnings/errors, and provided is in the .zip. You may change the admin checks to rcon or your own admin system if you like with relative ease.


Download: http://www.sendspace.com/file/1undjm
