Quote:
Originally Posted by Potassium

If he hasn't logged into his old account for a long time then he's fine. If he still uses both accounts then he will be in trouble.
No - if I find that someone has multiple accounts I ban the later ones instantly.

Anyway, to answer the original question you need 10 infraction points to get banned. I did write a topic on this but never published it as I forgot. The current points and how long till the infraction expires are:
  • Posting in wrong forum, 2, 30 Days
  • Thread Bumping, 2, 30 Days
  • Inappropriate Language, 3, 30 Days
  • Signature Rule Violation, 3, 30 Days
  • Useless, unneeded or offtopic post, 3, 30 Days
  • Posting more than one server advertisement in a month, 4, 30 Days
  • Discussing cheat programs, 5, 30 Days
  • Inappropriate Post Content (Offensive/Adult/Other), 5, 60 Days
  • Insulted Other Member/Flaming/Trolling, 5, 60 Days
  • Spammed Advertisements (Existing member), 5, 30 Days
  • Trying to increase post count with 1 line posts, 5, 60 Days
  • Spammed Advertisements (New User or Bot), 10, 30 Days
Note that some of these are quite generic - I often give out "Useless, unneeded or offtopic post" when one of the three areas applies.

Most sub-forums have their own rules and they're not there for the fun of it. If you really want to get banned just start posting in an area without having read its rules first - ignorance is never an excuse.
