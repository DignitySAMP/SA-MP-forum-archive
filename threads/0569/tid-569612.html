This:
PHP Code:
gamemode1 ******** 
It should be:
PHP Code:
gamemode0 ******** 
Because the first gamemode is 0, not 1.

And:
PHP Code:
[08:40:10]    Error: Function not registered: 'mysql_init'

Make sure that you also have the CORRECT include of the MySQL plugin on your "Server/pawno/include" folder. The plugin and the include should be the same version to avoid problems (and if necessary, re-compile your gamemode too).

And lastly... I don't know why you put "********" as the gamemode file name, I will assume it is for privacy purposes, if it is not, then put the correct file name of your gamemode.
