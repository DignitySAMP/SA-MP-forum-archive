Hello out there! As this is my first thread it gonna be a tutorial about "PowerPC"'s trucking server. Pretty much i got the idea to make this because alot, of people dont know how to edit the name of the server. I know he made a tutorial with it, but anyway.. So lets get started, heres the first step:

How to edit servername:

[SIZE="4"]First, open up the folder and go to the pawn folder, and open up pawno. Now you see some icons up at the left corner. Click on the icon that look like a folder with a arrow that pointing OUT of the folder that you can see. Now find the location of the main folder, example: Desktop/PPCtrucking/gamemodes/PPCtrucking.pwn, and open that file up. You now should think "WHAT THA FACK IS THAT!?". Dont worry.. You just have to edit the name which is on the almost top of the script:

Code:
#define GameModeName				"Yournamehere"
How to edit player options:

This, is very easy. Open up the main folder and go to scriptfiles/serverdata/players and choose your name. Something like this should pop up:
Code:
Password ******** - Shows your password.
Level 0 - Edit to 5
Jailed 0 - How many times you've been jailed.
Wanted 0 - What your wanted lvl is on.
Bans 0 - How many times you've been banned. If this happen 5 times, you are permanent banned.
BanTime 0 - If you are banned, then how long time.
TruckerLicense 0 - If you got a trucker license. Set to 1 if you want 1.
BusLicense 0 - If you got a bus license. Set to 1 if you want 1.
Muted No - If you are muted.
RulesRead Yes - If you have read the rules. Set to yes, if you dont want questions about it.
StatsMetersDriven 9944.563476 - How much you've driven (In jobs).
StatsTruckerJobs 0 - How many Trucker jobs you have done.
StatsConvoyJobs 0 - How many Convoys you have done.
StatsBusDriverJobs 0 - How many Bus driver jobs you have done.
StatsPilotJobs 0 - How many Pilot jobs you have done.
StatsMafiaJobs 0 - How many Mafia jobs you have done.
StatsMafiaStolen 0 - How many Mafia-steal jobs you have done.
StatsPoliceFined 0 - How many players you have Fined
StatsPoliceJailed 0 - How many Players you have Jailed.
StatsAssistance 0 - How many Assistance jobs you have done.
StatsCourierJobs 0 - How many Courier jobs you have done.
StatsRoadworkerJobs 0 - How many Roadworker jobs you have done.
Money 999999999 - How much money you've got.
Score 5013 - How much score you got.
How to create houses and speedcameras.

This is fast to explain, so here it comes:
basically, you just have to go in front of a house, (you can choose where) and type this:
Code:
/createhouse <price> <maxlevel 1-10> - For houses.
/createcamera <maxspeed> - For cameras.


To delete houses and camera's just type in:
Code:
/delhouse or /delcamera


Have fun with your server!

If there was some thing you didnt understood then just PM me, or you can ask in reply'ies. I hope this was helpfull, and i know PPCtrucking have done a tutorial too, but this was just more explained i think. Ask for EVERYTHING you want, and im making this gamemode done with all houses done, so you should not use time to make the houses and cameras..
