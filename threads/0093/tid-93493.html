Valkyrie Military Base



Idea: Guedes747
Creator: Guedes747 & Dr4x
  • Mapping: Guedes747 (with a little help from Dr4x, to get it done quicker )
  • Scripting: Dr4x
Worktime: 48 hours
Objects count: 328
Location: Las venturas / Desert

Info: Well, at first it started as a simple idea that ive had on Dr4x's MTA server... we were both bored and decided to try map togheder on the new MTA 1.0 on his server. And then, we made this map, a military base with Airfield, Docks and a island along with a missile silo.

Hope you guys enjoy playing on it, as much as me and Dr4x enjoy building it!

Screens?
No

Video?
Yes, its here:


[ame]http://www.youtube.com/watch?v=lzEcEulaPA4[/ame]

Enjoy the HD

If you use the Filterscript along with this map, type /valkyrie and it will teleport you to the place ware the map is located.



(filter script and map are all inclued and also the object streamer((Use a streamer!)) we used, so incase don't want to change it, so you don't have to search arround for the streamer)

Updated to version 1.2
(You will now be helped on how to install with a readme file (basically, just to extract the folders on server directory)

What was changed?
  • Updated filterscript due to some gamemodes conflicts
  • Updated filterscript to unload objects when unloadfs is called
  • Removed test vehicles & auto spawn for players (it was in conflict with gamemodes of some ppl)
