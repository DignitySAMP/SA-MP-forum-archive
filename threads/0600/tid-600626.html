K Deathmatch System v1.0
This deathmatch script can be useful for freeroam/stunt/dm servers.To compile this script you will need k_INC library which you can get from here

And please +Rep me if you like this script

Features
Code:
Ping Labels
FPS Labels
3 Deathmatch Areas
Deathmatch Random Spawns
Hitsound On/Off
Headshot System
Kill Streak System
Deathmatch Join/Leave
Deathmatch selection from commands and dialogs both
Commands
Code:
/ddm - Join deagle deathmatch
/sdm - Join sniper deathmatch (Headshot system included)
/sos - Join sawn-off shotgun
/hitsound - Toggle hitsound on/off
Credits
Code:
<a_samp>
<foreach>
<zcmd>
<k_functions>
