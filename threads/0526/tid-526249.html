This idea would never work:

- The SA-MP team would have to inspect every server and check if the server owner has a "roleplay" license. How could the owner prove that they own a roleplay license? They could be lying about it.

- Not everyone has $200 to spare for a "roleplay license". SA-MP is a free mod, and if anyone wants to own a server then they shouldn't have to pay for it.

- This idea would be detrimental to potential roleplay servers, especially those that have great scripts which are still being developed.

If you don't like RP servers, don't play them. SA-MP is not all about roleplay; there are many servers out there that are not roleplay.
