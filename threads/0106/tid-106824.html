Hi guys, I've heard alot of people have had trouble getting they're server online (like me) so, I've made a tutorial

ok, first you have to make your server. Open notepad click on "open" then click on the bottom right to allow all files to be seen so you can access server.cfg when you find it, click on it

Then you come up with this:

echo Executing Server Config...
lanmode 0
rcon_password
maxplayers
port 7777
hostname
gamemode0 grandlarc 1
filterscripts base gl_actions gl_property gl_realtime
announce 0
query 1
weburl
maxnpc 10
onfoot_rate 40
incar_rate 40
weapon_rate 40
stream_distance 300.0
stream_rate 1000

From here, where it says announce 0 change it to announce 1 and add your gamemode (lvdm1 for example) Max players for the biggets amount of players who can play on your server, host name for the server name (eg. Blackblood's server) and web url (if you dont have a website, just use www.sa-mp.com) Save it, then open sa-mp. Add this in add server in your favourites: :7777 (Whatever port you used) Now your server should be public. You might have to wait for a security warning asking you to allow connection or whatever. Thanks for reading

Wait. So I entered :7777, does that mean it's in the internet tab?
No if your announce line is set to 1 it will be in the internet tab. And port 7777 is the port which you allow clients to connect to you. You can choose to open any ports from your router than 7777, But the port has to be set to UDP for sa-mp players to connect, you can set it to both if you like to UDP & TCP or whatever.
