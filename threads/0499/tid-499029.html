Features:


First Money : 500.000$ For buying a car from dealer for racer and drifter
Language : But sorry for the language , because the language is indonesia if you ask why indonesia , because it created from scratch and btw there's english language too , you can translate it on www.******.com on ****** translate hahahahah
Houses: Fully functioning dynamic houses with 10 different levels and interiors. ( PPC_Housing )
Vehicles Dealership: You can add dealership , fuelstation , and the vehicle is static ( If you logout the vehicle not gone )
Teleport : There's Race Map , And Drift Map ( /teleport )
Killing Spree : its killing spree features , its NFS with TDM and DM system , you can teamingup with /setteam and teamchat with /tc
Banking : you can store your money to the bank for avoid robber
Class : There's two class , drifter and racer but you can be a Police / COP by admin set /makecop
Faction : LSPD ( For Pursuit With Drifter and Racer )
Doors: Fully functioning dynamic doors.
Robbery : you can rob alhambra , city hall , bank and more
Event : there's event race and auto event race you can use it by admin set
Duel : you can duel with your friend 1 vs 1 with car like NFS if you lead the race your enemy must follow you , if your enemy lead the race you must follow your enemy ( /duel )
Anti Cheat : there's anti moneyhack with my method but there's no anti weapon hack , sorry :3
Gates: Fully functioning dynamic gates using 0.3e objects editor.
Toys: Fully functioning toys using 0.3e objects editor. (Credits to SA-MP )
Vehicle Toys: /vattach Fully functioning vehicle toys using (Credits to iVO And me for edit it and fix bad object)
Admin System: 5 Different levels Helper - Security - Police - Army - President
Drift system : you can got money from drift system Luby and Abhinav
Level System : there's level system if you kill someone you will get exp
Mode System : There's 3 Mode Drift Mode / TDM DM Mode / Netral Mode
On drift mode he will have infinite health and cant robbing and holding weapon
On TDM DM mode he can holding weapon , killing someone and robbing
On Netral Mode he can drift holding weapon , killing , robbing ( 2 Mode )
VIP System: 1 Different levels with different features you can add more levels because you have got the basic script.
You can find the features more from download it , i can explain all
