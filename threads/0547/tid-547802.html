Hey guys i made this filterscript more than 6 months ago for a popular server, and now the server is offline i have had time to update it. before you used to have to use /music to beable to see the list and it would play while not in vehicle (Due to requests in the quiet gamemode).

Now i have set it so when your in a vehicle you only need to press 'N' and it will show all the radio stations which is is easier to access while driving.

Features
  • 12 Radio Stations
  • Radio turns off when exiting the vehicle
  • Passenger can hear the radio
Radio Stations
  • Dubstep FM
  • Capital FM
  • Pulse Radio
  • Radio Klass Romania
  • Its a Trap Radio
  • Russian Hits Radio
  • Madein Hits Radio
  • Absolute Hits Radio (France)
  • DnB Pirate Radio
  • I Love To Dance Radio
  • Electronic Playground Radio
  • Radio Gothic
Its quite a simple script and should be easy to add more stations

Download:
Here (Solidfiles.com)

Note: No bugs found, if you find any pm me and i will fix them.

Suggest if you think other things need adding.
