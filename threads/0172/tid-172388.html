Open a command prompt window (Start -> All Programs -> Accessories -> Command Prompt) and type in "ipconfig". It will list a bunch of junk, but you need to find where it says "IPv4 Address", the number that follows should be your computers local IP address. When trying to connect to your server with your networked computers, use that address. If you haven't done so already, you need to open the port 7777, which is the SA-MP server default. (unless you changed it) I might be able to help do that through TeamViewer later on today.
