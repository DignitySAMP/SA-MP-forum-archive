28.06.2008, 18:52
1# I can\'t see vehicle names
Where do you mean?In the Spawnmenu?

2# I can\'t see SpeedOMeter
Are you sure you have activated it?
If not,generalconfig.cfg DisplayMode=? (0=off/1=SpeedOMeter/2=AreaName/3=SpeedOMeter+Areaname)
Although you can only see it in a vehicle,not while you are on foot.

3# I can\'t see area names
Same as for 2#

4# I can\'t see vip (*) and admin (# /a) chat
Are you sure you are adminlevel 2 or higher/vip and use it right?If so,could you please check
if anything is written into gAdmin Log/adminlog.txt or gAdmin Log/viplog.txt ?
*[TEXT] = Vip Chat
#[TEXT] or /a [TEXT] = AdmimChat


5# If I try to put bounty on someone with /hitman id amount - then only my "character" will go to animation /hide
There is no /hide in gAdmin,I have no clue.

6# I changed english.inc little bit, but it wont change ingame.
I dont know,but that\'s a problem on your side I guess.

7# If i use /setscore amount - it wont change.

I think you have ScoreUpdate active.
If ScoreUpdate is active(1=On) it doesn\'t work,because it will set score to the amount of money after a few seconds .
The score you set with /setscore will be "overwritten" pretty fast.

And question: is there a way that others cant see everything admin does (like teleporting etc).
There\'s an option to show only other admins the message,
generalconfig.cfg ShowAdminCommand=0

Actually you could read most thinks up in the readme,or generalconfig.txt (info file to generalconfig) .
