Originally Posted by Arthur Kane

Not talking about microphone quality.
This. The guy is asking which is better as a communication platform.

Both have pros and cons. Most of what's written below is taken from another forum. I was lazy to write everything, but I did add my own notes.

Discord advantages
1. Easy to manage.
2. Easy setup
3. Bot extension
4. Easy rank setup
5. Free of charge
6. APIs good for MC Servers rank syncing,
7. Nice Audio quality
8. Beautiful GUI

Discord disadvantages
1. No root access
2. Less extension
3. Audio quality.
4. Buggy/glitchy in-game overlay.
TS advantages
1. Easy to customize
2. Audio Quality
3. Almost no connection problems (If yes it is server misconfiguration)
4. Permission-managment is great
5. Good in-game overlay.

TS disadvantages
1. Ugly GUI
2. It is a pain in setting up
3. You have to own a dedicated server or a VPS or a TS Host for your TS server, it costs money.

I used both of them and so far, for new communities, I can say Discord is the better choice.
It's easy to set everything up, and it has social features that are useful.

However, if you want the pro way and you have the budget, I suggest Teamspeak.
It may be a bitch to set up, but it's more flexible than Discord, and it's made to get you the best voice chat experience.
