Windows:
1. Go to samp server folder and open a command prompt window (press shift+right click)
2. Type:
Code:
set AMX_PATH=path\to\amx
3. Type:
Code:
samp-server
Linux:
1. Go to samp server folder and open a shell there
2. Type:
Code:
export AMX_PATH=path/to/amx
3. Type:
Code:
./samp03svr
