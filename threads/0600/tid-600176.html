Well fixing a connection issue is quite hard if you don't happen to be your own internet provider.
Check your connection data (upload/download speed) and if they are lower then they're supposed to be, contact your provider, they should be able to fix it then. If they aren't slower than they should be, it'll be hard.
You could try running the server on another host.
I'd suggest to not replace it completely, but set up a secondary on another host and check if this solves the issue. if so, then you can move your server to a new host.
If it really is a connection issue, it'll be hard to resolve though.
