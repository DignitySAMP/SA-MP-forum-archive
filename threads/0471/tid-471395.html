Creating a file pawn.cfg into pawno directory/folder and writing in it:
pawn Code:
-d3
makes it to be compiled with debug mode. Compiling VWRP.pwn now will give extra information (if it does, then that means the file is ok. Otherwise, you've made a mistake (probably wrong extension or directory)).

So.. if the server crashes again, then it might give the line the crash was caused. If it still prints nothing else than the previous time show us OnGameModeInit callback.
