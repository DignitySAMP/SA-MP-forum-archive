Checkpoint Creator


Author's Comments

After 1 week i've managed to release this FilterScript, wich allows you to Create Checkpoints In Game + Saving Them in a .txt file.

FilterScript Features

- Checkpoint Creator ( Dot & Race )
- Able to create in game
- Only logged Rcon can use it
- Much More...

FilterScript Usage & Installation

Just download the .rar file, extract the files in your filterscript folder, and add ' CGenerator ' in server.cfg at filterscripts.

Its pretty simple to use, just go in game, loggin as Rcon, type /createcheckpoints.You will have some steps right there. Important: Sometimes, when you press enter, to go on the other step, it may go fast. Just be sure that you made those steps:

Dot Checkpoint Steps: 1. Possition. 2.Size. 3.File Name.

Race Checkpoint Steps: 1.Type of Checkpoint. 2.Possition. 3.Next Checkpoint Possition. 4.Size. 5. File Name.

For changing the possition or size, you just need to use the arrows ( up & down ).
