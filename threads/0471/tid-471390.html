DomAdmin System
Hi guyz this is my 3rd Filterscript .it take me to much time to make more than 4 weeks .
I hope you Guyz Like it


It Consist of 5 Admins Levels
  1. Moderator
  2. Training Admin
  3. Administrator
  4. Senior Admin [Server Co-Owner]
  5. Server Owner

Higher Admin can use Lower Admins Cmds.

How to use It?
Just Add Filterscript Files in your Filterscript file
and Put DomAdmin Foldier in your ScriptFiles
Then Add Filterscript name in your Server CFG
And Then Login In game With Rcon login pass
Then Do /setlevel Now you are Server Owner
For admin Menu use /dacmds
For Player menu use /pcmds
