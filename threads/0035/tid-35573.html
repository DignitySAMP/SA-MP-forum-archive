[FS]Simple Cashbox Mini-Game [V2]

What is it:

This filterscript contains a minigame called 'Cashbox'
It's like the one in PenLS, but i have never played PenLS so i don't know exactly how that one works so i created my own version.
The game is not very extensive but its fun to play with a large group of players.


Gameplay:

Once in a while (default: 3 minutes) a new game will start.
A random place will be chosen somewhere in San Andreas, a pickup: 'cashbox' (default model is a briefcase) will be spawned on that position.
_________________________________________________
Difficullty mode 1:
A checkpoint will appear on the map at the location of the checkpoint
_________________________________________________
Difficulty mode 2:
All player-camera's will be centered on the location for 10 seconds. Then they have to recognize the location of the cashbox
_________________________________________________
The server will give the cashbox a random value.
The objective for all players is to get there first and pickup the cashbox, when a player has picked up the cashbox, a checkpoint will appear on the radar (default drop-location = Las Venturas Airport).
If the player reaches that drop-location, he/she will earn the value of the cashbox.

If the player who holds the cashbox dies or leaves the server before reaching the drop-location, he/she will lose the cashbox and a new pickup will get created on the place where he/she died or left the server.

During the game, the value of the cashbox will drop every second a certain amount of dollars.

If the cashbox is delivered at the drop-location, a new game will start in (default) 3 minutes.


Configuration:

You can change:
  • The modelID of the cashbox-pickup
  • The minimum value of the cashbox
  • The maximum value of the cashbox
  • The droplocation
  • If you want to show a textdraw (showing current value of the cashbox) yes or no
  • How many dollars the value of the cashbox drop every second
I added 65 cashbox-locations, you can add or remove as many as you want.
