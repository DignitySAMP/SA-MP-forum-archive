TUTORIAL:
Upload the .rar file, extract it
open the file, re-compile,
if you're using linux
change the plugins with .so

Code:

make sure you have the scriptfiles which I have given
run the samp-server.exe
enjoy the server

HOW TO MAKE YOURSELF TO BE ADMIN:
go register/login
type /rcon login [yourrconpass]
type /makeadmin yourid thelevel
