pawn Code:
if (!(0 <= level <= 4)) return SendClientMessage(playerid,0x3740B3,"Admin level must be between 0 and 4");

if (level < 0 || level > 4) return SendClientMessage(playerid,0x3740B3,"Admin level must be between 0 and 4");
