Installation Guide:

1. Copy the reallifeXX.amx file to your gamemodes-directory.
2. Create the directory "scriptfiles".
3. Create the directory "userdb" in the "scriptfiles" directory
4. Create in the "userdb" directory a file named "YOUR_WISHED_USERNAME.pwd".
5. Put your wished password in this file.
6. Make sure that "scriptfiles" is writable (CHMOD 0777)
7. Add following lines to your server.cfg: gamemode0 reallifeXX 1
Note: Replace "0" to the next number, and XX to the downloaded version number.
8. Start gamemode using rcon: /rcon changemode reallifeXX.
9. Create an account with /register
10. Login as admin: /alogin <username> <password>
11. See /admin for admin commands.
12. Have fun.
