Hello guys,
I saw that all newbies ask everything about how to make a server so I decided to create this tutorial.It is very easy to create a server but you need to have a good GM scripted!

First of all, you should follow 7 steps to create your own server.
Let's start!

1)Open your ****** Chrome/Opera/Firefox/Explorer (etc) and go to www.sa-mp.com .

2)Go to download and download the "SA-MP 0.3x Windows Server".

3)Create a new folder and then put all files which you downloaded there.

4)Then open the "server.cfg" to set up your server (Set up max players , the Host Name etc).

5)After some edits open again your ****** Chrome/Opera/Firefox/Explorer (etc) and then go here to open a port (I can explain you how to create a port so learn it from *******).

6)After that go to server's folder and open the ''samp-server.exe''

7)You server is ready and now you need to know your ip (www.whatismyip.com). Add your ip to favourites (samp) and you are ready to play


DON'T FORGET! YOU NEED A GameMode TO PLAY IN YOUR SERVER AND YOU CAN FIND ONE
HERE.
I hope to help you
