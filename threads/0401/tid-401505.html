Roleplay basemode [YINI]
- Information

I am releasing this small gamemode because it's no longer useful to me. I started it with the intention to create a roleplay script to be used for a community. Since I am no longer part of that project, I am releasing this script to the public. I want to release this script to be used as a base mode for others, use it as you feel.

- What's scripted?

Saving system (YINI, Login and Register Dialog logs)
House system (Started, /createhouse)
Added some textures
Last login dates when logged in.
Spawns at last coordinates when logged in.

- Commands:

/me
/pm
/b

- Admin commands:

/setadmin
/kick
/goto
/get
/jetpack
/removejetpack
/explode
/spawnls
/createhouse

- Plugin and Includes needed

1) YINI - Include
2) zcmd - Include
3) sscanf - Plugin/Include
4) Whirlpool - Plugin
