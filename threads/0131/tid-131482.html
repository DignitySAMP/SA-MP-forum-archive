Real Stunt City Release
Hello, I decided to release my Gamemode. But first I wanna say its not all by me. Almost everything is made by other persons from this forum. But I pasted everything in one. I rescripted everything twice. But still it had a high CPU.
So I had to run another server from the host owner. So now I'm scripting a Roleplay. So I don't need this gamemode anymore. I think I did a half year on this. But its my first on. It almost doesn't have any bugs. Its only a bit laggy. But you can fix that I gues. I was to lazy to rescript it again or find the cause. I didn't made credits. But I just release this because I don't want that it will get lost.
Features:

- Ladmin
- JunkBuster
- Teleports aren't in anymore.
- Perfect Car system. /car comand popups a menu. When you spawn your second car your first on will get deleted.
- Dynamic House/car system from GF.
- Dynamic Faction system.
- Deathmatch zone. 100% by me.
- Perfect /cmd menu.
- Hopboost(2) and Speedboost(H)
- Perfect /stats system with Kill level system. Also by myself. I counts the kills for each weapon you got in the dm zone.
- I also planned to make jobs But I only could finnish the arms job. You have to drive with a trucker and trailer.
- There are a few maps.

Its doesn't have any filterscripts but the /rcon gmx fuctions is bugged!
It had YSI object streamer but I couldn't release that one. So I added Double-O-Objects
I didn't change anything for this release. So you have to change the webiste-owner name and shit by yourself.
There may are somethings that are not 100% finished. Not sure witch. You will see find fast.
I hope you guys have fun with it.

Well I never heard any bad commands on this gamemode by people who playing it. And there were alot.
So I hope you guys can use it.
