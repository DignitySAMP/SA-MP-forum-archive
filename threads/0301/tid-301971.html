iColor
Buenas, hoy les traigo mi primer plugin para SA-MP, que sirve para ponerle colores a la consola de Windows. Disculpen si es solo una funciуn es mi primer plugin xD

Esta es la funciуn nativa:

pawn Code:
native CambiarColorConsola(colorid); // Esta funciуn funciona para poner la consola de un color, y todo los print y printf saldrбn de ese color.
Estos son los ID de color que acepta:

pawn Code:
/*
    IDs de Color:
    0 = Negro (No muy bien legible)
    1 = Blanco
    2 = Rojo
    3 = Verde
    4 = Azul
    5 = Amarillo
    6 = Azul claro
    7 = Fucsia
    8 = SA-MP por defecto
*/
Ejemplo de uso:

pawn Code:
public OnPlayerConnect(playerid)
{
    new nombre[MAX_PLAYER_NAME], string[64];
    GetPlayerName(playerid,nombre,MAX_PLAYER_NAME);
    
    CambiarColorConsola(5); // Cambio el color a Amarillo y saldrб amarillo el print
    printf("%s entrу al servidor.",nombre); // El print (saldrб de color amarillo)
    CambiarColorConsola(8); // Aquн ponemos el color normal o podrнan ponerse amarillo todo lo que salga en la consola en el futuro
    return 1;
}
La descarga incluye iColor.dll que es el plugin, iColor.inc que es el include que contiene la funciуn, si no la quieren poner pueden poner native CambiarColorConsola(colorid); arriba de tu gamemode / filterscript.
