Dynamic Door System 1.0
Introduction

Hello I dicided to create this simple and useful FS. If you ask me why I used SII I will answear that I want to test my skills I never worked with SII. So I saw that it's similar with YSI - y_ini include. Sorry for bad english

Pictures

http://i.imgur.com/KfF6Naf.png

Commands

  1. /createdoor [name] - create a door
  2. /editdoor [id] [name] [amount] - exterior, interior, pickup, delete
  3. /doorname [id] [name] - change door name


How to install

First you need to move DoorSys.amx file to your filterscript folder then open scriptfiles and create folder called Doors after open your server.cfg and add DoorSys to Filterscripts line.
