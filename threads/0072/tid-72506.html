Euro - AFK System
By: Epsilon

Script Infos:

Code:
- This script check the players for AFK.
- If the player AFK or do not playing the script puts him/her to AFK Mode
- If someone write: /afk he will be in AFK Mode.
- The /listafk command list the players who in AFK Mode
- If the player use chat or commands in afk mode he/she will be leave AFK mode.
- If the player in AFK Mode he can't see other players and he won't meet with them ( other Virtual World )
- If Someone in AFK Mode he can't move.
- In AFK mode we will see a cool blinking gametext
- If you are in AFK mode you will get the [AFK]_ tag
- If player in AFK Mode the server will freeze him/her any 2 seconds
- After connect the system wait 20second to start for the joined player.
- When a player leave AFK Mode the server will dont check him for 20 seconds.
