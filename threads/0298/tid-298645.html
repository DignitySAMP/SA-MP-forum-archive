Scripter Helper Script 2.0



First of all a nice song : click here .

Now before we even start this (page[?])... I want you to know , this script will NOT work with 0.3D

What is this script using ?

Quote:
sscanf2 - by ******

file - by SA-MP
What can I do with this script ?

Quote:
Well, I saw many systems witch you can create 3d text labels , map icons, and more with them .
But the labels and map icons doesnt get saved !
You have to turn off your server, go to the system's(fs) log, copy the line and add it to your script !
Now, here you can create map icons and 3d text labels ( dynamic ) IG,without turning off your server !
Another very good thing in this FS , is that you can create doors IG !
What do I mean doors ?
I mean , that insted of turning you server off every time , going to your script, adding map icons , pickupd and 3d text labels , and command like /enter /exit , you can DO IT IN GAME !
What is extra special here ? that you can make COSTUM INTERIORS !
Now, lets say you create a door , and it ID is ... 5 .. so the doors interior Virtual world will be 1005 ( 1000 + ID ).
Now , if you want to make it costum :
lets say the interior of this door will be the gym..
So when you add the objects , make sure you set them to the door id + 1000 ( 1005 in this case )..
Now the player will see them only if his VW is 1005 !
COSTUM !
COMMANDS

Basic
Quote:

/shslogin - before using any commands ( but /enter and /exit ) you must login to the system .
/cv - create a vehicle [modelid] [color1] [color2]
/dv - enter a vehicle , use this and destroy it .
/dvs - destroy all created vehicles .
/mpos - save your position with interior and virtual world , and the position will go to the file in scriptfiles/logs/mpos.txt [savename]
Dynamic Map Icons
Quote:
/dmp Edit the dynamic map icon [name] [dmpID] [(optional)value]
Available names : [NON _ CASE SENSITIVE] Position, Model, Color, VirtualWorld, Interior, Delete
/dmpnext - next DMP ID Available
/dmpclose - list nearest dmps
Dynamic 3D Text Labels
Quote:
/3dlabel - edit the dynamic 3d text label [name] [labelID] [(optional)value]
Available names : [NON _ CASE SENSITIVE] Position, Color, VirtualWorld, Interior, Distance, Delete
/3dnext - next 3dtextlabel ID available
/3dtext - set 3d label's text
/3dclose - get nearest 3d text label ID
Dynamic doors
Quote:
/door - edit a door
Available names : [NON _ CASE SENSITIVE] Exterior, Color, Interior, Delete, Lock, PickupType, Level, VehicleAble, Admin
level = if you level is smaller then the door's level , you will not be able to enter. so with the admin thing.
vehicle able - decide if you can enter with vehicles or not.
/dnext - next door ID available
/dname - set door's name
/dgoto - goto specific door
Expected Bugs

Server crash when using a command :
ITS NOT THE SCRIPT'S BUG !
You must have the folders /scriptfiles/logs and /scriptfiles/cfgs !!

Commands doesnt work :
This script will be very bugged with 0.3D
