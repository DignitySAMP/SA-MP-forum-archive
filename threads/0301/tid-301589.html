Чтобы не спрашивали, чем занимается разработчик был предоставлен список обновлений.

Последние обновления:
- Выполнен переход с 0.3c на 0.3d.
- Выполнена оптимизация кода и функций 0.3d.
- Убраны зоны у мафий Yakuza, Russian Mafia, NGM и т.п.
- Убраны лишние Include.
- Убраны линки на наш сайт в /help.
- Убран диалог при посадке в транспорт.
- Убран старый АнтиЧит JunkBuster.
- Убран диалог из команды /dev.
- Добавлена команда /donate с информацией о пожертвованиях.
- Добавлена команда /update с информацией о обновлениях.
- Добавлено "Онлайн Радио" в диалоге по команде /radios.
- Добавлены Include из 0.3d.
- Добавлены несколько автомобилей в городе Las Venturas.
- Добавлены функции управления транспортом при посадке.
- Добавлен АнтиЧит ArmastGuard на основе JunkBuster.
- Исправлены проблемы со входом в нескольких домах.
- Исправлена опечатка мафии Yakuza была Yakudza.
- Данные в scriptfiles расположены по новым папкам.
