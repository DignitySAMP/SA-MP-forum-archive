Free for all
Simple, fun, script for events/practice




Features


All skins (EXCEPT A FEW) can be selected
Ability to change personal skin without proceeding to class selection
Ability to change a personal text label (On the top of your player)
Kill spree system (Counting upto 100 kills)
Stable weather which changes every 15-30 minutes
Stable time which is updated for everyone (Server-sided)
Weapon info textdraws
Leaderboard which shows players with top 3 (MAP) kills and your own (i.e the players own) (map) kills
Profile fields : Kills, Deaths, Map Kills, Session Kills, Kill spree, Skin (Skin with a name too)
Commands for - Links (Forums,groups etc.) , Viewing stats
Random (Troll) pickups at different spots on the map
Map fields - Map city, Author, Pickups (Enabled/Disabled)
Random spawns (Min. 15 ) per map
Random Messages (Help messages)
Map Objects loaded from .txt files
Added weapon kills for each player
Added weapon kills stats
Added personalize menu/dialog
Added health and armour textdraws



Maps section

If you want to add any maps, You can PM me on forums OR contact me via skype and I'll add them for you. DO NOT try to mess with the map system, it's pretty delicate, Things CAN get fucked up even in the minorest *fuck* of yours, so just try to stay outta the map system.



Download link and other information


There's NO saving or admin system on this thing and I added some debugging commands in the past and I haven't removed them.

Includes -
Top 3 (https://forum.sa-mp.com/showthread.php?tid=361560)
Sscanf (PLUGIN +INCLUDE) by ****** a.k.a Alex Cole
ZCMD by ZeeX


Download link - http://www.mediafire.com/download.php?r698h65uxyumxtr



NOTE - This gamemode is barely tested with more than 1 players, if you find any bugs, Please post 'em asap, I'll be fixing bugs for the next 2-3 months, after that, you'll have to do 'em by yourself
