If the file check doesn't work then the best you can do is a fresh install. I had a PC with a similar problem in the shop last week with random blue screens and the sfc unable to repair. In the end I reinstalled that one too.

What you might try still is booting from the OS DVD. If you don't have one then you can download an ISO copy (legally, since it still requires a key to activate) somewhere on DigitalRiver (Microsoft's software distribution platform). Use Microsoft's USB preparation tool or just burn the image to a DVD.

Boot from the USB/DVD. At the welcome screen select language and keyboard settings. Click Next. DON'T CLICK 'Install Now'! In the left bottom corner there should be an option "Repair My PC" or something along those lines. If I remember correctly there should be an option to automatically detect problems.
