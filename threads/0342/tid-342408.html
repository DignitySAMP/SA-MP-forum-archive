PHP Code:
public OnPlayerUpdate(playerid)
{
        new Float:vPos[3];
    GetVehiclePos(GetPlayerVehicleID(playerid),vPos[0],vPos[1],vPos[2]);
    SetVehiclePos(GetPlayerVehicleID(playerid),vPos[0],vPos[1],vPos[2]+0.01);
return true;
} 
Проверки ставь какие нужно и все, транспорт будет (будь то самолет) висеть в воздухе неподвижно.
