Description:
This system Anti Weapon Cheat controls the weapons that have not been septate through the function of the system. If the weapon was taken with a cheat / cleo / hack or command (which does not give the weapons with the function of this included), the player will be banned. Melee weapons, brass knuckles, dildo, parachute, have not been taken into account by this Weapon Anti Cheat.

Functions:
  • GivePlayerWeaponAC(playerid, weaponid, ammo); //It would be enough to replace only "GivePlayerWeapon" with "GivePlayerWeaponAC".
  • The checkrate are setted on 2,5 seconds
  • If you are admin RCon or you are a victim of the ban of the Anti Cheat, text will appear in chat "[AWC] Weapon Cheat finded. Nick: Name (ID:% d) | Weapon: Name (ID: Value | Slot: Value) | ammo: value"
  • When a player is banned by anti cheat, the server sends a message to all players connected "Name (ID: Value) Has Been banned || Reason: Weapon Cheat"
How to install:

Put the include in "YourServer/pawno/include"

In top of the GM:
pawn Code:
#include <AWC>
In OnPlayerDisconnect(playerid, reason);
pawn Code:
DarK_OnPlayerDisconnect(playerid, reason);
In OnPlayerSpawn(playerid);
pawn Code:
DarK_OnPlayerSpawn(playerid);
In OnPlayerDeath(playerid, killerid, reason);
pawn Code:
DarK_OnPlayerDeath(playerid, killerid, reason);
