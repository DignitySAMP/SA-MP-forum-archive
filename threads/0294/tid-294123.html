K - Loading Screen

Info:

This small FilterScript created by me, makes sure that when the player spawns as appears in the Gta San Andreas game screen with the texture and with a loading bar (thanks to the PCaricamento by Phanto). Currently only 1 start in the next, and Texture versions will try to start more of a texture.
Current version: 1.0
