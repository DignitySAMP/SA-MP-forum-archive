All of them failed. Open server.cfg and change from the line:
pawn Code:
rcon_password changeme
the changeme to your desired password.

Also is the server for Linux or Windows? If Linux, upload all the .so plugin files* and add plugin_name.so in the plugins line (server.cfg). Else if Windows, upload all the .dll plugin files* and add plugin_name in the plugins line without the extension.

* By uploading, I mean to paste the file into plugins folder.

You need to update not only the plugin files but their includes too. So update streamer.inc sscanf2.inc audio.inc to their latest version as well. They can be found from the .rar file you got the .dll or .so files.

About the runtime error, it may be caused because of the old version of the streamer (include) or maybe you miss another plugin(s). Load nativechecker plugin and add it last in the server.cfg (plugins line).

Re-compile your scripts (after getting the updated includes) and run the server.
