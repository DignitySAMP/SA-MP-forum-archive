IIRC (and its been a long while)...you need to make sure both x86 and x64 versions of glibc are installed. Also try disabling SELINUX.

If all else fails, start a blank server w/ default gamemode, no plugins or filterscripts. Add plugins one-by-one, start the server each time and let it run for 5-10 minutes and see if it tanks. If it starts crashing as you're re-adding plugins...start looking at the most recently added plugin.
